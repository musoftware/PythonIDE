# الدرس 4: تخطيطات منطقة العمل: Visual Studio و VS Code و Agent

**في هذا الدرس ستتعلم:**

- التخطيطات الثلاثة للبيئة، ومتى يناسبك كل واحد.
- التبديل بينها من المفتاح في زاوية شريط القوائم، أو من **View > Layout**، أو بـ `Ctrl+K Ctrl+L`.
- شريط النشاط (Activity Bar)، والشريط الجانبي (Side Bar)، واللوحة السفلية (Panel)، ووضع التركيز (Zen).
- ترتيب النوافذ المثبّتة، وتقسيم المحرر، والتنقل بلوحة المفاتيح بـ `F6`.

## غرفة واحدة بثلاثة ترتيبات

تخيّل غرفة معيشة تستطيع ترتيب أثاثها بثلاث طرق: ترتيب للضيوف، وترتيب للمذاكرة، وترتيب لمشاهدة مباراة.
الأثاث نفسه لم يتغير، فقط مكانه. كذلك التخطيطات في RAD IDE: **النوافذ نفسها** (مستكشف الحلول، والمخرجات، و Git ...) تنتقل وتظهر وتختفي، ولا يتكرر شيء.

| التخطيط | يشبه | مناسب لـ |
|---|---|---|
| **Visual Studio** | Visual Basic 2005 و Visual Studio | تصميم النماذج بالسحب والإفلات: قوائم كاملة، وأشرطة أدوات، ونوافذ مثبّتة حول المصمم |
| **VS Code** | محرر VS Code | كتابة الكود والمواقع: شريط نشاط على الجانب، وشريط جانبي واحد، ولوحة سفلية، وشريط حالة أزرق |
| **Agent** | بيئات الذكاء الاصطناعي الحديثة | العمل مع وكلاء الذكاء الاصطناعي: **مدير الوكلاء** (Agent Manager) في الوسط والمحرر على اليمين |

## كيف أبدّل بينها؟

ثلاث طرق، اختر أسهلها لك:

1. **المفتاح في زاوية شريط القوائم** (أعلى اليمين): ثلاثة أزرار صغيرة **VS | Code | Agent**. انقر أحدها.
2. القائمة: **View > Layout** (عرض > التخطيط) ثم **Visual Studio** أو **VS Code** أو **Agent** (الوكيل).
3. لوحة المفاتيح: `Ctrl+K` ثم `Ctrl+L` (**Next Layout**: التخطيط التالي) يدور على الثلاثة.

ويمكنك اختيار التخطيط الافتراضي من **Tools > Options... > Environment** > **Workbench layout:** (تخطيط منطقة العمل:).

> 💡 **كل تخطيط يتذكر ترتيبك:** إذا كبّرت المخرجات في تخطيط VS Code ثم انتقلت إلى Visual Studio وعدت، ستجد VS Code كما تركته، حتى حجم النافذة.

## تخطيط VS Code بالتفصيل

### شريط النشاط (Activity Bar)

عمود أيقونات على حافة النافذة. كل أيقونة تفتح "عرضًا" في الشريط الجانبي:

| الأيقونة | الاسم | الاسم العربي | ماذا تعرض؟ |
|---|---|---|---|
| ملفات | Explorer | المستكشف | مستكشف الحلول |
| عدسة | Search | بحث | البحث في الملفات (`Ctrl+Shift+F`) |
| فروع | Source Control | التحكم في المصدر | Git |
| تشغيل | Run and Debug | التشغيل وتصحيح الأخطاء | المتغيرات، والمراقبة، ومكدس الاستدعاءات |
| صناديق | Packages | الحزم | مدير الحزم |
| أسطوانة | Databases | قواعد البيانات | مساحة قواعد البيانات |
| فقاعة | AI Chat | محادثة الذكاء الاصطناعي | المحادثة |
| كتاب | Tutorials | الدروس | هذه الدروس |
| ترس | Manage | إدارة | لوحة الأوامر، والخيارات، والسمة، والتخطيط |

انقر الأيقونة مرة لفتح عرضها، وانقرها مرة ثانية لإخفاء الشريط الجانبي.

### اختصارات الإظهار والإخفاء

| الأمر | القائمة | الاختصار |
|---|---|---|
| إظهار/إخفاء الشريط الجانبي | **View > Layout > Toggle Side Bar** | `Ctrl+B` |
| إظهار/إخفاء اللوحة السفلية (المخرجات، والطرفية ...) | **View > Layout > Toggle Panel** | `Ctrl+J` |
| وضع التركيز: المحرر وحده بملء الشاشة | **View > Layout > Zen Mode** (وضع التركيز) | `Ctrl+K` ثم `Z` |
| إعادة ترتيب التخطيط الحالي إلى أصله | **View > Layout > Reset Current Layout** (إعادة ضبط التخطيط الحالي) | — |

للخروج من وضع التركيز اضغط `Esc` مرتين بسرعة، أو الاختصار نفسه `Ctrl+K Z`.

## تخطيط Agent

في هذا التخطيط يصبح **مدير الوكلاء** (Agent Manager، `Ctrl+Alt+M`) السطح الرئيسي: تكتب مهمة مثل "أضف زر حفظ للنموذج" فيعمل عليها وكيل ذكاء اصطناعي، وترى التغييرات في المحرر على اليمين لتقبلها أو ترفضها.
تفتح مهمة جديدة من **View > New Agent Task...** (عرض > مهمة وكيل جديدة...).

## ترتيب النوافذ بنفسك (في كل التخطيطات)

- **اسحب** النافذة من شريط عنوانها إلى حافة أخرى. يظهر مستطيل أزرق يوضح مكانها الجديد.
- **اجعلها عائمة**: اسحبها إلى منتصف الشاشة، أو انقر زر "التعويم" في شريط عنوانها.
- **ألسنة متراكبة**: أفلت نافذة فوق أخرى لتصبحا لسانين في مكان واحد.
- **أعدها إلى مكانها**: انقر شريط عنوان النافذة العائمة مرتين.

### تقسيم المحرر

لترى ملفين جنبًا إلى جنب:

- **Window > Split Editor Right** (نافذة > تقسيم المحرر لليمين) أو `Ctrl+\`.
- **Window > Split Editor Down** (تقسيم المحرر لأسفل).
- **Window > Remove Split** (إزالة التقسيم) للعودة إلى محرر واحد.

## التنقل بلوحة المفاتيح

| المفتاح | الوظيفة |
|---|---|
| `F6` | انقل التركيز إلى النافذة المثبّتة التالية (المحرر، ثم مستكشف الحلول، ثم الخصائص ...) |
| `Shift+F6` | النافذة السابقة |
| `Ctrl+F6` | عُد إلى المحرر |
| `Alt` + الحرف المسطّر | افتح قائمة، مثل `Alt+F` لقائمة File |

## مثال للتجربة في كل تخطيط

شغّل المثال مرة في تخطيط Visual Studio ومرة في VS Code. لاحظ أين تظهر نافذة **Output** في كل مرة: في الأسفل مع النوافذ المثبّتة، أو داخل **اللوحة** السفلية.

```vb run
Sub Main()
    Dim layouts(2) As String
    Dim i As Integer
    layouts(0) = "Visual Studio"
    layouts(1) = "VS Code"
    layouts(2) = "Agent"
    For i = 0 To 2
        Debug.Print "التخطيط " & (i + 1) & ": " & layouts(i)
    Next i
    Debug.Print "Ctrl+K Ctrl+L ينتقل إلى التخطيط التالي"
End Sub
```

```text output
التخطيط 1: Visual Studio
التخطيط 2: VS Code
التخطيط 3: Agent
Ctrl+K Ctrl+L ينتقل إلى التخطيط التالي
```

## أخطاء شائعة

- **"اختفت كل النوافذ!"**: ربما ضغطت `Ctrl+K Z` (وضع التركيز) أو `Ctrl+B`. اضغط الاختصار مرة أخرى، أو **View > Layout > Reset Current Layout**.
- **"لا أجد صندوق الأدوات في تخطيط VS Code":** هذا التخطيط مخصص للكود. للتصميم بالسحب والإفلات انتقل إلى تخطيط Visual Studio، أو افتح **View > Toolbox**.
- **ظن أن التبديل يغلق المشروع:** التخطيط شكل فقط؛ المشروع والملفات المفتوحة تبقى كما هي.

## تمرين

### تمرين 1: التخطيط الحالي

اكتب برنامجًا يخزن اسم التخطيط في متغير `current` قيمته `"VS Code"`، ثم يطبع `أنت تعمل الآن بتخطيط VS Code`.

```vb exercise
Sub Main()
    Dim current As String
    ' اكتب هنا
End Sub
```

```vb solution
Sub Main()
    Dim current As String
    current = "VS Code"
    Debug.Print "أنت تعمل الآن بتخطيط " & current
End Sub
```

```text output
أنت تعمل الآن بتخطيط VS Code
```

### مهمة عملية: رتّب، ثم أعد الضبط

1. انتقل إلى تخطيط **VS Code** بـ `Ctrl+K Ctrl+L`.
2. افتح عرض **Source Control** من شريط النشاط، ثم أخفِ الشريط الجانبي بـ `Ctrl+B`.
3. افتح اللوحة السفلية بـ `Ctrl+J`، وقسّم المحرر بـ `Ctrl+\`.
4. ارجع إلى **Visual Studio** ثم إلى **VS Code**: لاحظ أن ترتيبك محفوظ.
5. اختر **View > Layout > Reset Current Layout** لترجع إلى الترتيب الأصلي.

## الخلاصة

- ثلاثة تخطيطات: **Visual Studio** للتصميم، و **VS Code** للكود، و **Agent** للعمل مع وكلاء الذكاء الاصطناعي.
- التبديل: المفتاح **VS | Code | Agent**، أو **View > Layout**، أو `Ctrl+K Ctrl+L`، وكل تخطيط يحفظ ترتيبه.
- `Ctrl+B` الشريط الجانبي، و `Ctrl+J` اللوحة، و `Ctrl+K Z` التركيز، و `Ctrl+\` تقسيم المحرر، و `F6` للتنقل بين النوافذ.

# الدرس 9: ورقة الاختصارات وقاموس المصطلحات

**في هذا الدرس:**

- كل اختصارات هذا الدليل في جداول قصيرة تطبعها وتضعها بجانب الشاشة.
- قاموس المصطلحات: الاسم العربي، والاسم الإنجليزي، ومعناه في جملة.

## الملفات والمشروعات

| الأمر | القائمة | الاختصار |
|---|---|---|
| مشروع جديد | **File > New Project...** (ملف > مشروع جديد...) | `Ctrl+Shift+N` |
| فتح مشروع | **File > Open Project...** (فتح مشروع...) | `Ctrl+Shift+O` |
| فتح مجلد | **File > Open Folder...** (فتح مجلد...) | `Ctrl+K` `Ctrl+O` |
| فتح ملف | **File > Open File...** (فتح ملف...) | `Ctrl+O` |
| نافذة جديدة | **File > New Window** (نافذة جديدة) | `Ctrl+Alt+N` |
| حفظ الكل | **File > Save All** (حفظ الكل) | `Ctrl+S` |
| البحث عن الأخطاء / بناء الحل | **Build > Build Solution** (بناء الحل) | `Ctrl+Shift+B` |

## المحرر والتنقل

| الأمر | الاختصار |
|---|---|
| لوحة الأوامر | `Ctrl+Shift+P` |
| فتح سريع لملف | `Ctrl+P` |
| بحث / استبدال | `Ctrl+F` / `Ctrl+H` |
| بحث في الملفات | `Ctrl+Shift+F` |
| الانتقال إلى سطر | `Ctrl+G` |
| الانتقال إلى التعريف / كل المراجع | `F12` / `Shift+F12` |
| إعادة تسمية رمز | `F2` |
| تنسيق المستند | `Alt+Shift+F` |
| تعليق / إلغاء تعليق | `Ctrl+/` |
| IntelliSense / معلومات المعاملات | `Ctrl+Space` / `Ctrl+Shift+Space` |
| الكود / المصمم | `F7` / `Shift+F7` |

| الأمر | الاختصار |
|---|---|
| التخطيط التالي (VS، Code، Agent) | `Ctrl+K` `Ctrl+L` |

| وضع التركيز (Zen) | `Ctrl+K` `Z` |
| تقسيم المحرر لليمين | `Ctrl+\` |
| النافذة التالية / السابقة / العودة إلى المحرر | `F6` / `Shift+F6` / `Ctrl+F6` |
| الطرفية | `` Ctrl+` `` |
| تغييرات Git | `Ctrl+Alt+G` |
| قواعد البيانات | `Ctrl+Alt+D` |
| محادثة الذكاء الاصطناعي / مدير الوكلاء | `Ctrl+Alt+I` / `Ctrl+Alt+M` |

| الأمر | الاختصار |
|---|---|
| تشغيل مع المصحح / متابعة | `F5` |

## قاموس المصطلحات

| بالعربية | بالإنجليزية | المعنى |
|---|---|---|
| بيئة التطوير المتكاملة | IDE | برنامج يجمع المحرر والمصمم والمصحح وأدوات البناء |
| مشروع | Project | برنامج واحد بلغة واحدة، ملفه `project.radproj` |
| حل | Solution | مجموعة مشروعات، ملفه `.radsln` |
| مشروع بدء التشغيل | StartUp Project | المشروع الذي يعمل عند `F5`، يظهر بخط عريض |
| مرجع | Reference | ربط مشروع بمشروع آخر لاستدعاء دواله |
| نموذج | Form | نافذة برنامجك، تصممها في المصمم |
| وحدة برمجية | Module | ملف كود بلا نافذة |
| أداة / عنصر تحكم | Control | زر، أو مربع نص، أو قائمة ... توضع على النموذج |
| نافذة مثبّتة | Dock | نافذة جانبية تُسحب وتُثبّت وتُعوَّم |
| تخطيط منطقة العمل | Workbench layout | ترتيب النوافذ: Visual Studio أو VS Code أو Agent |
| شريط النشاط | Activity Bar | عمود الأيقونات في تخطيطي VS Code و Agent |
| لوحة الأوامر | Command Palette | مربع تكتب فيه اسم أي أمر لتنفيذه |
| فتح سريع | Quick Open | الوصول إلى أي ملف بكتابة جزء من اسمه |
| اختصار مزدوج | Chord | اختصاران متتاليان مثل `Ctrl+K` ثم `Ctrl+O` |
| سمة | Theme | ألوان البيئة |
| فتح في المكان | Open in place | فتح مشروع بيئة أخرى دون تحويله أو إضافة ملفات إليه |
| مجلد عادي | Folder workspace | مجلد يُفتح كشجرة ملفات بلا ملف مشروع |
| نسخة احتياطية تلقائية | Auto-save backup | نسخة طوارئ للتغييرات غير المحفوظة في `.radide_backup` |
| مفسّر / مترجم | Interpreter / Compiler | البرنامج الذي يشغّل لغة ما أو يحوّلها إلى ملف تنفيذي |
| خادم لغة | Language Server | برنامج يعطي المحرر الإكمال الذكي والانتقال إلى التعريف |
| التكامل مع ويندوز | Windows integration | ربط الملفات وقوائم المستكشف والاختصارات |

## الخطوة التالية

أنهيت دليل أساسيات البيئة. تابع مع:

- **دليل مصمم النماذج**: الأدوات، والخصائص، والأحداث، و Anchor و Dock، والترجمة، والحركة.
- **دليل البيانات والتقارير**: قواعد البيانات، وربط النماذج بها، والتقارير.
- **دليل التصحيح والاختبار**: نقاط التوقف، والمراقبة، ومستكشف الاختبارات.
- **دليل Git والتعاون**: Git، و GitHub، والمشاركة المباشرة، والعمل عن بعد، والنشر.

# الدرس 1: مرحبًا بك في Fortran وأول برنامج بـ gfortran

أهلًا بك في دورة **Fortran**! اسمها اختصار **FORmula TRANslation** أي «ترجمة المعادلات». ظهرت سنة 1957 في شركة IBM، فهي **أقدم لغة برمجة عالية المستوى** ما زالت مستخدمة بكثرة حتى اليوم.

## لماذا نتعلم لغة عمرها أكثر من 60 سنة؟

- **ملكة الحسابات العلمية:** توقعات الطقس، ومحاكاة الزلازل والطائرات، والفيزياء والكيمياء، تُكتب كثيرًا بـ Fortran.
- **سريعة جدًا** في الحسابات على الأرقام والمصفوفات، وأسرع الحواسيب العملاقة في العالم تُقاس بمكتبة مكتوبة بـ Fortran.
- **لغة حديثة فعلًا:** Fortran اليوم (معايير 90 و2003 و2008 و2018) فيها وحدات ومصفوفات ديناميكية وبرمجة كائنية، وليست «اللغة القديمة» بالبطاقات المثقبة.
- **سهلة القراءة:** كلماتها إنجليزية واضحة مثل `program` و`if ... then` و`do` و`end`.

> **تشبيه:** إن كانت Python **سكينًا سويسرية** تصلح لكل شيء، فـ Fortran **آلة حاسبة علمية عملاقة**: متخصصة في الأرقام، وفي هذا المجال لا يسبقها أحد تقريبًا.

## المترجم gfortran

نستخدم المترجم المجاني **gfortran** من حزمة **MinGW-w64**، وهي نفس الحزمة التي فيها `gcc` لدورتي C وC++.

- تبحث الـ IDE عنه في `%LOCALAPPDATA%\RADIDE\toolchains\mingw64\bin` ثم في `PATH`.
- إن كانت دورة C أو C++ تعمل عندك، فغالبًا `gfortran` موجود أيضًا.
- ملفات Fortran الحديثة امتدادها **`.f90`**.

## أول مشروع Fortran في الـ IDE

1. **File ← New Project...** (ملف ← مشروع جديد...).
2. في شجرة اللغات: **Native** (أصلي) ← **Fortran (GUI Bridge, gfortran)**.
3. من **Template** (القالب) اختر **Console Application** (تطبيق طرفية)، وسمّ المشروع `HelloFortran`.
4. تفتح الـ IDE الملف `Program.f90`. امسح ما فيه واكتب:

```fortran run
program hello
  implicit none
  print *, 'Hello, Fortran!'
  print *, 'مرحبًا بلغة Fortran'
end program hello
```

```text output
 Hello, Fortran!
 مرحبًا بلغة Fortran
```

5. اضغط **Ctrl+F5** (**Start Without Debugging** - بدء بدون تصحيح الأخطاء). تترجم الـ IDE البرنامج بـ `gfortran` وتعرض الناتج في نافذة **Output** (المخرجات).

لاحظ **المسافة** في أول كل سطر من الناتج: `print *` تضعها دائمًا. سنتعلم في الدرس القادم كيف نتحكم في شكل الطباعة بالضبط.

## الشرح سطرًا سطرًا

| السطر | معناه |
|---|---|
| `program hello` | بداية البرنامج، واسمه `hello` (أي اسم تختاره) |
| `implicit none` | «لا تخمّن أنواع المتغيرات؛ سأعرّف كل متغير بنفسي». اكتبه **دائمًا** |
| `print *, 'نص'` | اطبع النص. النجمة `*` تعني «بالشكل الافتراضي» |
| `end program hello` | نهاية البرنامج |

- النصوص بين علامتي تنصيص مفردة `'...'` أو مزدوجة `"..."`.
- **Fortran لا تفرق بين الحروف الكبيرة والصغيرة:** `PRINT` و`print` و`Print` نفس الشيء. الأسلوب الحديث: حروف صغيرة.
- **لا توجد فاصلة منقوطة** في آخر السطر. كل سطر تعليمة.
- التعليقات تبدأ بـ **`!`** وتمتد لآخر السطر.

### لماذا `implicit none` مهمة جدًا؟

في Fortran القديمة كان أي متغير يبدأ بالحروف من `i` إلى `n` يعتبر عددًا صحيحًا تلقائيًا، والباقي أعداد حقيقية! فلو أخطأت في كتابة اسم متغير، تنشئ Fortran متغيرًا جديدًا بصمت ولا تخبرك. مع `implicit none` يرفض المترجم أي متغير لم تعرّفه، فيكشف أخطاء الكتابة فورًا.

## طباعة أرقام وحسابات

```fortran run
program calc
  implicit none
  ! التعليقات تبدأ بعلامة التعجب
  print *, 'Sum:', 7 + 5
  print *, 'Power:', 2**10
end program calc
```

```text output
 Sum:          12
 Power:        1024
```

`**` هي عملية **الأُس** في Fortran: `2**10` = 1024. والأرقام في `print *` تأخذ عرضًا ثابتًا (مسافات قبلها)، وهذا طبيعي.

## أخطاء شائعة

| الرسالة | السبب | الحل |
|---|---|---|
| `Symbol 'x' at (1) has no IMPLICIT type` | متغير غير معرّف (مع `implicit none`) | عرّفه: `integer :: x` |
| `Unclassifiable statement at (1)` | كلمة مكتوبة خطأ مثل `prnt` | صحح الكلمة |
| `Unterminated character constant` | نسيت إغلاق علامة التنصيص | أغلق النص بـ `'` |
| `Expecting END PROGRAM statement` | نسيت `end program` | أضفه في آخر الملف |

> **نصيحة:** رسائل gfortran تضع الرمز `(1)` تحت مكان الخطأ بالضبط في السطر. انقر مرتين على الخطأ في **Error List** (قائمة الأخطاء) لتنتقل إليه.

## تمرين

### التمرين 1

اكتب برنامجًا يطبع اسمك في سطر، وناتج `15 * 4` في سطر ثانٍ:

```fortran exercise
program me
  implicit none
  ! اكتب هنا
end program me
```

```fortran solution
program me
  implicit none
  print *, 'My name is Omar'
  print *, '15 * 4 =', 15 * 4
end program me
```

```text output
 My name is Omar
 15 * 4 =          60
```

## الخلاصة

- Fortran لغة الحسابات العلمية، والمترجم `gfortran` من MinGW.
- مشروع جديد: **Native ← Fortran (GUI Bridge, gfortran)** ← **Console Application**.
- البرنامج بين `program اسم` و`end program اسم`، ومعه دائمًا `implicit none`.
- `print *, ...` تطبع، و`!` للتعليقات، و`**` للأُس.

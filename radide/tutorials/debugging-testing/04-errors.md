# الدرس 4: أخطاء التشغيل وقائمة الأخطاء

**في هذا الدرس ستتعلم:**

- الأنواع الثلاثة للأخطاء: **أخطاء الصياغة**، و**أخطاء التشغيل**، و**الأخطاء المنطقية**.
- نافذة **Error List** (قائمة الأخطاء): فحص المشروع عند كل حفظ وبـ `Ctrl+Shift+B`، ومهام `TODO`.
- قراءة رسالة خطأ التشغيل: رقمه، ووصفه، وسطره، والانتقال إليه.
- معالجة الخطأ في الكود بـ `On Error` حتى لا ينهار البرنامج أمام المستخدم.

## ثلاثة أنواع من الأخطاء

| النوع | مثال من الحياة | مثال في الكود | من يكتشفه؟ |
|---|---|---|---|
| **خطأ صياغة** (Syntax error) | جملة بلا فعل: "أنا إلى السوق" | `If x > 3` بلا `Then` | البيئة، قبل التشغيل: **Error List** |
| **خطأ تشغيل** (Run-time error) | وصفة تقول "اقسم الكعكة على عدد الضيوف" والضيوف صفر | القسمة على صفر، أو ملف غير موجود | البرنامج أثناء التشغيل: رسالة خطأ |
| **خطأ منطقي** (Logic error) | وصفة تقول ملعقة ملح بدل ملعقة سكر | `For i = 1 To 10 Step 2` بدل `2 To 10` | **أنت**، بالمصحح والاختبارات |

الأسهل اكتشافًا الأول، والأصعب الثالث، لأن البرنامج "يعمل" لكنه يعطي نتيجة خطأ.

## قائمة الأخطاء (Error List)

افتحها من **View > Error List** (عرض > قائمة الأخطاء).

- البيئة **تفحص المشروع عند كل حفظ** (`Ctrl+S`)، أو عندما تطلب: **Project > Check for Errors** (مشروع > البحث عن الأخطاء) أو `Ctrl+Shift+B`.
- كل خطأ في سطر: النوع (خطأ أو تحذير)، والوصف، والملف، والسطر.
- **انقر الخطأ مرتين** لتقفز إلى السطر في المحرر.
- التعليقات التي تبدأ بـ `TODO` أو `FIXME` تظهر **مهامًا** في القائمة نفسها، لتتذكر ما لم تكمله:

```vb
' TODO: أضف التحقق من البريد الإلكتروني
' FIXME: هذه الدالة بطيئة مع القوائم الكبيرة
```

وفي المحرر نفسه يظهر **خط متعرج أحمر** تحت الخطأ (في اللغات التي لها خادم لغة)، وتلميح بالوصف عند الوقوف عليه بالفأرة.

## خطأ التشغيل: اقرأ الرسالة

عند خطأ تشغيل في BASIC تظهر رسالة فيها:

- **الرقم**: مثل `11` (القسمة على صفر)، و `9` (فهرس خارج حدود المصفوفة)، و `13` (عدم تطابق النوع)، و `53` (الملف غير موجود).
- **الوصف**: مثل `Division by zero`.
- **السطر** الذي حدث فيه. استخدم `Ctrl+G` (الانتقال إلى سطر) لتذهب إليه.

ومع **Debug > Break on Exceptions** يتوقف المصحح على السطر نفسه، فترى المتغيرات في لحظة الخطأ.

جرّب البرنامج التالي. سيطبع سطرين ثم يحدث خطأ القسمة على صفر (رقم 11) في الطالب الثالث، لأن عدد مواده صفر:

<!-- test: {"error": 11} -->
```vb run
Function Average(total As Long, count As Integer) As Long
    Average = total \ count
End Function

Sub Main()
    Debug.Print "أحمد: " & Average(270, 3)
    Debug.Print "منى: " & Average(180, 2)
    Debug.Print "يوسف: " & Average(0, 0)
    Debug.Print "لن يُطبع هذا السطر"
End Sub
```

```text output
أحمد: 90
منى: 90
```

## معالجة الخطأ: `On Error`

بعض الأخطاء متوقعة: المستخدم كتب حرفًا بدل رقم، أو الملف غير موجود. بدل أن ينهار البرنامج، **التقط** الخطأ وتصرّف:

```vb run
Function SafeAverage(total As Long, count As Integer) As String
    On Error GoTo Failed
    SafeAverage = CStr(total \ count)
    Exit Function
Failed:
    SafeAverage = "لا يوجد (خطأ " & Err.Number & ")"
End Function

Sub Main()
    Debug.Print "أحمد: " & SafeAverage(270, 3)
    Debug.Print "يوسف: " & SafeAverage(0, 0)
    Debug.Print "انتهى البرنامج بسلام"
End Sub
```

```text output
أحمد: 90
يوسف: لا يوجد (خطأ 11)
انتهى البرنامج بسلام
```

- `On Error GoTo Failed`: إذا حدث خطأ اقفز إلى العلامة `Failed:`.
- `Exit Function` قبل العلامة حتى لا يُنفّذ كود الخطأ في الحالة السليمة.
- `Err.Number` و `Err.Description` يصفان الخطأ.

> ⚠️ **لا تُخفِ الأخطاء:** `On Error Resume Next` في أول البرنامج كله يجعل الأخطاء صامتة، فتصبح أخطاء منطقية أصعب بكثير. التقط فقط ما تتوقعه.

## أخطاء شائعة

- **تجاهل قائمة الأخطاء والضغط على F5:** ابدأ بإصلاح أول خطأ في القائمة؛ أحيانًا يسبب خطأ واحد أخطاء كثيرة بعده.
- **قراءة الوصف فقط:** الرقم والسطر أهم. اذهب إلى السطر بـ `Ctrl+G`، أو شغّل مع **Break on Exceptions**.
- **`On Error Resume Next` للبرنامج كله:** يخفي المشكلات بدل حلها.
- **نسيان `Exit Function` قبل علامة الخطأ:** كود المعالجة يُنفّذ دائمًا.

## تمرين

### تمرين 1: لا قسمة على صفر

أصلح الدالة `Average` لتُرجع `0` إذا كان `count` يساوي صفرًا، **بدون** `On Error`، باستخدام `If`. يجب أن يطبع البرنامج الأسطر الأربعة.

```vb exercise
Function Average(total As Long, count As Integer) As Long
    Average = total \ count
End Function

Sub Main()
    Debug.Print "أحمد: " & Average(270, 3)
    Debug.Print "منى: " & Average(180, 2)
    Debug.Print "يوسف: " & Average(0, 0)
    Debug.Print "تم"
End Sub
```

```vb solution
Function Average(total As Long, count As Integer) As Long
    If count = 0 Then
        Average = 0
    Else
        Average = total \ count
    End If
End Function

Sub Main()
    Debug.Print "أحمد: " & Average(270, 3)
    Debug.Print "منى: " & Average(180, 2)
    Debug.Print "يوسف: " & Average(0, 0)
    Debug.Print "تم"
End Sub
```

```text output
أحمد: 90
منى: 90
يوسف: 0
تم
```

### مهمة عملية: قائمة الأخطاء

1. في مشروع BASIC اكتب في `Sub Main` سطرًا خطأً عمدًا: `If 1 > 0` بدون `Then`.
2. احفظ بـ `Ctrl+S` وافتح **View > Error List**: انقر الخطأ مرتين.
3. أصلحه واحفظ: تختفي الرسالة.
4. أضف تعليق `' TODO: جرّب قائمة المهام` ولاحظ ظهوره في القائمة.

## الخلاصة

- صياغة (البيئة تكتشفه)، وتشغيل (رسالة برقم وسطر)، ومنطقي (أنت تكتشفه).
- **Error List**: فحص عند الحفظ و `Ctrl+Shift+B`، والنقر المزدوج يقفز إلى السطر، و `TODO` / `FIXME` مهام.
- **Break on Exceptions** يوقفك على سطر الخطأ، و `On Error GoTo` يلتقط الأخطاء المتوقعة، و `Err.Number` يصفها.

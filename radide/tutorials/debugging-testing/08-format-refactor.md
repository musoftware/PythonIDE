# الدرس 8: التنسيق عند الحفظ وإعادة الهيكلة

**في هذا الدرس ستتعلم:**

- **تنسيق المستند** (Format Document) بضغطة واحدة: `Shift+Alt+F`.
- تفعيل **التنسيق عند الحفظ** (Format on Save) واختيار أداة التنسيق لكل لغة من نافذة الخيارات.
- **إعادة الهيكلة** (Refactoring): إعادة التسمية `F2`، والإجراءات السريعة `Ctrl+.`، واستخراج دالة أو متغير.
- **البحث عن كل المراجع** `Shift+F12`: أين يُستخدم هذا الاسم في المشروع كله؟

## ترتيب الغرفة وتغيير الأثاث

**التنسيق** يشبه ترتيب الغرفة: لا يغيّر الأثاث، بل يرتبه. المسافات والإزاحة وعلامات التنصيص تصبح بشكل موحد، **والبرنامج يعمل كما هو تمامًا**.
**إعادة الهيكلة** تشبه إعادة توزيع الأثاث: تغيّر **شكل** الكود (اسم متغير، تقسيم دالة طويلة) دون أن تغيّر **ما يفعله**. القاعدة الذهبية: المخرجات قبل إعادة الهيكلة وبعدها **متطابقة**.

## تنسيق المستند

افتح ملفًا واضغط **Edit > Format Document** (تحرير > تنسيق المستند) أو `Shift+Alt+F` (أو `Ctrl+K` ثم `Ctrl+D`). كل التنسيق **خطوة تراجع واحدة**: `Ctrl+Z` واحدة تعيد الملف كما كان.

البيئة تختار الأداة حسب اللغة (أول أداة مثبتة):

| اللغة | أداة التنسيق |
|---|---|
| Python | Ruff ثم Black |
| JavaScript و TypeScript و HTML و CSS و JSON و Markdown و YAML | Prettier |
| C و C++ و Java و C#‎ | clang-format |
| Go / Rust / Dart / PHP | gofmt / rustfmt / dart format / PHP CS Fixer |
| Ring | منسّق Ring المدمج |
| أي لغة لها خادم لغة (Language Server) | تنسيق خادم اللغة |

### مثال: كود Python مبعثر

هذا كود يعمل، لكنه مكتوب على عجل: إزاحة غير منتظمة، ومسافات عشوائية، وعلامات تنصيص مختلطة:

<!-- test: {"format": "ruff"} -->
```python
def total( prices,tax = 0.14 ):
  s=0
  for p in prices :
        s+=p
  return round(s*(1+tax),2)
names=[ 'سارة','علي' ,'منى']
print( total([100,250]) )
print(len( names ))
```

بعد `Shift+Alt+F` (بأداة Ruff) يصبح هكذا، ويعطي **المخرجات نفسها**:

```python run
def total(prices, tax=0.14):
    s = 0
    for p in prices:
        s += p
    return round(s * (1 + tax), 2)


names = ["سارة", "علي", "منى"]
print(total([100, 250]))
print(len(names))
```

```text output
399.0
3
```

لاحظ: إزاحة بأربع مسافات، ومسافة حول `=` و `+`، وسطران فارغان بعد الدالة، وعلامات تنصيص مزدوجة. لم يتغير أي منطق.

## التنسيق عند الحفظ

بدل أن تتذكر `Shift+Alt+F` كل مرة:

1. **Edit > Format on Save** (تحرير > التنسيق عند الحفظ): علامة صح بجوار الأمر تعني أنه مفعّل.
2. من الآن، كل `Ctrl+S` ينسّق الملف ثم يحفظه.

وللتحكم في كل لغة على حدة: **Tools > Options...** (أدوات > خيارات...) ثم صفحة **Formatting** (التنسيق):

| العنصر | المعنى |
|---|---|
| **Format the document when it is saved (Format on Save)** | المفتاح الرئيسي للتنسيق عند الحفظ |
| عمود **Language** | اللغة |
| عمود **Formatter** | الأداة: **Automatic** (أول أداة مثبتة) أو أداة محددة أو **None** (بلا تنسيق) |
| عمود **On save** | تنسيق هذه اللغة عند الحفظ أم لا |
| عمود **Found** | الأدوات التي وجدتها البيئة على جهازك |
| زر **Install Prettier** | يثبّت Prettier للغات الويب بضغطة |

> 💡 في فريق عمل، التنسيق عند الحفظ يمنع "حروب المسافات": الجميع يحفظ بالشكل نفسه، فتصبح الفروق في Git هي التغييرات الحقيقية فقط.

## إعادة التسمية (F2)

اسم المتغير `x` لا يقول شيئًا. لنسمّه `total`:

1. ضع المؤشر على الاسم.
2. **Edit > Refactor > Rename...** (تحرير > إعادة الهيكلة > إعادة تسمية...) أو `F2`.
3. اكتب الاسم الجديد في نافذة **Rename** واضغط **OK**.
4. تظهر نافذة **المعاينة**: "N change(s) in M file(s)"، وفيها كل تغيير بسطره مع علامة صح. أزل علامة أي تغيير لا تريده، ثم طبّق.

لماذا لا نستخدم **بحث واستبدال** (`Ctrl+H`)؟ لأن الاستبدال الأعمى يغيّر `x` داخل `max` و `xValue` والنصوص. إعادة التسمية تغيّر **الاسم نفسه فقط** وكلمات كاملة.

قبل إعادة التسمية:

```vb run
Sub Main()
    Dim x As Long
    Dim i As Long
    For i = 1 To 5
        x = x + i
    Next
    Debug.Print "المجموع = " & x
End Sub
```

```text output
المجموع = 15
```

وبعد `F2` على `x` وكتابة `total`، ثم `F2` على `i` وكتابة `day`. المخرجات **لم تتغير**:

```vb run
Sub Main()
    Dim total As Long
    Dim day As Long
    For day = 1 To 5
        total = total + day
    Next
    Debug.Print "المجموع = " & total
End Sub
```

```text output
المجموع = 15
```

> 💡 مع **خادم لغة** (Python و TypeScript و C#‎ و Rust و Go ...) تشمل إعادة التسمية **كل ملفات المشروع**. بدونه تعمل على الكلمات الكاملة في الملف الحالي، مع المعاينة نفسها. ثبّت الخوادم من **Tools > Language Servers and Debuggers...** (أدوات > خوادم اللغات والمصححات...).

## الإجراءات السريعة واستخراج دالة

| الأمر | القائمة | الاختصار |
|---|---|---|
| إجراءات سريعة (إصلاحات واقتراحات) | **Edit > Refactor > Quick Actions and Refactorings...** (إجراءات سريعة وإعادة هيكلة...) | `Ctrl+.` |
| استخراج دالة من الكود المحدد | **Edit > Refactor > Extract Method...** (استخراج دالة...) | `Ctrl+Shift+M` |
| استخراج متغير من التعبير المحدد | **Edit > Refactor > Extract Variable...** (استخراج متغير...) | — |
| البحث عن كل المراجع | **Edit > Refactor > Find All References** (البحث عن كل المراجع) | `Shift+F12` |

**استخراج دالة**: حدّد عدة أسطر تقوم بمهمة واحدة، واضغط `Ctrl+Shift+M`، واكتب اسمًا للدالة الجديدة. البيئة تنقل الأسطر إلى دالة وتضع مكانها استدعاءً لها. هذا يحتاج خادم لغة يدعمه (مثل Python مع pylsp-rope، و TypeScript، و Rust).

قبل: حساب الفاتورة مكرر داخل الحلقة:

```python run
orders = [("سارة", 3, 50), ("علي", 1, 200)]
for name, qty, price in orders:
    subtotal = qty * price
    tax = subtotal * 14 // 100
    print(name, subtotal + tax)
```

```text output
سارة 171
علي 228
```

بعد تحديد سطري الحساب و **Extract Method** باسم `invoice_total`:

```python run
def invoice_total(qty, price):
    subtotal = qty * price
    tax = subtotal * 14 // 100
    return subtotal + tax


orders = [("سارة", 3, 50), ("علي", 1, 200)]
for name, qty, price in orders:
    print(name, invoice_total(qty, price))
```

```text output
سارة 171
علي 228
```

**البحث عن كل المراجع** (`Shift+F12`) يفتح نافذة **Find All References** (View > Find All References Window): كل مكان يُستخدم فيه الاسم بملفه وسطره. **انقر مرتين** على أي نتيجة لتنتقل إليها. استخدمها قبل حذف دالة أو تغيير معاملاتها.

## أخطاء شائعة

- **"Extract method needs a language server":** ثبّت خادم اللغة من **Tools > Language Servers and Debuggers...**، أو استخرج الدالة يدويًا.
- **التنسيق لا يعمل:** عمود **Found** في صفحة Formatting فارغ للغتك، أي أن الأداة غير مثبتة. ثبّتها (مثل `pip install ruff`) أو اختر أداة أخرى.
- **إعادة التسمية بـ Replace All:** تكسر أسماء أخرى تحتوي النص نفسه. استخدم `F2` دائمًا.
- **إعادة الهيكلة بلا اختبارات:** شغّل الاختبارات (`Ctrl+R, A`) قبل إعادة الهيكلة وبعدها؛ يجب أن تبقى خضراء.

## تمرين

### تمرين 1: أعد الهيكلة دون تغيير السلوك

هذا البرنامج يعمل، لكن أسماءه غامضة والحساب مكرر. أعد تسمية المتغيرات بأسماء واضحة، واستخرج دالة `Area(w, h)`، بحيث تبقى المخرجات كما هي تمامًا.

```vb exercise
Sub Main()
    Dim a As Long, b As Long
    a = 4: b = 5
    Debug.Print "مساحة 1 = " & a * b
    a = 10: b = 3
    Debug.Print "مساحة 2 = " & a * b
End Sub
```

```vb solution
Function Area(w As Long, h As Long) As Long
    Area = w * h
End Function

Sub Main()
    Debug.Print "مساحة 1 = " & Area(4, 5)
    Debug.Print "مساحة 2 = " & Area(10, 3)
End Sub
```

```text output
مساحة 1 = 20
مساحة 2 = 30
```

### مهمة عملية

1. أنشئ ملف Python والصق الكود المبعثر، ثم `Shift+Alt+F`، ثم `Ctrl+Z` لترى أن التنسيق خطوة تراجع واحدة.
2. فعّل **Edit > Format on Save**، وشوّه الإزاحة، واضغط `Ctrl+S`.
3. في مشروع BASIC، ضع المؤشر على متغير واضغط `F2`، وراجع نافذة المعاينة قبل التطبيق.
4. ضع المؤشر على اسم دالة واضغط `Shift+F12` لترى كل استدعاءاتها.

## الخلاصة

- `Shift+Alt+F` ينسّق المستند كخطوة تراجع واحدة، و **Edit > Format on Save** ينسّق مع كل حفظ، وصفحة **Formatting** في الخيارات تحدد الأداة لكل لغة.
- `F2` إعادة تسمية آمنة مع معاينة، و `Ctrl+.` إجراءات سريعة، و `Ctrl+Shift+M` استخراج دالة، و `Shift+F12` كل المراجع.
- إعادة الهيكلة الصحيحة لا تغيّر المخرجات، والاختبارات هي الدليل.

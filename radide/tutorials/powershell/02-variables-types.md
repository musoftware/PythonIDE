# الدرس 2: المتغيرات والأنواع والإدخال

**المتغير** في PowerShell يبدأ دائمًا بعلامة الدولار `$`: `$name` و`$age` و`$total`.

> **تشبيه:** علامة `$` مثل **قبعة** يلبسها كل متغير، فتعرفه فورًا بين الكلمات: الأوامر بلا قبعة، والمتغيرات بقبعة.

## إنشاء المتغيرات

```powershell run
$name = "خالد"
$age = 30
$price = 19.99
$active = $true

"$name عمره $age سنة"
$age = $age + 1
$age += 1
$age++
"بعد ثلاث سنوات: $age"
"السعر: $price"
"نشط؟ $active"
```

```text output
خالد عمره 30 سنة
بعد ثلاث سنوات: 33
السعر: 19.99
نشط؟ True
```

- القيم المنطقية تُكتب `$true` و`$false`، والقيمة الفارغة `$null`.
- أسماء المتغيرات لا تهتم بحالة الأحرف: `$Name` و`$name` متغير واحد.

## الأنواع

كل قيمة في PowerShell كائن من منصة .NET، ونسأله عن نوعه بـ `.GetType().Name`:

```powershell run
(42).GetType().Name
(3.14).GetType().Name
("نص").GetType().Name
($true).GetType().Name
(Get-Date -Year 2026 -Month 1 -Day 1).GetType().Name
```

```text output
Int32
Double
String
Boolean
DateTime
```

| النوع | معناه | مثال |
|---|---|---|
| `[int]` | عدد صحيح | `42` |
| `[double]` | عدد عشري | `3.14` |
| `[string]` | نص | `"مرحبا"` |
| `[bool]` | منطقي | `$true` |
| `[datetime]` | تاريخ ووقت | `Get-Date` |
| `[array]` | مصفوفة | `1, 2, 3` |
| `[hashtable]` | جدول تجزئة | `@{a = 1}` |

## تحديد النوع والتحويل

```powershell run
[int]$count = "25"
$count + 5
"10" + 5
5 + "10"
[int]"7" * 2
[double]"2.5" * 2
[string]100 + " نقطة"
[math]::Round(3.14159, 2)
```

```text output
30
105
15
14
5
100 نقطة
3.14
```

- `[int]$count = "25"` تجبر المتغير على أن يكون عددًا صحيحًا دائمًا، فتحوّل النص تلقائيًا.
- انتبه: **نوع الطرف الأيسر يحدد العملية**. `"10" + 5` لصق نصوص (`105`)، و`5 + "10"` جمع أرقام (`15`).
- `[int]` و`[double]` و`[string]` قبل قيمة تحوّلها.

## عوامل المقارنة

PowerShell تستخدم **كلمات** للمقارنة وليس رموزًا مثل `>` (لأن `>` تعني تحويل المخرجات إلى ملف):

| العامل | معناه |
|---|---|
| `-eq` | يساوي |
| `-ne` | لا يساوي |
| `-gt` / `-lt` | أكبر من / أصغر من |
| `-ge` / `-le` | أكبر أو يساوي / أصغر أو يساوي |
| `-like` | يطابق نمطًا بعلامة `*` |
| `-match` | يطابق تعبيرًا نمطيًا |

```powershell run
5 -gt 3
"Ali" -eq "ali"
"Ali" -ceq "ali"
"report.txt" -like "*.txt"
"2026-11-21" -match "^\d{4}"
```

```text output
True
True
False
True
True
```

مقارنة النصوص **لا تهتم بحالة الأحرف** افتراضيًا؛ أضف `c` (`-ceq`، `-clike`) لتجعلها تهتم.

## الإدخال من لوحة المفاتيح

في نافذة PowerShell العادية نقرأ بالأمر `Read-Host`:

```powershell
$name = Read-Host "ما اسمك؟"
```

لكن البرنامج في الـ IDE يعمل دون نافذة تفاعلية (ويُرسل إليه الإدخال من نافذة Output أو من الدرس)، لذلك نقرأ السطر بالطريقة التي تعمل في الحالتين:

```powershell run
Write-Host "ما اسمك؟ " -NoNewline
$name = [Console]::ReadLine()
Write-Host "كم عمرك؟ " -NoNewline
$age = [int][Console]::ReadLine()
Write-Host ""
"أهلًا يا $name!"
"بعد عشر سنوات سيكون عمرك $($age + 10)"
```

```text input
ليلى
24
```

```text output
ما اسمك؟ كم عمرك؟ 
أهلًا يا ليلى!
بعد عشر سنوات سيكون عمرك 34
```

- `[Console]::ReadLine()` تقرأ سطرًا من الإدخال (دالة من .NET).
- `[int]` تحوّل النص المقروء إلى رقم.
- `$($age + 10)` لازمة داخل النص؛ أما `"$age + 10"` فتطبع `24 + 10` حرفيًا.

## التنسيق بالعامل `-f`

```powershell run
$avg = 87.456
"المتوسط: {0:F1}" -f $avg
"{0} حصل على {1} درجة" -f "علي", 95
"[{0,5}] [{0,-5}] [{0:D3}]" -f 42
"نسبة النجاح: {0:P0}" -f 0.85
```

```text output
المتوسط: 87.5
علي حصل على 95 درجة
[   42] [42   ] [042]
نسبة النجاح: 85%
```

`"قالب" -f قيم` يضع القيم مكان `{0}` و`{1}`. و`F1` منزلة عشرية واحدة، و`D3` ثلاث خانات بأصفار، و`P0` نسبة مئوية، و`{0,5}` عرض خمس خانات.

## أخطاء شائعة

### `>` بدل `-gt`

`if (5 > 3)` لا تقارن! بل تنشئ ملفًا اسمه `3` فيه الرقم 5. استخدم `-gt`.

### المسافات حول العوامل

`$x-eq5` لا تعمل. اكتب المسافات: `$x -eq 5`.

### نسيان `$( )` داخل النص

`"المجموع: $a + $b"` تطبع الأرقام وبينها `+`. اكتب `"المجموع: $($a + $b)"`.

## تمارين

### التمرين 1

اقرأ عددين (كل عدد في سطر) واطبع مجموعهما ومتوسطهما بمنزلة عشرية واحدة.

```powershell exercise
$a = [double][Console]::ReadLine()
$b = [double][Console]::ReadLine()
```

```powershell solution
$a = [double][Console]::ReadLine()
$b = [double][Console]::ReadLine()
"المجموع = $($a + $b)"
"المتوسط = {0:F1}" -f (($a + $b) / 2)
```

```text input
7
8
```

```text output
المجموع = 15
المتوسط = 7.5
```

### التمرين 2

اقرأ اسم ملف وافحص بـ `-like` هل امتداده `.txt`، واطبع `ملف نصي` أو `ليس ملفًا نصيًا` (استخدم العامل الثلاثي البسيط: `if`).

```powershell exercise
$file = [Console]::ReadLine()
```

```powershell solution
$file = [Console]::ReadLine()
if ($file -like "*.txt") { "ملف نصي" } else { "ليس ملفًا نصيًا" }
```

```text input
notes.TXT
```

```text output
ملف نصي
```

لاحظ أن `-like` لم تهتم بأن الامتداد بحروف كبيرة.

## الخلاصة

- المتغير يبدأ بـ `$`، و`$true` و`$false` و`$null` قيم خاصة.
- `[int]` و`[double]` و`[string]` للتحويل، ونوع الطرف الأيسر يحدد العملية.
- المقارنة بالكلمات: `-eq` و`-ne` و`-gt` و`-lt` و`-like` و`-match`.
- `[Console]::ReadLine()` لقراءة سطر، و`-f` للتنسيق.

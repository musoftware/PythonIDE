# الدرس 13: حزم المكونات: أدوات جديدة في صندوق الأدوات

**في هذا الدرس ستتعلم:**

- ما هي **حزمة المكون** (Component Package)، ولماذا كل أدوات صندوق الأدوات حزم.
- تثبيت حزمة من ملف `.radcomp` لكل المشروعات أو لمشروع واحد.
- اختيار ما يظهر في صندوق الأدوات بـ **Choose Toolbox Items...**.
- صناعة حزمتك: ملف الوصف `component.json`، وتحويل عنصر تحكم من تصميمك (الدرس 8) إلى حزمة، وتصديرها لزملائك.

## 1) ما هي حزمة المكون؟

كل أداة في **Toolbox** (صندوق الأدوات)، من `Button` إلى `Timer`، **حزمة**: مجلد يصف الأداة. فيه:

- **الخصائص** و**الأحداث** و**الدوال** (Properties / Events / Methods): منها تُبنى نافذة الخصائص وتبويب الأحداث، و IntelliSense في المحرر، و **F1** للمساعدة.
- **طريقة الرسم** على سطح التصميم.
- **كود التشغيل** لكل لغة (Python Tkinter و Python Qt ...)، فيولّد مصمم النماذج الكود الذي ينشئ الأداة.

الفكرة نفسها في Visual Studio (مكونات .NET) و Delphi (حزم المكونات). فإذا ثبّتّ حزمة جديدة، تظهر الأداة في صندوق الأدوات تحت مجموعتها، وتعمل مثل الأدوات الأصلية تمامًا.

| الملف في الحزمة | إلزامي؟ | وظيفته |
|---|---|---|
| `component.json` | نعم | **ملف الوصف** (manifest): الاسم والإصدار والخصائص والأحداث والدوال |
| `icon.png` | لا | أيقونة الأداة في صندوق الأدوات |
| `designer.py` | لا | رسم خاص على سطح التصميم |
| `editors.py` | لا | محرر خاص لخاصية في نافذة الخصائص |
| `runtime/...` | حسب اللغة | كود التشغيل لكل لغة |
| `help.md` | لا | صفحة المساعدة التي يفتحها **F1** |

## 2) قائمة Component Packages

كل الأوامر في **Tools > Component Packages** (أدوات > حزم المكونات):

| الأمر | ماذا يفعل؟ |
|---|---|
| **Manage Component Packages...** | نافذة الحزم: Install و Uninstall و Export .radcomp و New Package و User Control -> Package و Open Folder و Reload |
| **Install Component Package (.radcomp)...** | تثبيت حزمة من ملف مباشرة |
| **Choose Toolbox Items...** | اختيار الأدوات الظاهرة في صندوق الأدوات |
| **Hot Reload (package development)** | إعادة التحميل التلقائي أثناء تطوير حزمة |
| **Reload Packages** | إعادة تحميل كل الحزم يدويًا |

> 💡 في نافذة الحزم ضع علامة على **Show built-in controls** لترى الأدوات الأصلية أيضًا: كلها حزم.

### خطوة بخطوة: تثبيت حزمة

1. احصل على ملف حزمة امتداده `.radcomp` (ملف مضغوط فيه مجلد الحزمة).
2. **Tools > Component Packages > Install Component Package (.radcomp)...** واختر الملف.
3. تسألك البيئة: **لكل المشروعات** (تُحفظ في `%APPDATA%\RADIDE\components`) أم **لهذا المشروع فقط** (تُحفظ في مجلد المشروع `.radide\components`، فتنتقل مع المشروع إلى أي جهاز).
4. تظهر الأداة في صندوق الأدوات تحت مجموعتها. اسحبها إلى النموذج كأي أداة.

> **تنبيه أمان:** ملفات `designer.py` و `editors.py` تعمل داخل البيئة بصلاحياتك. ثبّت الحزم من مصادر تثق بها فقط.

### نموذج يستخدم أداة غير مثبتة

إذا فتحت نموذجًا من جهاز آخر يستخدم أداة حزمتها غير مثبتة عندك، يفتح النموذج عاديًا: تظهر الأداة **مربعًا أحمر** مكتوبًا عليه أن الحزمة غير مثبتة، وتبقى خصائصها المحفوظة كما هي. ثبّت الحزمة فتظهر الأداة.

### Choose Toolbox Items

مثل نافذة **Choose Toolbox Items** في Visual Studio: انقر بالزر الأيمن على صندوق الأدوات واختر **Choose Items...**، ثم ضع العلامة على الأدوات التي تريدها وأزلها عن غيرها. **Browse...** يثبّت ملف `.radcomp`، و **Reset** يُظهر كل شيء من جديد. وفي أعلى صندوق الأدوات مربع **بحث**، والمجموعات تُطوى وتُفتح.

## 3) ملف الوصف component.json

هذا ملف وصف حزمة صغيرة لأداة تقييم بالنجوم (`StarRating`):

```json
{
  "schemaVersion": 1,
  "name": "StarRating",
  "displayName": "Star Rating",
  "version": "1.0.0",
  "description": "A row of stars the user clicks to rate something.",
  "category": "Rating & Input",
  "prefix": "Rating",
  "defaultSize": [130, 26],
  "kind": "visual",
  "defaultEvent": "ValueChanged",
  "properties": [{"name": "Value", "type": "int", "default": 3, "min": 0, "max": 5,
                  "category": "Behavior", "description": "The rating shown."}],
  "events": [{"name": "ValueChanged", "description": "The Value changed."}],
  "methods": [{"name": "Reset", "signature": "Reset()", "description": "Sets Value to 0."}],
  "targets": {"python-tk": {"file": "runtime/starrating_tk.py", "class": "StarRating"}}
}
```

| المفتاح | المعنى |
|---|---|
| `name` | اسم النوع المحفوظ في ملف النموذج (فريد) |
| `version` | الإصدار، مثل `1.0.0`: عند وجود نسختين تُستخدم الأحدث |
| `category` | المجموعة في صندوق الأدوات |
| `prefix` | أسماء النسخ الجديدة: `Rating1` و `Rating2` ... |
| `kind` | `visual` أداة عادية، `container` تحتوي أدوات، `nonvisual` تظهر تحت النموذج مثل `Timer` |
| `properties` | الخصائص: النوع (`str` و `int` و `bool` و `enum` و `color` و `font` ...) والقيمة الافتراضية والمجموعة والوصف |
| `events` / `methods` | الأحداث والدوال: تظهر في تبويب الأحداث وفي IntelliSense |
| `targets` | كود التشغيل لكل لغة |

> **ملاحظة:** القيمة المختلفة عن الافتراضية تظهر **بخط عريض** في نافذة الخصائص، والزر الأيمن > **Reset** يرجعها، مثل Visual Studio.

## 4) حزمتك الأولى

### من عنصر تحكم صممته

في الدرس 8 صنعت عنصر تحكم من تصميمك (`AddressBox`). لتشاركه مع مشروعات أخرى:

1. افتح **Tools > Component Packages > Manage Component Packages...**.
2. اضغط **User Control -> Package** واختر عنصر التحكم. تتحول خصائصه وأحداثه إلى ملف الوصف، وكوده إلى كود التشغيل، وصورته إلى رسمه في المصمم.
3. حدد الحزمة الجديدة واضغط **Export .radcomp...**: تحصل على ملف واحد ترسله لزملائك.

### من الصفر

**New Package...** يكتب لك مجلد حزمة جاهزًا (ملف الوصف وكود تشغيل لـ Tkinter و Qt). عدّله ثم:

- فعّل **Hot Reload (package development)**: كلما حفظت ملفًا من الحزمة يُعاد بناء صندوق الأدوات وتُرسم النماذج المفتوحة من جديد.
- أخطاء ملف الوصف (مثل مفتاح مكتوب خطأ) تظهر في نافذة **Output** بالشكل `[components] ...`، والحزمة غير الصحيحة لا تُثبَّت.

> 💡 الامتدادات (Extensions) يمكنها أن تحمل حزمًا أيضًا. تفاصيل كل المفاتيح وأنواع الخصائص في `docs/COMPONENTS.md` داخل مجلد البيئة.

## أخطاء شائعة

- **الأداة لا تظهر بعد التثبيت:** ربما أخفيتها بـ **Choose Items...**: اضغط **Reset**. أو ثبّتها «لهذا المشروع فقط» وأنت في مشروع آخر.
- **حزمة بنفس اسم أداة أصلية:** تُتجاهل، إلا إذا كتب صاحبها في ملف الوصف `"overrideBuiltin": true`.
- **إصدار أقدم:** تثبيت إصدار أقدم فوق إصدار أحدث يطلب تأكيدك أولًا.

## الخلاصة

- كل أداة في صندوق الأدوات **حزمة**: ملف وصف `component.json` + رسم + كود تشغيل لكل لغة.
- **Tools > Component Packages**: إدارة الحزم وتثبيت ملف `.radcomp` واختيار أدوات صندوق الأدوات.
- التثبيت لكل المشروعات أو لمشروع واحد، و **User Control -> Package** و **Export .radcomp...** لمشاركة أدواتك.
- **Hot Reload** أثناء التطوير، والأخطاء في نافذة **Output**.

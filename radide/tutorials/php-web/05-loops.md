# الدرس 5: حلقات التكرار

**في هذا الدرس ستتعلم:**

- تكرار الأوامر بـ `for` عندما تعرف عدد المرات.
- التكرار بـ `while` و`do ... while` ما دام شرط صحيحًا.
- `break` للخروج من الحلقة، و`continue` لتخطي دورة.
- صنع قوائم وجداول HTML بالحلقات.

## لماذا نحتاج التكرار؟

تخيّل أنك تريد طباعة الأرقام من 1 إلى 100. هل ستكتب 100 سطر `echo`؟ **حلقة التكرار** (loop) مثل عدّاد في صالة الألعاب: «كرّر التمرين 10 مرات»، وأنت تكتب التمرين مرة واحدة فقط.

## الحلقة `for`

```php run
<?php
for ($i = 1; $i <= 5; $i++) {
    echo "الدورة رقم $i\n";
}
echo "انتهت الحلقة\n";
```

```text output
الدورة رقم 1
الدورة رقم 2
الدورة رقم 3
الدورة رقم 4
الدورة رقم 5
انتهت الحلقة
```

رأس الحلقة فيه ثلاثة أجزاء بينها `;`:

1. **البداية** `$i = 1`: تُنفّذ مرة واحدة قبل كل شيء.
2. **الشرط** `$i <= 5`: يُفحص قبل كل دورة؛ إن كان خطأ تتوقف الحلقة.
3. **الخطوة** `$i++`: تُنفّذ بعد كل دورة (تزيد العدّاد 1).

يمكن العدّ بخطوات أكبر أو بالعكس:

```php run
<?php
for ($i = 10; $i >= 0; $i -= 2) {
    echo $i, " ";
}
echo "\n";

$sum = 0;
for ($n = 1; $n <= 100; $n++) {
    $sum += $n;
}
echo "مجموع الأعداد من 1 إلى 100 = $sum\n";
```

```text output
10 8 6 4 2 0 
مجموع الأعداد من 1 إلى 100 = 5050
```

## الحلقة `while`

`while` تكرّر **ما دام** الشرط صحيحًا، وتناسب الحالات التي لا نعرف فيها عدد المرات مسبقًا:

```php run
<?php
$balance = 1000;
$years = 0;
while ($balance < 2000) {
    $balance *= 1.10;      // زيادة 10% كل سنة
    $years++;
}
echo "يتضاعف المبلغ بعد $years سنوات\n";
echo "الرصيد: " . round($balance, 2) . "\n";
```

```text output
يتضاعف المبلغ بعد 8 سنوات
الرصيد: 2143.59
```

> **تحذير:** إذا لم يتغير شيء داخل الحلقة يجعل الشرط خطأ يومًا ما، ستدور **إلى الأبد** (حلقة لا نهائية). في الموقع تتوقف الصفحة بعد 30 ثانية بخطأ `Maximum execution time exceeded`.

و`do ... while` مثلها، لكنها تنفّذ الجسم **مرة واحدة على الأقل** ثم تفحص الشرط في النهاية:

```php run
<?php
$tries = 0;
do {
    $tries++;
    echo "محاولة $tries\n";
} while ($tries < 3);
```

```text output
محاولة 1
محاولة 2
محاولة 3
```

## `break` و `continue`

- `break` يخرج من الحلقة فورًا.
- `continue` يتخطى بقية الدورة الحالية وينتقل للدورة التالية.

```php run
<?php
// اطبع الأعداد الفردية فقط حتى 9
for ($i = 1; $i <= 20; $i++) {
    if ($i % 2 === 0) {
        continue;          // تخطَّ الزوجي
    }
    if ($i > 9) {
        break;             // توقف تمامًا
    }
    echo $i, " ";
}
echo "\n";
```

```text output
1 3 5 7 9 
```

## حلقات متداخلة: جدول الضرب

حلقة داخل حلقة: الخارجية للصفوف، والداخلية للأعمدة. و`str_pad` تجعل كل رقم بعرض ثابت ليتحاذى الجدول:

```php run
<?php
for ($row = 1; $row <= 4; $row++) {
    for ($col = 1; $col <= 4; $col++) {
        echo str_pad($row * $col, 4, " ", STR_PAD_LEFT);
    }
    echo "\n";
}
```

```text output
   1   2   3   4
   2   4   6   8
   3   6   9  12
   4   8  12  16
```

## الحلقات في صفحات الويب

هنا تظهر قوة PHP: نولّد عناصر HTML متكررة بحلقة. والصيغة البديلة `for (...):` و`endfor;` تجعل القالب واضحًا:

<!-- test: {"requests": [{"path": "/?n=7"}]} -->
```php web run
<?php
$n = (int) ($_GET['n'] ?? 5);
?>
<h1>جدول ضرب <?= $n ?></h1>
<table border="1">
<?php for ($i = 1; $i <= 3; $i++): ?>
    <tr><td><?= $n ?> × <?= $i ?></td><td><?= $n * $i ?></td></tr>
<?php endfor; ?>
</table>
```

بالعنوان `/?n=7` يصل للمتصفح:

```text output
<h1>جدول ضرب 7</h1>
<table border="1">
    <tr><td>7 × 1</td><td>7</td></tr>
    <tr><td>7 × 2</td><td>14</td></tr>
    <tr><td>7 × 3</td><td>21</td></tr>
</table>
```

افتح المثال بـ «جرّبه»، ثم غيّر العنوان في المعاينة إلى `?n=9` واضغط Enter.

## أخطاء شائعة

- **الحلقة لا تتوقف:** نسيت `$i++` أو كتبت الشرط بالعكس (`$i >= 5` بدل `$i <= 5`).
- **الخطأ بواحد** (off-by-one): `$i < 10` تعطي 1 إلى 9 فقط. فكّر: هل أريد `<` أم `<=`؟
- **الفاصلة بدل الفاصلة المنقوطة** في رأس `for`: `for ($i = 0, $i < 5, $i++)` خطأ.
- **نسيان `endfor;`** في الصيغة البديلة.

## تمارين

### تمرين 1: العد التنازلي

اطبع `5 4 3 2 1 انطلق!` في سطر واحد (بين الأرقام مسافة).

```php exercise
<?php
// ابدأ من 5 وانقص 1 في كل دورة:
// for ($i = 5; ...; ...) { ... }
```

```php solution
<?php
for ($i = 5; $i >= 1; $i--) {
    echo $i, " ";
}
echo "انطلق!\n";
```

```text output
5 4 3 2 1 انطلق!
```

### تمرين 2: مجموع الأعداد الزوجية

احسب مجموع الأعداد الزوجية من 2 إلى 20 واطبع: `المجموع = 110`.

```php exercise
<?php
$sum = 0;
// حلقة تبدأ من 2 وتزيد 2
echo "المجموع = $sum\n";
```

```php solution
<?php
$sum = 0;
for ($i = 2; $i <= 20; $i += 2) {
    $sum += $i;
}
echo "المجموع = $sum\n";
```

```text output
المجموع = 110
```

### تمرين 3: قائمة HTML

اصنع قائمة `<ul>` فيها 3 عناصر `<li>الدرس 1</li>` إلى `<li>الدرس 3</li>` بحلقة `for` بالصيغة البديلة.

```php web exercise
<ul>
<?php for ($i = 1; $i <= 3; $i++): ?>
<?php endfor; ?>
</ul>
```

```php web solution
<ul>
<?php for ($i = 1; $i <= 3; $i++): ?>
    <li>الدرس <?= $i ?></li>
<?php endfor; ?>
</ul>
```

```text output
<ul>
    <li>الدرس 1</li>
    <li>الدرس 2</li>
    <li>الدرس 3</li>
</ul>
```

## الخلاصة

- `for` عندما تعرف عدد المرات، و`while` ما دام الشرط صحيحًا، و`do ... while` لمرة واحدة على الأقل.
- `break` للخروج، و`continue` لتخطي دورة.
- الحلقات مع الصيغة البديلة `for: ... endfor;` تولّد HTML المتكرر بسهولة.
- في الدرس القادم: **المصفوفات** والحلقة `foreach` المصممة لها.

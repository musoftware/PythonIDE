# الدرس 15: التصحيح بـ Xdebug ونشر الموقع

**في هذا الدرس ستتعلم:**

- قراءة رسائل أخطاء PHP وفهم أنواعها.
- طرق التتبع السريعة: `var_dump` و`print_r`.
- **مصحح الأخطاء** في RAD IDE مع **Xdebug**: نقاط التوقف، والتنفيذ خطوة بخطوة، ونوافذ المتغيرات.
- **نشر** الموقع على استضافة حقيقية بـ **Site > Publish...** (FTP أو SFTP أو مجلد).
- قائمة مراجعة قبل وضع الموقع على الإنترنت.

## أنواع الأخطاء في PHP

| النوع | مثال على الرسالة | ماذا يحدث؟ |
|---|---|---|
| **Parse error** | `syntax error, unexpected end of file` | الملف لا يُنفّذ أصلًا: خطأ في الكتابة (قوس أو `;` ناقص) |
| **Fatal error** | `Uncaught Error: Call to undefined function` | يتوقف التنفيذ عند هذا السطر |
| **Warning** | `Undefined variable $total` أو `Undefined array key` | يكمل التنفيذ لكن غالبًا بنتيجة خاطئة |
| **Deprecated** | `... is deprecated` | يعمل الآن لكنه سيُحذف في نسخة قادمة |

كل رسالة تخبرك **بالملف ورقم السطر**: `in C:\...\index.php on line 12`. ابدأ دائمًا من هناك، وتذكّر أن الخطأ أحيانًا يكون في السطر **السابق** (مثل `;` منسية). وفي الـ IDE يُشغَّل الموقع أثناء التطوير مع إظهار الأخطاء في الصفحة نفسها.

## التتبع السريع: `var_dump` و `print_r`

أبسط طريقة: اطبع قيمة المتغير لترى ما فيه فعلًا:

```php run
<?php
$cart = ["قلم" => 2, "دفتر" => 1];
print_r($cart);
var_dump($cart["دفتر"]);
var_dump($_POST);          // في سطر الأوامر لا يوجد نموذج: مصفوفة فارغة
```

```text output
Array
(
    [قلم] => 2
    [دفتر] => 1
)
int(1)
array(0) {
}
```

`print_r` أبسط للقراءة، و`var_dump` يعرض الأنواع أيضًا (مهم لاكتشاف أن `"5"` نص وليس رقمًا). داخل صفحة ويب ضعها بين `<pre>` و`</pre>` لتبقى منسقة. لكن هذه الطريقة متعبة في البرامج الكبيرة، وتنسى أحيانًا حذف الأسطر... وهنا يأتي دور المصحح.

## مثال: خطأ منطقي

هذه الدالة يُفترض أن تحسب متوسط الدرجات، لكن النتيجة خاطئة. البرنامج لا يعطي رسالة خطأ، فكيف نجد المشكلة؟

```php run
<?php
function average(array $grades): float
{
    $sum = 0;
    for ($i = 1; $i < count($grades); $i++) {
        $sum += $grades[$i];
    }
    return $sum / count($grades);
}
echo average([90, 80, 70]), "\n";
```

```text output
50
```

المتوسط الصحيح `80`. سنكتشف السبب بالمصحح خطوة بخطوة.

## مصحح الأخطاء (Xdebug)

المصحح يجعلك **توقف الزمن** داخل برنامجك: تتوقف عند سطر معيّن، وترى قيمة كل متغير في تلك اللحظة، ثم تتقدّم سطرًا سطرًا.

### التجهيز (مرة واحدة)

اضغط **F5** على موقع PHP (**Debug > Start Debugging / Continue** - بدء تصحيح الأخطاء / متابعة). في أول مرة تعرض الـ IDE تنزيل ما يلزم: امتداد **Xdebug** المناسب لنسخة PHP الخاصة بموقعك، و**محوّل التصحيح** (vscode-php-debug). التنزيل من المواقع الرسمية مرة واحدة إلى `%LOCALAPPDATA%\RADIDE\tools`، دون تثبيت أو صلاحيات مدير. ويحتاج المحوّل إلى **Node.js** على جهازك. (بدونها يعمل الموقع عاديًا لكن بلا مصحح.)

### خطوة بخطوة

1. ضع الدالة السابقة في صفحة `index.php` (مع `echo average(...)`) في موقع PHP.
2. انقر في الهامش بجوار السطر `$sum += $grades[$i];` أو ضع المؤشر عليه واضغط **F9** (**Toggle Breakpoint** - تبديل نقطة التوقف): تظهر دائرة حمراء = **نقطة توقف**.
3. اضغط **F5**: يعمل الخادم مع Xdebug وتُفتح الصفحة في المعاينة.
4. عندما يصل الطلب إلى السطر **يتوقف** التنفيذ، ويُظلَّل السطر في المحرر، وتنتظر المعاينة.
5. انظر إلى نافذة **Locals** (المتغيرات المحلية): `$i = 1`، و`$sum = 0`، و`$grades` مصفوفة يمكنك فتحها. لاحظ: `$i` بدأت من **1** لا من 0! العنصر الأول `90` لن يُجمع أبدًا.
6. تقدّم بـ:
   - **F10** (**Step Over** - خطوة فوق): نفّذ السطر الحالي وانتقل للتالي.
   - **F11** (**Step Into** - خطوة إلى الداخل): ادخل داخل الدالة المستدعاة في السطر.
   - **Shift+F11** (**Step Out** - خطوة إلى الخارج): أكمل الدالة الحالية وارجع لمن استدعاها.
   - **F5** (متابعة): أكمل حتى نقطة التوقف التالية.
   - **Shift+F5** (**Stop Debugging** - إيقاف تصحيح الأخطاء).
7. نوافذ أخرى مفيدة: **Call Stack** (مكدس الاستدعاءات: من استدعى من؟)، و**Watch** (المراقبة: اكتب تعبيرًا مثل `count($grades)` أو `$sum / 3` لتراقب قيمته)، و**Immediate** (الأوامر الفورية: نفّذ تعبيرًا في لحظة التوقف).

نقاط التوقف تعمل في **أي ملف** يمر به الطلب: الصفحة، والملفات المضمّنة (`inc/db.php`)، وملفات القالب. وتعمل مع طلبات `POST` من النماذج: ضع نقطة توقف في `create.php` من المشروع النهائي، ثم أرسل النموذج من المعاينة، وافحص `$_POST` في Locals.

### الإصلاح

```php run
<?php
function average(array $grades): float
{
    if (count($grades) === 0) {
        return 0;                      // لا قسمة على صفر
    }
    $sum = 0;
    foreach ($grades as $g) {          // foreach لا تخطئ في البداية والنهاية
        $sum += $g;
    }
    return $sum / count($grades);
}
echo average([90, 80, 70]), "\n";
echo average([]), "\n";
```

```text output
80
0
```

## النشر: Site > Publish...

عندما يجهز موقعك ترفعه إلى **استضافة** (خادم على الإنترنت فيه PHP). افتح **Site > Publish...** (الموقع > نشر...):

1. على اليسار قائمة **Publish profiles** (ملفات تعريف النشر): **New** لإنشاء ملف تعريف جديد (يمكنك أن تحتفظ بأكثر من وجهة: «تجريبي» و«حقيقي»).
2. املأ البيانات:

| الحقل | معناه |
|---|---|
| **Profile name** | اسم تختاره، مثل `الاستضافة` |
| **Method** | `FTP`، أو `FTPS (explicit TLS)`، أو `SFTP (SSH)`، أو `Local folder / network share` (مجلد على جهازك أو على الشبكة) |
| **Host** / **Port** / **User** / **Password** | بيانات الاستضافة التي أرسلتها لك الشركة |
| **Save password** | يحفظ كلمة المرور في إعداداتك أنت (مموّهة)، **لا** في مجلد المشروع، فلا تُرفع أو تُشارك بالخطأ |
| **Site path** | المجلد على الخادم، مثل `/public_html` |
| **Destination URL** | عنوان الموقع بعد النشر، لزر **Open site** |
| **Local folder** | ما يُرفع من جهازك (افتراضيًا جذر الموقع) |
| **Delete remote files that were removed locally** | يحذف من الخادم ما حذفته عندك |
| **Exclude** | أنماط ملفات لا تُرفع أبدًا (مثل `.git` و`*.bak`) |

3. **Test Connection** للتأكد من البيانات.
4. **Preview**: «تشغيل تجريبي» يعرض قائمة الملفات التي **سترفع أو تُحذف** دون أن يفعل شيئًا (أو من القائمة مباشرة: **Site > Publish Preview (dry run)...**).
5. **Publish**: يرفع الملفات مع شريط تقدّم. والنشر **تدريجي**: في المرة التالية لا يرفع إلا ما تغيّر منذ آخر نشر، فيصبح سريعًا جدًا. (خانة **Upload all files** تتجاهل السجل وترفع كل شيء.)
6. **Open site** يفتح الموقع المنشور.

> **جرّب بلا استضافة:** اختر **Local folder / network share** ومجلدًا فارغًا على جهازك، ثم **Preview** ثم **Publish**، وافتح المجلد لترى ما رُفع.

## قائمة مراجعة قبل النشر

- **أخفِ رسائل الأخطاء** عن الزوار: على الخادم الحقيقي `display_errors = Off` (في `php.ini` أو إعدادات الاستضافة)؛ رسالة الخطأ قد تكشف مسارات ومعلومات حساسة.
- **جذر الموقع** على الاستضافة يجب أن يشير إلى مجلد `public` إن كنت تستخدمه، أو ارفع محتواه فقط.
- **مجلد البيانات** (`data/`) يجب أن يكون **قابلًا للكتابة** لخادم الويب (SQLite تكتب فيه ملفاتها المؤقتة أيضًا)، وغير قابل للوصول من المتصفح.
- **نسخة PHP** على الاستضافة مثل نسختك أو أحدث (هذه الدورة تحتاج PHP 8.1 على الأقل). تأكد من **Site > Site Settings... > PHP version** أنك تطوّر على نفس النسخة.
- استخدم **HTTPS** دائمًا للمواقع التي فيها تسجيل دخول.
- شغّل **Site > SEO Report** لاكتشاف الروابط المكسورة قبل أن يكتشفها الزوار.

## أخطاء شائعة

- **التصحيح لا يتوقف عند نقطة التوقف:** هل شغّلت بـ **F5** (لا Ctrl+F5)؟ وهل الطلب يمر فعلًا بذلك السطر؟ (مثلًا كود داخل `if POST` لا يُنفّذ عند فتح الصفحة بـ GET.)
- **نسيان `var_dump` في الكود المنشور:** يرى الزوار بياناتك. المصحح أنظف لأنه لا يغيّر الكود.
- **رفع ملف إعدادات فيه كلمات سر إلى مكان عام:** ضعه خارج جذر الموقع، وأضفه إلى **Exclude** إن لزم.
- **«الموقع يعمل عندي ولا يعمل على الاستضافة»:** غالبًا نسخة PHP مختلفة، أو امتداد غير مفعّل (`pdo_sqlite`)، أو صلاحيات الكتابة، أو حالة الأحرف في أسماء الملفات (خوادم Linux تفرّق بين `Index.php` و`index.php`).

## تمارين

### تمرين 1: أصلح الحلقة

الدالة يجب أن تطبع الأعداد من 1 إلى 5 مفصولة بمسافة، لكنها تطبع 1 إلى 4. أصلحها.

```php exercise
<?php
for ($i = 1; $i < 5; $i++) {
    echo $i, " ";
}
echo "\n";
```

```php solution
<?php
for ($i = 1; $i <= 5; $i++) {
    echo $i, " ";
}
echo "\n";
```

```text output
1 2 3 4 5 
```

### تمرين 2: أصلح التحذير

البرنامج يعطي التحذير `Warning: Undefined array key "qty"` ويطبع إجماليًا خاطئًا (`40`). اجعل الطلب الذي ليس له كمية يُحسب بكمية `1` باستخدام `??`، فيطبع `الإجمالي: 70`.

```php exercise
<?php
$order = [
    ["price" => 20, "qty" => 2],
    ["price" => 30],
];
$total = 0;
foreach ($order as $line) {
    $total += $line["price"] * $line["qty"];
}
echo "الإجمالي: $total\n";
```

```php solution
<?php
$order = [
    ["price" => 20, "qty" => 2],
    ["price" => 30],
];
$total = 0;
foreach ($order as $line) {
    $total += $line["price"] * ($line["qty"] ?? 1);
}
echo "الإجمالي: $total\n";
```

```text output
الإجمالي: 70
```

## الخلاصة

- اقرأ رسالة الخطأ: نوعها، والملف، والسطر.
- `var_dump` و`print_r` للتتبع السريع، و**Xdebug** للتصحيح الحقيقي: **F9** نقطة توقف، و**F5** تشغيل مع التصحيح، و**F10/F11/Shift+F11** للتقدّم، و**Locals** و**Watch** و**Call Stack** للفحص.
- **Site > Publish...**: ملف تعريف (FTP/FTPS/SFTP/مجلد)، ثم **Test Connection** و**Preview** و**Publish**، والنشر تدريجي.
- قبل النشر: أخفِ الأخطاء، وتأكد من جذر الموقع وصلاحيات `data/` ونسخة PHP و HTTPS.
- 🎉 أنهيت الدورة! الخطوة التالية: دليلا **Laravel** و**CodeIgniter** في نفس نافذة الدروس، وستجد أن كل ما تعلمته هنا (النماذج، والجلسات، وPDO، والأمان) هو الأساس الذي بُنيا عليه.

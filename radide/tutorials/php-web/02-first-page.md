# الدرس 2: أول صفحة ويب في RAD IDE

**في هذا الدرس ستتعلم:**

- إنشاء مشروع **PHP Web Site** وتشغيله.
- نافذة **Preview** (المعاينة) ونافذة **Requests** (الطلبات).
- كتابة PHP **داخل** HTML بالوسمين `<?php ... ?>` و`<?= ... ?>`.
- كيف ترى الصفحة «بعين المتصفح»: الـ HTML الذي يصله فعلًا.

## خطوة بخطوة: إنشاء الموقع

1. من القائمة اختر **File > New Project...** (ملف > مشروع جديد...).
2. في الشجرة على اليسار افتح المجموعة **Web** (ويب)، واختر **PHP Web Site** (موقع ويب PHP).
3. في القوالب اختر **PHP Empty Site** (موقع فارغ)، واكتب اسم المشروع مثلًا `MySite`، ثم **OK**.

تنشئ الـ IDE مجلد الموقع وفيه `index.php` وصفحة `about.php` وملف تنسيق `css/site.css`. وفي **Solution Explorer** (مستكشف الحلول) ترى **شجرة المجلدات** كما هي على القرص.

> **قوالب أخرى ستجدها في نفس المكان:** **PHP Starter Site** (صفحات بقالب مشترك ونموذج تواصل)، و**PHP + SQLite Data App** (تطبيق كامل بتسجيل دخول وإدارة منتجات)، و**Laravel App** و**CodeIgniter 4 App**. ستفهم كل ما فيها مع نهاية هذه الدورة.

## التشغيل: المعاينة والطلبات

اضغط **Ctrl+F5** (Debug > Start Without Debugging - بدء بدون تصحيح الأخطاء)، أو من قائمة **Site** (الموقع) اختر **Run Site in Preview** (تشغيل الموقع في المعاينة). يحدث الآتي:

1. تشغّل الـ IDE **خادم PHP المدمج** (`php -S`) على منفذ محلي مثل `http://127.0.0.1:8123/`.
2. تظهر نافذة **Preview** (معاينة): متصفح صغير داخل الـ IDE، فيه شريط عنوان، وأزرار رجوع وتقدّم وتحديث، وقائمة **أحجام الأجهزة** (هاتف، تابلت، شاشة كبيرة) وزر **Rotate** (تدوير) وزر **Open in Browser** (فتح في المتصفح الخارجي).
3. تظهر نافذة **Requests** (الطلبات): كل طلب يصل للخادم يُسجَّل فيها بأعمدة: الوقت، والطريقة (`GET` أو `POST`)، والمسار، ورمز الحالة (`200` نجاح، `404` غير موجود، `500` خطأ)، والمدة، والحجم.

والأجمل: **التحديث المباشر** (Live reload). عدّل `index.php` واحفظ (**Ctrl+S**)، فتتحدّث المعاينة وحدها.

> **F5 أم Ctrl+F5؟** الاثنان يشغّلان الموقع. **F5** يشغّله مع **مصحح الأخطاء** (Xdebug) لتتوقف عند نقاط التوقف، و**Ctrl+F5** بدونه وأسرع. سنتعلم التصحيح في الدرس 15. ولإيقاف الخادم: **Shift+F5** أو **Site > Stop Web Server** (إيقاف خادم الويب).

## PHP داخل HTML

ملف `.php` يمكن أن يحتوي HTML عاديًا، وبداخله «جزر» من PHP. كل ما خارج وسوم PHP يُرسل كما هو، وما بداخلها يُنفّذ:

```php web run
<!DOCTYPE html>
<html lang="ar" dir="rtl">
<head><meta charset="utf-8"><title>صفحتي الأولى</title></head>
<body>
    <h1>مرحبًا بك في موقعي</h1>
    <p>اليوم نتعلم PHP.</p>
    <p>2 + 3 = <?= 2 + 3 ?></p>
</body>
</html>
```

هذا ما يصل إلى المتصفح بالضبط (لاحظ أن الكود اختفى وحلّ محله الناتج `5`):

```text output
<!DOCTYPE html>
<html lang="ar" dir="rtl">
<head><meta charset="utf-8"><title>صفحتي الأولى</title></head>
<body>
    <h1>مرحبًا بك في موقعي</h1>
    <p>اليوم نتعلم PHP.</p>
    <p>2 + 3 = 5</p>
</body>
</html>
```

- `<?= ... ?>` اختصار لـ `<?php echo ... ?>`: يطبع قيمة واحدة في مكانه. نستخدمه كثيرًا داخل HTML.
- `<?php ... ?>` لكتلة كود كاملة (حسابات، شروط، حلقات).

> **جرّب بنفسك:** في المعاينة اضغط بالزر الأيمن واختر «View page source» أو افتح الصفحة في المتصفح الخارجي واضغط **Ctrl+U**: سترى HTML فقط، ولن تجد أثرًا لكود PHP.

## كتلة PHP كاملة في أعلى الصفحة

العادة الجيدة: نجهّز البيانات في **أعلى** الملف، ثم نعرضها في HTML بالأسفل:

```php web run
<?php
$siteName = "مكتبة النور";
$books = 120;
$visitors = 35;
?>
<h1><?= $siteName ?></h1>
<p>عدد الكتب: <?= $books ?></p>
<p>زوار اليوم: <?= $visitors ?></p>
<p>متوسط الكتب لكل زائر: <?= round($books / $visitors, 1) ?></p>
```

```text output
<h1>مكتبة النور</h1>
<p>عدد الكتب: 120</p>
<p>زوار اليوم: 35</p>
<p>متوسط الكتب لكل زائر: 3.4</p>
```

الكلمات التي تبدأ بـ `$` مثل `$siteName` هي **متغيرات** (صناديق نحفظ فيها القيم)، وسنشرحها بالتفصيل في الدرس القادم. و`round` دالة جاهزة تقرّب العدد.

> **لاحظ:** السطر الفارغ بعد `?>` لا يظهر في الناتج: PHP تبتلع سطرًا جديدًا واحدًا يأتي مباشرة بعد وسم النهاية.

## صفحتان وروابط بينهما

الموقع مجموعة صفحات بينها روابط عادية `<a href="...">`. أضف صفحة جديدة: انقر بالزر الأيمن على المشروع في Solution Explorer واختر **Add > New File...** (إضافة > ملف جديد...)، ثم اختر **PHP Page** واكتب الاسم `contact.php`.

<!-- test: {"requests": [{"path": "/index.php"}, {"path": "/contact.php"}], "all": true} -->
```php web run
// #file: index.php
<h1>الرئيسية</h1>
<nav><a href="index.php">الرئيسية</a> | <a href="contact.php">اتصل بنا</a></nav>
// #file: contact.php
<h1>اتصل بنا</h1>
<p>البريد: info@example.com</p>
<nav><a href="index.php">الرئيسية</a></nav>
```

عند فتح الصفحتين بالترتيب يصل للمتصفح:

```text output
<h1>الرئيسية</h1>
<nav><a href="index.php">الرئيسية</a> | <a href="contact.php">اتصل بنا</a></nav>

<h1>اتصل بنا</h1>
<p>البريد: info@example.com</p>
<nav><a href="index.php">الرئيسية</a></nav>
```

اضغط الروابط في المعاينة وراقب نافذة **Requests**: كل نقرة = طلب `GET` جديد برمز `200`. جرّب أيضًا كتابة عنوان غير موجود مثل `/nothing.php` في شريط العنوان، وستجد في Requests الرمز `404`.

> سطر `// #file: contact.php` في الأمثلة يعني «من هنا يبدأ ملف اسمه `contact.php`»، والـ IDE تقسم المثال إلى ملفات عندما تضغط «جرّبه».

## صفحة البدء وإعدادات الموقع

الصفحة التي تُفتح أولًا هي **صفحة البدء** (Start page). لتغييرها: انقر بالزر الأيمن على الملف في Solution Explorer واختر **Set as Start Page** (تعيين كصفحة البدء). ولكل الإعدادات: **Site > Site Settings...** (الموقع > إعدادات الموقع...) وفيها:

| الإعداد | معناه |
|---|---|
| **Web root** | المجلد الذي يراه الزائر (مثلًا `public`)؛ ما خارجه لا يصل إليه المتصفح |
| **Start page** | الصفحة الأولى |
| **Port** | رقم المنفذ (`0` = تختاره الـ IDE تلقائيًا) |
| **live reload** | تحديث المعاينة عند الحفظ |
| **PHP version** | نسخة PHP لهذا الموقع بالذات |

## أخطاء شائعة

- **فتح ملف PHP مباشرة من القرص في المتصفح** (`file:///C:/...`): يظهر الكود نفسه أو صفحة فارغة، لأن لا أحد ينفّذ PHP. شغّل الموقع دائمًا من الـ IDE (أو أي خادم PHP).
- **نسيان `?>` قبل HTML:** إذا فتحت `<?php` ثم كتبت HTML قبل إغلاقه، يحاول PHP فهم HTML ككود فيظهر `Parse error`.
- **امتداد `.html` بدل `.php`:** كود PHP داخل ملف `.html` لا يُنفّذ. استخدم `.php`.

## تمارين

### تمرين 1: بطاقة منتج

أكمل الصفحة لتعرض اسم المنتج وسعره، والسعر بعد الخصم (السعر × 0.8) محسوبًا بـ PHP.

```php web exercise
<?php
$name = "لوحة مفاتيح";
$price = 250;
?>
<h2><?= $name ?></h2>
<p>السعر: <?= $price ?> جنيه</p>
<!-- أضف سطر السعر بعد الخصم -->
```

```php web solution
<?php
$name = "لوحة مفاتيح";
$price = 250;
?>
<h2><?= $name ?></h2>
<p>السعر: <?= $price ?> جنيه</p>
<p>بعد الخصم: <?= $price * 0.8 ?> جنيه</p>
```

```text output
<h2>لوحة مفاتيح</h2>
<p>السعر: 250 جنيه</p>
<p>بعد الخصم: 200 جنيه</p>
```

### تمرين 2: مساحة الغرفة

اعرض طول الغرفة `5` وعرضها `4` ومساحتها (الطول × العرض) في ثلاث فقرات `<p>`.

```php web exercise
<?php
$length = 5;
$width = 4;
?>
<p>الطول: <?= $length ?></p>
```

```php web solution
<?php
$length = 5;
$width = 4;
?>
<p>الطول: <?= $length ?></p>
<p>العرض: <?= $width ?></p>
<p>المساحة: <?= $length * $width ?></p>
```

```text output
<p>الطول: 5</p>
<p>العرض: 4</p>
<p>المساحة: 20</p>
```

## الخلاصة

- **File > New Project... > Web > PHP Web Site** ينشئ موقعًا، و**Ctrl+F5** يشغّله في **Preview**.
- نافذة **Requests** تُظهر كل طلب ورمز حالته.
- `<?= ... ?>` يطبع قيمة داخل HTML، و`<?php ... ?>` لكتلة كود.
- المتصفح لا يرى PHP أبدًا، بل يرى HTML الناتج.

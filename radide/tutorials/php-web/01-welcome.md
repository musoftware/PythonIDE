# الدرس 1: مرحبًا بك في PHP - كيف يعمل الويب؟

**في هذا الدرس ستتعلم:**

- ماذا يحدث عندما تكتب عنوان موقع في المتصفح.
- ما دور لغة PHP، ولماذا نقول إنها تعمل «على الخادم».
- أين تجد PHP في RAD IDE، وكيف تشغّل أول برنامج لك.
- قواعد الكتابة الأساسية: الوسم `<?php`، والأمر `echo`، والفاصلة المنقوطة `;`، والتعليقات.

## المتصفح والخادم: زبون ومطعم

تخيّل أنك في مطعم:

- **أنت (الزبون)** = **المتصفح** (Chrome أو Edge...).
- **النادل** يأخذ طلبك ويوصله إلى المطبخ = **طلب HTTP** (Request).
- **المطبخ** يطبخ الطبق حسب طلبك = **الخادم** (Server) الذي تعمل عليه PHP.
- **الطبق الجاهز** الذي يصل إلى طاولتك = **صفحة HTML** (Response).

الزبون لا يرى المطبخ ولا الوصفة، يرى الطبق فقط. وكذلك المتصفح: لا يرى كود PHP أبدًا، بل يرى **النتيجة** التي أنتجها الكود، وهي صفحة HTML عادية.

```text
المتصفح  --- طلب: أعطني /index.php --->  الخادم (PHP تنفّذ الكود)
المتصفح  <--- رد: صفحة HTML جاهزة -----  الخادم
```

> **لماذا هذا مهم؟** لأن PHP تستطيع أن تصنع صفحة **مختلفة لكل زائر**: اسمه، وسلة مشترياته، ونتائج بحثه... كلها تُحسب على الخادم ثم تُرسل كـ HTML.

## ما هي PHP؟

**PHP** لغة برمجة صُممت خصيصًا للويب، وتعمل عليها ملايين المواقع (منها ووردبريس). مميزاتها للمبتدئ:

- سهلة البداية: سطر واحد يكفي لترى نتيجة.
- تُكتب **داخل** ملفات HTML مباشرة.
- معها كل ما يحتاجه الموقع: النماذج، والجلسات، وقواعد البيانات.
- عليها أُطر عمل قوية مثل **Laravel** و**CodeIgniter** (لكل منهما دليل خاص في هذه الدروس).

## PHP في RAD IDE

لا تحتاج إلى تثبيت شيء بنفسك: الـ IDE تحمل نسخة PHP محمولة (PHP 8.4) في مجلد الأدوات الخاص بها. ولمعرفة النسخ الموجودة أو تثبيت نسخة أحدث:

- **Tools > PHP Versions...** (أدوات > إصدارات PHP...): تعرض كل نسخ PHP الموجودة على جهازك، وزر لتثبيت PHP 8.x.

في هذه الدورة نعمل بطريقتين:

1. **برامج سطر الأوامر** (أمثلة `PHP`): تُشغَّل وتظهر نتيجتها في نافذة **Output** (المخرجات). نستخدمها لتعلّم أساسيات اللغة بسرعة.
2. **صفحات الويب** (أمثلة `PHP (صفحة ويب)`): تُفتح كمشروع **PHP Web Site** وتظهر في نافذة **Preview** (معاينة) داخل الـ IDE، كما يراها الزائر في المتصفح.

اضغط **«جرّبه»** فوق أي مثال: تنشئ الـ IDE مشروعًا صغيرًا وتشغّله لك.

## برنامجك الأول

```php run
<?php
echo "السلام عليكم يا عالم الويب!\n";
echo "هذا أول برنامج لي بلغة PHP\n";
```

```text output
السلام عليكم يا عالم الويب!
هذا أول برنامج لي بلغة PHP
```

لنفهمه سطرًا سطرًا:

- `<?php` **وسم البداية**: يقول «من هنا يبدأ كود PHP». كل ملف PHP يبدأ به.
- `echo` أمر **الطباعة**: يخرج النص. في صفحة الويب يذهب النص إلى المتصفح، وفي سطر الأوامر يظهر في نافذة المخرجات.
- النص بين علامتي تنصيص `"..."` يسمى **سلسلة نصية** (string).
- `\n` معناها «انزل سطرًا جديدًا».
- `;` **الفاصلة المنقوطة** تنهي كل تعليمة، مثل النقطة في آخر الجملة.

> **ملاحظة:** في الملف الذي فيه كود PHP فقط، لا نكتب وسم النهاية `?>` في آخره. هذه عادة يوصي بها المحترفون لتجنّب مسافات زائدة تُطبع بالخطأ.

## الأرقام والعمليات

`echo` تطبع الأرقام أيضًا، وتستطيع أن تحسب:

```php run
<?php
echo 7 + 3;
echo "\n";
echo 10 * 4, "\n";
echo "النتيجة: ", 100 / 4, "\n";
```

```text output
10
40
النتيجة: 25
```

لاحظ أن `echo` تقبل **عدة قيم** بينها فواصل `,` فتطبعها متتالية.

## التعليقات

التعليق كلام للمبرمج، وPHP **تتجاهله** تمامًا:

```php run
<?php
// تعليق من سطر واحد
# وهذا أيضًا تعليق من سطر واحد

/*
   تعليق
   من عدة أسطر
*/

echo "التعليقات لا تظهر في الناتج\n"; // تعليق في آخر السطر
// echo "هذا السطر معطّل\n";
```

```text output
التعليقات لا تظهر في الناتج
```

## علامتا التنصيص: المفردة والمزدوجة

في PHP نوعان من علامات التنصيص، والفرق بينهما مهم:

- **المزدوجة** `"..."` تفهم الرموز الخاصة مثل `\n`.
- **المفردة** `'...'` تطبع النص كما هو حرفيًا.

```php run
<?php
echo "سطر\tبعد مسافة جدولة\n";
echo 'سطر\tبدون تفسير';
echo "\n";
```

```text output
سطر	بعد مسافة جدولة
سطر\tبدون تفسير
```

## أخطاء شائعة

- **نسيان الفاصلة المنقوطة:** `echo "مرحبا"` ثم سطر آخر يعطي خطأ `Parse error: syntax error`. أضف `;` في آخر كل تعليمة.
- **نسيان `<?php`:** بدونه يُطبع الكود نفسه كنص عادي بدل أن يُنفّذ!
- **علامات تنصيص غير متطابقة:** `"مرحبا'` خطأ. ابدأ وانتهِ بنفس النوع.
- **استخدام `\n` داخل علامات مفردة:** `'مرحبا\n'` تطبع الحرفين `\n` حرفيًا.

## تمارين

### تمرين 1: بطاقة تعريف

اطبع ثلاثة أسطر: `الاسم: منى` ثم `المدينة: القاهرة` ثم `اللغة: PHP`.

```php exercise
<?php
echo "الاسم: منى\n";
// أكمل السطرين الباقيين
```

```php solution
<?php
echo "الاسم: منى\n";
echo "المدينة: القاهرة\n";
echo "اللغة: PHP\n";
```

```text output
الاسم: منى
المدينة: القاهرة
اللغة: PHP
```

### تمرين 2: آلة حاسبة صغيرة

اطبع ناتج `12 + 8` ثم `12 - 8` ثم `12 * 8` كل واحد في سطر بالشكل `12 + 8 = 20`، واجعل PHP تحسب النواتج بنفسها.

```php exercise
<?php
echo "12 + 8 = ", 12 + 8, "\n";
// أكمل
```

```php solution
<?php
echo "12 + 8 = ", 12 + 8, "\n";
echo "12 - 8 = ", 12 - 8, "\n";
echo "12 * 8 = ", 12 * 8, "\n";
```

```text output
12 + 8 = 20
12 - 8 = 4
12 * 8 = 96
```

## الخلاصة

- المتصفح يطلب، والخادم ينفّذ PHP ويرد بصفحة HTML.
- كل ملف PHP يبدأ بـ `<?php`، وكل تعليمة تنتهي بـ `;`.
- `echo` تطبع النصوص والأرقام، و`"\n"` سطر جديد.
- في الدرس القادم نصنع **أول صفحة ويب** حقيقية ونراها في نافذة المعاينة.

# الدرس 4: العمليات والشروط

**في هذا الدرس ستتعلم:**

- عمليات المقارنة، والفرق المهم بين `==` و`===`.
- العمليات المنطقية `&&` و`||` و`!`.
- اتخاذ القرار بـ `if` و`elseif` و`else`.
- التعبير `match` الحديث، والعامل `??` للقيم الناقصة.
- الشروط داخل صفحات HTML.

## المقارنات: أسئلة جوابها نعم أو لا

كل مقارنة تُرجع `true` (صح) أو `false` (خطأ):

| العامل | معناه | مثال | النتيجة |
|---|---|---|---|
| `==` | يساوي في القيمة | `5 == "5"` | `true` |
| `===` | يساوي في القيمة **والنوع** | `5 === "5"` | `false` |
| `!=` | لا يساوي | `3 != 4` | `true` |
| `!==` | لا يساوي في القيمة أو النوع | `5 !== "5"` | `true` |
| `<` و`>` | أصغر، أكبر | `2 < 9` | `true` |
| `<=` و`>=` | أصغر أو يساوي، أكبر أو يساوي | `7 >= 7` | `true` |

```php run
<?php
var_dump(5 == "5");
var_dump(5 === "5");
var_dump(0 == "");
var_dump(null === null);
var_dump(10 <=> 20);
```

```text output
bool(true)
bool(false)
bool(false)
bool(true)
int(-1)
```

> **قاعدة ذهبية:** استخدم `===` و`!==` في الغالب. المقارنة الصارمة لا تحوّل الأنواع من وراء ظهرك، فتتجنب مفاجآت كثيرة. والعامل `<=>` (سفينة الفضاء) يُرجع `-1` أو `0` أو `1`، وسنحتاجه في الترتيب.

## `if` و `elseif` و `else`

`if` مثل **حارس البوابة**: يفحص الشرط، فإن كان صحيحًا نفّذ ما بين القوسين `{ }`:

```php run
<?php
$degree = 76;

if ($degree >= 90) {
    echo "ممتاز\n";
} elseif ($degree >= 75) {
    echo "جيد جدًا\n";
} elseif ($degree >= 50) {
    echo "ناجح\n";
} else {
    echo "راسب\n";
}
```

```text output
جيد جدًا
```

PHP تفحص الشروط **بالترتيب من الأعلى**، وتنفّذ أول فرع صحيح فقط ثم تتجاوز الباقي.

## الشروط المركبة

- `&&` تعني **و**: الشرط كله صحيح عندما يكون الطرفان صحيحين.
- `||` تعني **أو**: صحيح عندما يكون أحد الطرفين صحيحًا على الأقل.
- `!` تعني **ليس**: تقلب الشرط، فالصحيح يصبح خطأ والعكس.

```php run
<?php
$age = 20;
$hasTicket = true;
$isVip = false;

if ($age >= 18 && $hasTicket) {
    echo "تفضل بالدخول\n";
}
if ($isVip || $age > 60) {
    echo "مقعد مميز\n";
} else {
    echo "مقعد عادي\n";
}
if (!$isVip) {
    echo "لست من كبار الزوار\n";
}
```

```text output
تفضل بالدخول
مقعد عادي
لست من كبار الزوار
```

## `match`: اختيار من قائمة

عندما نقارن قيمة واحدة بعدة احتمالات، فإن `match` (منذ PHP 8) أنظف من سلسلة `if` طويلة. هي **تعبير** يُرجع قيمة، ويقارن بـ `===`:

```php run
<?php
$day = 5;
$name = match ($day) {
    1 => "السبت",
    2 => "الأحد",
    3, 4, 5 => "منتصف الأسبوع",
    6 => "الخميس",
    7 => "الجمعة",
    default => "يوم غير معروف",
};
echo $name, "\n";

$degree = 64;
$grade = match (true) {
    $degree >= 85 => "A",
    $degree >= 65 => "B",
    $degree >= 50 => "C",
    default => "F",
};
echo "التقدير: $grade\n";
```

```text output
منتصف الأسبوع
التقدير: C
```

الحيلة `match (true)` تجعل كل فرع شرطًا مستقلًا. وتوجد أيضًا جملة `switch` القديمة، لكن `match` أوضح وأأمن لأنها لا تحتاج `break`.

## العامل ?? : قيمة بديلة

كثيرًا ما تكون قيمة **غير موجودة** (مثل حقل لم يرسله الزائر). العامل `??` يقول: «خذ هذه القيمة إن كانت موجودة وليست `null`، وإلا فخذ البديل»:

```php run
<?php
$nickname = null;
echo $nickname ?? "زائر", "\n";

$city = "طنطا";
echo $city ?? "غير محددة", "\n";

$stock = 0;
echo $stock > 0 ? "متوفر" : "نفد من المخزن", "\n";
```

```text output
زائر
طنطا
نفد من المخزن
```

والسطر الأخير فيه **العامل الثلاثي** `شرط ? قيمة1 : قيمة2`: اختصار لـ `if/else` صغير يُرجع قيمة.

## الشروط داخل HTML

في صفحات الويب نستخدم كثيرًا **الصيغة البديلة** `if (...):` و`endif;` لأنها أوضح وسط HTML:

<!-- test: {"requests": [{"path": "/?items=3"}]} -->
```php web run
<?php
$items = (int) ($_GET['items'] ?? 0);
?>
<?php if ($items === 0): ?>
<p>سلتك فارغة.</p>
<?php elseif ($items === 1): ?>
<p>في سلتك منتج واحد.</p>
<?php else: ?>
<p>في سلتك <?= $items ?> منتجات.</p>
<?php endif; ?>
```

عند فتح الصفحة بالعنوان `/?items=3` يصل للمتصفح:

```text output
<p>في سلتك 3 منتجات.</p>
```

`$_GET['items']` هي القيمة المكتوبة في **عنوان الصفحة** بعد علامة `?`. جرّب في المعاينة أن تكتب في شريط العنوان `?items=0` ثم `?items=1`. سنتعمق في هذا في درس النماذج.

## أخطاء شائعة

- **`=` بدل `==` في الشرط:** `if ($x = 5)` لا تقارن، بل **تضع** 5 في `$x` فيصبح الشرط صحيحًا دائمًا!
- **الاعتماد على `==` مع أنواع مختلفة:** `"abc" == 0` كانت `true` في PHP 7 وأصبحت `false` في PHP 8. استخدم `===` وارتح.
- **نسيان `default` في `match`:** إذا لم يطابق أي فرع تحدث مشكلة `UnhandledMatchError`.
- **نسيان `endif;`** في الصيغة البديلة يعطي `Parse error` في آخر الملف.

## تمارين

### تمرين 1: زوجي أم فردي؟

استخدم باقي القسمة `%` لتطبع `13 عدد فردي`.

```php exercise
<?php
$n = 13;
// if ($n % 2 === 0) ...
```

```php solution
<?php
$n = 13;
if ($n % 2 === 0) {
    echo "$n عدد زوجي\n";
} else {
    echo "$n عدد فردي\n";
}
```

```text output
13 عدد فردي
```

### تمرين 2: سعر التذكرة

التذكرة بـ `100` جنيه، والأطفال أقل من 12 سنة أو الكبار 60 سنة فأكثر يدفعون النصف. اطبع سعر التذكرة لعمر `65`.

```php exercise
<?php
$age = 65;
$price = 100;
```

```php solution
<?php
$age = 65;
$price = 100;
if ($age < 12 || $age >= 60) {
    $price = $price / 2;
}
echo "سعر التذكرة: $price جنيه\n";
```

```text output
سعر التذكرة: 50 جنيه
```

### تمرين 3: فصول السنة بـ `match`

حوّل رقم الشهر إلى اسم الفصل: 12 و1 و2 شتاء، 3 و4 و5 ربيع، 6 و7 و8 صيف، 9 و10 و11 خريف. اطبع فصل الشهر `7`.

```php exercise
<?php
$month = 7;
$season = match ($month) {
    12, 1, 2 => "الشتاء",
    // أكمل
};
echo $season, "\n";
```

```php solution
<?php
$month = 7;
$season = match ($month) {
    12, 1, 2 => "الشتاء",
    3, 4, 5 => "الربيع",
    6, 7, 8 => "الصيف",
    9, 10, 11 => "الخريف",
    default => "شهر غير صحيح",
};
echo $season, "\n";
```

```text output
الصيف
```

## الخلاصة

- قارن بـ `===` و`!==`، واجمع الشروط بـ `&&` و`||` و`!`.
- `if / elseif / else` تنفّذ أول فرع صحيح.
- `match` تختار قيمة من قائمة احتمالات بمقارنة صارمة.
- `??` يعطي قيمة بديلة للقيم الناقصة، والصيغة `if: ... endif;` مريحة داخل HTML.

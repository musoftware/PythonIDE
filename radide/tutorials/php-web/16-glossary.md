# الدرس 16: قاموس المصطلحات (إنجليزي - عربي)

مرجع سريع لكل المصطلحات التي مرت بك في الدورة، مرتبة حسب الموضوع. ارجع إليه كلما قابلت كلمة لا تتذكرها. (المصطلحات العامة مثل **متغير** و**حلقة تكرار** و**دالة** هي نفسها في دورتي BASIC و C++.)

## الويب

| English | العربية | شرح مختصر |
|---|---|---|
| Client / Browser | العميل / المتصفح | البرنامج الذي يطلب الصفحات ويعرضها |
| Server | الخادم | الجهاز الذي ينفّذ PHP ويرد بالصفحات |
| Request / Response | الطلب / الرد | رسالة المتصفح للخادم، ورد الخادم عليها |
| HTTP method (GET, POST) | طريقة الطلب | GET للقراءة والبحث، POST لإرسال بيانات تغيّر شيئًا |
| Status code | رمز الحالة | `200` نجاح، `302` تحويل، `404` غير موجود، `500` خطأ في الخادم |
| URL / Query string | العنوان / سلسلة الاستعلام | الجزء بعد `?` مثل `?q=php` ويُقرأ من `$_GET` |
| Header | ترويسة | معلومات مرافقة للطلب أو الرد، مثل `Location` و`Content-Type` |
| Redirect | تحويل | رد يطلب من المتصفح فتح صفحة أخرى |
| Web root / Document root | جذر الموقع | المجلد الذي يستطيع الزائر الوصول إليه (مثل `public`) |
| Start page | صفحة البدء | أول صفحة تفتح عند تشغيل الموقع |
| JSON | جيسون | صيغة نصية لتبادل البيانات بين البرامج |
| API | واجهة برمجية | صفحات ترد ببيانات (JSON) لبرامج أخرى لا لأشخاص |

## لغة PHP

| English | العربية | شرح مختصر |
|---|---|---|
| Variable | متغير | صندوق له اسم يبدأ بـ `$` يحفظ قيمة |
| Constant | ثابت | قيمة لا تتغير: `const TAX = 0.14;` |
| Data type | نوع البيانات | `string`، `int`، `float`، `bool`، `null`، `array` |
| String | سلسلة نصية | نص بين علامات تنصيص |
| Concatenation | ربط النصوص | بالنقطة `.` |
| Interpolation | إدراج المتغيرات في النص | `"أهلًا {$name}"` داخل علامات مزدوجة |
| Operator | عامل | `+` و`===` و`&&` و`??` ... |
| Condition | شرط | `if` و`elseif` و`else` و`match` |
| Loop | حلقة تكرار | `for` و`while` و`do ... while` و`foreach` |
| Array (indexed / associative) | مصفوفة (مرقّمة / ترابطية) | قائمة قيم بأرقام أو بمفاتيح أسماء |
| Key / Value | مفتاح / قيمة | `"name" => "سارة"` |
| Function | دالة | كود له اسم يُستدعى بمعاملات ويُرجع قيمة |
| Parameter / Argument | معامل / وسيط | المتغير في تعريف الدالة / القيمة الممررة عند الاستدعاء |
| Return value | القيمة المرجعة | ما تُرجعه الدالة بـ `return` |
| Arrow function | دالة سهمية | `fn($x) => $x * 2` |
| Scope | نطاق المتغير | المكان الذي يُرى فيه المتغير |
| Class / Object | صنف / كائن | القالب / النسخة المصنوعة منه بـ `new` |
| Property / Method | خاصية / دالة الصنف | بيان الكائن / سلوكه |
| Constructor | المُنشئ | `__construct` يُستدعى مع `new` |
| Inheritance | الوراثة | `class Admin extends User` |
| Encapsulation | التغليف | إخفاء البيانات بـ `private` وإتاحتها بدوال |
| Exception | استثناء | خطأ يُرمى بـ `throw` ويُلتقط بـ `try / catch` |
| include / require | تضمين | إدراج ملف داخل آخر |

## النماذج والجلسات والأمان

| English | العربية | شرح مختصر |
|---|---|---|
| Form | نموذج | حقول يملؤها الزائر ويرسلها |
| Validation | التحقق من المدخلات | فحص البيانات على الخادم قبل استخدامها |
| Sticky form | نموذج لاصق | يعيد عرض ما كتبه الزائر بعد الخطأ |
| Session | جلسة | بيانات الزائر على الخادم (`$_SESSION`) |
| Cookie | كوكي (ملف تعريف ارتباط) | قيمة صغيرة يحفظها المتصفح (`$_COOKIE`) |
| Flash message | رسالة فلاش | رسالة تُعرض مرة واحدة بعد التحويل |
| PRG (Post/Redirect/Get) | نمط إرسال ثم تحويل ثم عرض | يمنع إعادة إرسال النموذج عند التحديث |
| Hash (password) | بصمة كلمة المرور | `password_hash` و`password_verify` |
| XSS | حقن السكربتات | يُمنع بـ `htmlspecialchars` عند الطباعة |
| SQL Injection | حقن SQL | يُمنع بالاستعلامات المُجهّزة |
| CSRF | تزوير الطلبات | يُمنع برمز سري في كل نموذج POST |
| Whitelist | قائمة مسموحة | قبول قيم معروفة فقط (مثل أسماء أعمدة الترتيب) |

## قواعد البيانات

| English | العربية | شرح مختصر |
|---|---|---|
| Database | قاعدة بيانات | تخزين دائم ومنظم للبيانات |
| Table / Row / Column | جدول / صف / عمود | ورقة البيانات / سجل واحد / خاصية |
| Primary key | المفتاح الأساسي | رقم فريد لكل صف (عادة `id`) |
| SQL | لغة الاستعلامات | `SELECT` و`INSERT` و`UPDATE` و`DELETE` |
| Query | استعلام | أمر SQL يُرسل لقاعدة البيانات |
| Prepared statement | استعلام مُجهّز | `prepare` ثم `execute` مع القيم منفصلة |
| Placeholder | علامة مكان | `?` أو `:name` داخل الاستعلام المُجهّز |
| CRUD | العمليات الأربع | إنشاء، قراءة، تعديل، حذف |
| SQLite | SQLite | قاعدة بيانات كاملة في ملف واحد |
| PDO | PDO | طبقة PHP الموحدة للاتصال بقواعد البيانات |

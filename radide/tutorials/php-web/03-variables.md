# الدرس 3: المتغيرات وأنواع البيانات

**في هذا الدرس ستتعلم:**

- ما هو **المتغير**، وكيف نكتبه في PHP بعلامة `$`.
- أنواع البيانات: النصوص، والأعداد الصحيحة والعشرية، والقيم المنطقية، و`null`.
- ربط النصوص بالنقطة `.`، ووضع المتغيرات داخل النص.
- معرفة نوع القيمة بـ `var_dump` و`gettype`، والتحويل بين الأنواع.
- الثوابت `const`.

## المتغير صندوق له اسم

**المتغير** (variable) مثل صندوق عليه ملصق باسمه، نضع فيه قيمة ثم نستخدمها أو نغيّرها لاحقًا. في PHP يبدأ اسم كل متغير بعلامة الدولار `$`:

```php run
<?php
$name = "سارة";
$age = 22;
echo "الاسم: " . $name . "\n";
echo "العمر: " . $age . "\n";

$age = 23;            // غيّرنا محتوى الصندوق
echo "العمر بعد سنة: " . $age . "\n";
```

```text output
الاسم: سارة
العمر: 22
العمر بعد سنة: 23
```

- العلامة `=` تعني **«ضع في»** (إسناد)، وليست «يساوي» كما في الرياضيات.
- النقطة `.` **تربط** النصوص ببعضها (في لغات أخرى تُستخدم `+` أو `&`).

**قواعد الأسماء:** تبدأ بـ `$` ثم حرف أو `_`، وبعدها حروف وأرقام و`_`. والأسماء **حساسة لحالة الأحرف**: `$name` و`$Name` متغيران مختلفان. اختر أسماء واضحة بالإنجليزية مثل `$totalPrice` بدل `$x`.

## أنواع البيانات الأساسية

| النوع | الاسم في PHP | أمثلة |
|---|---|---|
| نص | `string` | `"مرحبا"`، `'PHP'` |
| عدد صحيح | `int` | `42`، `-7`، `0` |
| عدد عشري | `float` | `3.14`، `0.5` |
| منطقي | `bool` | `true`، `false` |
| لا شيء | `null` | `null` |

PHP لغة **ديناميكية**: لا تكتب نوع المتغير عند إنشائه، بل تستنتجه من القيمة. ولمعرفة النوع نستخدم `var_dump` (للمبرمج: تطبع النوع والقيمة) أو `gettype`:

```php run
<?php
$title = "PHP";
$pages = 300;
$price = 99.5;
$available = true;
$discount = null;

var_dump($title);
var_dump($pages);
var_dump($price);
var_dump($available);
var_dump($discount);
echo gettype($pages), "\n";
```

```text output
string(3) "PHP"
int(300)
float(99.5)
bool(true)
NULL
integer
```

> **لاحظ:** `string(3)` تعني أن النص طوله 3 **بايت**. الحروف العربية تأخذ 2 بايت لكل حرف في ترميز UTF-8، فـ `var_dump("سارة")` تطبع `string(8)`. سنعرف في درس النصوص كيف نعدّ الحروف العربية بشكل صحيح.

## المتغيرات داخل النص

داخل علامات التنصيص **المزدوجة** تستطيع وضع المتغير مباشرة، فتستبدله PHP بقيمته. وهذا أريح من النقاط الكثيرة:

```php run
<?php
$city = "الإسكندرية";
$temp = 28;
echo "الطقس في $city اليوم $temp درجة\n";
echo "الطقس في {$city} اليوم {$temp} درجة\n";
echo 'بعلامات مفردة: $city لا تُستبدل', "\n";
```

```text output
الطقس في الإسكندرية اليوم 28 درجة
الطقس في الإسكندرية اليوم 28 درجة
بعلامات مفردة: $city لا تُستبدل
```

الأقواس المعقوصة `{$city}` اختيارية هنا، لكنها تمنع الالتباس عندما يلتصق المتغير بحروف أخرى، وهي ضرورية مع عناصر المصفوفات والكائنات (سنراها لاحقًا). عوّد نفسك عليها.

## العمليات الحسابية

```php run
<?php
$a = 17;
$b = 5;
echo "الجمع: " . ($a + $b) . "\n";
echo "الطرح: " . ($a - $b) . "\n";
echo "الضرب: " . ($a * $b) . "\n";
echo "القسمة: " . ($a / $b) . "\n";
echo "القسمة الصحيحة: " . intdiv($a, $b) . "\n";
echo "باقي القسمة: " . ($a % $b) . "\n";
echo "الأُس: " . (2 ** 10) . "\n";
```

```text output
الجمع: 22
الطرح: 12
الضرب: 85
القسمة: 3.4
القسمة الصحيحة: 3
باقي القسمة: 2
الأُس: 1024
```

> **مهم:** ضع العملية الحسابية بين **أقواس** عند ربطها بنص. بدونها قد تحصل على نتيجة غريبة أو خطأ، لأن PHP تحتاج أن تعرف ماذا تحسب أولًا.

وهناك اختصارات للتعديل على المتغير نفسه:

```php run
<?php
$score = 10;
$score += 5;     // نفس $score = $score + 5
$score *= 2;     // نفس $score = $score * 2
$score--;        // ينقص 1
$msg = "النقاط";
$msg .= ": " . $score;   // يلصق في آخر النص
echo $msg, "\n";
```

```text output
النقاط: 29
```

## التحويل بين الأنواع

البيانات القادمة من الزائر (من النماذج) تصل دائمًا **نصوصًا**. لذلك نحتاج كثيرًا إلى تحويلها لأرقام:

```php run
<?php
$input = "25";            // نص، كما يصل من نموذج
$n = (int) $input;        // تحويل صريح إلى عدد صحيح
var_dump($n);
var_dump((float) "3.75");
var_dump((string) 100);
var_dump((bool) 0);
var_dump(intval("12abc"));
var_dump(is_numeric("12abc"), is_numeric("12.5"));
```

```text output
int(25)
float(3.75)
string(3) "100"
bool(false)
int(12)
bool(false)
bool(true)
```

- `(int)` و`(float)` و`(string)` و`(bool)` تحويلات صريحة.
- `is_numeric` تخبرك هل النص رقم صحيح الشكل؛ استخدمها **للتحقق** قبل التحويل.

## الثوابت

**الثابت** (constant) قيمة لا تتغير طوال البرنامج، ونكتبه بدون `$` وبحروف كبيرة عادةً:

```php run
<?php
const SITE_NAME = "متجر الأمل";
const TAX_RATE = 0.14;

$price = 200;
echo SITE_NAME, "\n";
echo "الضريبة: ", $price * TAX_RATE, "\n";
echo "نسخة PHP الرئيسية: ", PHP_MAJOR_VERSION, "\n";
```

```text output
متجر الأمل
الضريبة: 28
نسخة PHP الرئيسية: 8
```

`PHP_MAJOR_VERSION` ثابت جاهز في اللغة نفسها.

## أخطاء شائعة

- **نسيان `$`:** كتابة `name = "علي";` خطأ صياغة. كل متغير يبدأ بـ `$`.
- **متغير غير معرّف:** استخدام `$total` قبل إعطائه قيمة يظهر تحذير `Warning: Undefined variable $total`.
- **الخلط بين `.` و`+`:** `"العمر: " + 5` تعطي خطأ `TypeError` في PHP 8، لأن `+` للأرقام فقط. اربط النصوص بالنقطة.
- **اختلاف حالة الأحرف:** `$Total` ليس هو `$total`.

## تمارين

### تمرين 1: فاتورة بسيطة

لدينا سعر القطعة `45` والكمية `3`. احسب الإجمالي واطبع: `الإجمالي: 135 جنيه`.

```php exercise
<?php
$price = 45;
$qty = 3;
// احسب $total ثم اطبعه
```

```php solution
<?php
$price = 45;
$qty = 3;
$total = $price * $qty;
echo "الإجمالي: {$total} جنيه\n";
```

```text output
الإجمالي: 135 جنيه
```

### تمرين 2: من الدقائق إلى الساعات

حوّل `135` دقيقة إلى ساعات ودقائق باستخدام `intdiv` و`%`، واطبع: `2 ساعة و 15 دقيقة`.

```php exercise
<?php
$minutes = 135;
```

```php solution
<?php
$minutes = 135;
$h = intdiv($minutes, 60);
$m = $minutes % 60;
echo "$h ساعة و $m دقيقة\n";
```

```text output
2 ساعة و 15 دقيقة
```

### تمرين 3: نوع كل قيمة

اطبع نوع كل من القيم `"10"` و`10` و`10.0` و`false` باستخدام `gettype`، كل نوع في سطر.

```php exercise
<?php
echo gettype("10"), "\n";
```

```php solution
<?php
echo gettype("10"), "\n";
echo gettype(10), "\n";
echo gettype(10.0), "\n";
echo gettype(false), "\n";
```

```text output
string
integer
double
boolean
```

> `gettype` تسمّي النوع العشري `double` لأسباب تاريخية، وهو نفسه `float`.

## الخلاصة

- المتغير يبدأ بـ `$`، و`=` للإسناد، و`.` لربط النصوص.
- الأنواع: `string` و`int` و`float` و`bool` و`null`، و`var_dump` يكشف النوع.
- داخل `"..."` تُستبدل المتغيرات بقيمها، وداخل `'...'` لا.
- بيانات الزائر نصوص؛ تحقق منها بـ `is_numeric` ثم حوّلها.

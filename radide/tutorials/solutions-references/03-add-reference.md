# الدرس 3: إضافة مرجع وملفات الوكيل

**في هذا الدرس ستتعلم:**

- فتح نافذة **Reference Manager** وتبويباتها الثلاثة.
- ما **ملف الوكيل** (proxy) الذي تكتبه البيئة في مشروعك، ولماذا لا تعدّله.
- متى تُحدَّث المراجع، وأمر **Refresh References**.
- لماذا لا يُسمح بالمراجع **الدائرية**.

## فتح نافذة المراجع

لمشروع `App` الذي يريد استخدام المكتبة `PriceLib`:

- بالزر الأيمن على `App` في Solution Explorer > **Add > Reference...** (إضافة > مرجع...)، أو
- بالزر الأيمن على عقدة **References** تحت `App` > **Add Reference...**، أو
- **Project > Add Reference...** (مشروع > إضافة مرجع...).

تفتح نافذة **Reference Manager - App** بثلاثة تبويبات:

| التبويب | بالعربية | ماذا فيه |
|---|---|---|
| Projects | المشروعات | مشاريع الحل التي يستطيع `App` استخدامها. ضع علامة على `PriceLib` |
| Packages | الحزم | مكتبات مدير الحزم للغة المشروع (pip لـ Python، NuGet لـ C# ...) عبر **Manage Packages...** |
| Browse | استعراض | مشروع RAD IDE موجود خارج الحل: **Add to Solution and Reference** يضيفه إلى الحل ويربطه |

اضغط **OK**. تظهر `PriceLib` تحت **References** في شجرة `App`.

## ماذا حدث في الخلفية؟ ملف الوكيل

البيئة كتبت في مجلد `App` ملفًا جديدًا اسمه `PriceLib.py`. هذا الملف **وكيل** (proxy): فيه دالة Python لكل دالة عامة في المكتبة، بنفس الاسم والمعاملات، وكل دالة منها **تمرر الاستدعاء** إلى المكتبة الحقيقية:

```python
# AUTO-GENERATED by RAD IDE (reference to PriceLib) - do not edit, regenerated on build
"""PriceLib - reference to the PriceLib project of the solution.

    import PriceLib
    PriceLib.<function>(...)

The functions run in the library's own language; calls go through RAD Hub.
"""
...
def Discount(price, percent):
    """Price after a discount percent.  [PriceLib: PriceLib.Discount(price, percent)]"""
    return _radcall('PriceLib.Discount', price, percent)
```

> **تشبيه:** الوكيل مثل **موظف الاستقبال** في شركة. أنت تكلمه بلغتك، وهو ينقل طلبك إلى القسم المختص (المكتبة بلغتها) ويرجع لك بالرد. أنت لا تحتاج أن تعرف لغة القسم.

لهذا تكتب في `App` ببساطة:

```python
import PriceLib
print(PriceLib.Discount(200, 15))
```

لاحظ أن التعليق التوثيقي (`/// <summary>` في C#) انتقل إلى الوكيل، فيظهر لك في الإكمال التلقائي (IntelliSense) وعند المرور بالفأرة.

## لا تعدّل ملف الوكيل

أول سطر في الملف: «AUTO-GENERATED ... do not edit, regenerated on build». أي تعديل تكتبه فيه **سيضيع** عند التحديث التالي. وكل لغة لها شكل وكيل خاص بها: `PriceLib.py` في Python، و`PriceLib.ref.cs` في C#، و`PriceLib.ref.java` في Java ... ولرؤيته: بالزر الأيمن على المرجع تحت **References** > **View (generated)**.

والبيئة تتذكر أي ملفات وكيل كتبت، في ملف المشروع `project.radproj`:

```text
"references": ["PriceLib"],
"reference_files": {"PriceLib": ["PriceLib.py"]}
```

حتى تحذفها إذا أزلت المرجع أو تغيرت دوال المكتبة.

## متى يُحدَّث الوكيل؟

- عند **حفظ** المكتبة: المشاريع التي تستخدمها ترى دوالها الجديدة.
- قبل كل **تشغيل** (`F5`) و**بناء** (**Build > Build Solution**).
- يدويًا: **Build > Refresh References** (بناء > تحديث المراجع)، أو بالزر الأيمن على **References** > **Refresh References**.

ولإزالة مرجع: بالزر الأيمن عليه > **Remove** (إزالة)، فيُحذف ملف الوكيل.

## المراجع الدائرية ممنوعة

إذا كان `App` يستخدم `PriceLib`، فلا يمكن أن يستخدم `PriceLib` المشروع `App`. هذا اسمه **مرجع دائري** (circular reference)، والبيئة ترفضه برسالة واضحة: «PriceLib cannot reference App: App already references PriceLib (circular reference)». ولا يمكن أيضًا أن يستخدم مشروع نفسه.

هذا مثال يكتشف المرجع الدائري قبل إضافته، بالبحث في المراجع خطوة خطوة:

```python run
refs = {"App": ["PriceLib"], "PriceLib": ["TaxLib"], "TaxLib": []}

def reaches(start, target):
    """هل يصل start إلى target عبر المراجع؟"""
    todo, seen = [start], set()
    while todo:
        p = todo.pop()
        if p == target:
            return True
        if p not in seen:
            seen.add(p)
            todo.extend(refs.get(p, []))
    return False

def would_create_cycle(project, lib):
    return project == lib or reaches(lib, project)

print("TaxLib -> App:", "دائري" if would_create_cycle("TaxLib", "App") else "مسموح")
print("App -> TaxLib:", "دائري" if would_create_cycle("App", "TaxLib") else "مسموح")
print("App -> App:", "دائري" if would_create_cycle("App", "App") else "مسموح")
```

```text output
TaxLib -> App: دائري
App -> TaxLib: مسموح
App -> App: دائري
```

## أخطاء شائعة

- **تعديل ملف الوكيل:** يضيع التعديل. عدّل المكتبة نفسها.
- **دالة جديدة لا تظهر:** احفظ المكتبة، أو استخدم **Refresh References**.
- **مرجع دائري:** أعد تنظيم المشاريع: انقل الجزء المشترك إلى مكتبة ثالثة يستخدمها الاثنان.
- **حذف ملف الوكيل يدويًا:** سيُكتب من جديد عند التحديث التالي، فلا فائدة. أزل المرجع بـ **Remove**.

```python solution
refs = {"Web": ["Core"], "Core": ["Utils"], "Utils": [], "Desktop": ["Core"]}
requests = [("Utils", "Web"), ("Desktop", "Utils"), ("Core", "Desktop")]

def reaches(start, target):
    todo, seen = [start], set()
    while todo:
        p = todo.pop()
        if p == target:
            return True
        if p not in seen:
            seen.add(p)
            todo.extend(refs.get(p, []))
    return False

for project, lib in requests:
    cycle = project == lib or reaches(lib, project)
    print(project, "->", lib, ":", "دائري" if cycle else "مسموح")
```

## الخلاصة

- **Add > Reference...** يفتح **Reference Manager**: Projects وPackages وBrowse.
- البيئة تكتب **ملف وكيل** بلغة مشروعك، فتستدعي المكتبة كأنها منها.
- لا تعدّل الوكيل، و**Refresh References** يحدّثه.
- المراجع الدائرية ممنوعة.

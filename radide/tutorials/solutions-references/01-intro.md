# الدرس 1: ما الحل (Solution)؟ ولماذا عدة لغات؟

**في هذا الدرس ستتعرف على:**

- الفرق بين **المشروع** (Project) و**الحل** (Solution).
- لماذا قد تحتاج برنامجًا من أجزاء بلغات مختلفة.
- شكل ملف الحل `.radsln` من الداخل.
- شجرة **Solution Explorer** وما تعنيه كل عقدة فيها.

## مشروع وحل: تشبيه

- **المشروع** مثل **غرفة** في بيت: لها غرض واحد (مطبخ، أو غرفة نوم) ولغة واحدة.
- **الحل** هو **البيت كله**: عدة غرف، كل غرفة بأثاثها الخاص، وبينها **أبواب** تسمح بالانتقال.

في RAD IDE: كل مشروع بلغة واحدة (Python أو C# أو VB6 أو C++ ...)، والحل يجمع عدة مشاريع. و«الأبواب» بينها اسمها **المراجع** (References): مشروع يستخدم دوال مشروع آخر.

هذا نفس نموذج **Visual Studio** تمامًا: الحل (`.sln` هناك، `.radsln` هنا) يحتوي مشاريع، ومشروع **البدء** (StartUp Project) هو الذي يعمل عند `F5`.

## لماذا عدة لغات؟

- عندك **مكتبة C# قديمة** فيها حسابات الشركة (الضرائب، الخصومات)، وتريد واجهة جديدة بـ **Python** دون إعادة كتابة الحسابات.
- جزء يحتاج **سرعة عالية** فتكتبه بـ C++ أو Rust، والباقي بلغة أسهل.
- فريق فيه من يجيد VB6 ومن يجيد Python، وكل منهم يكتب جزءه.

والأهم: في RAD IDE تستدعي دالة من مشروع آخر **كأنها دالة من لغتك**، مثل `PriceLib.Discount(200, 15)` في Python، مع أن `PriceLib` مكتوبة بـ C#.

## ملف الحل .radsln

ملف الحل ملف JSON بسيط في مجلد الحل:

```text
{
  "name": "Shop",
  "projects": [
    {"name": "App", "path": "App"},
    {"name": "PriceLib", "path": "PriceLib"}
  ],
  "startup": "App"
}
```

- `name`: اسم الحل.
- `projects`: كل مشروع باسمه ومساره **نسبةً إلى مجلد الحل**.
- `startup`: مشروع البدء.

وكل مشروع مجلد فيه ملفه الخاص `project.radproj` (لغته، ونماذجه، ووحداته، ومراجعه).

هذا مثال يقرأ ملف حل (نصًا جاهزًا) ويطبع مشاريعه، ويميز مشروع البدء:

```python run
import json

text = """{
  "name": "Shop",
  "projects": [{"name": "App", "path": "App"}, {"name": "PriceLib", "path": "PriceLib"}],
  "startup": "App"
}"""

sln = json.loads(text)
print("الحل:", sln["name"])
for p in sln["projects"]:
    mark = "  <- مشروع البدء" if p["name"] == sln["startup"] else ""
    print("-", p["name"], "في المجلد", p["path"] + mark)
```

```text output
الحل: Shop
- App في المجلد App  <- مشروع البدء
- PriceLib في المجلد PriceLib
```

## شجرة Solution Explorer

افتح **View > Solution Explorer** (عرض > مستكشف الحلول). مع حل فيه مشروعان ترى شيئًا مثل:

```text
Solution 'Shop' (2 projects)
├── App                 <- بخط عريض: مشروع البدء
│   ├── References
│   │   └── PriceLib
│   ├── Form1
│   └── main.py
└── PriceLib
    └── PriceLib.cs
```

- **Solution 'Shop'**: الجذر. بالزر الأيمن عليه: إضافة مشاريع، وبناء الحل، والخصائص.
- **المشروع بخط عريض** هو مشروع البدء.
- **References**: المكتبات التي يستخدمها المشروع.

> **فتح مشروع واحد بلا حل:** إذا فتحت مشروعًا عاديًا، تتعامل معه البيئة كحل «ضمني» فيه مشروع واحد. وعند حفظه أو إضافة مشروع ثانٍ إليه، يُكتب ملف `.radsln` ويصبح حلًا حقيقيًا.

## أخطاء شائعة

- **وضع كل شيء في مشروع واحد بلغات مختلفة:** المشروع لغة واحدة. اللغة الثانية مكانها مشروع آخر في نفس الحل.
- **نقل مجلد مشروع خارج مجلد الحل يدويًا:** المسارات في `.radsln` نسبية، فيضيع المشروع. انقل الحل كاملًا.
- **الخلط بين مشروع البدء والمشروع المفتوح:** `F5` يشغّل **مشروع البدء** دائمًا، وليس الملف الذي أمامك.

## تمرين

### تمرين 1: أضف مشروعًا إلى الحل

أضف إلى قاموس الحل مشروعًا ثالثًا اسمه `Reports` في المجلد `Reports`، واجعله مشروع البدء، ثم اطبع عدد المشاريع واسم مشروع البدء.

```python exercise
sln = {
    "name": "Shop",
    "projects": [{"name": "App", "path": "App"}, {"name": "PriceLib", "path": "PriceLib"}],
    "startup": "App",
}
# أضف المشروع واجعله مشروع البدء
```

```python solution
sln = {
    "name": "Shop",
    "projects": [{"name": "App", "path": "App"}, {"name": "PriceLib", "path": "PriceLib"}],
    "startup": "App",
}
sln["projects"].append({"name": "Reports", "path": "Reports"})
sln["startup"] = "Reports"
print("عدد المشاريع:", len(sln["projects"]))
print("مشروع البدء:", sln["startup"])
```

```text output
عدد المشاريع: 3
مشروع البدء: Reports
```

## الخلاصة

- المشروع = لغة واحدة. الحل = عدة مشاريع بلغات مختلفة.
- المراجع تسمح لمشروع باستدعاء دوال مشروع آخر كأنها من لغته.
- `.radsln` ملف JSON فيه المشاريع ومشروع البدء.
- **Solution Explorer** يعرض الحل، ومشروع البدء بخط عريض.

# الدرس 1: ما هو الـ ROM؟ وما المسموح به قانونيًا

**في هذا الدرس ستتعرف على:**

- معنى **ROM** في الأجهزة القديمة، ولماذا تسمى ملفات الألعاب «ROMs».
- أشهر صيغ الملفات: `.a26` و`.bin` (أتاري 2600) و`.nes` و`.gb` و`.gbc` و`.sfc` و`.md` و`.prg` و`.d64`...
- **رأس الملف** (Header): بايتات في أول الملف تصف الخرطوشة.
- الحدود القانونية: ما الذي تعدّله وما الذي لا تنزّله أبدًا.
- أدوات RAD IDE لهذا العالم كله.

## الخرطوشة شريحة ذاكرة

في جهاز مثل **أتاري 2600** (1977) أو **NES** (1983) أو **Game Boy** (1989) لا يوجد قرص صلب. اللعبة **خرطوشة** فيها شريحة ذاكرة للقراءة فقط: **ROM** (Read-Only Memory). المعالج يقرأ البرنامج والرسوم منها مباشرة.

عندما ينسخ شخص محتوى الشريحة إلى ملف يسمى ذلك **تفريغ** (Dump)، والملف الناتج يسمى «ROM». الملف مجرد بايتات: كود المعالج (6502 أو Z80 أو SM83...) والرسوم والنصوص والأصوات، وأحيانًا **رأس** يضيفه من فرّغ الخرطوشة ليعرف المحاكي نوعها.

| الجهاز | المعالج | الامتداد الشائع | الرأس |
|---|---|---|---|
| Atari 2600 | 6507 (نسخة من 6502) | `.a26` `.bin` | لا يوجد؛ الحجم يحدد طريقة تبديل البنوك (2K / 4K / F8 ...) |
| NES / Famicom | 2A03 (6502 بلا الوضع العشري) | `.nes` | 16 بايت **iNES**: يبدأ بـ `NES` ثم `1A` |
| Game Boy / Color | SM83 (قريب من Z80) | `.gb` `.gbc` | داخل الـ ROM عند `0100`-`014F`: العنوان والشعار والمجموع الاختباري |
| SNES | 65816 | `.sfc` `.smc` | داخل الـ ROM عند `7FC0` أو `FFC0` |
| Commodore 64 | 6510 | `.prg` `.d64` `.tap` | `.prg`: أول بايتين عنوان التحميل |

## اقرأ رأس iNES بنفسك

هذا البرنامج يبني رأس iNES في الذاكرة (لا يقرأ أي لعبة) ثم يفكّه كما يفعل المحاكي. شغّله بزر **تشغيل**:

```python run
header = bytes([0x4E, 0x45, 0x53, 0x1A,   # "NES" + 1A
                2,                        # PRG ROM: عدد قطع 16 KB
                1,                        # CHR ROM: عدد قطع 8 KB
                0x01, 0x00,               # Flags 6 و 7: المخطط (Mapper) والانعكاس
                0, 0, 0, 0, 0, 0, 0, 0])

if header[:4] != b"NES\x1a":
    print("ليس ملف iNES")
else:
    prg = header[4] * 16
    chr_ = header[5] * 8
    mapper = (header[6] >> 4) | (header[7] & 0xF0)
    mirroring = "vertical" if header[6] & 1 else "horizontal"
    print("PRG ROM:", prg, "KB")
    print("CHR ROM:", chr_, "KB")
    print("Mapper:", mapper)
    print("Mirroring:", mirroring)
    print("File size:", 16 + prg * 1024 + chr_ * 1024, "bytes")
```

```text output
PRG ROM: 32 KB
CHR ROM: 8 KB
Mapper: 0
Mirroring: vertical
File size: 40976 bytes
```

في RAD IDE لا تحتاج إلى حساب ذلك يدويًا: افتح أي ملف `.nes` بـ **File > Open** فيظهر في **محرر السادس عشر** ومعه لوحة **معلومات الـ ROM** (النظام، والمخطط، وأحجام PRG و CHR، والمتجهات NMI و RESET و IRQ)، وتلوين فوق حقول الرأس نفسها.

## الحدود القانونية - اقرأها جيدًا

ألعاب الشركات (نينتندو وأتاري وسيجا...) **محمية بحقوق النشر** حتى لو كان الجهاز قديمًا. لذلك:

| مسموح | غير مسموح |
|---|---|
| تعديل ROM **فرّغتها بنفسك** من خرطوشة تملكها، لاستخدامك الشخصي (حسب قانون بلدك) | تنزيل ROMs تجارية من مواقع الإنترنت |
| ألعابك أنت (Homebrew) التي تكتبها بالكامل | نشر ملف ROM معدَّل لعبة تجارية |
| برامج **ملكية عامة** أو بترخيص مفتوح (مثل برامج أبولو في الدورة الأخرى) | نسخ رسوم أو موسيقى لعبة تجارية في لعبتك |
| نشر **رقعة** (Patch) تحتوي تعديلاتك فقط: IPS أو BPS | إرفاق الـ ROM الأصلية مع الرقعة |

لهذا السبب **لا ينزّل RAD IDE أي ROM أبدًا**، وكل الأمثلة في هذه الدورة وفي `samples/Tests/Retro` ألعاب صغيرة أصلية كُتبت لـ RAD IDE (ترخيص CC0). أما **المحاكيات والأدوات** (Stella و Mesen و mGBA و VICE و DOSBox-X و DASM و cc65 و RGBDS) فبرامج مفتوحة المصدر تنزّلها RAD IDE عند طلبك **من صفحات إصداراتها الرسمية فقط**، وتتحقق من بصمة SHA-256، وتضعها في `%LOCALAPPDATA%\RADIDE\tools` دون صلاحيات مدير.

> **لماذا الرقعة قانونية والـ ROM لا؟** الرقعة تحتوي «الفرق» فقط: «في العنوان 1234 ضع هذه البايتات». لا فائدة منها لمن لا يملك اللعبة الأصلية. هكذا تُنشر الترجمات العربية للألعاب القديمة.

## أدواتك في RAD IDE

| ما تريد | أين |
|---|---|
| فتح ROM أو أي ملف ثنائي وتعديله | File > Open، أو Tools > Retro > ROM Workbench > Open in Hex Editor |
| مشروع تعديل لا يلمس الأصل أبدًا | New Project > **Retro** > ROM Hacking Project |
| كتابة لعبة جديدة | New Project > **Retro Games**: Atari 2600 و NES و Game Boy و C64 و ZX Spectrum |
| تفكيك ROM إلى كود تجميع | Tools > Retro > Retro Development > Disassemble ROM into Project... |
| تعديل الرسوم والنصوص | Tools > Retro > Graphics & Text |
| تشغيل اللعبة | `F5`، والمحاكيات من Tools > Retro > Emulators... |
| برامج DOS القديمة | New Project > Retro > DOS Program (تعمل في DOSBox-X) |

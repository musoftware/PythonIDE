# الدرس 8: ترجمة نصوص الألعاب بجداول الحروف (ومنها العربية)

**في هذا الدرس:**

- لماذا لا تجد نص اللعبة بالبحث العادي: **جداول الحروف** (`.tbl`).
- **البحث النسبي** (Relative Search) لاكتشاف الجدول.
- **مؤشرات النصوص** (Pointer Tables) وإعادة حسابها عند تغيير الطول.
- **Script Dump / Insert** في RAD IDE.
- العربية في لعبة قديمة: **أشكال الحروف** والكتابة من اليمين إلى اليسار.

## جدول الحروف

كثير من الألعاب لا تستخدم ASCII. قد يكون `00` = `A` و`01` = `B`... لأن البلاطة رقم 0 في الخط هي A. لذلك يُكتب **جدول** نصي يربط البايت بالحرف:

```text
; mygame.tbl
00=A
01=B
1A= 
/FF=<end>        نهاية النص (الشرطة المائلة تعني رمز نهاية)
*FE=<br>         سطر جديد
8081=<name>      مفتاح من بايتين (مثلًا اسم البطل)
```

```python run
TABLE_TEXT = """00=A
01=B
02=C
03=D
04=E
0B=L
0E=O
0D=N
1A=
/FF=<end>"""

table = {}
for line in TABLE_TEXT.splitlines():
    key, _, ch = line.partition("=")
    table[int(key.lstrip("/"), 16)] = ch if ch else " "

rom_text = bytes([0x0D, 0x0E, 0x1A, 0x02, 0x0E, 0x03, 0x04, 0xFF])
print("".join(table.get(b, f"<${b:02X}>") for b in rom_text))
```

```text output
NO CODE<end>
```

## البحث النسبي

لا تعرف الجدول؟ إن كانت الحروف متتالية في الخط (A ثم B ثم C) فالفروق بين البايتات تبقى كما هي. لكلمة `START` الفروق: `S→T = +1`، `T→A = -19`... ابحث في الـ ROM عن هذه الفروق بغض النظر عن القيمة الأولى. محرر السادس عشر في RAD IDE يفعل ذلك: زر **Tools** في شريط المحرر ثم **Relative Search...**، ثم يبني لك جدولًا من النتيجة.

## المؤشرات

النصوص في ROM غالبًا متتالية، وفي مكان آخر **جدول مؤشرات**: لكل نص عنوانه (بايتان، Little Endian في 6502 و Z80). إن جعلت نصًا أطول فإما أن يتسع في مكانه، وإما أن تعيد ترتيب النصوص كلها وتعيد حساب كل المؤشرات:

```python run
texts = ["PRESS START", "GAME OVER", "HELLO"]
base = 0x8000                       # عنوان المنطقة في ذاكرة المعالج
pointers, blob = [], bytearray()
for t in texts:
    pointers.append(base + len(blob))
    blob += t.encode("ascii") + b"\xff"     # FF = نهاية النص
print([hex(p) for p in pointers])
print(len(blob), "bytes")
table = b"".join(p.to_bytes(2, "little") for p in pointers)
print(table.hex(" ").upper())
```

```text output
['0x8000', '0x800c', '0x8016']
28 bytes
00 80 0C 80 16 80
```

## Script Dump / Insert في RAD IDE

**Tools > Retro > Graphics & Text > Script Dump / Insert**:

1. اختر الـ ROM (نسخة العمل في مشروع ROM Hacking) والجدول `.tbl`.
2. **Find strings by**: *Pointer table* (الإزاحة، والعدد، وحجم المؤشر 2 أو 3 أو 4، وترتيب البايتات، و«اطرح» و«أضف» لتحويل المؤشر إلى إزاحة في الملف - مثلًا اطرح `8000` وأضف `10` لرأس iNES) أو *Ranges* (مدى إزاحات).
3. **Dump**: جدول فيه كل نص، وعمود **Translation** تكتب فيه الترجمة، وعمود الطول (أخضر إن اتسع، أحمر إن لم يتسع أو فيه حرف ليس في الجدول). البايتات المجهولة تبقى `<$XX>` فلا يضيع شيء.
4. احفظ الجدول **CSV** (UTF-8) لتترجم في أي برنامج، ثم **Load**.
5. **Insert**: *In place* (كل نص في مكانه) أو *Repack* (أعد الترتيب في منطقة حرة وأصلح المؤشرات، والنصوص المتطابقة تُخزَّن مرة واحدة). إن لم يتسع نص واحد أو نقص حرف من الجدول **لا يُكتب شيء** ويظهر تقرير بكل المشكلات.

ثم في مشروع ROM Hacking: **Capture Edits as Patch** فتصبح الترجمة رقعة BPS تنشرها.

## العربية في لعبة قديمة

الألعاب القديمة تكتب من اليسار إلى اليمين وتعرف شكلًا واحدًا لكل حرف. العربية تحتاج:

1. **أشكال الحروف**: لكل حرف شكل منفرد وأول ووسط وآخر (ب ﺑ ﺒ ﺐ)، ولام-ألف (لا). الزر **Add Arabic Letter Forms** في محرر الجدول يضيف لكل شكل بايتًا، ثم ترسم الأشكال في بلاطات خط اللعبة بـ Tile Editor.
2. **التشكيل حسب الموضع** (Shape Arabic): يختار الشكل الصحيح لكل حرف حسب جيرانه.
3. **الترتيب البصري** (Right-to-left): يعكس كل سطر ليظهر صحيحًا في محرك يكتب من اليسار، والأرقام والكلمات اللاتينية و`<الرموز>` تبقى بترتيبها.

هذا مثال مبسط للفكرة (حرفان فقط وأشكالهما):

```python run
# أشكال الحرفين: منفرد، أول (متصل بما بعده)، وسط، آخر (متصل بما قبله)
FORMS = {"ب": ("ﺏ", "ﺑ", "ﺒ", "ﺐ"), "ت": ("ﺕ", "ﺗ", "ﺘ", "ﺖ")}


def shape(word: str) -> str:
    out = []
    for i, ch in enumerate(word):
        before = i > 0                       # الحرفان هنا يتصلان من الجهتين
        after = i < len(word) - 1
        iso, ini, med, fin = FORMS[ch]
        out.append(med if before and after else ini if after else fin if before else iso)
    return "".join(out)


word = "تبت"
shaped = shape(word)
visual = shaped[::-1]                        # محرك اللعبة يكتب من اليسار إلى اليمين
table = {"ﺗ": 0x90, "ﺒ": 0x91, "ﺖ": 0x92}
print([f"U+{ord(c):04X}" for c in shaped])
print(bytes(table[c] for c in visual).hex(" ").upper())
```

```text output
['U+FE97', 'U+FE92', 'U+FE96']
92 91 90
```

الكلمة «تبت» صارت: تاء أولى ثم باء وسطى ثم تاء أخيرة، ثم عُكس ترتيبها لأن اللعبة تكتب من اليسار. محرر النصوص في RAD IDE يفعل هذا لكل الحروف العربية تلقائيًا (الخياران **Shape Arabic** و**Right-to-left**).

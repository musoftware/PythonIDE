# الدرس 3: برنامجك الأول - MsgBox و Debug.Print

**في هذا الدرس ستتعلم:**

- عرض الرسائل للمستخدم بـ `MsgBox`.
- طباعة النتائج في نافذة المخرجات بـ `Debug.Print`.
- ربط النصوص ببعضها بعلامة `&`، والانتقال إلى سطر جديد بـ `vbCrLf`.
- أنواع أزرار صندوق الرسالة، وكيف تعرف أي زر ضغطه المستخدم.

## طريقتان للكلام مع العالم

- `Debug.Print` مثل **دفتر ملاحظات المبرمج**: يكتب في نافذة المخرجات، والمستخدم العادي لا يراها. نستخدمه للتجربة وتتبّع البرنامج.
- `MsgBox` مثل **لافتة** ترفعها أمام المستخدم: نافذة صغيرة فيها رسالة وزر "موافق"، ولا يكمل البرنامج حتى يغلقها المستخدم.

## صندوق الرسالة MsgBox

أبسط صورة: `MsgBox "النص"`.

<!-- test: {"msgbox": ["السلام عليكم!"]} -->
```vb run
Sub Main()
    MsgBox "السلام عليكم!"
End Sub
```

يمكن إضافة **أيقونة** و**عنوان** للنافذة. الصيغة الكاملة:

```vb
MsgBox الرسالة, الأزرار_والأيقونة, العنوان
```

<!-- test: {"msgbox": ["تم حفظ الملف بنجاح", "انتبه: البطارية ضعيفة"]} -->
```vb run
Sub Main()
    MsgBox "تم حفظ الملف بنجاح", vbInformation, "معلومة"
    MsgBox "انتبه: البطارية ضعيفة", vbExclamation, "تحذير"
End Sub
```

| الثابت | المعنى |
|---|---|
| `vbInformation` | أيقونة معلومة (i) |
| `vbExclamation` | أيقونة تحذير (!) |
| `vbCritical` | أيقونة خطأ (X) |
| `vbQuestion` | أيقونة سؤال (?) |

## ربط النصوص بالعلامة &

علامة `&` تلصق نصّين (أو نصًّا ورقمًا) ببعضهما، مثل وصل قطارين:

```vb run
Sub Main()
    Debug.Print "أحمد" & " " & "علي"
    Debug.Print "عمري " & 20 & " سنة"
    Debug.Print "النتيجة = " & (6 * 7)
End Sub
```

```text output
أحمد علي
عمري 20 سنة
النتيجة = 42
```

لاحظ المسافة `" "` بين الاسمين: الحاسوب لا يضع مسافات من عنده!

## سطر جديد داخل الرسالة: vbCrLf

`vbCrLf` ثابت معناه "انزل لسطر جديد". مفيد في `MsgBox` لعرض رسالة من عدة أسطر:

<!-- test: {"msgbox": ["الاسم: سارة\r\nالمدينة: الإسكندرية\r\nالعمر: 22"]} -->
```vb run
Sub Main()
    MsgBox "الاسم: سارة" & vbCrLf & "المدينة: الإسكندرية" & vbCrLf & "العمر: 22"
End Sub
```

## أسئلة بنعم أو لا

إذا أضفت `vbYesNo` يظهر زرّا "نعم" و"لا". وعندها نكتب `MsgBox(...)` بين **قوسين** لأننا نريد معرفة **القيمة المرجعة**، أي الزر الذي ضُغط:

<!-- test: {"msgbox": ["هل تحب البرمجة؟"], "msgbox_answers": [6]} -->
```vb run
Sub Main()
    Dim answer As Integer
    answer = MsgBox("هل تحب البرمجة؟", vbYesNo + vbQuestion, "سؤال")
    If answer = vbYes Then
        Debug.Print "رائع! أنت في المكان الصحيح"
    Else
        Debug.Print "سنجعلك تحبها :)"
    End If
End Sub
```

```text output
رائع! أنت في المكان الصحيح
```

لا تقلق من `Dim` و`If` الآن، سنشرحهما بالتفصيل قريبًا. الفكرة المهمة: `MsgBox` يمكن أن يُرجع قيمة: `vbYes` أو `vbNo` أو `vbOK` أو `vbCancel`.

| ثابت الأزرار | الأزرار الظاهرة |
|---|---|
| `vbOKOnly` (الافتراضي) | موافق |
| `vbOKCancel` | موافق، إلغاء |
| `vbYesNo` | نعم، لا |
| `vbYesNoCancel` | نعم، لا، إلغاء |

## متى أستخدم الأقواس؟

- إذا كنت **تعرض** الرسالة فقط: بدون أقواس `MsgBox "مرحبا"`.
- إذا كنت **تأخذ** النتيجة: بأقواس `x = MsgBox("مرحبا", vbYesNo)`.

## أخطاء شائعة

- **استخدام `+` لربط النصوص:** في BASIC تعمل أحيانًا، لكنها تسبب مفاجآت مع الأرقام. استخدم `&` دائمًا للنصوص.
- **نسيان المسافات حول `&`:** `"عمري"&20` قد تُفهم خطأً. اكتب `"عمري " & 20`.
- **أقواس بدون أخذ النتيجة:** `MsgBox("أ", vbYesNo, "ب")` وحدها في سطر تعطي خطأ صياغة. إما بدون أقواس، أو اكتب `x = MsgBox(...)`.
- **نسيان الفاصلة بين أجزاء MsgBox:** `MsgBox "نص" vbInformation` خطأ؛ الصحيح `MsgBox "نص", vbInformation`.

### تمرين 1: بطاقة تعريف

اعرض صندوق رسالة واحدًا من ثلاثة أسطر: "الاسم: منى" ثم "الوظيفة: مبرمجة" ثم "اللغة: BASIC"، بأيقونة معلومة وعنوان "بطاقتي".

```vb exercise
Sub Main()
    ' استخدم & و vbCrLf
End Sub
```

<!-- test: {"msgbox": ["الاسم: منى\r\nالوظيفة: مبرمجة\r\nاللغة: BASIC"]} -->
```vb solution
Sub Main()
    MsgBox "الاسم: منى" & vbCrLf & "الوظيفة: مبرمجة" & vbCrLf & "اللغة: BASIC", vbInformation, "بطاقتي"
End Sub
```

### تمرين 2: جدول الضرب للرقم 3 (أول 3 أسطر)

اطبع في نافذة المخرجات: `3 x 1 = 3` ثم `3 x 2 = 6` ثم `3 x 3 = 9`، بحيث يحسب الحاسوب النواتج بنفسه.

```vb exercise
Sub Main()
    Debug.Print "3 x 1 = " & (3 * 1)
    ' أكمل
End Sub
```

```vb solution
Sub Main()
    Debug.Print "3 x 1 = " & (3 * 1)
    Debug.Print "3 x 2 = " & (3 * 2)
    Debug.Print "3 x 3 = " & (3 * 3)
End Sub
```

```text output
3 x 1 = 3
3 x 2 = 6
3 x 3 = 9
```

### تمرين 3: تأكيد الخروج

اسأل المستخدم "هل تريد الخروج؟" بزرّي نعم/لا. إذا اختار "لا" اطبع "سنكمل العمل".

```vb exercise
Sub Main()
    Dim r As Integer
    ' r = MsgBox(...)
End Sub
```

<!-- test: {"msgbox": ["هل تريد الخروج؟"], "msgbox_answers": [7]} -->
```vb solution
Sub Main()
    Dim r As Integer
    r = MsgBox("هل تريد الخروج؟", vbYesNo + vbQuestion)
    If r = vbNo Then
        Debug.Print "سنكمل العمل"
    End If
End Sub
```

```text output
سنكمل العمل
```

## الخلاصة

- `MsgBox` للمستخدم، و`Debug.Print` للمبرمج.
- `&` لربط النصوص، و`vbCrLf` لسطر جديد.
- `MsgBox(...)` بأقواس يُرجع الزر الذي ضغطه المستخدم (`vbYes`، `vbNo`...).

# الدرس 1: ما هي البرمجة؟

**في هذا الدرس ستتعلم:**

- ما معنى "برنامج" و"برمجة" و"لغة برمجة".
- لماذا نبدأ بلغة BASIC (فيجوال بيسك 6).
- كيف تكتب أول سطر برمجي وتشغّله داخل بيئة RAD IDE.

## البرنامج وصفة طبخ

تخيّل أنك تريد أن تعلّم صديقًا كيف يُعِدّ كوبًا من الشاي. ستكتب له خطوات واضحة ومرتّبة:

1. املأ الغلاية بالماء.
2. شغّل الغلاية وانتظر حتى يغلي الماء.
3. ضع كيس الشاي في الكوب.
4. اسكب الماء الساخن في الكوب.

هذه الخطوات المرتّبة تُسمّى **خوارزمية** (Algorithm). و**البرنامج** هو خوارزمية مكتوبة بلغة يفهمها الحاسوب.
الحاسوب سريع جدًّا لكنه "حرفي" جدًّا أيضًا: ينفّذ ما تكتبه بالضبط، خطوة بعد خطوة، ولا يخمّن ما كنت تقصده.

> 💡 **نصيحة:** إذا لم تكن الخطوات واضحة لصاحبك فسيُعدّ الشاي بطريقة خاطئة، والحاسوب كذلك تمامًا! الوضوح والترتيب هما سرّ البرمجة.

## ما هي لغة البرمجة؟

**لغة البرمجة** هي مجموعة من الكلمات والقواعد نكتب بها الأوامر للحاسوب. هناك لغات كثيرة: BASIC و C++ و Python و Java وغيرها.
كلها تشترك في الأفكار نفسها: المتغيرات، والشروط، وحلقات التكرار، والدوال. إذا فهمت هذه الأفكار في لغة واحدة، سيسهل عليك تعلّم أي لغة أخرى.

## لماذا BASIC؟

كلمة BASIC اختصار لعبارة إنجليزية معناها "لغة رموز تعليمية للمبتدئين". صُمِّمت أصلًا لتكون سهلة القراءة.
ونحن هنا نستخدم لهجة **فيجوال بيسك 6** (Visual Basic 6)، وهي من أشهر لغات تصميم البرامج ذات النوافذ.
بيئة RAD IDE فيها **مفسّر** (Interpreter) خاص بها لهذه اللغة، أي برنامج يقرأ أوامرك وينفّذها سطرًا سطرًا، فلن تحتاج إلى تثبيت أي شيء إضافي.

## أول أمر: Debug.Print

الأمر `Debug.Print` يكتب نصًّا في نافذة **المخرجات** (Output) أسفل البيئة. هذا أبسط برنامج يمكن كتابته:

```vb run
Sub Main()
    Debug.Print "مرحبا بك في عالم البرمجة!"
End Sub
```

```text output
مرحبا بك في عالم البرمجة!
```

اضغط زر **جرّبه** فوق المثال: ستُنشئ البيئة مشروعًا مؤقتًا وتشغّله، وسترى الرسالة في نافذة المخرجات.

لاحظ ما يلي:

- `Sub Main()` هي **نقطة البداية**: عندما يبدأ البرنامج يبحث عنها وينفّذ ما بداخلها.
- `End Sub` تعني نهاية هذا الجزء من البرنامج.
- النص المكتوب بين علامتي التنصيص `"..."` يُسمّى **نصًّا** أو **سلسلة نصية** (String).
- المسافات في أول السطر (الإزاحة) ليست ضرورية للحاسوب، لكنها تجعل البرنامج أسهل في القراءة.

## الأوامر تُنفَّذ بالترتيب

الحاسوب ينفّذ الأوامر من الأعلى إلى الأسفل، واحدًا بعد الآخر، تمامًا مثل خطوات الشاي:

```vb run
Sub Main()
    Debug.Print "1) املأ الغلاية بالماء"
    Debug.Print "2) شغّل الغلاية"
    Debug.Print "3) ضع كيس الشاي في الكوب"
    Debug.Print "4) اسكب الماء الساخن"
    Debug.Print "بالهناء والشفاء!"
End Sub
```

```text output
1) املأ الغلاية بالماء
2) شغّل الغلاية
3) ضع كيس الشاي في الكوب
4) اسكب الماء الساخن
بالهناء والشفاء!
```

## الحاسوب يحسب أيضًا

يمكن أن تطلب من الحاسوب حساب عملية رياضية وطباعة نتيجتها. لاحظ أن الأرقام تُكتب **بدون** علامات تنصيص:

```vb run
Sub Main()
    Debug.Print 2 + 3
    Debug.Print 10 * 4
    Debug.Print "2 + 3"
End Sub
```

```text output
5
40
2 + 3
```

السطر الأخير طبع `2 + 3` كما هو، لأنه مكتوب بين علامتي تنصيص، فالحاسوب يعامله كنص وليس كعملية حسابية.

## التعليقات

أي شيء يأتي بعد علامة الفاصلة العليا `'` يُسمّى **تعليقًا** (Comment). الحاسوب يتجاهله تمامًا، وهو مكتوب للبشر فقط لشرح البرنامج:

```vb run
Sub Main()
    ' هذا تعليق: لن يُنفَّذ
    Debug.Print "السلام عليكم"   ' يمكن كتابة تعليق في آخر السطر أيضًا
End Sub
```

```text output
السلام عليكم
```

## أخطاء شائعة

- **نسيان علامة التنصيص الثانية:** `Debug.Print "مرحبا` ستظهر رسالة خطأ في الصياغة (Syntax error).
- **كتابة الأمر خطأ:** `Debug.Prnt` بدلًا من `Debug.Print`. الحاسوب لا يصحّح الإملاء!
- **الكتابة خارج `Sub Main`:** الأوامر يجب أن تكون بين `Sub Main()` و`End Sub`.
- **وضع الأرقام بين علامات تنصيص عند الحساب:** `"2" + "3"` ليست مثل `2 + 3`. سنفهم السبب في درس المتغيرات.

## تمارين

### تمرين 1: عرّف بنفسك

اكتب برنامجًا يطبع ثلاثة أسطر: اسمك، ومدينتك، وهوايتك المفضلة.

```vb exercise
Sub Main()
    ' اكتب هنا ثلاثة أوامر Debug.Print
End Sub
```

```vb solution
Sub Main()
    Debug.Print "اسمي: أحمد"
    Debug.Print "مدينتي: القاهرة"
    Debug.Print "هوايتي: كرة القدم"
End Sub
```

```text output
اسمي: أحمد
مدينتي: القاهرة
هوايتي: كرة القدم
```

### تمرين 2: آلة حاسبة صغيرة

اطبع ناتج العمليات: 15 + 27، ثم 9 × 8، ثم 100 - 37.
(تذكّر: علامة الضرب في البرمجة هي النجمة `*`).

```vb exercise
Sub Main()
    ' اطبع ناتج كل عملية في سطر
End Sub
```

```vb solution
Sub Main()
    Debug.Print 15 + 27
    Debug.Print 9 * 8
    Debug.Print 100 - 37
End Sub
```

```text output
42
72
63
```

## الخلاصة

- البرنامج خطوات مرتّبة يكتبها المبرمج وينفّذها الحاسوب بالترتيب.
- `Debug.Print` يطبع في نافذة المخرجات، و`Sub Main` نقطة البداية.
- النصوص بين علامات تنصيص، والأرقام بدونها، والتعليقات تبدأ بـ `'`.

في الدرس القادم نتعرّف على بيئة التطوير نفسها: مصمّم النماذج ونافذة الكود.

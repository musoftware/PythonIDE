# الدرس 6: العمليات والتعبيرات

**في هذا الدرس ستتعلم:**

- العمليات الحسابية: `+ - * / \ Mod ^`.
- ترتيب تنفيذ العمليات (الأولوية) والأقواس.
- عمليات المقارنة: `= <> < > <= >=`.
- العمليات المنطقية: `And` و`Or` و`Not`.

## التعبير جملة تُحسب

**التعبير** (Expression) هو أي شيء يُحسب ليعطي قيمة: `3 + 4` تعبير قيمته 7، و`price * 2` تعبير، و`age >= 18` تعبير قيمته `True` أو `False`.
**العملية** (Operator) هي الرمز الذي يربط القيم، مثل `+` و`*`.

## العمليات الحسابية

| العملية | المعنى | مثال | الناتج |
|---|---|---|---|
| `+` | جمع | `7 + 2` | 9 |
| `-` | طرح | `7 - 2` | 5 |
| `*` | ضرب | `7 * 2` | 14 |
| `/` | قسمة عادية | `7 / 2` | 3.5 |
| `\` | قسمة صحيحة (بدون الكسر) | `7 \ 2` | 3 |
| `Mod` | باقي القسمة | `7 Mod 2` | 1 |
| `^` | أُس (رفع لقوة) | `2 ^ 3` | 8 |

```vb run
Sub Main()
    Debug.Print "7 / 2 = " & (7 / 2)
    Debug.Print "7 \ 2 = " & (7 \ 2)
    Debug.Print "7 Mod 2 = " & (7 Mod 2)
    Debug.Print "2 ^ 10 = " & (2 ^ 10)
End Sub
```

```text output
7 / 2 = 3.5
7 \ 2 = 3
7 Mod 2 = 1
2 ^ 10 = 1024
```

### فائدة `\` و `Mod`: توزيع البرتقال

لديك 17 برتقالة وتريد توزيعها على 5 أطفال بالتساوي: كل طفل يأخذ `17 \ 5 = 3`، ويتبقى `17 Mod 5 = 2`.
ومثال عملي آخر: تحويل الدقائق إلى ساعات ودقائق:

```vb run
Sub Main()
    Dim totalMinutes As Integer
    totalMinutes = 135
    Debug.Print totalMinutes & " دقيقة = " & (totalMinutes \ 60) & " ساعة و " & (totalMinutes Mod 60) & " دقيقة"
End Sub
```

```text output
135 دقيقة = 2 ساعة و 15 دقيقة
```

و`Mod` تخبرك هل العدد زوجي: إذا كان `n Mod 2 = 0` فالعدد زوجي.

## الأولوية والأقواس

مثل الرياضيات تمامًا: الأُس أولًا، ثم الضرب والقسمة، ثم الجمع والطرح. والأقواس تغيّر الترتيب:

```vb run
Sub Main()
    Debug.Print 2 + 3 * 4
    Debug.Print (2 + 3) * 4
    Debug.Print 10 - 4 - 3
    Debug.Print 2 * 3 ^ 2
End Sub
```

```text output
14
20
3
18
```

ترتيب الأولوية من الأعلى للأدنى:

1. الأقواس `( )`
2. الأُس `^`
3. الضرب والقسمة `* /`
4. القسمة الصحيحة `\`
5. باقي القسمة `Mod`
6. الجمع والطرح `+ -`
7. ربط النصوص `&`
8. المقارنات `= <> < > <= >=`
9. `Not` ثم `And` ثم `Or`

> 💡 **نصيحة:** لما تشك، حط أقواس. الأقواس ما بتضرّش، وبتخلّي الكود أوضح لك وللي بيقرأ بعدك.

## عمليات المقارنة

المقارنة تسأل سؤالًا جوابه **صح** (`True`) أو **خطأ** (`False`):

| العملية | المعنى |
|---|---|
| `=` | يساوي |
| `<>` | لا يساوي |
| `<` | أصغر من |
| `>` | أكبر من |
| `<=` | أصغر من أو يساوي |
| `>=` | أكبر من أو يساوي |

```vb run
Sub Main()
    Dim age As Integer
    age = 20
    Debug.Print age >= 18
    Debug.Print age = 30
    Debug.Print age <> 30
    Debug.Print "أحمد" = "أحمد"
End Sub
```

```text output
True
False
True
True
```

لاحظ: `=` لها معنيان حسب مكانها. في `age = 20` (أول السطر) هي **إسناد**، وفي `Debug.Print age = 30` هي **مقارنة**.

## العمليات المنطقية

نستخدمها لربط أكثر من شرط:

- `And` (و): الناتج صح فقط إذا كان **الشرطان** صحيحين. مثل: "تدخل السينما إذا كان معك تذكرة **و** عمرك فوق 12".
- `Or` (أو): الناتج صح إذا كان **أحدهما على الأقل** صحيحًا. مثل: "تدفع نقدًا **أو** بالبطاقة".
- `Not` (ليس): تعكس القيمة: `Not True` = `False`.

```vb run
Sub Main()
    Dim hasTicket As Boolean, age As Integer
    hasTicket = True
    age = 10
    Debug.Print "يدخل؟ " & (hasTicket And age > 12)
    Debug.Print "نقدًا أو بطاقة؟ " & (False Or True)
    Debug.Print "عكس True: " & (Not True)
End Sub
```

```text output
يدخل؟ False
نقدًا أو بطاقة؟ True
عكس True: False
```

| A | B | A And B | A Or B |
|---|---|---|---|
| True | True | True | True |
| True | False | False | True |
| False | True | False | True |
| False | False | False | False |

```vb run
Sub Main()
```


## أخطاء شائعة

- **الخلط بين `/` و`\`:** `7 / 2` = 3.5 أما `7 \ 2` = 3.
- **نسيان الأقواس:** `(a + b) / 2` هو المتوسط، أما `a + b / 2` فشيء مختلف تمامًا.
- **القسمة على صفر:** `x / 0` تعطي خطأ "Division by zero" ويتوقف البرنامج. تأكد أن المقسوم عليه ليس صفرًا.
- **كتابة `=<` أو `=>`:** الصحيح `<=` و`>=`.
- **كتابة `x > 5 And < 10`:** يجب تكرار المتغير: `x > 5 And x < 10`.

## تمارين

### تمرين 1: الثواني

حوّل 3725 ثانية إلى ساعات ودقائق وثوانٍ. الناتج المطلوب: `1 ساعة 2 دقيقة 5 ثانية`.

```vb exercise
Sub Main()
    Dim total As Long
    total = 3725
    ' استخدم \ و Mod
End Sub
```

```vb solution
Sub Main()
    Dim total As Long, h As Long, m As Long, s As Long
    total = 3725
    h = total \ 3600
    m = (total Mod 3600) \ 60
    s = total Mod 60
    Debug.Print h & " ساعة " & m & " دقيقة " & s & " ثانية"
End Sub
```

```text output
1 ساعة 2 دقيقة 5 ثانية
```

### تمرين 2: زوجي أم فردي؟

اطبع `True` إذا كان العدد 42 زوجيًّا، ثم اطبع نتيجة الاختبار نفسه للعدد 17.

```vb exercise
Sub Main()
    ' استخدم Mod 2
End Sub
```

```vb solution
Sub Main()
    Debug.Print (42 Mod 2 = 0)
    Debug.Print (17 Mod 2 = 0)
End Sub
```

```text output
True
False
```

### تمرين 3: النطاق

العدد `x = 15`. اطبع هل هو بين 10 و 20 (شامل الطرفين)، ثم هل هو أصغر من 0 أو أكبر من 100.

```vb exercise
Sub Main()
    Dim x As Integer
    x = 15
End Sub
```

```vb solution
Sub Main()
    Dim x As Integer
    x = 15
    Debug.Print (x >= 10 And x <= 20)
    Debug.Print (x < 0 Or x > 100)
End Sub
```

```text output
True
False
```

# الدرس 15: معرض أمثلة Ring وتعليمات F1 والمنقّح

**في هذا الدرس ستتعلم:**

- استخدام **معرض أمثلة Ring** (Ring Samples): مئات الأمثلة الجاهزة التي تأتي مع Ring.
- الوصول إلى **توثيق Ring** و**التعليمات حسب السياق** بالمفتاح `F1`.
- الإكمال التلقائي (IntelliSense) وقائمة الأخطاء والتنسيق.
- **تصحيح الأخطاء** (Debugging): نقاط التوقف والتنفيذ خطوة بخطوة ومراقبة المتغيرات.
- تثبيت مكتبات إضافية بـ **RingPM**.

## معرض أمثلة Ring

Ring تأتي ومعها كنز: أمثلة لكل شيء تقريبًا (الكونسول، والنوافذ، والألعاب، والويب، وقواعد البيانات)، وتطبيقات كاملة، وأمثلة التوثيق. RAD IDE تجمعها لك في مكان واحد.

### فتح المعرض

- من القائمة: **Help > Ring Samples...** (تعليمات > أمثلة Ring).
- أو من **Start Page** (صفحة البداية)، أو من أيقونة الخاتم في **Activity Bar** (في تخطيطات VS Code وAgent).

### ما ستراه

| الجزء | العمل |
|---|---|
| مربع البحث | اكتب كلمة مثل `sqlite` أو `button` أو `snake` |
| قائمة النوع | **All kinds** أو **Console** أو **GUI** أو **Games** أو **Web** |
| قائمة نتيجة الاختبار | أمثلة جُرّبت آليًا: ✓ يعمل، ⌨ يحتاج إدخالًا من لوحة المفاتيح، ✗ فشل |
| الشجرة | **Samples** و**Applications** و**Documentation** و**Extensions Tutorial** و**Library Tests** |
| المعاينة | كود المثال ملوّنًا |

### الأزرار الثلاثة

1. **Run** (تشغيل): يشغّل المثال في مكانه، والناتج في نافذة **Output**. أمثلة النوافذ والألعاب تفتح نافذتها.
2. **Open as Project** (فتح كمشروع): ينسخ مجلد المثال إلى `Documents\RAD IDE Projects\RingSamples\<الاسم>` ويفتحه كمشروع Ring. هنا تستطيع **التعديل** والتجربة بحرية، فمجلد Ring الأصلي لا يُكتب فيه أبدًا.
3. **Open Folder** (فتح المجلد): يفتح مجلد المثال في مستكشف ويندوز.

> **نصيحة للتعلم:** اختر مثالًا قريبًا مما تريد صنعه، وافتحه كمشروع، ثم غيّر فيه شيئًا صغيرًا وشغّله. التعلم بتعديل كود يعمل أسرع كثيرًا من البدء من صفحة فارغة.

### أمثلة تستحق التجربة

- ابحث عن `snake` أو `tetris` أو `flappy` لألعاب RingRayLib كاملة.
- ابحث عن `calculator` و`notepad` لتطبيقات RingQt.
- ابحث عن `natural` لأمثلة البرمجة الطبيعية التي بدأناها في الدرس 9.
- ابحث عن `sqlite` و`libcurl` لتكملة الدرس 13.

## توثيق Ring و F1

- **Help > Ring Documentation** (تعليمات > توثيق Ring): يفتح دليل Ring الكامل (بالإنجليزية) للإصدار المثبت عندك.
- **F1** (**Help > Context Help**، أي التعليمات حسب السياق): ضع المؤشر على أي كلمة في الكود واضغط `F1`:
  - على اسم دالة مثل `substr` أو `sqlite_execute`: تفتح صفحتها في التوثيق مباشرة.
  - على كلمة محجوزة مثل `give` أو `switch`: تفتح شرحها.
  - على أداة مختارة في مصمم النماذج: تفتح تعليمات تلك الأداة.
- **Help > RingQt / Qt 5 Class Reference**: مرجع أصناف Qt، لأن دوال أدوات RingQt مثل `setText` و`currentRow` هي نفسها دوال Qt.

> **كيف تقرأ مرجع Qt؟** في مرجع Qt (بلغة C++) ستجد مثلًا `QString QLineEdit::text() const`. في Ring تكتبها ببساطة `txtName.text()`. والصنف `QLineEdit` اسمه في RingQt `qLineEdit`.

## الإكمال التلقائي والأخطاء والتنسيق

- **IntelliSense**: اكتب أول حروف دالة فتظهر قائمة بالدوال المطابقة ومعاملاتها. بعد كتابة اسم كائن ونقطة (`txtName.`) تظهر دوال الأداة.
- **Error List** (قائمة الأخطاء): الـ IDE تفحص الكود وأنت تكتب (بالأمر `ring file -norun`)، وتعرض أخطاء الكتابة مثل نسيان `ok` أو `next`. اضغط مرتين على الخطأ لتقفز إلى سطره.
- **Edit > Format Document** (تنسيق المستند، `Shift+Alt+F`): يرتب المسافات البادئة في الكود كله تلقائيًا.
- **Document Outline**: يعرض الدوال والأصناف والخصائص في الملف، واضغط على أي منها لتقفز إليه.

## تصحيح الأخطاء (Debugging)

**المنقّح** (debugger) يسمح لك بإيقاف البرنامج في سطر معيّن، ثم تنفيذه **خطوة خطوة** ورؤية قيم المتغيرات. هذه أقوى طريقة لفهم سبب خطأ في منطق البرنامج.

> **تشبيه:** تشغيل البرنامج عاديًا مثل مشاهدة مباراة بالسرعة الطبيعية. المنقّح مثل **الإعادة بالتصوير البطيء**: توقف اللقطة، وتقدّمها إطارًا إطارًا، وترى مكان كل لاعب.

هذا برنامج فيه خطأ منطقي: المفروض أن يحسب متوسط الدرجات `85`، لكنه يطبع رقمًا آخر:

```ring run
aGrades = [80, 90, 85]
nSum = 0
for i = 1 to len(aGrades) - 1
    nSum += aGrades[i]
next
see "المتوسط: " + (nSum / len(aGrades)) + nl
```

```text output
المتوسط: 56.67
```

لنكتشف السبب بالمنقّح:

1. ضع المؤشر على السطر `nSum += aGrades[i]` واضغط `F9` (**Debug > Toggle Breakpoint**، أي تبديل نقطة التوقف). تظهر نقطة حمراء بجانب السطر.
2. اضغط `F5` (**Debug > Start Debugging / Continue**). يتوقف البرنامج عند النقطة الحمراء.
3. انظر إلى نافذة **Locals** (المتغيرات المحلية): ترى `i` و`nSum` وقيمهما الآن.
4. اضغط `F10` (**Step Over**، خطوة فوق) لتنفيذ سطر واحد، وراقب تغيّر `nSum`.
5. اضغط `F5` للمتابعة حتى نقطة التوقف التالية. ستلاحظ أن الحلقة توقفت عندما كانت `i = 2`، ولم تصل أبدًا إلى `i = 3`!

السبب: `len(aGrades) - 1`. هذه عادة من لغات ترقيمها يبدأ من 0. في Ring الترقيم من 1 إلى `len()`:

```ring run
aGrades = [80, 90, 85]
nSum = 0
for i = 1 to len(aGrades)
    nSum += aGrades[i]
next
see "المتوسط: " + (nSum / len(aGrades)) + nl
```

```text output
المتوسط: 85
```

### أوامر المنقّح

| المفتاح | الأمر | العمل |
|---|---|---|
| `F9` | Toggle Breakpoint | وضع أو إزالة نقطة توقف |
| `F5` | Start Debugging / Continue | بدء التصحيح أو المتابعة إلى النقطة التالية |
| `F10` | Step Over | تنفيذ السطر الحالي كاملًا (حتى لو استدعى دالة) |
| `F11` | Step Into | الدخول إلى الدالة التي يستدعيها السطر |
| `Shift+F11` | Step Out | إكمال الدالة الحالية والخروج منها |
| `Shift+F5` | Stop Debugging | إيقاف البرنامج |

ونوافذ مفيدة أثناء التوقف: **Locals** (المتغيرات المحلية)، و**Call Stack** (مكدس الاستدعاءات: أي دالة استدعت أي دالة)، و**Immediate** (الأوامر الفورية).

> **ملحوظة:** `F5` تشغّل مع المنقّح، و`Ctrl+F5` (**Start Without Debugging**) تشغّل بدونه وتتجاهل نقاط التوقف.

### الطباعة للتتبع

أبسط من المنقّح أحيانًا: اطبع قيم المتغيرات في الأماكن المشكوك فيها، ثم احذف هذه الأسطر بعد إصلاح الخطأ:

```ring run
aGrades = [80, 90, 85]
nSum = 0
for i = 1 to len(aGrades) - 1
    nSum += aGrades[i]
    see "[تتبع] i = " + i + "، nSum = " + nSum + nl
next
```

```text output
[تتبع] i = 1، nSum = 80
[تتبع] i = 2، nSum = 170
```

## RingPM: مدير حزم Ring

**RingPM** يثبّت مكتبات إضافية كتبها مجتمع Ring. في RAD IDE لها ثلاث طرق:

- **Project > Manage Packages...** (إدارة الحزم...): ابحث عن الحزمة واضغط تثبيت.
- قائمة **Ring** التي تظهر في شريط القوائم عندما يكون مشروع Ring مفتوحًا: **Install Package (ringpm)...** و**Installed Packages (ringpm list)**.
- أو من سطر الأوامر:

```text
ringpm search json
ringpm install <اسم الحزمة>
ringpm list
```

الحزم تُثبَّت داخل مجلد Ring نفسه، فتصبح متاحة لكل مشاريعك بالأمر `load`.

## قائمة Ring

عندما يكون مشروع Ring مفتوحًا تظهر قائمة **Ring** في شريط القوائم، وفيها:

| الأمر | العمل |
|---|---|
| **Run** | تشغيل المشروع |
| **Build EXE (Publish)...** | تحويل البرنامج إلى ملف `.exe` بالأداة `ring2exe` لتوزيعه على أجهزة ليس عليها Ring |
| **Install Package (ringpm)...** | تثبيت حزمة |
| **Installed Packages (ringpm list)** | عرض الحزم المثبتة |

وكليك يمين على أي ملف `.ring` في **Solution Explorer** يعطيك **Run This File** (تشغيل هذا الملف) و**Build EXE from This File (ring2exe)**.

## تمرين

### صحّح البرنامج

البرنامج التالي يجب أن يطبع أكبر رقم في القائمة (`42`)، لكنه يطبع `3`. استخدم المنقّح أو الطباعة للتتبع لتجد الخطأ، ثم صحّحه.

```ring exercise
aNums = [7, 42, 19, 3]
nMax = aNums[1]
for n in aNums
    if n < nMax
        nMax = n
    ok
next
see "أكبر رقم: " + nMax + nl
```

```ring solution
aNums = [7, 42, 19, 3]
nMax = aNums[1]
for n in aNums
    if n > nMax
        nMax = n
    ok
next
see "أكبر رقم: " + nMax + nl
```

```text output
أكبر رقم: 42
```

الخطأ كان في علامة المقارنة: `n < nMax` تبحث عن **الأصغر**، ولهذا ظهر `3`. ضع نقطة توقف داخل `if` وراقب `nMax` في **Locals** لترى متى تتغير.

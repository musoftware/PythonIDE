# الدرس 1: مرحبًا بك في Ring: برنامجك الأول

**في هذا الدرس ستتعلم:**

- ما هي لغة **Ring** ولماذا هي مناسبة للمبتدئين.
- كيف تتأكد أن Ring مثبتة وأن RAD IDE وجدتها.
- كيف تنشئ مشروع Ring جديدًا وتشغّله.
- أمر الطباعة `see` والتعليقات.

## ما هي Ring؟

**Ring** لغة برمجة حديثة ومجانية ومفتوحة المصدر، صمّمها المبرمج المصري **محمد فايد**، وأول إصدار لها ظهر سنة 2016. من أهم صفاتها:

- **بسيطة**: لا تحتاج إلى تعريف نوع المتغير، ولا إلى فاصلة منقوطة في آخر كل سطر.
- **متعددة الأساليب**: تستطيع أن تكتب بها برمجة إجرائية عادية، أو برمجة كائنية (Classes)، أو برمجة **طبيعية** قريبة من لغة البشر.
- **معها مكتبات جاهزة**: نوافذ رسومية (RingQt)، وألعاب (RingRayLib)، وقواعد بيانات (SQLite وMySQL)، وإنترنت (RingLibCurl)، وغيرها.
- **غير حساسة لحالة الأحرف**: `see` و`SEE` و`See` كلها نفس الأمر.

> **تشبيه:** إذا كانت لغات مثل C++ سيارة سباق تحتاج سائقًا محترفًا، فإن Ring دراجة كهربائية مريحة: تصل بها بسرعة، وتستطيع أن تتعلم القيادة عليها من اليوم الأول.

## تجهيز بيئة العمل

1. نزّل Ring من الموقع الرسمي `https://ring-lang.github.io/download.html` وثبّتها. المثبّت في ويندوز يضعها عادة في المجلد `C:\ring`، والمفسّر نفسه هو الملف `C:\ring\ring\bin\ring.exe`.
2. افتح RAD IDE. ستجد Ring تلقائيًا إذا كانت في هذا المكان.
3. إذا لم تجدها، اختر من القائمة **Tools > Interpreter Path...** (أدوات > مسار المفسّر...) وحدّد الملف `ring.exe`.

> **ما هو المفسّر (Interpreter)؟** هو البرنامج الذي يقرأ الكود الذي كتبته وينفّذه سطرًا سطرًا. Ring لغة **مفسَّرة**: لا تحتاج إلى خطوة ترجمة طويلة قبل التشغيل.

## إنشاء أول مشروع

1. من القائمة **File > New Project...** (ملف > مشروع جديد) أو `Ctrl+Shift+N`.
2. في شجرة اللغات على اليسار افتح مجموعة **Ring** واختر **Ring (Console / Web / Library)** (Ring (كونسول / ويب / مكتبة)).
3. اختر القالب **Console Application (Ring)** (تطبيق كونسول (Ring)).
4. اكتب اسمًا للمشروع مثل `HelloRing` ثم اضغط **OK** (موافق).

سيفتح المشروع ومعه الملف `main.ring`. امسح ما فيه واكتب:

```ring run
see "Hello, World!" + nl
```

```text output
Hello, World!
```

اضغط `Ctrl+F5` (**Debug > Start Without Debugging**، أي بدء بدون تصحيح الأخطاء) فيظهر الناتج في نافذة **Output** (المخرجات).

> **نصيحة:** في هذه الدروس، كل مثال بجانبه زر «جرّبه». اضغطه وستنشئ لك الـ IDE مشروعًا فيه هذا الكود وتشغّله مباشرة.

## فهم السطر الأول

- `see` أمر **الطباعة**: يكتب ما بعده على الشاشة.
- `"Hello, World!"` **نص** (string) بين علامتي تنصيص.
- `+` هنا تعني **ربط** نصّين ببعضهما.
- `nl` اختصار New Line، أي «انزل سطرًا جديدًا».

بدون `nl` يكمل الأمر التالي على نفس السطر:

```ring run
see "السلام "
see "عليكم"
see nl
see "أهلًا بك في Ring" + nl
```

```text output
السلام عليكم
أهلًا بك في Ring
```

## الاختصار `?`

علامة الاستفهام `?` تطبع ثم تنزل سطرًا تلقائيًا، فهي تساوي `see ... + nl`:

```ring run
? "أنا أتعلم Ring"
? "وهي لغة سهلة"
? 2026
```

```text output
أنا أتعلم Ring
وهي لغة سهلة
2026
```

## الطباعة على عدة أسطر

Ring تقبل النص على أكثر من سطر، وتقبل ثلاثة أنواع من علامات التنصيص: `"..."` و`'...'` و`` `...` ``. هذا يسهّل كتابة نص يحتوي علامة تنصيص:

```ring run
see "قال: 'مرحبًا'" + nl
see 'كتب: "Ring"' + nl
see "السطر الأول
السطر الثاني" + nl
```

```text output
قال: 'مرحبًا'
كتب: "Ring"
السطر الأول
السطر الثاني
```

## التعليقات (Comments)

التعليق كلام تكتبه لنفسك، والمفسّر **يتجاهله**. في Ring ثلاثة أشكال:

```ring run
# هذا تعليق من سطر واحد
// وهذا أيضًا تعليق من سطر واحد
/*
   وهذا تعليق
   من عدة أسطر
*/
see "التعليقات لا تظهر في الناتج" + nl   # تعليق في آخر السطر
```

```text output
التعليقات لا تظهر في الناتج
```

## العربية في الكونسول

داخل الـ IDE تظهر العربية صحيحة دائمًا، لأن ملفات الكود تُحفظ بترميز **UTF-8** ونافذة المخرجات تقرأ بنفس الترميز. إذا شغّلت البرنامج بنفسك في نافذة `cmd` القديمة فقد تظهر الحروف رموزًا غريبة؛ اكتب قبل التشغيل الأمر `chcp 65001` لتحويل الكونسول إلى UTF-8.

## تشغيل Ring بدون الـ IDE

يمكنك أيضًا تشغيل أي ملف من سطر الأوامر هكذا:

```text
C:\ring\ring\bin\ring.exe main.ring
```

والـ IDE تفعل نفس الشيء عندما تضغط `Ctrl+F5`، لكنها تعرض الناتج وتلوّن الأخطاء وتسمح لك بالقفز إلى سطر الخطأ.

## أخطاء شائعة

- **نسيان علامة التنصيص الأخيرة:** `see "Hello` يعطي خطأ لأن النص لم يُغلق.
- **علامات تنصيص ذكية:** عند النسخ من Word قد تظهر `“` بدل `"`، وRing لا تفهمها.
- **نسيان `nl`:** فتلتصق الأسطر ببعضها.

مثال على خطأ، لاحظ الرسالة التي تعطيها Ring:

```ring
see "Hello
```

```text
Error (S1) In file: main.ring
In Line (1) Literal not closed
```

ومثال آخر: استخدام متغير لم نعطه قيمة بعد:

```ring
see y
```

```text
Line 1 Error (R24) : Using uninitialized variable: y
in file main.ring
```

رسائل الأخطاء في Ring تذكر **رقم السطر** و**رمز الخطأ**. الحرف `S` أو `C` يعني خطأ في كتابة الكود اكتُشف **قبل** التشغيل، والحرف `R` يعني خطأ حدث **أثناء** التشغيل (Runtime). في الـ IDE تظهر هذه الأخطاء أيضًا في **Error List** (قائمة الأخطاء)، واضغط عليها مرتين لتقفز إلى السطر.

## تمارين

### التمرين 1

اطبع اسمك في سطر، ومدينتك في السطر التالي، باستخدام `see` و`nl`.

```ring exercise
# اطبع:
# الاسم: منى
# المدينة: القاهرة
```

```ring solution
see "الاسم: منى" + nl
see "المدينة: القاهرة" + nl
```

```text output
الاسم: منى
المدينة: القاهرة
```

### التمرين 2

اطبع مثلثًا من النجوم بثلاثة أسطر باستخدام `?`.

```ring exercise
# *
# **
# ***
```

```ring solution
? "*"
? "**"
? "***"
```

```text output
*
**
***
```

## الخلاصة

- Ring لغة بسيطة ومفسَّرة، والمفسّر هو `ring.exe`.
- أنشئ المشروع من **File > New Project... > Ring > Console Application (Ring)**.
- `see` للطباعة، و`nl` لسطر جديد، و`?` تطبع وتنزل سطرًا.
- التعليقات: `#` و`//` و`/* */`.

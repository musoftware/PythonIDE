# الدرس 2: المتغيرات وأنواع البيانات والإدخال

**في هذا الدرس ستتعلم:**

- ما هو **المتغير** وكيف تعطيه قيمة.
- أنواع البيانات في Ring: الرقم، والنص، والقائمة، والكائن.
- قاعدة مهمة جدًا: ماذا يحدث عند جمع نص ورقم.
- قراءة ما يكتبه المستخدم بالأمر `give`.

## ما هو المتغير؟

**المتغير** (variable) صندوق له اسم، نضع فيه قيمة لنستخدمها لاحقًا. في Ring لا تحتاج إلى تعريف المتغير قبل استخدامه ولا إلى ذكر نوعه: يكفي أن تعطيه قيمة بعلامة `=`.

```ring run
cName = "سارة"
nAge = 22
nHeight = 1.65

see "الاسم: " + cName + nl
see "العمر: " + nAge + nl
see "الطول: " + nHeight + nl
```

```text output
الاسم: سارة
العمر: 22
الطول: 1.65
```

> **عادة جيدة:** كثير من مبرمجي Ring يبدؤون اسم المتغير بحرف يدل على نوعه: `c` للنص (character)، و`n` للرقم (number)، و`a` للقائمة (array/list)، و`o` للكائن (object). Ring لا تُلزمك بهذا، لكنه يجعل الكود أوضح.

## أنواع البيانات

في Ring أربعة أنواع أساسية فقط:

| النوع | مثال | ما تُرجعه `type()` |
|---|---|---|
| رقم (Number) | `25` أو `3.14` | `NUMBER` |
| نص (String) | `"Ring"` | `STRING` |
| قائمة (List) | `[1, 2, 3]` | `LIST` |
| كائن (Object) | `new Person` | `OBJECT` |

الدالة `type()` تخبرك بنوع أي قيمة:

```ring run
see type(25) + nl
see type("Ring") + nl
see type([1, 2, 3]) + nl
```

```text output
NUMBER
STRING
LIST
```

والمتغير الواحد يمكن أن يحمل قيمة من نوع ثم من نوع آخر، ولهذا نقول إن Ring لغة **ديناميكية الأنواع** (dynamic typing):

```ring run
x = 10
see type(x) + nl
x = "عشرة"
see type(x) + nl
```

```text output
NUMBER
STRING
```

## الأرقام العشرية

Ring تطبع الأرقام العشرية افتراضيًا **برقمين** بعد العلامة العشرية. والأمر `decimals(n)` يغيّر هذا العدد:

```ring run
see 10 / 3
see nl
see 7 / 2
see nl
decimals(4)
see 10 / 3
see nl
```

```text output
3.33
3.50
3.3333
```

لاحظ أن `7 / 2` ظهرت `3.50` وليس `3.5`. أما الأعداد الصحيحة مثل `22` فتظهر بلا علامة عشرية.

## النص + الرقم: القاعدة الذهبية

علامة `+` تعمل حسب نوع **القيمة التي على اليسار**:

- إذا كان اليسار **نصًا**: يتحول اليمين إلى نص ويُلصق به.
- إذا كان اليسار **رقمًا**: يتحول اليمين إلى رقم ويُجمع.

```ring run
see "5" + 10
see nl
see 5 + "10"
see nl
see "العمر: " + 20 + nl
```

```text output
510
15
العمر: 20
```

> **تشبيه:** الطرف الأيسر هو «صاحب البيت»، والضيف على اليمين يلبس ملابس صاحب البيت. إذا كان صاحب البيت نصًا صار الضيف نصًا، وإذا كان رقمًا صار الضيف رقمًا.

ولهذا فهذا السطر يعطي **خطأ**، لأن اليسار رقم والنص `" سنة"` لا يمكن تحويله إلى رقم:

```ring
nAge = 20
see nAge + " سنة"
```

```text
Line 2 Error (R41) : Invalid numeric string
```

والحل أن نبدأ بنص، ولو كان نصًا فارغًا:

```ring run
nAge = 20
see "" + nAge + " سنة" + nl
```

```text output
20 سنة
```

## التحويل بين الأنواع

| الدالة | العمل | مثال |
|---|---|---|
| `number(c)` | نص إلى رقم | `number("42")` تعطي `42` |
| `string(n)` | رقم إلى نص | `string(42)` تعطي `"42"` |
| `isnumber(x)` | هل هي رقم؟ | `1` (نعم) أو `0` (لا) |
| `isstring(x)` | هل هي نص؟ | `1` أو `0` |

```ring run
cText = "42"
nValue = number(cText)
see nValue + 8
see nl
see isnumber(nValue)
see nl
see isstring(cText)
see nl
```

```text output
50
1
1
```

لاحظ أن Ring تمثل «صحيح» بالرقم `1` و«خطأ» بالرقم `0`. والكلمتان `true` و`false` موجودتان، وقيمتهما `1` و`0`.

## الإدخال من المستخدم: `give`

الأمر `give` ينتظر المستخدم حتى يكتب شيئًا ويضغط Enter، ثم يضع ما كتبه في المتغير. ما يكتبه المستخدم يصل دائمًا **نصًا**:

```ring run
see "ما اسمك؟ "
give cName
see "أهلًا يا " + cName + nl
```

```text input
أحمد
```

```text output
ما اسمك؟ أهلًا يا أحمد
```

> **ملحوظة:** في نافذة المخرجات لا يظهر ما كتبه المستخدم، لذلك يظهر السؤال والرد على نفس السطر. عند الضغط على «جرّبه» تطلب منك الـ IDE ما تريد إدخاله، أو تأخذه من مربع «المدخلات» في الدرس.

### قراءة الأرقام

لأن `give` تعطي نصًا، فجمع رقمين مباشرة يلصقهما. حوّلهما بـ `number()` أولًا:

```ring run
see "الرقم الأول: "
give a
see "الرقم الثاني: "
give b
see nl
see "بدون تحويل: " + (a + b) + nl
see "بعد التحويل: " + (number(a) + number(b)) + nl
```

```text input
3
4
```

```text output
الرقم الأول: الرقم الثاني: 
بدون تحويل: 34
بعد التحويل: 7
```

## الثوابت المفيدة

| الكلمة | معناها |
|---|---|
| `nl` | سطر جديد |
| `true` / `false` | 1 / 0 |
| `NULL` | قيمة فارغة (نص فارغ) |
| `tab` | مسافة جدولة |

## أخطاء شائعة

- **بدء التعبير برقم ثم نص:** `see nAge + " سنة"` خطأ R41. ابدأ بنص: `"" + nAge + " سنة"`.
- **نسيان أن `give` تعطي نصًا:** `"3" + "4"` تساوي `"34"` وليس `7`.
- **استخدام متغير قبل إعطائه قيمة:** يعطي الخطأ `R24 Using uninitialized variable`.
- **أسماء المتغيرات غير حساسة لحالة الأحرف:** `Name` و`name` نفس المتغير، فلا تستخدمهما لشيئين مختلفين.

## تمارين

### التمرين 1: بطاقة طالب

ضع اسم الطالب ودرجته في متغيرين، ثم اطبع: `الطالب: خالد - الدرجة: 88`.

```ring exercise
cStudent = "خالد"
nGrade = 88
# اطبع السطر المطلوب
```

```ring solution
cStudent = "خالد"
nGrade = 88
see "الطالب: " + cStudent + " - الدرجة: " + nGrade + nl
```

```text output
الطالب: خالد - الدرجة: 88
```

### التمرين 2: مساحة المستطيل

اقرأ الطول والعرض من المستخدم، ثم اطبع المساحة.

```ring exercise
see "الطول: "
give cLength
see "العرض: "
give cWidth
# حوّل واحسب المساحة
```

```ring solution
see "الطول: "
give cLength
see "العرض: "
give cWidth
nArea = number(cLength) * number(cWidth)
see nl + "المساحة = " + nArea + nl
```

```text input
5
4
```

```text output
الطول: العرض: 
المساحة = 20
```

## الخلاصة

- المتغير يُنشأ بمجرد إعطائه قيمة، ونوعه يتحدد بقيمته.
- الأنواع: رقم، نص، قائمة، كائن، و`type()` تخبرك بالنوع.
- في `+` الطرف الأيسر يقرر: نص = ربط، رقم = جمع.
- `give` تقرأ نصًا، و`number()` تحوّله إلى رقم.

# الدرس 3: العمليات والشروط واتخاذ القرار

**في هذا الدرس ستتعلم:**

- العمليات الحسابية وعمليات المقارنة والعمليات المنطقية.
- الشرط `if` و`but` و`else` و`ok`.
- الاختيار من متعدد بـ `switch`.

## العمليات الحسابية

| العملية | الرمز | مثال | الناتج |
|---|---|---|---|
| جمع | `+` | `7 + 2` | `9` |
| طرح | `-` | `7 - 2` | `5` |
| ضرب | `*` | `7 * 2` | `14` |
| قسمة | `/` | `7 / 2` | `3.50` |
| باقي القسمة | `%` | `7 % 2` | `1` |
| أُس (قوة) | `pow(a, b)` | `pow(2, 3)` | `8` |

```ring run
a = 7
b = 2
see "a + b = " + (a + b) + nl
see "a * b = " + (a * b) + nl
see "a / b = " + (a / b) + nl
see "a % b = " + (a % b) + nl
see "2 أُس 10 = " + pow(2, 10) + nl
see "الجزء الصحيح من 7/2 = " + floor(a / b) + nl
```

```text output
a + b = 9
a * b = 14
a / b = 3.50
a % b = 1
2 أُس 10 = 1024
الجزء الصحيح من 7/2 = 3
```

> **انتبه:** الأقواس حول `(a + b)` ضرورية هنا. بدونها يُلصق النص بـ `a` أولًا ثم بـ `b`، فيظهر `72` بدل `9`.

> **وانتبه أيضًا:** العلامة `^` في Ring ليست الأُس، بل عملية على البتات (XOR). استخدم `pow()` للأُس.

### الاختصارات

```ring run
n = 10
n += 5     # n = n + 5
n -= 3     # n = n - 3
n *= 2     # n = n * 2
n++        # n = n + 1
see n
see nl
```

```text output
25
```

## عمليات المقارنة

نتيجة المقارنة `1` (صحيح) أو `0` (خطأ):

| الرمز | المعنى |
|---|---|
| `=` | يساوي |
| `!=` | لا يساوي |
| `>` و`<` | أكبر من، أصغر من |
| `>=` و`<=` | أكبر من أو يساوي، أصغر من أو يساوي |

لاحظ أن المساواة في Ring علامة `=` واحدة، سواء في إعطاء القيمة أو في المقارنة؛ والسياق يحدد المعنى.

```ring run
see 5 = 5
see nl
see 5 != 5
see nl
see "Ring" = "ring"
see nl
```

```text output
1
0
0
```

مقارنة النصوص **حساسة** لحالة الأحرف: `"Ring"` لا تساوي `"ring"` (بعكس أسماء المتغيرات والأوامر).

## العمليات المنطقية

| الكلمة | الرمز البديل | المعنى |
|---|---|---|
| `and` | `&&` | الشرطان صحيحان معًا |
| `or` | `\|\|` | أحدهما على الأقل صحيح |
| `not` | `!` | يعكس الشرط |

## الشرط `if`

الصيغة في Ring:

```ring
if الشرط
    تعليمات تُنفذ إذا كان الشرط صحيحًا
ok
```

الكلمة `ok` تُغلق الشرط (يمكنك أيضًا استخدام `end` أو `endif`، و`ok` هي الأشهر).

```ring run
nTemp = 38
if nTemp > 37
    see "عندك حرارة، استرح اليوم" + nl
ok
see "انتهى الفحص" + nl
```

```text output
عندك حرارة، استرح اليوم
انتهى الفحص
```

### `else` و`but`

- `else` تعني «وإلا».
- `but` تعني «وإلا إذا» (مثل `elseif` في لغات أخرى، ويمكنك كتابة `elseif` أيضًا).

```ring run
nGrade = 77
if nGrade >= 90
    see "ممتاز" + nl
but nGrade >= 75
    see "جيد جدًا" + nl
but nGrade >= 50
    see "ناجح" + nl
else
    see "راسب" + nl
ok
```

```text output
جيد جدًا
```

> **تشبيه:** الشرط مثل إشارة المرور: إذا كانت خضراء تعبر، **وإلا إذا** كانت صفراء تستعد، **وإلا** تقف.

### شرط من سطر واحد

يمكن كتابة الشرط القصير في سطر واحد:

```ring run
nAge = 20
if nAge >= 18 see "بالغ" + nl else see "قاصر" + nl ok
```

```text output
بالغ
```

### دمج الشروط

```ring run
nAge = 25
lHasLicense = true
if nAge >= 18 and lHasLicense
    see "يمكنك قيادة السيارة" + nl
ok
if not lHasLicense or nAge < 18
    see "لا يمكنك القيادة" + nl
else
    see "قُد بأمان" + nl
ok
```

```text output
يمكنك قيادة السيارة
قُد بأمان
```

## الاختيار من متعدد: `switch`

عندما نقارن متغيرًا واحدًا بقيم كثيرة، يكون `switch` أوضح من سلسلة `but`:

```ring
switch المتغير
on القيمة1
    ...
on القيمة2
    ...
other
    ... (أي قيمة أخرى)
off
```

```ring run
nDay = 6
switch nDay
on 1
    see "السبت" + nl
on 6
    see "الخميس" + nl
on 7
    see "الجمعة: إجازة" + nl
other
    see "يوم عمل عادي" + nl
off
```

```text output
الخميس
```

ويعمل `switch` مع النصوص أيضًا:

```ring run
cColor = "أحمر"
switch cColor
on "أخضر"
    see "اعبر" + nl
on "أصفر"
    see "استعد" + nl
on "أحمر"
    see "قف" + nl
off
```

```text output
قف
```

## أخطاء شائعة

- **نسيان `ok`:** يعطي الخطأ `C3 Unclosed control structure, 'ok' is missing`.
- **كتابة `^` للأُس:** استخدم `pow(2, 3)`.
- **نسيان الأقواس عند جمع رقمين داخل نص:** `"الناتج " + a + b` تلصق ولا تجمع.
- **مقارنة نص بحالة أحرف مختلفة:** `"Yes" = "yes"` تعطي `0`. استخدم `lower()` على الطرفين (سنراها في درس النصوص).

## تمارين

### التمرين 1: زوجي أم فردي

اطبع هل الرقم `n` زوجي أم فردي باستخدام باقي القسمة `%`.

```ring exercise
n = 17
# اطبع: 17 فردي
```

```ring solution
n = 17
if n % 2 = 0
    see "" + n + " زوجي" + nl
else
    see "" + n + " فردي" + nl
ok
```

```text output
17 فردي
```

### التمرين 2: الآلة الحاسبة

اقرأ رقمين وعملية (`+` أو `-` أو `*` أو `/`)، واطبع الناتج باستخدام `switch`.

```ring exercise
give a
give op
give b
a = number(a)
b = number(b)
# استخدم switch op
```

```ring solution
give a
give op
give b
a = number(a)
b = number(b)
switch op
on "+"
    see "الناتج = " + (a + b) + nl
on "-"
    see "الناتج = " + (a - b) + nl
on "*"
    see "الناتج = " + (a * b) + nl
on "/"
    if b = 0
        see "لا يمكن القسمة على صفر" + nl
    else
        see "الناتج = " + (a / b) + nl
    ok
other
    see "عملية غير معروفة" + nl
off
```

```text input
12
*
3
```

```text output
الناتج = 36
```

## الخلاصة

- العمليات: `+ - * / %` و`pow()`، والاختصارات `+= -= ++`.
- المقارنة بـ `=` و`!=`، والنتيجة `1` أو `0`.
- `if ... but ... else ... ok` للشروط، و`switch ... on ... other ... off` للاختيار من متعدد.

# Ring course (ring): block format and tests

17 Arabic lessons (`NN-slug.md`, listed in `course.json`) for Ring 1.28+ (`C:\ring\ring\bin\ring.exe`).
The runner code is `radide/tutorials/ring_support.py` (projects, headless checks, a small Pygments lexer).

| Info string | Meaning | "جرّبه" / "تحقق" |
|---|---|---|
| ```` ```ring run ```` | console program (`main.ring`) | ring-app project, startup `main.ring`; stdin from the following ```` ```text input ```` |
| ```` ```ring form run ```` | the code file of a RingQt form (`Form1.ring`: `load "Form1_designer.ring"` + handlers) | ring-qt project: Form1 gets the controls the code names (`btn`, `txt`, `lbl`, `lst`, `cbo`, `chk`, `opt`, `tmr`, `prg`, `grp`, `num`, `trk` prefixes), laid out in a column; the designer file is generated by the ring-qt plugin |
| ```` ```ring exercise ```` / ```` ```ring solution ```` (also with `form`) | starter code / hidden solution | as above; exercises are checked against the solution's output / test |
| ```` ```ring ```` | snippet, not run | display only |

`// #file: name.ring` lines split a block into several files (lesson 16: `Form1.ring` + `contacts.ring`).

Hidden `<!-- test: {...} -->` before a block:

* `"form"`: `{"Text": ..., "Width": ..., "controls": {"btnHello": {"Text": "...", "Type": "Label", "Items": "a;b"}}}` -
  captions / extra controls of the generated form (also used by "جرّبه").
* `"do"`: Ring statements run after `Form1_Create()` (QT_QPA_PLATFORM=offscreen, the form is never shown).
* `"expect"`: `{"Ring expression": "expected text"}` evaluated after `do`.
* `"norun": true`: only `ring file -norun` (RayLib windows, internet examples).
* `"error"`: an expected run-time error code (e.g. `"R24"`).

A program fails the check when ring.exe exits with an error that was not caught, when the output differs from the
```` ```text output ```` block, or when an `expect` value differs.

## Testing

`tools/check_lessons.py` extracts every block and runs it with the real ring.exe:

    python radide/tutorials/ring/tools/check_lessons.py          # all lessons (about 30 s)
    python radide/tutorials/ring/tools/check_lessons.py 12 -v    # one lesson, list every block

(It calls `radide.tutorials.check()` for every `run` / `solution` block, `ring -norun` for exercises, validates the
quiz JSON and builds the "جرّبه" project of every block with `make_project()`.)

## Ring facts the lessons rely on (Ring 1.28)

- Decimals print with 2 digits by default (`7 / 2` -> `3.50`, `decimals(n)` changes it); `100 * 1.1` prints `110.00`.
- `number + string` converts the string to a number (`5 + " x"` -> R41); lessons start with `"" + n`.
- `^` is XOR (`pow()` for powers); string comparison is case-sensitive, names are not (`oR` is the keyword `or`).
- `len()` counts UTF-8 bytes (Arabic letter = 2); `see`, comparison, `substr` search/replace work with Arabic.
- Lists and objects are copied on assignment and passed by reference to functions.
- RingQt indexes from 0 (`currentRow()` = -1 when nothing is selected); `qListWidget.setCurrentRow(row, 3)` needs
  the selection flags; `qComboBox.addItem(text, 0)`.
- `sqlite_execute()` returns rows as lists of `[column, value]` pairs with string values.
- RayLib's `DrawText` has no Arabic glyphs (game texts are English).

# الدرس 5: القوائم (Lists) والقواميس

**في هذا الدرس ستتعلم:**

- إنشاء **قائمة** والوصول إلى عناصرها (الترقيم يبدأ من **1**).
- الإضافة والحذف والبحث والترتيب.
- القوائم المتداخلة (جداول).
- القوائم ذات المفاتيح (القواميس) مثل `aPerson[:name]`.

## ما هي القائمة؟

**القائمة** (list) متغير واحد يحمل عدة قيم مرتبة. في Ring القائمة هي الأداة الأساسية لتجميع البيانات، وتقوم بدور المصفوفة (array) في اللغات الأخرى.

> **تشبيه:** القائمة مثل قطار له عربات مرقمة: العربة 1، والعربة 2، وهكذا. كل عربة تحمل قيمة، ويمكنك إضافة عربات أو فصلها.

```ring run
aNames = ["علي", "سارة", "يوسف"]
see aNames[1] + nl
see aNames[3] + nl
see "عدد العناصر: " + len(aNames) + nl
```

```text output
علي
يوسف
عدد العناصر: 3
```

> **مهم:** ترقيم القوائم في Ring يبدأ من **1** وليس من 0 كما في C++ وPython. العنصر الأول هو `aNames[1]` والأخير هو `aNames[len(aNames)]`.

القائمة يمكن أن تحمل أنواعًا مختلفة معًا: `[1, "نص", 3.5, [1, 2]]`.

## طباعة القائمة

الأمر `see` يطبع كل عنصر في سطر:

```ring run
aNumbers = [10, 20, 30]
see aNumbers
```

```text output
10
20
30
```

## تعديل العناصر والمرور عليها

```ring run
aScores = [70, 85, 90]
aScores[1] = 75            # تعديل العنصر الأول
for i = 1 to len(aScores)
    see "الدرجة " + i + ": " + aScores[i] + nl
next
```

```text output
الدرجة 1: 75
الدرجة 2: 85
الدرجة 3: 90
```

## الإضافة والحذف والبحث

| الدالة | العمل |
|---|---|
| `add(aList, x)` | يضيف `x` في آخر القائمة |
| `insert(aList, n, x)` | يضيف `x` **بعد** العنصر رقم `n` (و`0` تعني في البداية) |
| `del(aList, n)` | يحذف العنصر رقم `n` |
| `find(aList, x)` | رقم العنصر الذي يساوي `x`، أو `0` إذا لم يوجد |
| `len(aList)` | عدد العناصر |

```ring run
aTasks = ["مذاكرة", "رياضة"]
add(aTasks, "قراءة")
insert(aTasks, 0, "صلاة الفجر")
del(aTasks, 3)
for cTask in aTasks
    see "- " + cTask + nl
next
see "مكان القراءة: " + find(aTasks, "قراءة") + nl
see "مكان النوم: " + find(aTasks, "نوم") + nl
```

```text output
- صلاة الفجر
- مذاكرة
- قراءة
مكان القراءة: 3
مكان النوم: 0
```

## الترتيب والعكس والقيم الكبرى

```ring run
aNums = [42, 7, 19, 3]
aSorted = sort(aNums)
see "مرتبة: "
for n in aSorted see "" + n + " " next
see nl
see "معكوسة: "
for n in reverse(aSorted) see "" + n + " " next
see nl
see "الأكبر: " + max(aNums) + " والأصغر: " + min(aNums) + nl
```

```text output
مرتبة: 3 7 19 42 
معكوسة: 42 19 7 3 
الأكبر: 42 والأصغر: 3
```

لاحظ أن `sort()` و`reverse()` تُرجعان قائمة **جديدة** ولا تغيّران القائمة الأصلية.

## قائمة من مدى أرقام

`1:5` تنشئ القائمة `[1, 2, 3, 4, 5]`، و`list(n)` تنشئ قائمة فيها `n` عنصر فارغ:

```ring run
aRange = 1:5
see "عدد العناصر: " + len(aRange) + " وآخرها " + aRange[5] + nl
aEmpty = list(3)
see "قائمة فيها " + len(aEmpty) + " عناصر" + nl
```

```text output
عدد العناصر: 5 وآخرها 5
قائمة فيها 3 عناصر
```

## القوائم المتداخلة (الجداول)

عنصر القائمة يمكن أن يكون قائمة أخرى، فنحصل على جدول له صفوف وأعمدة:

```ring run
aStudents = [
    ["علي", 90],
    ["سارة", 95],
    ["يوسف", 78]
]
for aRow in aStudents
    see aRow[1] + ": " + aRow[2] + nl
next
see "درجة سارة: " + aStudents[2][2] + nl
```

```text output
علي: 90
سارة: 95
يوسف: 78
درجة سارة: 95
```

ويمكن الترتيب حسب عمود معيّن بـ `sort(aList, رقم_العمود)` والبحث في عمود بـ `find(aList, قيمة, رقم_العمود)`:

```ring run
aStudents = [["علي", 90], ["سارة", 95], ["يوسف", 78]]
aByGrade = sort(aStudents, 2)
see "الأقل درجة: " + aByGrade[1][1] + nl
see "مكان يوسف: " + find(aStudents, "يوسف", 1) + nl
```

```text output
الأقل درجة: يوسف
مكان يوسف: 3
```

## القواميس: قوائم بمفاتيح

بدل الأرقام يمكن أن نصل إلى العنصر **بمفتاح نصي**، مثل قاموس فيه كلمة ومعناها. نكتب المفتاح بنقطتين قبله `:name` أو كنص `"name"`:

```ring run
aPerson = [:name = "منى", :age = 28, :city = "طنطا"]
see aPerson[:name] + nl
see aPerson["age"]
see nl
aPerson[:job] = "مهندسة"     # مفتاح جديد يُضاف تلقائيًا
for aItem in aPerson
    see aItem[1] + " => " + aItem[2] + nl
next
```

```text output
منى
28
name => منى
age => 28
city => طنطا
job => مهندسة
```

في الحقيقة القاموس في Ring قائمة من أزواج `[المفتاح, القيمة]`، ولهذا نصل إلى المفتاح بـ `aItem[1]` وإلى القيمة بـ `aItem[2]`.

## القوائم تُنسخ عند الإسناد

عندما تكتب `b = a` تحصل `b` على **نسخة** مستقلة، فتعديلها لا يغيّر `a`:

```ring run
a = [1, 2, 3]
b = a
b[1] = 100
see "a[1] = " + a[1] + nl
see "b[1] = " + b[1] + nl
```

```text output
a[1] = 1
b[1] = 100
```

## أخطاء شائعة

- **البدء من 0:** `aList[0]` يعطي خطأ «Array Access (Index out of range)». الترقيم يبدأ من 1.
- **تجاوز آخر عنصر:** `aList[len(aList) + 1]` خطأ أيضًا. استخدم `add()` للإضافة.
- **طباعة رقم من القائمة مع نص بعده:** `see aList[1] + " درجة"` خطأ إذا كان العنصر رقمًا؛ ابدأ بنص.
- **توقع أن `sort()` تغيّر القائمة نفسها:** هي تُرجع قائمة جديدة، فاكتب `aList = sort(aList)`.

احسب مجموع ومتوسط الدرجات في القائمة.

## الخلاصة

- القائمة `[ ... ]` والترقيم من 1، و`len()` لعدد العناصر.
- `add` و`insert` و`del` و`find` و`sort` و`reverse` و`max` و`min`.
- القوائم المتداخلة للجداول، والقواميس `aList[:key]` للمفاتيح النصية.

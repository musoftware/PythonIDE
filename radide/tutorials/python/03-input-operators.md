# الدرس 3: الإدخال والعمليات الحسابية

حتى الآن كانت برامجنا تطبع قيمًا كتبناها بأنفسنا. اليوم نجعل البرنامج **يسأل المستخدم** ويحسب بناءً على إجابته.

## الدالة `input`

`input("سؤال")` تطبع السؤال، ثم تنتظر المستخدم حتى يكتب شيئًا ويضغط **Enter**، ثم ترجع ما كتبه **كنص** (`str`).

```python run
name = input("ما اسمك؟ ")
print(f"أهلًا يا {name}!")
```

```text input
Youssef
```

```text output
ما اسمك؟ أهلًا يا Youssef!
```

> **في الـ IDE:** عندما تضغط «جرّبه» على مثال يقرأ من لوحة المفاتيح، تُرسل الـ IDE المدخلات المكتوبة في الدرس (المربع «المدخلات») إلى البرنامج، أو تسألك أنت عنها. وعندما تشغّل مشروعك بنفسك، اكتب الإجابة في نافذة **Output** (المخرجات) ثم اضغط Enter.

لاحظ أن الترحيب ظهر بجوار السؤال على نفس السطر: ما كتبه المستخدم (ومعه ضغطة Enter) أُرسل إلى البرنامج من «المدخلات» ولم يُطبع في الناتج. أما عندما تكتب الإجابة بنفسك أثناء التشغيل فستراها مكتوبة وينزل المؤشر سطرًا جديدًا.

## `input` ترجع نصًا دائمًا!

هذا أهم شيء في الدرس. لو كتب المستخدم `5` فإن `input` ترجع `"5"` (نصًا)، ولكي تحسب بها يجب أن تحوّلها:

```python run
a = int(input("العدد الأول: "))
b = int(input("العدد الثاني: "))
print("المجموع =", a + b)
```

```text input
7
8
```

```text output
العدد الأول: العدد الثاني: المجموع = 15
```

لو نسيت `int(...)` لكان الناتج `78` بدل `15`، لأن Python كانت ستلصق النصين.

## العمليات الحسابية (Arithmetic Operators)

| العملية | الرمز | مثال | الناتج |
|---|---|---|---|
| جمع | `+` | `7 + 2` | `9` |
| طرح | `-` | `7 - 2` | `5` |
| ضرب | `*` | `7 * 2` | `14` |
| قسمة | `/` | `7 / 2` | `3.5` |
| قسمة صحيحة | `//` | `7 // 2` | `3` |
| باقي القسمة | `%` | `7 % 2` | `1` |
| أُس (قوة) | `**` | `7 ** 2` | `49` |

```python run
print(7 / 2)
print(8 / 2)       # القسمة / تعطي float دائمًا
print(7 // 2)
print(7 % 2)
print(2 ** 10)
print(-7 // 2)     # القسمة الصحيحة تقرّب لأسفل
```

```text output
3.5
4.0
3
1
1024
-4
```

> **فائدة `%`:** باقي القسمة على 2 يخبرك هل العدد زوجي (`0`) أم فردي (`1`). وسنستخدم ذلك كثيرًا في الشروط.

## ترتيب العمليات

مثل الرياضيات تمامًا: الأقواس أولًا، ثم الأُس، ثم الضرب والقسمة، ثم الجمع والطرح.

```python run
print(2 + 3 * 4)
print((2 + 3) * 4)
print(2 ** 3 * 2)
```

```text output
14
20
16
```

## دوال رياضية مفيدة

```python run
print(abs(-8))            # القيمة المطلقة
print(round(3.14159, 2))  # التقريب لخانتين
print(max(4, 9, 2))
print(min(4, 9, 2))

import math
print(math.sqrt(16))      # الجذر التربيعي
print(math.pi)
```

```text output
8
3.14
9
2
4.0
3.141592653589793
```

`import math` تُحضر **وحدة** (module) الرياضيات التي تأتي مع Python. سنتعلم الوحدات بالتفصيل في الدرس 12.

## مشكلة الأعداد العشرية

```python run
print(0.1 + 0.2)
print(round(0.1 + 0.2, 2))
```

```text output
0.30000000000000004
0.3
```

هذا ليس خطأ في Python، بل هو طريقة تخزين الأعداد العشرية في كل الحواسيب تقريبًا. عند عرض الأسعار والنتائج استخدم `round` أو التنسيق `f"{x:.2f}"`.

## مثال كامل: حساب مساحة غرفة وتكلفة دهانها

```python run
length = float(input("طول الغرفة بالمتر: "))
width = float(input("عرض الغرفة بالمتر: "))
price = float(input("سعر دهان المتر المربع: "))
area = length * width
cost = area * price
print(f"المساحة = {area:.1f} متر مربع")
print(f"التكلفة = {cost:.2f} جنيه")
```

```text input
4.5
3
25
```

```text output
طول الغرفة بالمتر: عرض الغرفة بالمتر: سعر دهان المتر المربع: المساحة = 13.5 متر مربع
التكلفة = 337.50 جنيه
```

## أخطاء شائعة

### تحويل نص لا يمثل رقمًا

إذا كتب المستخدم `abc` بدل رقم:

```python run
n = int("abc")
```

```text output

  File "main.py", line 1, in <module>
    n = int("abc")
ValueError: invalid literal for int() with base 10: 'abc'
```

سنتعلم في الدرس 10 كيف نتعامل مع هذا الخطأ بلطف بدل أن يتوقف البرنامج.

## تمارين

### التمرين 1

اقرأ درجة الحرارة بالمئوي، وحوّلها إلى فهرنهايت بالقانون `F = C × 9 / 5 + 32`.

```python exercise
c = float(input("الحرارة بالمئوي: "))
# اطبع: 37.0 مئوي = 98.6 فهرنهايت
```

```python solution
c = float(input("الحرارة بالمئوي: "))
f = c * 9 / 5 + 32
print(f"{c} مئوي = {f:.1f} فهرنهايت")
```

```text input
37
```

```text output
الحرارة بالمئوي: 37.0 مئوي = 98.6 فهرنهايت
```

### التمرين 2

اقرأ عددًا صحيحًا من المستخدم واطبع باقي قسمته على `7` ثم مربّعه.

```python exercise
n = int(input("اكتب عددًا: "))
```

```python solution
n = int(input("اكتب عددًا: "))
print("الباقي:", n % 7)
print("المربع:", n ** 2)
```

```text input
23
```

```text output
اكتب عددًا: الباقي: 2
المربع: 529
```

### التمرين 3

مطعم يضيف ضريبة `14%` على الفاتورة. اقرأ قيمة الفاتورة واطبع الضريبة والإجمالي بخانتين عشريتين.

```python exercise
bill = float(input("قيمة الفاتورة: "))
```

```python solution
bill = float(input("قيمة الفاتورة: "))
tax = bill * 14 / 100
print(f"الضريبة: {tax:.2f}")
print(f"الإجمالي: {bill + tax:.2f}")
```

```text input
250
```

```text output
قيمة الفاتورة: الضريبة: 35.00
الإجمالي: 285.00
```

## الخلاصة

- `input()` تقرأ من المستخدم وترجع نصًا، فحوّله بـ `int()` أو `float()`.
- العمليات: `+ - * / // % **`، والأقواس تغيّر الترتيب.
- `round` و`abs` و`max` و`min` ووحدة `math` تساعدك في الحسابات.
- الأعداد العشرية قد تظهر بكسور غريبة، فنسّقها عند العرض.

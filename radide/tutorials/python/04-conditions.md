# الدرس 4: الشروط: if و elif و else

البرامج الذكية **تتخذ قرارات**: إذا كانت كلمة المرور صحيحة افتح الحساب، وإلا اعرض رسالة خطأ. هذه القرارات نكتبها بـ **الشروط**.

## عوامل المقارنة

كل مقارنة ناتجها قيمة منطقية: `True` (صح) أو `False` (خطأ).

| العامل | معناه | مثال | الناتج |
|---|---|---|---|
| `==` | يساوي | `5 == 5` | `True` |
| `!=` | لا يساوي | `5 != 3` | `True` |
| `>` | أكبر من | `5 > 8` | `False` |
| `<` | أصغر من | `5 < 8` | `True` |
| `>=` | أكبر من أو يساوي | `5 >= 5` | `True` |
| `<=` | أصغر من أو يساوي | `4 <= 3` | `False` |

> **انتبه:** `=` (علامة واحدة) **تضع قيمة** في متغير، أما `==` (علامتان) **تقارن**. الخلط بينهما من أشهر الأخطاء.

```python run
age = 18
print(age == 18)
print(age > 20)
print("ali" == "Ali")    # المقارنة حساسة لحالة الأحرف
```

```text output
True
False
False
```

## جملة `if`

```python run
temperature = 38
if temperature > 37.5:
    print("عندك حرارة، استرح واشرب سوائل")
    print("وإذا استمرت فاستشر الطبيب")
print("انتهى الفحص")
```

```text output
عندك حرارة، استرح واشرب سوائل
وإذا استمرت فاستشر الطبيب
انتهى الفحص
```

لاحظ ثلاثة أشياء مهمة:

1. النقطتان `:` في آخر سطر الشرط.
2. الأسطر التي تتبع الشرط **مزاحة** (indented) بأربع مسافات. هذه الإزاحة هي التي تقول لـ Python: «هذه الأسطر داخل الشرط».
3. السطر `print("انتهى الفحص")` غير مزاح، فهو خارج الشرط ويُنفذ دائمًا.

> **تشبيه:** الإزاحة مثل **الفقرات الفرعية** في كتاب: كل ما هو مزاح تحت العنوان يتبعه. في لغات أخرى تُستخدم الأقواس `{ }`، أما Python فتستخدم الإزاحة نفسها.

## `else`: وإلا

```python run
number = 7
if number % 2 == 0:
    print(f"{number} عدد زوجي")
else:
    print(f"{number} عدد فردي")
```

```text output
7 عدد فردي
```

## `elif`: وإلا إذا

عندما تكون الاحتمالات أكثر من اثنين نستخدم `elif` (اختصار else if):

```python run
score = 76
if score >= 90:
    grade = "ممتاز"
elif score >= 80:
    grade = "جيد جدًا"
elif score >= 65:
    grade = "جيد"
elif score >= 50:
    grade = "مقبول"
else:
    grade = "راسب"
print(f"الدرجة {score}: {grade}")
```

```text output
الدرجة 76: جيد
```

تُفحص الشروط **بالترتيب من أعلى لأسفل**، وأول شرط صحيح يُنفذ ثم يُتجاهل الباقي. لذلك `76` لم تدخل في «مقبول» رغم أنها أكبر من `50`.

## العوامل المنطقية: `and` و `or` و `not`

| العامل | معناه |
|---|---|
| `and` | صحيح إذا كان **الطرفان** صحيحين |
| `or` | صحيح إذا كان **أحد** الطرفين صحيحًا على الأقل |
| `not` | يعكس القيمة |

```python run
age = 25
has_license = True
if age >= 18 and has_license:
    print("يمكنك قيادة السيارة")

day = "الجمعة"
if day == "الجمعة" or day == "السبت":
    print("عطلة نهاية الأسبوع")

is_raining = False
if not is_raining:
    print("الجو مناسب للتنزه")
```

```text output
يمكنك قيادة السيارة
عطلة نهاية الأسبوع
الجو مناسب للتنزه
```

### المقارنة المتسلسلة

Python تسمح بكتابة المدى بطريقة رياضية جميلة:

```python run
x = 15
if 10 <= x <= 20:
    print("x بين 10 و 20")
```

```text output
x بين 10 و 20
```

## الشرط في سطر واحد

للحالات البسيطة يوجد **التعبير الشرطي**:

```python run
age = 15
status = "بالغ" if age >= 18 else "قاصر"
print(status)
```

```text output
قاصر
```

## `match`: اختيار من عدة حالات

منذ Python 3.10 يوجد `match` لمقارنة قيمة بعدة حالات، مثل `Select Case` في BASIC:

```python run
command = "stop"
match command:
    case "start":
        print("بدء التشغيل")
    case "stop" | "exit":
        print("إيقاف")
    case _:
        print("أمر غير معروف")
```

```text output
إيقاف
```

الحالة `case _` تعني «أي شيء آخر»، مثل `else`.

## مثال كامل: آلة حاسبة صغيرة

```python run
a = float(input("العدد الأول: "))
op = input("العملية (+ - * /): ")
b = float(input("العدد الثاني: "))
if op == "+":
    print("الناتج =", a + b)
elif op == "-":
    print("الناتج =", a - b)
elif op == "*":
    print("الناتج =", a * b)
elif op == "/":
    if b == 0:
        print("لا يمكن القسمة على صفر")
    else:
        print("الناتج =", a / b)
else:
    print("عملية غير معروفة")
```

```text input
9
/
0
```

```text output
العدد الأول: العملية (+ - * /): العدد الثاني: لا يمكن القسمة على صفر
```

لاحظ الشرط **المتداخل**: `if b == 0` داخل فرع القسمة، ولذلك أُزيح ثماني مسافات.

## القيم «الصحيحة» و«الخاطئة»

في الشرط، Python تعتبر هذه القيم **خاطئة**: `0` و`0.0` والنص الفارغ `""` و`None` والقائمة الفارغة `[]`. وأي شيء آخر **صحيح**.

```python run
name = ""
if name:
    print(f"أهلًا {name}")
else:
    print("لم تكتب اسمك")
```

```text output
لم تكتب اسمك
```

## أخطاء شائعة

### نسيان النقطتين

```python
if age > 18
    print("بالغ")
```

```text
SyntaxError: expected ':'
```

### نسيان الإزاحة

```python
if age > 18:
print("بالغ")
```

```text
IndentationError: expected an indented block after 'if' statement on line 1
```

### استخدام `=` بدل `==`

```python
if age = 18:
    print("18")
```

```text
SyntaxError: invalid syntax. Maybe you meant '==' or ':=' instead of '='?
```

> **نصيحة:** محرر الـ IDE يزيح السطر تلقائيًا عندما تضغط Enter بعد `:`، وإذا أردت إرجاع الإزاحة اضغط **Backspace** أو **Shift+Tab**.

### التمرين 2

السنة **كبيسة** إذا كانت تقبل القسمة على 4 ولا تقبل القسمة على 100، أو إذا كانت تقبل القسمة على 400. اكتب برنامجًا يحدد ذلك للسنة `2024`.

```python exercise
year = 2024
```

```python solution
year = 2024
if (year % 4 == 0 and year % 100 != 0) or year % 400 == 0:
    print(f"{year} سنة كبيسة")
else:
    print(f"{year} ليست كبيسة")
```

```text output
2024 سنة كبيسة
```

### التمرين 3

اقرأ اسم المستخدم وكلمة المرور. إذا كانا `admin` و`1234` اطبع `مرحبًا بك`، وإلا اطبع `بيانات غير صحيحة`.

```python exercise
user = input("اسم المستخدم: ")
password = input("كلمة المرور: ")
```

```python solution
user = input("اسم المستخدم: ")

if user == "admin" and password == "1234":

else:
    print("بيانات غير صحيحة")
```

```text input
0000
```

```text output
اسم المستخدم: كلمة المرور: بيانات غير صحيحة
```

## الخلاصة

- المقارنة `== != > < >= <=` تعطي `True` أو `False`.
- `if` ثم `elif` ثم `else`، مع النقطتين `:` والإزاحة.
- `and` و`or` و`not` لربط الشروط، و`10 <= x <= 20` للمدى.
- `match` / `case` للاختيار بين قيم كثيرة.

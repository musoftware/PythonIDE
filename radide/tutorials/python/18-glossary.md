# الدرس 18: قاموس المصطلحات (إنجليزي - عربي)

هذا القاموس يجمع أهم المصطلحات التي مرت بك في الدورة، مرتبة أبجديًا بالإنجليزية. ارجع إليه كلما نسيت معنى كلمة.

## المصطلحات العامة

| English | العربية | شرح مختصر |
|---|---|---|
| Argument | وسيط | القيمة التي تمررها للدالة عند استدعائها |
| Assignment | إسناد | وضع قيمة في متغير بالعلامة `=` |
| Attribute | خاصية | متغير تابع لكائن، مثل `self.name` |
| Boolean (`bool`) | قيمة منطقية | `True` أو `False` |
| Breakpoint | نقطة توقف | سطر يتوقف عنده البرنامج أثناء التصحيح |
| Bug | خطأ برمجي | خلل يجعل البرنامج يعطي نتيجة خاطئة |
| Call Stack | مكدس الاستدعاءات | سلسلة الدوال التي استُدعيت حتى السطر الحالي |
| Class | صنف (ويُسمّى أيضًا: فئة) | تصميم تُنشأ منه الكائنات |
| Comment | تعليق | نص بعد `#` يتجاهله المفسّر |
| Condition | شرط | تعبير ناتجه `True` أو `False` |
| Constructor (`__init__`) | المُنشئ | الدالة التي تعمل عند إنشاء كائن جديد |
| Debugger | مصحح الأخطاء | أداة لتتبع البرنامج سطرًا سطرًا |
| Dictionary (`dict`) | قاموس | أزواج من مفتاح وقيمة |
| Docstring | نص التوثيق | نص بين علامات تنصيص ثلاثية يشرح الدالة أو الصنف |
| Event | حدث | شيء يحدث في الواجهة، مثل الضغط على زر |
| Event handler | معالج الحدث | الدالة التي تعمل عند وقوع الحدث، مثل `btnHello_Click` |
| Exception | استثناء | خطأ يحدث أثناء التشغيل |
| Expression | تعبير | جزء من الكود ينتج قيمة، مثل `a + 2` |
| f-string | نص منسّق | نص يبدأ بـ `f` ويضم قيمًا بين `{ }` |
| Float | عدد عشري | عدد فيه علامة عشرية، مثل `3.14` |
| Form | نموذج | نافذة البرنامج التي ترسمها في المصمم |
| Function | دالة | مجموعة أسطر لها اسم تستدعيها متى شئت |
| Import | استيراد | إحضار وحدة لاستخدامها، `import math` |
| Indentation | إزاحة | المسافات في أول السطر التي تحدد الكتل في Python |
| Index | فهرس | رقم العنصر في القائمة أو النص، يبدأ من 0 |
| Inheritance | وراثة | صنف يأخذ خصائص ودوال صنف آخر |
| Integer (`int`) | عدد صحيح | عدد بلا كسور، مثل `42` |
| Interpreter | المفسّر | البرنامج الذي ينفذ كود Python |
| Iteration | دورة / تكرار | تنفيذ واحد لجسم حلقة التكرار |
| Keyword | كلمة محجوزة | كلمة لها معنى خاص في اللغة، مثل `if` و`def` |
| Lambda | دالة لامدا | دالة قصيرة بلا اسم في سطر واحد |
| List | قائمة | مجموعة مرتبة قابلة للتغيير `[ ]` |
| Local variable | متغير محلي | متغير داخل دالة لا يُرى خارجها |
| Loop | حلقة تكرار | تكرار مجموعة أسطر (`for` و`while`) |
| Method | دالة تابعة | دالة داخل صنف تعمل على كائن (وتُسمّى أيضًا: طريقة، تابع) |
| Module | وحدة | ملف `.py` نستورده |
| Object | كائن | نسخة مصنوعة من صنف |
| Operator | عامل | رمز عملية، مثل `+` و`==` و`and` |
| Package | حزمة | مجلد وحدات، أو مكتبة تُثبّت بـ pip |
| Parameter | معامل | الاسم الذي تستقبل به الدالة قيمة |
| pip | مدير الحزم | الأداة التي تثبّت المكتبات من PyPI |
| Property (designer) | خاصية | صفة لأداة في المصمم، مثل `Text` و`Name` |
| Recursion | استدعاء ذاتي | دالة تستدعي نفسها |
| Return value | القيمة المُرجعة | ما ترجعه الدالة بـ `return` |
| Scope | نطاق | المكان الذي يُرى فيه المتغير |
| Set | مجموعة | عناصر بلا تكرار `{ }` |
| Slicing | تقطيع | أخذ جزء من قائمة أو نص `[a:b]` |
| Standard library | المكتبة القياسية | الوحدات التي تأتي مع Python |
| String (`str`) | نص | سلسلة حروف بين علامات تنصيص |
| Syntax error | خطأ صياغة | كتابة لا تتبع قواعد اللغة |
| Toolbox | صندوق الأدوات | لوحة الأدوات التي تسحبها إلى النموذج |
| Control | أداة / عنصر تحكم | زر أو مربع نص أو قائمة على النموذج |
| Traceback | تتبع الخطأ | رسالة Python التي تبين مسار الخطأ |
| Tuple | صف | مجموعة مرتبة ثابتة `( )` |
| Type conversion | تحويل النوع | `int()` و`float()` و`str()` |
| Variable | متغير | اسم لقيمة محفوظة في الذاكرة |
| Virtual environment (`.venv`) | بيئة افتراضية | Python خاصة بالمشروع ومكتباته |

## أدوات المصمم وما يقابلها

| أداة المصمم | البادئة | Tkinter | PySide6 (Qt) |
|---|---|---|---|
| `Button` (زر) | `btn` | `tk.Button` | `QPushButton` |
| `Label` (عنوان / تسمية) | `lbl` | `tk.Label` | `QLabel` |
| `TextBox` (مربع نص) | `txt` | `tk.Entry` | `QLineEdit` |
| `ListBox` (قائمة) | `lst` | `tk.Listbox` | `QListWidget` |
| `ComboBox` (قائمة منسدلة) | `cbo` | `ttk.Combobox` | `QComboBox` |
| `CheckBox` (مربع اختيار) | `chk` | `tk.Checkbutton` | `QCheckBox` |
| `RadioButton` (زر خيار) | `opt` | `tk.Radiobutton` | `QRadioButton` |
| `Timer` (مؤقت) | `tmr` | `_Timer` | `QTimer` |
| `ProgressBar` (شريط تقدم) | `prg` | `ttk.Progressbar` | `QProgressBar` |
| `NumericUpDown` (عداد رقمي) | `num` | `tk.Spinbox` | `QSpinBox` |

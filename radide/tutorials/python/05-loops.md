# الدرس 5: حلقات التكرار: for و while

لو طلبت منك أن تطبع الأرقام من 1 إلى 1000، فلن تكتب ألف سطر `print`! هنا يأتي دور **حلقات التكرار** (loops): تكتب الأمر مرة واحدة ويتكرر كما تريد.

> **تشبيه:** حلقة التكرار مثل **العدّاد في صالة الألعاب الرياضية**: «كرر التمرين 10 مرات». أنت تصف التمرين مرة واحدة، والعدّاد يتولى التكرار.

## حلقة `for` مع `range`

```python run
for i in range(5):
    print("مرحبًا", i)
```

```text output
مرحبًا 0
مرحبًا 1
مرحبًا 2
مرحبًا 3
مرحبًا 4
```

- `range(5)` تولّد الأعداد `0, 1, 2, 3, 4`: خمسة أعداد تبدأ من الصفر وتتوقف **قبل** 5.
- في كل دورة يأخذ المتغير `i` القيمة التالية، ثم تُنفذ الأسطر المزاحة.

### أشكال `range`

| الشكل | يولّد |
|---|---|
| `range(5)` | `0 1 2 3 4` |
| `range(1, 6)` | `1 2 3 4 5` |
| `range(0, 11, 2)` | `0 2 4 6 8 10` |
| `range(5, 0, -1)` | `5 4 3 2 1` |

```python run
for n in range(1, 11):
    print(f"7 × {n} = {7 * n}")
```

```text output
7 × 1 = 7
7 × 2 = 14
7 × 3 = 21
7 × 4 = 28
7 × 5 = 35
7 × 6 = 42
7 × 7 = 49
7 × 8 = 56
7 × 9 = 63
7 × 10 = 70
```

## المرور على النصوص والقوائم

`for` لا تعمل مع الأعداد فقط؛ يمكنها المرور على أي **مجموعة** من العناصر:

```python run
for letter in "Python":
    print(letter, end=" ")
print()

fruits = ["تفاح", "موز", "برتقال"]
for fruit in fruits:
    print("أحب", fruit)
```

```text output
P y t h o n 
أحب تفاح
أحب موز
أحب برتقال
```

سنتعرف على القوائم بالتفصيل في الدرس القادم.

## حساب مجموع: نمط «المُجمِّع»

نمط شائع جدًا: نبدأ بمتغير قيمته صفر، ونضيف إليه في كل دورة:

```python run
total = 0
for n in range(1, 101):
    total += n
print("مجموع الأعداد من 1 إلى 100 =", total)
```

```text output
مجموع الأعداد من 1 إلى 100 = 5050
```

## حلقة `while`

`while` تكرر **طالما الشرط صحيح**. نستخدمها عندما لا نعرف عدد المرات مسبقًا.

```python run
balance = 1000
year = 0
while balance < 2000:
    balance = balance * 1.10    # زيادة 10% كل سنة
    year += 1
print(f"يتضاعف المبلغ بعد {year} سنوات، ويصبح {balance:.2f}")
```

```text output
يتضاعف المبلغ بعد 8 سنوات، ويصبح 2143.59
```

> **احذر الحلقة اللانهائية:** إذا لم يتغير شيء داخل `while` يجعل الشرط خاطئًا في النهاية، فستدور الحلقة إلى الأبد. إن حدث ذلك فأوقف البرنامج بـ **Debug > Stop Debugging** (تصحيح الأخطاء ← إيقاف تصحيح الأخطاء) أو **Shift+F5**.

### مثال: التحقق من الإدخال

```python run
password = input("كلمة المرور: ")
while password != "python":
    print("خطأ، حاول مرة أخرى")
    password = input("كلمة المرور: ")
print("تم الدخول بنجاح")
```

```text input
1234
abc
python
```

```text output
كلمة المرور: خطأ، حاول مرة أخرى
كلمة المرور: خطأ، حاول مرة أخرى
كلمة المرور: تم الدخول بنجاح
```

## `break` و `continue`

- `break` **يخرج** من الحلقة فورًا.
- `continue` **يتخطى** بقية الدورة الحالية ويبدأ الدورة التالية.

```python run
for n in range(1, 20):
    if n % 3 == 0:
        continue          # تخطَّ مضاعفات 3
    if n > 10:
        break             # توقف بعد 10
    print(n, end=" ")
print()
```

```text output
1 2 4 5 7 8 10 
```

### `while True` مع `break`

نمط شائع لقوائم الاختيار: حلقة «لا نهائية» نخرج منها بـ `break`:

```python run
total = 0
while True:
    text = input("أدخل عددًا (أو q للإنهاء): ")
    if text == "q":
        break
    total += int(text)
print("المجموع:", total)
```

```text input
10
25
5
q
```

```text output
أدخل عددًا (أو q للإنهاء): أدخل عددًا (أو q للإنهاء): أدخل عددًا (أو q للإنهاء): أدخل عددًا (أو q للإنهاء): المجموع: 40
```

## الحلقات المتداخلة

يمكن وضع حلقة داخل حلقة. الحلقة الداخلية تكتمل بالكامل في كل دورة من الحلقة الخارجية:

```python run
for row in range(1, 5):
    for col in range(row):
        print("*", end="")
    print()
```

```text output
*
**
***
****
```

## `else` مع الحلقات

ميزة خاصة في Python: جزء `else` بعد الحلقة يُنفذ إذا انتهت الحلقة **بدون** `break`:

```python run
n = 29
for d in range(2, n):
    if n % d == 0:
        print(n, "ليس أوليًا، يقبل القسمة على", d)
        break
else:
    print(n, "عدد أولي")
```

```text output
29 عدد أولي
```

## أخطاء شائعة

- **نسيان أن `range(1, 10)` لا تشمل 10.** إذا أردت حتى 10 فاكتب `range(1, 11)`.
- **نسيان تحديث متغير الشرط في `while`** فتصبح الحلقة لا نهائية.
- **إزاحة خاطئة:** السطر الذي يجب أن يُنفذ مرة واحدة بعد الحلقة إذا أزحته سيتكرر مع كل دورة:

```python run
total = 0
for n in range(1, 4):
    total += n
    print("المجموع:", total)   # مزاح: يُطبع 3 مرات
print("النهائي:", total)        # غير مزاح: مرة واحدة
```

```text output
المجموع: 1
المجموع: 3
المجموع: 6
النهائي: 6
```

### التمرين 2

احسب **مضروب** العدد 6 (أي `1 × 2 × 3 × 4 × 5 × 6`) باستخدام حلقة.

```python exercise
n = 6
result = 1
```

```python solution
n = 6
result = 1
for i in range(1, n + 1):
    result *= i
print(f"{n}! = {result}")
```

```text output
6! = 720
```

### التمرين 3

لعبة تخمين: الرقم السري `7`. اقرأ تخمينات المستخدم حتى يصيب، وفي كل مرة قل له `أكبر` أو `أصغر`، وفي النهاية اطبع عدد المحاولات.

```python exercise
secret = 7
tries = 0
```

```python solution
secret = 7
tries = 0
while True:
    guess = int(input("خمّن: "))
    tries += 1
    if guess < secret:
        print("أكبر")
    elif guess > secret:
        print("أصغر")
    else:
        print(f"أحسنت! عرفته في {tries} محاولات")
        break
```

```text input
5
9
7
```

```text output
خمّن: أكبر
خمّن: أصغر
خمّن: أحسنت! عرفته في 3 محاولات
```

## الخلاصة

- `for x in range(...)` لعدد معروف من المرات، و`for x in مجموعة` للمرور على العناصر.
- `while شرط:` تكرر طالما الشرط صحيح؛ احذر الحلقة اللانهائية.
- `break` للخروج، و`continue` للتخطي، و`else` بعد الحلقة يعمل إذا لم يحدث `break`.

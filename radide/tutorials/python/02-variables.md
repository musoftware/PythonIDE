# الدرس 2: المتغيرات وأنواع البيانات

البرامج تتعامل مع **بيانات**: أسماء وأعمار وأسعار ودرجات. ولكي نحتفظ بهذه البيانات ونستخدمها لاحقًا نضعها في **متغيرات**.

## ما هو المتغير؟

**المتغير** (variable) اسم نطلقه على قيمة محفوظة في ذاكرة الجهاز.

> **تشبيه:** المتغير مثل **علبة عليها ملصق**. الملصق هو الاسم (`age`)، وما بداخل العلبة هو القيمة (`20`). يمكنك في أي وقت أن تفتح العلبة وتضع فيها قيمة جديدة.

في Python تنشئ المتغير بمجرد أن تعطيه قيمة بالعلامة `=`، ولا تحتاج إلى كتابة نوعه:

```python run
name = "Omar"
age = 20
height = 1.75
print(name)
print(age)
print(height)
```

```text output
Omar
20
1.75
```

العلامة `=` هنا تعني **«ضع القيمة التي على اليمين في المتغير الذي على اليسار»**، وليست «يساوي» كما في الرياضيات. لذلك السطر `age = age + 1` صحيح تمامًا: خذ القيمة الحالية وأضف إليها واحدًا ثم ضع الناتج في `age` من جديد.

```python run
score = 10
print("قبل:", score)
score = score + 5
print("بعد:", score)
score += 5      # اختصار لـ score = score + 5
print("بعد الاختصار:", score)
```

```text output
قبل: 10
بعد: 15
بعد الاختصار: 20
```

## قواعد تسمية المتغيرات

- يبدأ الاسم بحرف أو بشرطة سفلية `_`، ولا يبدأ برقم: `name1` صحيح، و`1name` خطأ.
- يحتوي على حروف وأرقام و`_` فقط، بدون مسافات: `first_name` صحيح، و`first name` خطأ.
- حساس لحالة الأحرف: `Age` و`age` متغيران مختلفان.
- لا يكون كلمة محجوزة في اللغة مثل `if` و`for` و`class`.

> **عادة جيدة:** مبرمجو Python يكتبون أسماء المتغيرات بحروف صغيرة وكلمات مفصولة بشرطة سفلية، مثل `total_price` و`student_name`. وهذا الأسلوب اسمه **snake_case**.

## أنواع البيانات الأساسية

| النوع | الاسم في Python | أمثلة |
|---|---|---|
| عدد صحيح | `int` | `5`، `-3`، `2026` |
| عدد عشري | `float` | `3.14`، `0.5`، `-2.0` |
| نص | `str` | `"Ali"`، `'مرحبًا'` |
| منطقي | `bool` | `True`، `False` |
| لا شيء | `NoneType` | `None` |

الدالة `type()` تخبرك بنوع أي قيمة:

```python run
print(type(42))
print(type(3.14))
print(type("سلام"))
print(type(True))
print(type(None))
```

```text output
<class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>
<class 'NoneType'>
```

لاحظ أن `True` و`False` تُكتبان بحرف كبير في أولهما.

## النصوص المنسّقة f-string

أسهل طريقة لدمج المتغيرات داخل نص هي **f-string**: ضع الحرف `f` قبل علامة التنصيص، واكتب أسماء المتغيرات بين أقواس معقوصة `{ }`:

```python run
name = "Mona"
age = 22
print(f"اسمي {name} وعمري {age} سنة")
print(f"بعد 5 سنوات سيكون عمري {age + 5}")
price = 7.5
print(f"السعر: {price:.2f} جنيه")
```

```text output
اسمي Mona وعمري 22 سنة
بعد 5 سنوات سيكون عمري 27
السعر: 7.50 جنيه
```

- داخل `{ }` يمكنك كتابة أي تعبير، مثل `age + 5`.
- `:.2f` تعني «اعرض العدد العشري بخانتين بعد العلامة العشرية».

## التحويل بين الأنواع

أحيانًا تحتاج إلى تحويل قيمة من نوع إلى آخر:

| الدالة | تحوّل إلى | مثال | الناتج |
|---|---|---|---|
| `int()` | عدد صحيح | `int("15")` | `15` |
| `float()` | عدد عشري | `float("2.5")` | `2.5` |
| `str()` | نص | `str(99)` | `"99"` |
| `bool()` | منطقي | `bool(0)` | `False` |

```python run
a = "10"
b = "5"
print(a + b)              # دمج نصين
print(int(a) + int(b))    # جمع عددين
print("العدد " + str(7))
print(int(9.99))          # int يحذف الكسر ولا يقرّب
```

```text output
105
15
العدد 7
9
```

> **انتبه:** `+` بين نصين **تلصقهما** (`"10" + "5"` = `"105"`)، وبين عددين **تجمعهما**. وهذا من أشهر مصادر الأخطاء عند المبتدئين.

## إسناد عدة متغيرات في سطر واحد

```python run
x, y, z = 1, 2, 3
print(x, y, z)
x, y = y, x      # تبديل القيمتين بسهولة
print(x, y)
a = b = 0
print(a, b)
```

```text output
1 2 3
2 1
0 0
```

## أخطاء شائعة

### استخدام متغير قبل إنشائه

```python run
total = 100
print(totl)
```

```text output
Traceback (most recent call last):
  File "main.py", line 2, in <module>
    print(totl)
NameError: name 'totl' is not defined
```

`NameError` تعني أن الاسم غير معروف. السبب هنا خطأ إملائي: `totl` بدل `total`. اقرأ آخر سطر في رسالة الخطأ دائمًا، فهو يخبرك بالمشكلة، والسطر الذي قبله يخبرك برقم السطر.

### جمع نص مع عدد

```python run
age = 20
print("عمري " + age)
```

```text output
Traceback (most recent call last):
  File "main.py", line 2, in <module>
    print("عمري " + age)
TypeError: can only concatenate str (not "int") to str
```

**المعنى:** «يمكن لصق نص `str` فقط مع نص، وليس مع `int`». الحل: `"عمري " + str(age)` أو الأفضل `f"عمري {age}"`.

## تمارين

### التمرين 1

أنشئ متغيرين `product` و`price` بالقيمتين `"قلم"` و`12.5`، ثم اطبع الجملة التالية باستخدام f-string:

```python exercise
product = "قلم"
price = 12.5
# الناتج المطلوب: سعر قلم هو 12.50 جنيه
```

```python solution
product = "قلم"
price = 12.5
print(f"سعر {product} هو {price:.2f} جنيه")
```

```text output
سعر قلم هو 12.50 جنيه
```

### التمرين 2

عندك عدد الدقائق `135`. احسب الساعات والدقائق المتبقية (استخدم `//` للقسمة الصحيحة و`%` لباقي القسمة) واطبع: `135 دقيقة = 2 ساعة و 15 دقيقة`.

```python exercise
minutes = 135
```

```python solution
minutes = 135
hours = minutes // 60
rest = minutes % 60
print(f"{minutes} دقيقة = {hours} ساعة و {rest} دقيقة")
```

```text output
135 دقيقة = 2 ساعة و 15 دقيقة
```

### التمرين 3

بدّل قيمتي المتغيرين `a` و`b` في سطر واحد، ثم اطبعهما.

```python exercise
a = "شاي"
b = "قهوة"
# بدّل القيمتين هنا
print(a, b)
```

```python solution
a = "شاي"
b = "قهوة"
a, b = b, a
print(a, b)
```

```text output
قهوة شاي
```

## الخلاصة

- المتغير اسم لقيمة، وننشئه بـ `=` دون كتابة نوعه.
- الأنواع الأساسية: `int` و`float` و`str` و`bool` و`None`، و`type()` تكشف النوع.
- f-string مثل `f"عمري {age}"` أسهل طريقة لتكوين النصوص.
- `int()` و`float()` و`str()` للتحويل بين الأنواع.

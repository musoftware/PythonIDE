# الدرس 1: مرحبًا بك في Python: أول مشروع وأول برنامج

أهلًا بك في رحلة تعلّم **Python** (تُنطق «بايثون»)! هذه الدورة تبدأ معك من الصفر تمامًا، وتنتهي وأنت تبني برامج بنوافذ وأزرار تصممها بالسحب والإفلات داخل RAD IDE.

## لماذا Python؟

Python من أكثر لغات البرمجة انتشارًا في العالم، وذلك لعدة أسباب:

- **سهلة القراءة:** الكود فيها قريب من اللغة الإنجليزية العادية.
- **متعددة الاستخدامات:** برامج سطح المكتب، ومواقع الويب، وتحليل البيانات، والذكاء الاصطناعي، والأتمتة، والألعاب.
- **مكتبات كثيرة جدًا:** تجد مكتبة جاهزة لكل شيء تقريبًا.
- **مجتمع ضخم:** أي سؤال يخطر ببالك غالبًا سأله أحد قبلك وتجد إجابته.

> **تشبيه:** لغة البرمجة مثل اللغة التي تتحدث بها مع شخص ينفذ الأوامر بدقة شديدة لكنه لا يخمّن أبدًا. Python لغة «مهذبة وواضحة» تجعل هذا الحوار سهلًا.

## المفسّر (Interpreter)

Python لغة **مفسَّرة**: يوجد برنامج اسمه **المفسّر** (`python.exe`) يقرأ الكود سطرًا سطرًا وينفذه مباشرة، دون خطوة ترجمة منفصلة كما في C++. RAD IDE تأتي ومعها مفسّر Python جاهز، فلا تحتاج إلى تثبيت شيء لتبدأ.

إذا أردت استخدام نسخة Python أخرى مثبتة على جهازك، فاختر مسارها من **Tools > Interpreter Path...** (أدوات ← مسار المفسّر...).

## أول مشروع: تطبيق سطر أوامر

1. افتح **File > New Project** (ملف ← مشروع جديد...).
2. في شجرة اللغات على اليسار اختر **Python > Python (Tkinter)**.
3. من القوالب اختر **Console Application** (تطبيق سطر أوامر)، أي برنامج بدون نافذة يكتب نتائجه في نافذة **Output** (المخرجات).
4. اكتب اسم المشروع، مثلًا `HelloPython`، واضغط **OK**.

ستنشئ الـ IDE ملفًا اسمه `Program.py` وتفتحه في المحرر. امسح ما فيه واكتب:

```python run
print("Hello, World!")
print("مرحبًا بك في عالم Python")
```

```text output
Hello, World!
مرحبًا بك في عالم Python
```

اضغط **Ctrl+F5** (**Debug > Start Without Debugging**، أي تصحيح الأخطاء ← بدء بدون تصحيح الأخطاء)، وسترى الناتج في نافذة **Output**. مبروك، هذا أول برنامج لك!

> **ملحوظة:** في هذه الدروس يوجد بجانب كل مثال زر **«جرّبه»**: يصنع مشروعًا صغيرًا فيه الكود ويشغّله فورًا في الـ IDE. وزر **«افتح في المحرر»** يفتحه لتعدّل فيه بنفسك.

## الدالة `print`

`print` **دالة** (function) جاهزة في Python وظيفتها أن تطبع ما بين القوسين على الشاشة ثم تنزل سطرًا جديدًا.

- النص يُكتب بين علامتي تنصيص: `"نص"` أو `'نص'`، وكلاهما صحيح.
- يمكنك طباعة عدة أشياء مفصولة بفواصل، وستضع `print` مسافة بينها تلقائيًا.
- الأرقام تُكتب بدون علامات تنصيص.

```python run
print("العمر:", 20)
print("المجموع =", 5 + 7)
print('علامة تنصيص مفردة تعمل أيضًا')
print()
print("السطر الفارغ فوقي جاء من print() بدون شيء")
```

```text output
العمر: 20
المجموع = 12
علامة تنصيص مفردة تعمل أيضًا

السطر الفارغ فوقي جاء من print() بدون شيء
```

لاحظ أن `5 + 7` بدون علامات تنصيص حُسبت فطُبعت `12`. أما `"5 + 7"` بين علامتي تنصيص فستُطبع كما هي، لأنها نص وليست عملية حسابية.

### `sep` و `end`

للدالة `print` خياران مفيدان:

- `sep` يحدد الفاصل بين القيم بدل المسافة.
- `end` يحدد ما يُطبع في النهاية بدل السطر الجديد.

```python run
print("2026", "11", "21", sep="-")
print("بدون نزول سطر... ", end="")
print("ما زلنا على نفس السطر")
```

```text output
2026-11-21
بدون نزول سطر... ما زلنا على نفس السطر
```

## التعليقات (Comments)

أي شيء بعد العلامة `#` في السطر هو **تعليق**: كلام لك ولزملائك، ولا ينفذه المفسّر.

```python run
# هذا البرنامج يطبع ترحيبًا
print("أهلًا")   # تعليق في آخر السطر
# print("هذا السطر معطّل ولن يُنفذ")
```

```text output
أهلًا
```

> **نصيحة:** في المحرر، حدد عدة أسطر واضغط **Ctrl+/** لتحويلها إلى تعليقات أو لإلغاء التعليق عنها مرة واحدة.

## المسافات البادئة مهمة جدًا في Python

في Python، **المسافة في أول السطر لها معنى**، وسنرى ذلك بوضوح في درس الشروط. الآن تذكّر قاعدة واحدة: الأسطر العادية تبدأ من أول السطر بدون مسافات.

## أخطاء شائعة

### كتابة `Print` بحرف كبير

```python
Print("Hello")
```

```text
NameError: name 'Print' is not defined. Did you mean: 'print'?
```

Python **حساسة لحالة الأحرف**: `Print` و`print` اسمان مختلفان. والرسالة تقول لك: «الاسم `Print` غير معرّف، هل تقصد `print`؟».

### نسيان علامة التنصيص أو القوس

```python
print("Hello)
```

```text
SyntaxError: unterminated string literal (detected at line 1)
```

**المعنى:** «نص لم يُغلق». أضف علامة التنصيص الناقصة. وكذلك إذا نسيت القوس `)` ستظهر رسالة `SyntaxError: '(' was never closed`.

### مسافة زائدة في أول السطر

```python
print("أ")
    print("ب")
```

```text
IndentationError: unexpected indent
```

**المعنى:** «مسافة بادئة غير متوقعة». احذف المسافات من أول السطر الثاني.

## تمارين

### التمرين 1

اطبع اسمك في سطر، ومدينتك في السطر التالي، بهذا الشكل تمامًا:

```python exercise
# الناتج المطلوب:
# الاسم: سارة
# المدينة: القاهرة
```

```python solution
print("الاسم: سارة")
print("المدينة: القاهرة")
```

```text output
الاسم: سارة
المدينة: القاهرة
```

### التمرين 2

اطبع ناتج ضرب `12` في `7` بهذا الشكل: `12 × 7 = 84` (اجعل Python هي التي تحسب `84`).

```python exercise
# اطبع: 12 × 7 = 84
```

```python solution
print("12 × 7 =", 12 * 7)
```

```text output
12 × 7 = 84
```

### التمرين 3

استخدم `print` واحدة فقط مع `sep` لتطبع: `أ/ب/ج`.

```python exercise
print("أ", "ب", "ج")
```

```python solution
print("أ", "ب", "ج", sep="/")
```

```text output
أ/ب/ج
```

## الخلاصة

- Python لغة مفسَّرة وسهلة القراءة، وRAD IDE تأتي ومعها مفسّر جاهز.
- مشروع سطر الأوامر: **File > New Project > Python (Tkinter) > Console Application**.
- `print(...)` تطبع، و`sep` و`end` يتحكمان في الفاصل والنهاية.
- `#` تبدأ تعليقًا، وPython حساسة لحالة الأحرف وللمسافات في أول السطر.

# الدرس 16: تصحيح الأخطاء بنقاط التوقف

كل المبرمجين، حتى المحترفين، يكتبون أخطاء. الفرق أن المحترف يعرف **كيف يجدها بسرعة**. في هذا الدرس نتعلم استخدام **مصحح الأخطاء** (Debugger) في RAD IDE: نوقف البرنامج في سطر معين، ونرى قيم المتغيرات، وننفذ الكود سطرًا سطرًا.

> **تشبيه:** تشغيل البرنامج عاديًا مثل مشاهدة فيلم بسرعته الطبيعية. المصحح يعطيك **زر الإيقاف المؤقت والتقديم إطارًا بإطار**: توقف عند المشهد المهم، وتنظر في كل التفاصيل، ثم تتقدم خطوة خطوة.

## نوعان من الأخطاء

1. **أخطاء توقف البرنامج** (مثل `ZeroDivisionError`): Python تخبرك بالسطر في رسالة الخطأ، وهذه سهلة نسبيًا.
2. **الأخطاء المنطقية**: البرنامج يعمل بلا رسالة خطأ، لكن **الناتج غلط**! هذه أصعب، وهنا يتألق المصحح.

## برنامج فيه خطأ منطقي

هذا البرنامج يجب أن يحسب متوسط الدرجات **الناجحة فقط** (50 فأكثر). الدرجات الناجحة هي `80` و`90` و`70`، ومتوسطها `80`. لكن انظر إلى الناتج:

```python run
def average_passed(grades):
    total = 0
    count = 0
    for g in grades:
        if g >= 50:
            total += g
        count += 1
    return total / count


grades = [80, 40, 90, 30, 70]
print("المتوسط:", average_passed(grades))
```

```text output
المتوسط: 48.0
```

الناتج `48.0` وليس `80`! أين الخطأ؟ قد تراه بعينك في هذا المثال القصير، لكن تخيّل أن البرنامج 500 سطر. لنستخدم المصحح.

## الخطوة 1: نقطة توقف (Breakpoint)

1. أنشئ مشروع **Console Application** وضع فيه الكود أعلاه (أو اضغط «افتح في المحرر»).
2. ضع المؤشر على السطر `if g >= 50:` واضغط **F9** (**Debug > Toggle Breakpoint**، أي تبديل نقطة التوقف)، أو انقر في الهامش الأيسر بجوار رقم السطر.
3. تظهر **دائرة حمراء** بجوار السطر: هذه نقطة التوقف.

## الخطوة 2: التشغيل مع التصحيح

اضغط **F5** (**Debug > Start Debugging**). يبدأ البرنامج، ثم **يتوقف** عند نقطة التوقف قبل تنفيذ ذلك السطر، ويظهر السطر مظللًا بالأصفر.

الآن انظر إلى النوافذ في أسفل الـ IDE:

| النافذة | الاسم العربي | ماذا تعرض |
|---|---|---|
| **Locals** | المتغيرات المحلية | كل متغيرات الدالة الحالية وقيمها: `grades` و`total` و`count` و`g` |
| **Call Stack** | مكدس الاستدعاءات | سلسلة الدوال التي أوصلتنا هنا: `<module>` ← `average_passed` |
| **Watch** | المراقبة | تعبيرات تكتبها أنت وتتابع قيمتها، مثل `total / count` |
| **Immediate** | الأوامر الفورية | اكتب أي تعبير واضغط Enter لترى قيمته فورًا، مثل `g * 2` |

ستجد في **Locals**: `g = 80` و`total = 0` و`count = 0`.

## الخطوة 3: التنفيذ خطوة خطوة

| الأمر | الاختصار | ماذا يفعل |
|---|---|---|
| **Step Over** (خطوة فوق) | **F10** | ينفذ السطر الحالي وينتقل للتالي (إذا كان فيه استدعاء دالة ينفذها كاملة) |
| **Step Into** (خطوة إلى الداخل) | **F11** | إذا كان السطر يستدعي دالة، يدخل إليها |
| **Step Out** (خطوة إلى الخارج) | **Shift+F11** | يكمل الدالة الحالية ويرجع لمن استدعاها |
| **Continue** (متابعة) | **F5** | يكمل حتى نقطة التوقف التالية |
| **Stop Debugging** | **Shift+F5** | يوقف البرنامج |
| **Run to Cursor** (تشغيل حتى المؤشر) | **Ctrl+F10** | يكمل حتى السطر الذي عليه المؤشر |

اضغط **F10** عدة مرات وراقب **Locals**. في الدورة الثانية تكون `g = 40`، فلا يتحقق الشرط ولا تزيد `total`... لكن انظر: **`count` زادت رغم ذلك!** من `1` إلى `2`.

وجدنا الخطأ: السطر `count += 1` **غير مزاح بما يكفي**، فهو خارج الشرط ويُنفذ لكل الدرجات. التصحيح:

```python run
def average_passed(grades):
    total = 0
    count = 0
    for g in grades:
        if g >= 50:
            total += g
            count += 1          # داخل الشرط الآن
    return total / count


grades = [80, 40, 90, 30, 70]
print("المتوسط:", average_passed(grades))
```

```text output
المتوسط: 80.0
```

## نقاط توقف ذكية

ضع المؤشر على سطر نقطة التوقف، ثم اختر **Debug > Breakpoint Settings (Condition, Hit Count, Log)...** (أو **Debug > Breakpoint Condition...** بالاختصار **Alt+F9** للشرط فقط):

- **Condition (شرط):** يتوقف فقط إذا تحقق الشرط، مثل `g < 50`. مفيد جدًا في الحلقات الطويلة: بدل أن تضغط F5 ألف مرة، توقف فقط عند القيمة المشبوهة.
- **Hit Count (عدد المرات):** يتوقف في المرة العاشرة مثلًا.
- **Log (سجل):** لا يتوقف، بل يكتب رسالة في **Output** مثل `g = {g}`، كأنك أضفت `print` دون أن تعدل الكود.

## التوقف عند الاستثناءات

فعّل **Debug > Break on Exceptions** (التوقف عند الاستثناءات)، وعندها إذا حدث استثناء يتوقف المصحح **في السطر الذي حدث فيه**، فترى كل المتغيرات لحظة الخطأ وتفهم سببه. جرّب ذلك مع هذا البرنامج:

```python run
def unit_price(total, qty):
    return total / qty


orders = [(100, 4), (60, 3), (50, 0), (90, 9)]
for total, qty in orders:
    print(f"{total} / {qty} = {unit_price(total, qty)}")
```

```text output
100 / 4 = 25.0
60 / 3 = 20.0
Traceback (most recent call last):
  File "main.py", line 7, in <module>
    print(f"{total} / {qty} = {unit_price(total, qty)}")
  File "main.py", line 2, in unit_price
    return total / qty
ZeroDivisionError: division by zero
```

عند التوقف ستجد في **Locals**: `qty = 0`. والحل إما التحقق قبل القسمة أو استخدام `try`.

## تصحيح برامج النوافذ

المصحح يعمل مع نوافذ Tkinter وPySide6 أيضًا: ضع نقطة توقف داخل `btnHello_Click` ثم اضغط F5، وعندما تضغط الزر في نافذتك يتوقف البرنامج داخل الدالة، فترى ما في `self` وما كتبه المستخدم.

## نصائح لتصحيح أسرع

- **اقرأ رسالة الخطأ من الأسفل:** آخر سطر يقول **ماذا** حدث، والأسطر فوقه تقول **أين**.
- **`print` المؤقتة** ما زالت مفيدة للأشياء السريعة، لكن احذفها بعد الانتهاء.
- **قسّم المشكلة:** إذا كان الناتج خطأ، ضع نقطة توقف في منتصف البرنامج: هل القيم صحيحة هنا؟ إن كانت صحيحة فالخطأ بعدها، وإلا فقبلها.
- **اشرح الكود بصوت عالٍ** (حتى لدمية على مكتبك!). كثيرًا ما تكتشف الخطأ وأنت تشرح.

## تمارين

### التمرين 1

الدالة التالية يجب أن ترجع **أكبر** عدد في القائمة، لكنها تخطئ مع القوائم التي كل أعدادها سالبة. استخدم المصحح (أو التفكير!) لتجد الخطأ وتصححه. (لا تستخدم `max`.)

```python exercise
def largest(numbers):
    best = 0
    for n in numbers:
        if n > best:
            best = n
    return best


print(largest([3, 9, 2]))
print(largest([-5, -2, -8]))
```

```python solution
def largest(numbers):
    best = numbers[0]
    for n in numbers:
        if n > best:
            best = n
    return best


print(largest([3, 9, 2]))
print(largest([-5, -2, -8]))
```

```text output
9
-2
```

### التمرين 2

هذا البرنامج يجب أن يطبع الأعداد من 1 إلى 5 ثم «انتهى»، لكنه يطبع من 0 إلى 4. صحّحه.

```python exercise
i = 0
while i < 5:
    print(i)
    i += 1
print("انتهى")
```

```python solution
i = 1
while i <= 5:
    print(i)
    i += 1

```

```text output

2
3

5

```

### التمرين 3

الدالة تعكس كل كلمة في الجملة، لكن الناتج فيه مسافة زائدة في آخره. صحّحها (تلميح: `join`).

```python exercise
def reverse_words(sentence):
    result = ""
    for word in sentence.split():
        result += word[::-1] + " "
    return result


print("[" + reverse_words("hello big world") + "]")
```

```python solution
def reverse_words(sentence):
    return " ".join(word[::-1] for word in sentence.split())


print("[" + reverse_words("hello big world") + "]")
```

```text output
[olleh gib dlrow]
```

## الخلاصة

- **F9** نقطة توقف، و**F5** تشغيل مع التصحيح، و**F10 / F11 / Shift+F11** للتنفيذ خطوة خطوة.
- **Locals** و**Watch** و**Immediate** و**Call Stack** تكشف ما يحدث داخل البرنامج.
- نقاط التوقف الشرطية والسجلية و**Break on Exceptions** توفر عليك وقتًا كبيرًا.

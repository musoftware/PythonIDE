# الدرس 2: برنامجك الأول و`printf`

في الدرس السابق شغّلنا برنامجًا يطبع رسالة. اليوم نفهم كل كلمة فيه، ونتعرف على أهم دالة في C للطباعة: `printf`.

## البرنامج كاملًا

```c run
#include <stdio.h>

int main(void)
{
    printf("Hello, World!\n");
    return 0;
}
```

```text output
Hello, World!
```

## الشرح سطرًا سطرًا

### `#include <stdio.h>`

هذا السطر يطلب من المترجم إحضار **ملف الترويسة** `stdio.h` (اختصار standard input/output، أي الإدخال والإخراج القياسي). فيه تعريف الدالة `printf` ودوال أخرى كثيرة.

> **تشبيه:** ملف الترويسة مثل **فهرس الكتاب**: يخبر المترجم بأسماء الدوال الموجودة وكيف تُستدعى، أما تنفيذها الفعلي فموجود في المكتبة التي يربطها gcc تلقائيًا.

### `int main(void)`

هذه **الدالة الرئيسية**. كل برنامج C يبدأ تنفيذه من `main`.

- `int` معناها أن الدالة ترجع عددًا صحيحًا لنظام التشغيل عند انتهائها.
- `(void)` معناها أن الدالة لا تأخذ أي مدخلات. في C يُفضّل كتابة `void` صراحة.

### `{ }`

القوسان المعقوصان يحددان **جسم** الدالة: التعليمات التي تُنفذ بالترتيب من أعلى إلى أسفل.

### `printf("Hello, World!\n");`

- `printf` (تُنطق «برنت إف»، و f من formatted) تطبع نصًا على الشاشة.
- النص بين علامتي التنصيص `"..."` يسمى **سلسلة نصية** (string).
- `\n` تعني «سطر جديد».
- الفاصلة المنقوطة `;` تنهي التعليمة. نسيانها من أشهر الأخطاء!

### `return 0;`

ينهي `main` ويُرجع `0`، ومعناها «انتهى البرنامج بنجاح».

## الطباعة المنسقة: قلب `printf`

قوة `printf` في أنها تطبع **قيمًا** داخل النص باستخدام **محددات التنسيق** (format specifiers) التي تبدأ بـ `%`:

```c run
#include <stdio.h>

int main(void)
{
    printf("العمر: %d سنة\n", 20);
    printf("السعر: %f\n", 12.5);
    printf("السعر بخانتين: %.2f\n", 12.5);
    printf("الحرف: %c\n", 'A');
    printf("الاسم: %s\n", "سارة");
    printf("%d + %d = %d\n", 3, 4, 3 + 4);
    printf("نسبة النجاح 100%%\n");
    return 0;
}
```

```text output
العمر: 20 سنة
السعر: 12.500000
السعر بخانتين: 12.50
الحرف: A
الاسم: سارة
3 + 4 = 7
نسبة النجاح 100%
```

| المحدد | يطبع | مثال |
|---|---|---|
| `%d` | عدد صحيح (int) | `printf("%d", 5)` |
| `%f` | عدد عشري (6 خانات افتراضيًا) | `printf("%f", 1.5)` |
| `%.2f` | عدد عشري بخانتين بعد الفاصلة | `printf("%.2f", 1.5)` |
| `%c` | حرف واحد | `printf("%c", 'A')` |
| `%s` | نص | `printf("%s", "Hi")` |
| `%%` | علامة `%` نفسها | `printf("50%%")` |

لاحظ أن القيم تأتي بعد النص مفصولة بفواصل، **بنفس ترتيب** المحددات.

## رموز الهروب

| الرمز | معناه |
|---|---|
| `\n` | سطر جديد |
| `\t` | مسافة جدولة (Tab) |
| `\"` | علامة تنصيص داخل النص |
| `\\` | شرطة مائلة عكسية واحدة |

```c run
#include <stdio.h>

int main(void)
{
    printf("الاسم\tالدرجة\n");
    printf("علي\t90\n");
    printf("قال: \"أهلًا\"\n");
    printf("C:\\Projects\\hello.c\n");
    return 0;
}
```

```text output
الاسم	الدرجة
علي	90
قال: "أهلًا"
C:\Projects\hello.c
```

## التعليقات

```c run
#include <stdio.h>

/* تعليق
   من عدة أسطر */

int main(void)
{
    // تعليق من سطر واحد
    printf("التعليقات لا تظهر\n"); // تعليق في آخر السطر
    return 0;
}
```

```text output
التعليقات لا تظهر
```

المترجم يتجاهل التعليقات تمامًا. استخدمها لتشرح **لماذا** كتبت الكود هكذا.

## أخطاء شائعة

### نسيان الفاصلة المنقوطة

<!-- compile-error -->
```c
#include <stdio.h>
int main(void)
{
    printf("Hi\n")
    return 0;
}
```

```text
main.c:4:19: error: expected ';' before 'return'
```

المترجم يقول: «كنت أنتظر `;` قبل `return`». أضفها في آخر السطر السابق.

### نسيان `#include <stdio.h>`

بدون هذا السطر يعطيك gcc خطأ مثل `implicit declaration of function 'printf'`، أي أنه لا يعرف الدالة. أضف السطر في أول الملف.

### عدد القيم لا يطابق المحددات

إذا كتبت `printf("%d %d\n", 5);` فستطبع قيمة عشوائية مكان المحدد الثاني! تأكد أن لكل `%` قيمة.

## تمارين

### التمرين 1

اطبع بطاقة طالب كما في الناتج، باستخدام `%s` للاسم و`%d` للعمر و`%.1f` للمعدل:

```c exercise
#include <stdio.h>

int main(void)
{
    // الاسم: منى
    // العمر: 19
    // المعدل: 3.7
    return 0;
}
```

```c solution
#include <stdio.h>

int main(void)
{
    printf("الاسم: %s\n", "منى");
    printf("العمر: %d\n", 19);
    printf("المعدل: %.1f\n", 3.7);
    return 0;
}
```

```text output
الاسم: منى
العمر: 19
المعدل: 3.7
```

### التمرين 2

اطبع جدول ضرب الرقم 3 من 1 إلى 3 باستخدام `printf` واحد لكل سطر ومحددات `%d`:

```c exercise
#include <stdio.h>

int main(void)
{
    // 3 x 1 = 3
    // 3 x 2 = 6
    // 3 x 3 = 9
    return 0;
}
```

```c solution
#include <stdio.h>

int main(void)
{
    printf("%d x %d = %d\n", 3, 1, 3 * 1);
    printf("%d x %d = %d\n", 3, 2, 3 * 2);
    printf("%d x %d = %d\n", 3, 3, 3 * 3);
    return 0;
}
```

```text output
3 x 1 = 3
3 x 2 = 6
3 x 3 = 9
```

## الخلاصة

- `#include <stdio.h>` يعرّف `printf`، و`main` نقطة البداية.
- `printf` تطبع نصًا وقيمًا: `%d` و`%f` و`%c` و`%s`.
- `\n` سطر جديد، و`\t` مسافة جدولة.
- كل تعليمة تنتهي بـ `;`.

# الدرس 1: مرحبًا بك في لغة C وتجهيز المترجم gcc

أهلًا بك! في هذه الدورة سنتعلم لغة **C** خطوة بخطوة، من أول سطر حتى برنامج بنافذة وأزرار نرسمها في مصمم النماذج. لا نفترض أنك تعرف أي لغة أخرى، لكن إن كنت درست دورة C++ أو BASIC في هذه الـ IDE فستجد أشياء كثيرة مألوفة.

## لماذا لغة C؟

لغة C ظهرت سنة 1972 لكتابة نظام التشغيل Unix، وما زالت حتى اليوم من أهم اللغات في العالم:

- **أنظمة التشغيل**: نواة Linux ومعظم Windows مكتوبة بـ C.
- **الأجهزة الصغيرة**: الغسالة والمكيف والسيارة وأجهزة Arduino تُبرمج غالبًا بـ C.
- **لغات أخرى**: مفسر Python الرسمي مكتوب بـ C، وكذلك أجزاء كبيرة من قواعد البيانات.

> **تشبيه:** إذا كانت لغات مثل Python سيارة أوتوماتيك مريحة، فلغة C سيارة **ناقل يدوي**: تحتاج انتباهًا أكثر، لكنك تفهم كيف يعمل المحرك فعلًا، وتتحكم في كل شيء.

## C و C++: ما الفرق؟

لغة C++ وُلدت من C، وأضافت إليها الكائنات (`class`) والقوالب والمكتبة القياسية الكبيرة. لذلك:

| | C | C++ |
|---|---|---|
| الطباعة | `printf("...")` | `std::cout << ...` |
| النصوص | مصفوفة حروف `char[]` | `std::string` |
| الذاكرة | `malloc` و`free` | `new` و`delete` والمؤشرات الذكية |
| الكائنات | لا يوجد `class` (نستخدم `struct`) | يوجد `class` |
| امتداد الملف | `.c` | `.cpp` |

تعلُّم C يجعلك تفهم ما يحدث «تحت الغطاء» في C++ وفي أي لغة أخرى.

## المترجم gcc

الحاسوب لا يفهم نص لغة C مباشرة، بل يحتاج **مترجمًا** (compiler) يحوّل الكود إلى ملف تنفيذي `.exe`. في هذه الـ IDE نستخدم المترجم المشهور **gcc** من حزمة **MinGW-w64**.

- تبحث الـ IDE عن gcc أولًا في المجلد `%LOCALAPPDATA%\RADIDE\toolchains\mingw64\bin`، ثم في `PATH`، ثم في أماكن MSYS2 المعروفة.
- إذا لم تجد gcc، وكانت عندك Visual Studio مع أدوات C++، فستستخدم مترجم مايكروسوفت `cl.exe`.
- نفس الحزمة فيها `g++` (لـ C++) و`gfortran` (لـ Fortran)، فإن كانت دورة C++ تعمل عندك فـ C تعمل أيضًا.

> **ملحوظة:** عندما تطلب من الـ IDE أن تشغّل برنامجًا، فهي تنفذ في الخلفية أمرًا مثل `gcc -std=gnu11 -o _radapp.exe Program.c` ثم تشغّل الملف الناتج، وتعرض ما يطبعه في نافذة **Output** (المخرجات).

## أول مشروع C في الـ IDE

1. من القائمة **File > New Project...** (ملف ← مشروع جديد).
2. في شجرة اللغات اختر **Native** (أصلي)، ثم **C (GUI Bridge, gcc / MSVC)**.
3. من قائمة **Template** (القالب) اختر **Console Application** (تطبيق طرفية)، وسمّ المشروع `HelloC`.
4. تفتح الـ IDE الملف `Program.c`. امسح ما فيه واكتب البرنامج التالي.
5. اضغط **Ctrl+F5** (Start Without Debugging = بدء بدون تصحيح الأخطاء).

```c run
#include <stdio.h>

int main(void)
{
    printf("Hello, C!\n");
    printf("مرحبًا بلغة C\n");
    return 0;
}
```

```text output
Hello, C!
مرحبًا بلغة C
```

ستظهر الرسالتان في نافذة **Output**. مبروك، هذا أول برنامج C لك! سنشرحه سطرًا سطرًا في الدرس القادم.

> **طريقة أسرع:** في هذه الدروس، كل مثال بجانبه زر **«▶ جرّبه»**. اضغطه فتنشئ الـ IDE مشروعًا صغيرًا للمثال وتشغّله فورًا. وزر **«افتح في المحرر»** يفتح المشروع لتعدل فيه بنفسك.

## كيف تتعامل مع التمارين؟

في آخر كل درس تمارين. لكل تمرين:

- **كود بداية** تعدّل عليه داخل الدرس نفسه.
- زر **«تحقق ✓»** يترجم كودك ويشغّله ويقارن الناتج بالمطلوب.
- **الحل** مخفي، اضغط عليه لتراه، لكن حاول أولًا!

## إذا ظهر خطأ «gcc غير موجود»

ثبّت MinGW بإحدى الطرق:

- حمّل **WinLibs** (نسخة UCRT) وفك ضغطها في `%LOCALAPPDATA%\RADIDE\toolchains\mingw64` بحيث يكون الملف `gcc.exe` داخل المجلد `bin`.
- أو ثبّت **MSYS2** ثم نفذ في طرفيتها: `pacman -S mingw-w64-ucrt-x86_64-gcc`.

ثم أعد تشغيل الـ IDE.

## الخلاصة

- لغة C سريعة وقريبة من الجهاز، ومنها وُلدت C++.
- الـ IDE تترجم برامج C بالمترجم gcc من MinGW.
- مشروع C جديد: **File > New Project > Native > C**، والقالب **Console Application**.
- **Ctrl+F5** للتشغيل، والناتج يظهر في نافذة **Output**.

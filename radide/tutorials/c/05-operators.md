# الدرس 5: العوامل والتحويل بين الأنواع

**العوامل** (operators) هي الرموز التي نجري بها العمليات: الجمع والطرح والمقارنة وغيرها. في هذا الدرس نتعرف عليها، وعلى فخ مشهور جدًا في C اسمه **القسمة الصحيحة**.

## العوامل الحسابية

```c run
#include <stdio.h>

int main(void)
{
    int a = 17, b = 5;
    printf("a + b = %d\n", a + b);
    printf("a - b = %d\n", a - b);
    printf("a * b = %d\n", a * b);
    printf("a / b = %d\n", a / b);   // قسمة صحيحة!
    printf("a %% b = %d\n", a % b);  // باقي القسمة
    return 0;
}
```

```text output
a + b = 22
a - b = 12
a * b = 85
a / b = 3
a % b = 2
```

## فخ القسمة الصحيحة

عندما يكون الطرفان **عددين صحيحين**، تحذف C الجزء العشري: `17 / 5` تساوي `3` وليس `3.4`.

> **تشبيه:** إذا وزعت 17 تفاحة على 5 أطفال بالتساوي، فكل طفل يأخذ **3** تفاحات، ويتبقى **2**. هذا بالضبط ما تفعله `/` و`%` مع الأعداد الصحيحة.

للحصول على النتيجة العشرية يجب أن يكون أحد الطرفين عشريًا:

```c run
#include <stdio.h>

int main(void)
{
    int total = 17, count = 5;
    printf("خطأ: %d\n", total / count);
    printf("صح: %.2f\n", (double)total / count);
    printf("صح أيضًا: %.2f\n", total / 5.0);
    return 0;
}
```

```text output
خطأ: 3
صح: 3.40
صح أيضًا: 3.40
```

`(double)total` اسمها **تحويل صريح** (cast): نطلب من C معاملة `total` كعدد عشري في هذه العملية فقط.

## استخدامات عامل الباقي `%`

- معرفة الزوجي والفردي: `n % 2` تساوي `0` للزوجي.
- استخراج آخر رقم: `1234 % 10` تساوي `4`.
- تحويل الثواني إلى دقائق وثوانٍ:

```c run
#include <stdio.h>

int main(void)
{
    int seconds = 200;
    int minutes = seconds / 60;
    int rest = seconds % 60;
    printf("%d ثانية = %d دقيقة و %d ثانية\n", seconds, minutes, rest);
    return 0;
}
```

```text output
200 ثانية = 3 دقيقة و 20 ثانية
```

## عوامل الإسناد المختصرة والزيادة

| العامل | معناه |
|---|---|
| `x += 5` | `x = x + 5` |
| `x -= 2` | `x = x - 2` |
| `x *= 3` | `x = x * 3` |
| `x /= 2` | `x = x / 2` |
| `x++` | زيادة 1 |
| `x--` | نقص 1 |

```c run
#include <stdio.h>

int main(void)
{
    int score = 10;
    score += 5;
    printf("%d\n", score);
    score *= 2;
    printf("%d\n", score);
    score++;
    printf("%d\n", score);
    score--;
    score--;
    printf("%d\n", score);
    return 0;
}
```

```text output
15
30
31
29
```

## عوامل المقارنة والمنطق

نتيجة المقارنة في C عدد: `1` للصح و`0` للخطأ.

| العامل | معناه |
|---|---|
| `==` | يساوي |
| `!=` | لا يساوي |
| `<` `>` `<=` `>=` | أصغر، أكبر، ... |
| `&&` | و (AND) |
| <code>&#124;&#124;</code> | أو (OR) |
| `!` | ليس (NOT) |

```c run
#include <stdio.h>

int main(void)
{
    int age = 20;
    printf("%d\n", age >= 18);
    printf("%d\n", age == 30);
    printf("%d\n", age > 10 && age < 15);
    printf("%d\n", age < 10 || age > 15);
    printf("%d\n", !(age >= 18));
    return 0;
}
```

```text output
1
0
0
1
0
```

## ترتيب العمليات

الضرب والقسمة والباقي قبل الجمع والطرح، كما في الرياضيات. والأقواس أولًا دائمًا:

```c run
#include <stdio.h>

int main(void)
{
    printf("%d\n", 2 + 3 * 4);
    printf("%d\n", (2 + 3) * 4);
    printf("%d\n", 20 - 10 / 2);
    return 0;
}
```

```text output
14
20
15
```

> **نصيحة:** عندما تشك، ضع أقواسًا. الكود الواضح أهم من الكود القصير.

## أخطاء شائعة

- **كتابة `=` بدل `==`:** `if (x = 5)` تُسند 5 إلى `x` ولا تقارن! gcc يحذرك بـ `suggest parentheses around assignment`.
- **القسمة على صفر:** `x / 0` مع أعداد صحيحة توقف البرنامج فجأة. تأكد من المقسوم عليه أولًا.
- **نسيان القسمة الصحيحة في المتوسط:** استخدم `(double)` عند حساب المتوسطات.

## تمارين

### التمرين 1

حوّل `3725` ثانية إلى ساعات ودقائق وثوانٍ:

```c exercise
#include <stdio.h>

int main(void)
{
    int total = 3725;
    // اطبع: 1 ساعة 2 دقيقة 5 ثانية
    return 0;
}
```

```c solution
#include <stdio.h>

int main(void)
{
    int total = 3725;
    int h = total / 3600;
    int m = (total % 3600) / 60;
    int s = total % 60;
    printf("%d ساعة %d دقيقة %d ثانية\n", h, m, s);
    return 0;
}
```

```text output
1 ساعة 2 دقيقة 5 ثانية
```

### التمرين 2

احسب متوسط الدرجات `85` و`90` و`78` (أعداد صحيحة) واطبعه بخانتين عشريتين، بدون أن تقع في فخ القسمة الصحيحة:

```c exercise
#include <stdio.h>

int main(void)
{
    int a = 85, b = 90, c = 78;
    // اطبع: المتوسط = 84.33
    return 0;
}
```

```c solution
#include <stdio.h>

int main(void)
{
    int a = 85, b = 90, c = 78;
    double avg = (a + b + c) / 3.0;
    printf("المتوسط = %.2f\n", avg);
    return 0;
}
```

```text output
المتوسط = 84.33
```

## الخلاصة

- العوامل الحسابية: `+ - * / %`، والقسمة بين عددين صحيحين تحذف الكسر.
- `(double)x` تحويل صريح لنوع آخر.
- `+=` و`++` اختصارات مفيدة.
- المقارنات تعطي `1` أو `0`، و`&&` و`||` و`!` للمنطق.

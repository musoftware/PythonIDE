# الدرس 3: المتغيرات وأنواع البيانات

البرنامج يحتاج أن **يتذكر** أشياء: عمر المستخدم، سعر منتج، عدد المحاولات. لهذا نستخدم **المتغيرات**.

## ما هو المتغير؟

> **تشبيه:** المتغير **علبة** في ذاكرة الحاسوب، عليها **اسم** مكتوب، ولها **نوع** يحدد ماذا يوضع فيها. علبة الأحذية لا تصلح للماء، وكذلك متغير الأعداد الصحيحة لا يصلح للنصوص.

في C يجب أن تعلن عن المتغير (تحدد نوعه واسمه) **قبل** استخدامه:

```c run
#include <stdio.h>

int main(void)
{
    int age = 25;           // عدد صحيح
    double price = 19.99;   // عدد عشري
    char grade = 'A';       // حرف واحد

    printf("العمر: %d\n", age);
    printf("السعر: %.2f\n", price);
    printf("التقدير: %c\n", grade);

    age = age + 1;          // نغير قيمة المتغير
    printf("العمر بعد سنة: %d\n", age);
    return 0;
}
```

```text output
العمر: 25
السعر: 19.99
التقدير: A
العمر بعد سنة: 26
```

## أهم الأنواع

| النوع | يخزن | مثال | محدد printf |
|---|---|---|---|
| `int` | عدد صحيح | `int n = -7;` | `%d` |
| `long long` | عدد صحيح كبير | `long long big = 9000000000LL;` | `%lld` |
| `float` | عدد عشري (دقة أقل) | `float t = 36.6f;` | `%f` |
| `double` | عدد عشري (دقة مضاعفة) | `double pi = 3.14159;` | `%f` |
| `char` | حرف واحد بين `' '` | `char c = 'x';` | `%c` |
| `_Bool` أو `bool` | صح أو خطأ | `bool ok = true;` | `%d` |

> **ملحوظة:** النوع `bool` والقيمتان `true` و`false` تحتاج `#include <stdbool.h>`. في الحقيقة C تخزنها كأرقام: `true` هي `1` و`false` هي `0`.

## حجم كل نوع: `sizeof`

كل نوع يأخذ عددًا معينًا من **البايتات** في الذاكرة. العامل `sizeof` يخبرنا بالحجم:

```c run
#include <stdio.h>
#include <stdbool.h>

int main(void)
{
    printf("char: %zu\n", sizeof(char));
    printf("int: %zu\n", sizeof(int));
    printf("double: %zu\n", sizeof(double));
    printf("long long: %zu\n", sizeof(long long));
    bool ok = true;
    printf("ok = %d\n", ok);
    return 0;
}
```

```text output
char: 1
int: 4
double: 8
long long: 8
ok = 1
```

المحدد `%zu` خاص بنتيجة `sizeof` (نوعها `size_t`).

## قواعد تسمية المتغيرات

- يبدأ الاسم بحرف إنجليزي أو `_`، ويمكن أن يحتوي أرقامًا بعد ذلك: `total2` صحيح و`2total` خطأ.
- لا مسافات: استخدم `student_count` أو `studentCount`.
- C **حساسة لحالة الأحرف**: `Age` و`age` متغيران مختلفان.
- لا تستخدم الكلمات المحجوزة مثل `int` و`return` و`while`.

## الثوابت: `const` و`#define`

القيمة التي لا تتغير أبدًا نجعلها **ثابتًا**:

```c run
#include <stdio.h>

#define TAX_RATE 0.14      // ثابت بالمعالج المسبق (بلا = وبلا ;)

int main(void)
{
    const double PI = 3.14159;   // ثابت لا يمكن تغييره
    double r = 2.0;
    double area = PI * r * r;
    printf("مساحة الدائرة: %.2f\n", area);

    double price = 200.0;
    printf("الضريبة: %.2f\n", price * TAX_RATE);
    return 0;
}
```

```text output
مساحة الدائرة: 12.57
الضريبة: 28.00
```

- `const` يجعل المتغير للقراءة فقط؛ إن حاولت تغييره يعطيك المترجم خطأ.
- `#define` يستبدل الاسم بالقيمة نصيًا قبل الترجمة. عادةً نكتب أسماء الثوابت بحروف كبيرة.

## المتغير بلا قيمة ابتدائية خطر!

```c
int count;            // ما قيمته؟ لا أحد يعرف!
printf("%d\n", count); // قد يطبع أي رقم عشوائي
```

في C، المتغير المحلي الذي لم تُعطه قيمة يحتوي **بقايا** ما كان في الذاكرة. اعتد دائمًا على إعطاء قيمة ابتدائية: `int count = 0;`.

## أخطاء شائعة

- **استخدام محدد خاطئ:** `printf("%d", 3.5);` يطبع رقمًا غريبًا لأن `%d` تتوقع `int`. استخدم `%f` للعشري.
- **القسمة الصحيحة:** `int x = 7 / 2;` تعطي `3` وليس `3.5`. سنشرح السبب في درس العوامل.
- **علامات التنصيص:** الحرف الواحد بين علامتي تنصيص مفردتين `'A'`، والنص بين مزدوجتين `"A"`. هما شيئان مختلفان في C.

## تمارين

### التمرين 1

أعلن عن متغير `length` قيمته `8` ومتغير `width` قيمته `5` (كلاهما `int`)، ثم اطبع المساحة والمحيط:

```c exercise
#include <stdio.h>

int main(void)
{
    // المساحة = 40
    // المحيط = 26
    return 0;
}
```

```c solution
#include <stdio.h>

int main(void)
{
    int length = 8;
    int width = 5;
    printf("المساحة = %d\n", length * width);
    printf("المحيط = %d\n", 2 * (length + width));
    return 0;
}
```

```text output
المساحة = 40
المحيط = 26
```

### التمرين 2

حوّل درجة الحرارة `30` مئوية إلى فهرنهايت بالقانون `F = C * 9 / 5 + 32` مستخدمًا `double`، واطبع الناتج بخانة عشرية واحدة:

```c exercise
#include <stdio.h>

int main(void)
{
    double c = 30;
    // اطبع: 30.0 C = 86.0 F
    return 0;
}
```

```c solution
#include <stdio.h>

int main(void)
{
    double c = 30;
    double f = c * 9 / 5 + 32;
    printf("%.1f C = %.1f F\n", c, f);
    return 0;
}
```

```text output
30.0 C = 86.0 F
```

## الخلاصة

- المتغير علبة لها اسم ونوع: `int` و`double` و`char` و`bool`.
- `sizeof` يعطي حجم النوع بالبايت.
- `const` و`#define` للثوابت.
- أعطِ كل متغير قيمة ابتدائية.

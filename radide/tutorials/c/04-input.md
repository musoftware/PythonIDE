# الدرس 4: الإدخال بـ `scanf` و`fgets`

حتى الآن كانت برامجنا تتكلم فقط. اليوم نجعلها **تسمع**: تقرأ ما يكتبه المستخدم من لوحة المفاتيح.

## قراءة رقم: `scanf`

```c run
#include <stdio.h>

int main(void)
{
    int age;
    printf("كم عمرك؟ ");
    scanf("%d", &age);
    printf("\nبعد 10 سنوات سيكون عمرك %d\n", age + 10);
    return 0;
}
```

```text input
25
```

```text output
كم عمرك؟ 
بعد 10 سنوات سيكون عمرك 35
```

- `scanf` تستخدم نفس محددات `printf`: `%d` لعدد صحيح.
- العلامة `&` قبل اسم المتغير **ضرورية**: معناها «عنوان المتغير في الذاكرة»، حتى تعرف `scanf` أين تضع القيمة. سنفهم العناوين جيدًا في درس المؤشرات.

> **تشبيه:** `scanf` مثل **عامل التوصيل**: لا يكفي أن تقول له «ضع الطرد في العلبة age»، بل يحتاج **عنوان** العلبة، وهذا ما تعطيه `&age`.

> **كيف تجرب برنامجًا يقرأ مدخلات؟** عند الضغط على «جرّبه» ترسل الـ IDE إلى البرنامج القيم المكتوبة في مربع «المدخلات» تحت الكود. وفي مشروعك الخاص اكتب المدخلات في نافذة **Output** عندما ينتظرها البرنامج.

## قراءة عدة قيم

```c run
#include <stdio.h>

int main(void)
{
    double a, b;
    printf("اكتب رقمين: ");
    scanf("%lf %lf", &a, &b);
    printf("\nالمجموع = %.2f\n", a + b);
    printf("المتوسط = %.2f\n", (a + b) / 2);
    return 0;
}
```

```text input
7.5 2.5
```

```text output
اكتب رقمين: 
المجموع = 10.00
المتوسط = 5.00
```

> **انتبه:** مع `scanf` نستخدم `%lf` لقراءة `double`، بينما في `printf` يكفي `%f`. هذا فرق مشهور يحيّر المبتدئين.

| النوع | محدد `scanf` |
|---|---|
| `int` | `%d` |
| `double` | `%lf` |
| `float` | `%f` |
| `char` | `" %c"` (لاحظ المسافة قبلها لتجاهل الأسطر السابقة) |

## قراءة نص كامل: `fgets`

`scanf("%s", ...)` تقرأ كلمة واحدة فقط وتتوقف عند أول مسافة. لقراءة سطر كامل مثل «أحمد علي» نستخدم `fgets`:

```c run
#include <stdio.h>
#include <string.h>

int main(void)
{
    char name[50];
    printf("ما اسمك الكامل؟ ");
    fgets(name, sizeof(name), stdin);
    name[strcspn(name, "\n")] = '\0';   // احذف سطر النهاية الذي تحتفظ به fgets
    printf("\nأهلًا يا %s!\n", name);
    return 0;
}
```

```text input
أحمد علي
```

```text output
ما اسمك الكامل؟ 
أهلًا يا أحمد علي!
```

- `char name[50]` مصفوفة من 50 حرفًا لتخزين النص (سنشرح المصفوفات والنصوص لاحقًا).
- `fgets(name, sizeof(name), stdin)` تقرأ سطرًا من لوحة المفاتيح (`stdin`) دون أن تتجاوز حجم المصفوفة، وهذا **آمن**.
- `fgets` تحتفظ بحرف السطر الجديد `\n` في آخر النص، والسطر `strcspn` يحذفه.

> **ملحوظة عن العربية:** الحرف العربي الواحد يأخذ بايتين في ترميز UTF-8، لذلك مصفوفة من 50 بايت تكفي لنحو 24 حرفًا عربيًا. اجعل المصفوفة أكبر عند الحاجة.

## التحقق من نجاح القراءة

`scanf` تُرجع **عدد القيم** التي قرأتها بنجاح. إذا كتب المستخدم حروفًا بدل رقم تُرجع `0`:

```c run
#include <stdio.h>

int main(void)
{
    int n;
    printf("اكتب رقمًا: ");
    if (scanf("%d", &n) == 1)
        printf("\nشكرًا، الرقم هو %d\n", n);
    else
        printf("\nهذا ليس رقمًا!\n");
    return 0;
}
```

```text input
abc
```

```text output
اكتب رقمًا: 
هذا ليس رقمًا!
```

سنتعلم `if` في درس الشروط، لكن الفكرة واضحة: لا تثق في المستخدم!

## أخطاء شائعة

- **نسيان `&`:** `scanf("%d", age);` يجعل البرنامج ينهار غالبًا. الصواب `scanf("%d", &age);`. (لاحظ أن النصوص `char name[50]` لا تحتاج `&` لأن اسم المصفوفة عنوان في حد ذاته.)
- **`%f` بدل `%lf` مع `double`:** تُقرأ القيمة خطأ.
- **خلط `scanf` ثم `fgets`:** `scanf` تترك `\n` في الذاكرة المؤقتة، فتقرأه `fgets` التالية كسطر فارغ. الحل أن تستخدم `fgets` لكل المدخلات ثم تحوّل النص لرقم، أو تقرأ الحرف الزائد بـ `getchar()`.

### التمرين 2

اقرأ اسم مدينة بـ `fgets` (قد يحتوي مسافة) واطبع رسالة ترحيب:

```c exercise
#include <stdio.h>
#include <string.h>

int main(void)
{
    char city[80];
    printf("مدينتك؟ ");
    // اقرأ city بـ fgets واحذف \n ثم اطبع: مرحبًا بأهل ...
    return 0;
}
```

```c solution
#include <stdio.h>
#include <string.h>

int main(void)
{
    char city[80];
    printf("مدينتك؟ ");
    fgets(city, sizeof(city), stdin);
    city[strcspn(city, "\n")] = '\0';
    printf("\nمرحبًا بأهل %s\n", city);
    return 0;
}
```

```text input
شرم الشيخ
```

```text output
مدينتك؟ 
مرحبًا بأهل شرم الشيخ
```

## الخلاصة

- `scanf("%d", &x)` تقرأ قيمة، ولا تنسَ `&`.
- `%lf` لقراءة `double`.
- `fgets(buf, sizeof(buf), stdin)` تقرأ سطرًا كاملًا بأمان.
- تحقق مما تُرجعه `scanf` قبل أن تثق في القيمة.

# الدرس 1: مرحبًا بك في Go وتجهيز بيئة العمل

أهلًا بك في دورة **Go** (وتُسمى أحيانًا Golang). Go لغة حديثة صممتها Google سنة 2009 لتكون **بسيطة** و**سريعة** وممتازة في برامج الشبكات والخوادم. في نهاية هذه الدورة ستكتب برنامجًا بنافذة وأزرار نرسمه في مصمم النماذج.

## لماذا Go؟

- **بسيطة:** عدد الكلمات المحجوزة فيها قليل جدًا (25 كلمة فقط)، وتُقرأ بسهولة.
- **سريعة:** تُترجم إلى ملف تنفيذي `.exe` واحد، بلا حاجة لتثبيت أي شيء على جهاز المستخدم.
- **التزامن:** تشغيل آلاف المهام في نفس الوقت سهل جدًا بالـ goroutines (سنراها في الدرس 12).
- **مستخدمة بكثرة:** Docker وKubernetes وكثير من خوادم الإنترنت مكتوبة بـ Go.

> **تشبيه:** إذا كانت C سيارة سباق تحتاج سائقًا خبيرًا، وPython دراجة مريحة، فإن Go **قطار حديث**: سريع، ومنظم، وله قضبان واضحة تمنعك من الضياع.

## تثبيت Go

الـ IDE تبحث عن الأداة `go` في `PATH`، ثم في `C:\Program Files\Go\bin`، ثم في مجلدها الخاص `%LOCALAPPDATA%\RADIDE\toolchains\go\bin`. إذا لم تكن مثبتة:

- نفذ في الطرفية: `winget install GoLang.Go`، ثم أعد تشغيل الـ IDE.
- أو حمّل الملف المضغوط من موقع Go الرسمي وفك ضغطه في `%LOCALAPPDATA%\RADIDE\toolchains\go`.

## أول مشروع Go في الـ IDE

1. **File > New Project...** (ملف ← مشروع جديد).
2. **Native** (أصلي) ← **Go (GUI Bridge)**.
3. القالب: **Console Application** (تطبيق طرفية)، والاسم `HelloGo`.
4. يفتح الملف `Program.go`. امسح ما فيه واكتب:

```go run
package main

import "fmt"

func main() {
    fmt.Println("Hello, Go!")
    fmt.Println("مرحبًا بلغة Go")
}
```

```text output
Hello, Go!
مرحبًا بلغة Go
```

5. اضغط **Ctrl+F5** (Start Without Debugging = بدء بدون تصحيح الأخطاء). تنفذ الـ IDE الأمر `go build` ثم تشغل البرنامج، ويظهر الناتج في نافذة **Output** (المخرجات).

> **ماذا يحدث خلف الكواليس؟** تنشئ الـ IDE ملفًا اسمه `go.mod` في مجلد المشروع (سنشرحه في الدرس 13)، ثم تترجم كل ملفات `.go` معًا إلى `_radapp.exe` وتشغله.

> **طريقة أسرع:** بجانب كل مثال زر **«▶ جرّبه»**: يُنشئ مشروعًا صغيرًا للمثال ويشغله فورًا. وزر **«افتح في المحرر»** يفتحه لتعدل فيه.

## التمارين في هذه الدورة

- اكتب حلك في مربع التمرين داخل الدرس.
- اضغط **«تحقق ✓»**: تترجم الـ IDE كودك وتشغله وتقارن الناتج بالمطلوب.
- الحل مخفي؛ اضغط عليه إذا احتجت، لكن حاول أولًا.

## تمرين

### التمرين 1

اطبع سطرين: `Go` ثم `سهلة وسريعة`:

```go exercise
package main

import "fmt"

func main() {
    // اكتب هنا
}
```

```go solution
package main

import "fmt"

func main() {
    fmt.Println("Go")
    fmt.Println("سهلة وسريعة")
}
```

```text output
Go
سهلة وسريعة
```

## الخلاصة

- Go لغة بسيطة وسريعة من Google.
- المشروع: **File > New Project > Native > Go (GUI Bridge)**، والقالب **Console Application**.
- البرنامج يبدأ من `func main()` في `package main`.
- **Ctrl+F5** للتشغيل والناتج في **Output**.

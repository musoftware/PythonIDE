# الدرس 3: الشروط وحلقات التكرار

حتى الآن ينفذ برنامجنا كل الأسطر بالترتيب. لكن البرامج الحقيقية **تقرر** («إذا كانت الدرجة 50 فأكثر فهو ناجح») و**تكرر** («اطبع جدول الضرب من 1 إلى 10»).

> **تشبيه:** الشرط مثل **إشارة المرور**: إذا كانت خضراء تعبر، وإلا تنتظر. وحلقة التكرار مثل **عدّاد اللفّات** في سباق الجري: تجري لفة، ثم أخرى، حتى تكمل العدد المطلوب.

## if و else

```dart run
void main() {
  final score = 73;
  if (score >= 90) {
    print('ممتاز');
  } else if (score >= 75) {
    print('جيد جدًا');
  } else if (score >= 50) {
    print('ناجح');
  } else {
    print('راسب');
  }
}
```

```text output
ناجح
```

الشرط يُكتب بين قوسين `( )`، والكود الذي يُنفذ بين `{ }`. وتُفحص الشروط بالترتيب، ويُنفذ أول فرع صحيح فقط.

## عوامل المقارنة والمنطق

| العامل | معناه | مثال صحيح |
|---|---|---|
| `==` | يساوي | `5 == 5` |
| `!=` | لا يساوي | `5 != 3` |
| `>` `<` | أكبر / أصغر | `7 > 2` |
| `>=` `<=` | أكبر أو يساوي / أصغر أو يساوي | `5 >= 5` |
| `&&` | و (and): الطرفان صحيحان | `age > 12 && age < 20` |
| `\|\|` | أو (or): أحدهما على الأقل | `day == 'الجمعة' \|\| day == 'السبت'` |
| `!` | ليس (not) | `!isClosed` |

```dart run
void main() {
  final age = 15;
  final hasTicket = true;
  print(age >= 13 && age <= 19);
  print(age < 12 || hasTicket);
  print(!hasTicket);
  final type = age >= 18 ? 'بالغ' : 'قاصر';
  print(type);
}
```

```text output
true
true
false
قاصر
```

`شرط ? قيمة1 : قيمة2` **العامل الشرطي**: if مختصرة في سطر واحد تُرجع قيمة. ستستخدمها كثيرًا في Flutter.

## switch

عندما تقارن متغيرًا واحدًا بقيم كثيرة، `switch` أوضح من سلسلة `if`:

```dart run
void main() {
  final day = 5;
  switch (day) {
    case 5:
    case 6:
      print('عطلة نهاية الأسبوع');
    case 1:
      print('بداية الأسبوع');
    default:
      print('يوم عمل');
  }

  final grade = 'B';
  final text = switch (grade) {
    'A' => 'ممتاز',
    'B' => 'جيد جدًا',
    'C' => 'جيد',
    _ => 'غير معروف',
  };
  print(text);
}
```

```text output
عطلة نهاية الأسبوع
جيد جدًا
```

- في Dart 3 لا يكمل `case` إلى الذي بعده (لا تحتاج `break`)، و`case` فارغة تشارك التي تليها.
- **تعبير switch** (الشكل الثاني بـ `=>`) يُرجع قيمة مباشرة، و`_` تعني «أي قيمة أخرى».

## حلقة for

```dart run
void main() {
  for (var i = 1; i <= 5; i++) {
    print('اللفة رقم $i');
  }
  for (var i = 10; i > 0; i -= 3) {
    print(i);
  }
}
```

```text output
اللفة رقم 1
اللفة رقم 2
اللفة رقم 3
اللفة رقم 4
اللفة رقم 5
10
7
4
1
```

الحلقة `for (بداية; شرط الاستمرار; خطوة)`: تبدأ بـ `i = 1`، وتستمر ما دام `i <= 5`، وبعد كل دورة تنفذ `i++` (زيادة 1). و`i -= 3` تعني `i = i - 3`.

## حلقة for-in

للمرور على عناصر قائمة واحدًا واحدًا (القوائم بالتفصيل في الدرس 5):

```dart run
void main() {
  final fruits = ['تفاح', 'موز', 'برتقال'];
  for (final fruit in fruits) {
    print('أحب ال$fruit');
  }
}
```

```text output
أحب التفاح
أحب الموز
أحب البرتقال
```

## while و do-while

```dart run
void main() {
  var money = 100;
  var days = 0;
  while (money > 0) {
    money -= 30;
    days++;
  }
  print('نفدت النقود بعد $days أيام');

  var n = 0;
  do {
    print('do تعمل مرة واحدة على الأقل: $n');
    n++;
  } while (n < 0);
}
```

```text output
نفدت النقود بعد 4 أيام
do تعمل مرة واحدة على الأقل: 0
```

`while` تفحص الشرط **قبل** كل دورة، و`do-while` تفحصه **بعد** الدورة، فتعمل مرة واحدة على الأقل.

## break و continue

```dart run
void main() {
  for (var i = 1; i <= 10; i++) {
    if (i % 2 == 0) continue;   // تخطَّ الأعداد الزوجية
    if (i > 7) break;           // توقف تمامًا
    print(i);
  }
}
```

```text output
1
3
5
7
```

## أخطاء شائعة

- **`=` بدل `==` في الشرط:** `if (x = 5)` خطأ في Dart (لحسن الحظ تكتشفه قبل التشغيل). المقارنة بـ `==`.
- **حلقة لا تنتهي:** نسيان `money -= 30` داخل `while` يجعل الشرط صحيحًا للأبد. إذا علق البرنامج اضغط **Debug > Stop**.
- **الخطأ بواحد:** `for (var i = 0; i <= 5; i++)` تدور 6 مرات لا 5. انتبه لـ `<` و`<=`.

## تمارين

### التمرين 1

اقرأ عددًا واطبع جدول ضربه من 1 إلى 5 بالشكل `7 × 1 = 7`:

```dart exercise
import 'dart:io';

void main() {
  final n = int.parse(stdin.readLineSync()!);
}
```

```dart solution
import 'dart:io';

void main() {
  final n = int.parse(stdin.readLineSync()!);
  for (var i = 1; i <= 5; i++) {
    print('$n × $i = ${n * i}');
  }
}
```

```text input
7
```

```text output
7 × 1 = 7
7 × 2 = 14
7 × 3 = 21
7 × 4 = 28
7 × 5 = 35
```

### التمرين 2

لعبة FizzBuzz الشهيرة: اطبع الأعداد من 1 إلى 15، لكن إذا كان العدد يقبل القسمة على 3 و5 معًا اطبع `FizzBuzz`، وعلى 3 فقط `Fizz`، وعلى 5 فقط `Buzz`.

```dart exercise
void main() {
}
```

```dart solution
void main() {
  for (var i = 1; i <= 15; i++) {
    if (i % 15 == 0) {
      print('FizzBuzz');
    } else if (i % 3 == 0) {
      print('Fizz');
    } else if (i % 5 == 0) {
      print('Buzz');
    } else {
      print(i);
    }
  }
}
```

```text output
1
2
Fizz
4
Buzz
Fizz
7
8
Fizz
Buzz
11
Fizz
13
14
FizzBuzz
```

لماذا نفحص `15` أولًا؟ لأن 15 تقبل القسمة على 3 أيضًا، فلو فحصنا 3 أولًا لطبعنا `Fizz` وانتهى الأمر.

## الخلاصة

- `if / else if / else` للقرارات، و`? :` للقرار المختصر، و`switch` للمقارنة بقيم كثيرة.
- `&&` و`||` و`!` لربط الشروط.
- `for` للعد، و`for-in` لعناصر القائمة، و`while` / `do-while` للتكرار بشرط.
- `break` توقف الحلقة، و`continue` تتخطى إلى الدورة التالية.

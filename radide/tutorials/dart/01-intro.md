# الدرس 1: مرحبًا بك في Dart: برنامجك الأول

**Dart** (تُنطق «دارت»، ومعناها «السهم الصغير») لغة برمجة صنعتها شركة Google وظهرت سنة 2011. اشتهرت جدًا لأنها لغة **Flutter**، الإطار الذي تكتب به تطبيقًا واحدًا يعمل على Android وiPhone والويب وسطح المكتب.

> **تشبيه:** تعلّم Dart قبل Flutter مثل تعلّم **قيادة السيارة** قبل السفر بها بين المدن. Flutter هي الطريق والمدن الجميلة، وDart هي المقود والفرامل. إذا أتقنت القيادة صارت الرحلة سهلة وممتعة.

## لماذا Dart؟

- **سهلة القراءة:** تشبه Java وC# وJavaScript، فإذا تعلمتها فهمت تلك اللغات بسرعة.
- **آمنة:** تكتشف كثيرًا من الأخطاء **قبل** التشغيل، ومنها أشهر خطأ في البرمجة: استخدام قيمة فارغة (`null`).
- **سريعة:** تُترجم إلى كود الجهاز الأصلي في التطبيقات النهائية.
- **بوابة Flutter:** كل تطبيق Flutter هو برنامج Dart.

## كيف تعمل الأمثلة؟

اضغط **«▶ جرّبه»** تحت أي مثال: تنشئ الـ IDE مشروع Dart صغيرًا وتشغله، ويظهر الناتج في نافذة **Output** (المخرجات). تستخدم الـ IDE أداة `dart` التي تأتي مع Flutter SDK (مثل `C:\flutter\bin\cache\dart-sdk\bin\dart.exe`).

ولكي تنشئ مشروعك بنفسك: **File > New Project...** ثم من مجموعة **Scripting** اختر **Dart (GUI Bridge)**.

## برنامجك الأول

```dart run
void main() {
  print('Hello, World!');
  print('مرحبًا بك في Dart');
}
```

```text output
Hello, World!
مرحبًا بك في Dart
```

لنفهم كل جزء:

- `void main() { ... }` هي **الدالة الرئيسية**: من هنا يبدأ كل برنامج Dart. الكلمة `void` تعني أن الدالة لا تُرجع قيمة.
- القوسان `{` و`}` يحددان بداية الدالة ونهايتها.
- `print(...)` تطبع ما بين القوسين ثم تنزل سطرًا جديدًا.
- النص يُكتب بين علامتي تنصيص مفردتين `'...'` (أو مزدوجتين `"..."`).
- **كل جملة تنتهي بفاصلة منقوطة** `;`. نسيانها أشهر خطأ للمبتدئين.

## التعليقات

```dart run
// هذا تعليق في سطر واحد: Dart تتجاهله
/* وهذا تعليق
   في عدة أسطر */
void main() {
  print('التعليقات لا تظهر في الناتج'); // تعليق في آخر السطر
}
```

```text output
التعليقات لا تظهر في الناتج
```

التعليق ملاحظة لك ولمن يقرأ الكود بعدك، فاكتب فيه **لماذا** فعلت الشيء، لا **ماذا** فعلت فقط.

## Dart آلة حاسبة

```dart run
void main() {
  print(2 + 3);
  print(10 - 4);
  print(6 * 7);
  print(7 / 2);
  print(8 / 2);
  print(7 ~/ 2);
  print(7 % 2);
  print((2 + 3) * 4);
}
```

```text output
5
6
42
3.5
4.0
3
1
20
```

لاحظ:

- `/` تعطي دائمًا **عددًا عشريًا** (`double`): `8 / 2` تساوي `4.0`.
- `~/` قسمة صحيحة تُهمل الكسر، و`%` باقي القسمة.
- الأقواس تُحسب أولًا، ثم الضرب والقسمة، ثم الجمع والطرح، كما في الرياضيات.

## وضع القيم داخل النص

```dart run
void main() {
  print('2 + 3 = ${2 + 3}');
  print('العام القادم: ${2026 + 1}');
  print('أ' + 'ب' + 'ج');
}
```

```text output
2 + 3 = 5
العام القادم: 2027
أبج
```

`${...}` داخل النص تضع **ناتج تعبير** في مكانها، وتسمى **استيفاء النص** (string interpolation). و`+` بين نصين تلصقهما.

## أخطاء شائعة

- **نسيان الفاصلة المنقوطة:**

<!-- compile-error -->
```dart
void main() {
  print('مرحبا')
}
```

تظهر رسالة مثل `Expected ';' after this.`. الـ IDE تضع خطًا أحمر تحت السطر قبل التشغيل.

- **كتابة `Print` بحرف كبير:** Dart تفرق بين الحروف الكبيرة والصغيرة، و`Print` غير موجودة.
- **نسيان `main`:** البرنامج بلا `main` لا يعرف من أين يبدأ.

## تمارين

### التمرين 1

اكتب برنامجًا يطبع اسمك في سطر، ثم مدينتك في سطر ثانٍ، بهذا الشكل بالضبط:

```text
الاسم: سارة
المدينة: القاهرة
```

```dart exercise
void main() {
}
```

```dart solution
void main() {
  print('الاسم: سارة');
  print('المدينة: القاهرة');
}
```

```text output
الاسم: سارة
المدينة: القاهرة
```

### التمرين 2

احسب واطبع عدد الدقائق في أسبوع كامل بهذا الشكل: `دقائق الأسبوع = 10080` (استخدم `${...}` والضرب).

```dart exercise
void main() {
}
```

```dart solution
void main() {
  print('دقائق الأسبوع = ${7 * 24 * 60}');
}
```

```text output
دقائق الأسبوع = 10080
```

## الخلاصة

- Dart لغة Google ولغة Flutter، ويبدأ البرنامج من `void main()`.
- `print` للطباعة، وكل جملة تنتهي بـ `;`.
- `/` تعطي عددًا عشريًا، و`~/` قسمة صحيحة، و`%` باقي القسمة.
- `${...}` تضع قيمة تعبير داخل النص.

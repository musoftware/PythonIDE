# الدرس 2: الخلايا والنواة: ترتيب التشغيل وإعادة التشغيل

أكثر ما يربك المبتدئين في الدفاتر هو **ترتيب التشغيل**: الخلايا مكتوبة من أعلى لأسفل، لكنك تستطيع تشغيلها بأي ترتيب! في هذا الدرس نفهم **النواة** (kernel) وكيف نتجنب المفاجآت.

## ما هي النواة؟

**النواة** برنامج Python يعمل في الخلفية طوال فتح الدفتر. كل خلية تشغّلها تُرسل إلى النواة فتنفذها **في نفس الذاكرة**، ولذلك تبقى المتغيرات من خلية إلى أخرى.

> **تشبيه:** النواة مثل **الطاهي في المطبخ**، والخلايا مثل **الطلبات** التي ترسلها له. الطاهي يتذكر كل ما طبخه حتى الآن (المكونات المقطعة ما زالت على الطاولة). إذا أرسلت طلبًا يحتاج «البصل المقطع» قبل أن تطلب تقطيعه، سيقول لك: لا يوجد بصل!

### اختيار النواة

قائمة **Kernel** في أعلى يمين الدفتر تحدد **أي Python** تشغّل الدفتر: Python المشروع (`.venv`) إن وُجدت، أو Python الخاصة بالـ IDE، أو أي نواة Jupyter مثبتة على جهازك. وتجدها أيضًا في **Notebook > Select Kernel...**.

النواة تحتاج مكتبة اسمها `ipykernel`. إذا اخترت Python ليس فيها هذه المكتبة، تعرض عليك الـ IDE تثبيتها بضغطة واحدة. ومكتبات التحليل (`pandas` و`matplotlib`) يجب أن تكون مثبتة في نفس Python؛ ثبّتها عند الحاجة من **Project > Manage Packages...**.

## رقم التنفيذ

بجوار كل خلية كود رقم مثل `[3]`: هذا **ترتيب تنفيذها**. الخلية `[3]` هي ثالث خلية نُفذت منذ بدء النواة، بغض النظر عن مكانها في الدفتر. انظر إلى هذه الأرقام دائمًا لتعرف ماذا نُفذ قبل ماذا.

## مفاجأة الترتيب

تخيّل هذه الخلايا الثلاث:

```python notebook run
# %%
price = 100

# %%
price = price * 2

# %%
price
```

```text output
200
```

عند تشغيلها بالترتيب مرة واحدة تكون النتيجة `200`. لكن لو شغّلت الخلية الثانية **مرة أخرى** ثم الثالثة، ستصبح `400`! ولو أعدت تشغيلها خمس مرات... فهمت الفكرة. **حالة النواة** تعتمد على ما شغّلته فعلًا، لا على ما تراه مكتوبًا.

### خطأ شائع: متغير لم يُعرّف بعد

إذا فتحت دفترًا محفوظًا وشغّلت خلية في منتصفه مباشرة، فقد ترى:

```python notebook run
# %%
total = subtotal + 15
```

```text output
Traceback (most recent call last):
  Cell In[1], line 1
    total = subtotal + 15
NameError: name 'subtotal' is not defined
```

`NameError` معناها أن `subtotal` لم تُنشأ في هذه النواة بعد، لأن الخلية التي تعرّفها لم تُشغّل. الحل: **Run Above** لتشغيل كل ما فوق الخلية الحالية، أو **Run All**.

## إعادة تشغيل النواة (Restart)

**↻ Restart** (أو **Notebook > Restart Kernel**) توقف النواة وتبدأ واحدة جديدة **فارغة**: تُمسح كل المتغيرات والمكتبات المستوردة، لكن الكود والنتائج المعروضة تبقى في الدفتر.

متى نعيد التشغيل؟

- عندما تختلط الحالة ولا تعرف أي قيمة في أي متغير.
- بعد تثبيت مكتبة جديدة، لكي تستطيع النواة استيرادها.
- **قبل تسليم الدفتر أو مشاركته**: اختر **Restart && Run All** (إعادة التشغيل ثم تشغيل الكل) لتتأكد أن الدفتر يعمل من أوله لآخره بالترتيب. إذا نجح، فأي شخص آخر سيحصل على نفس النتائج.

## إيقاف خلية طويلة (Interrupt)

إذا كتبت حلقة لا تنتهي أو عملية تستغرق وقتًا طويلًا، اضغط **■ Interrupt** (أو **Notebook > Interrupt Kernel**). يتوقف تنفيذ الخلية الحالية مع رسالة `KeyboardInterrupt`، **وتبقى المتغيرات** كما هي (بخلاف Restart).

## الإدخال من المستخدم

`input()` تعمل في الدفتر أيضًا: يظهر مربع إدخال تحت الخلية تكتب فيه وتضغط Enter. لكن في التحليل نادرًا ما نحتاجها؛ البيانات تأتي غالبًا من ملفات.

## الأخطاء في الخلايا

عندما يحدث خطأ تظهر رسالة **Traceback** ملونة تحت الخلية، وتُعلَّم الخلية بلون الخطأ. الخلايا التالية في **Run All** لا تُنفذ بعد الخلية الفاشلة. صحح الخطأ ثم شغّل الخلية من جديد.

```python notebook run
# %%
numbers = [4, 8, 15]

# %%
try:
    print(numbers[5])
except IndexError as e:
    print("خطأ:", e)

# %%
numbers.append(16)
numbers
```

```text output
خطأ: list index out of range
[4, 8, 15, 16]
```

## مسح النتائج

**Clear Outputs** (أو **Notebook > Clear All Outputs**) يمسح كل النتائج المعروضة ويُبقي الكود. مفيد قبل حفظ دفتر كبير لتصغير حجمه، أو قبل رفعه إلى Git.

## نصائح لدفتر نظيف

1. ضع كل **الاستيرادات** (`import`) في أول خلية.
2. اجعل كل خلية تقوم بخطوة واحدة واضحة، واشرحها بخلية Markdown قبلها.
3. لا تعتمد على خلايا حذفتها: ما حُذف من الدفتر قد يبقى في النواة! **Restart && Run All** يكشف ذلك.
4. لا تعدّل متغيرًا في خلية ثم تعيد تشغيلها مرارًا (مثل `price = price * 2`)؛ أنشئ متغيرًا جديدًا بدلًا من ذلك.

## الخلاصة

- النواة Python واحدة في الخلفية تنفذ الخلايا وتحفظ المتغيرات بينها، وتختارها من قائمة **Kernel**.
- رقم التنفيذ `[n]` يبين الترتيب الحقيقي للتشغيل.
- **Run Above** و**Run All** لتشغيل ما تحتاجه، و**Interrupt** لإيقاف خلية، و**Restart** لنواة جديدة فارغة.
- **Restart && Run All** قبل المشاركة دائمًا.

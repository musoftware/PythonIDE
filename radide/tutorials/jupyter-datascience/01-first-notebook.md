# الدرس 1: ما هو دفتر Jupyter؟ وأول دفتر لك

في دورة Python كنا نكتب البرنامج كاملًا ثم نشغّله من أوله إلى آخره. أما في **تحليل البيانات** فنعمل بطريقة مختلفة: نجرّب سطرًا، ونرى النتيجة، ثم نقرر الخطوة التالية. لهذا العمل الاستكشافي صُمّمت **دفاتر Jupyter** (Jupyter Notebooks).

## ما هو الدفتر؟

**الدفتر** (notebook) ملف امتداده `.ipynb` يتكون من **خلايا** (cells):

- **خلية كود** (code cell): فيها كود Python، وتحتها **ناتجها** مباشرة: نص، أو جدول، أو رسم بياني.
- **خلية Markdown**: فيها نص منسّق (عناوين، وقوائم، وصيغ) تشرح به تحليلك.

> **تشبيه:** الدفتر مثل **كراسة المعمل** في درس العلوم: تكتب الخطوة، ثم تسجل النتيجة تحتها مباشرة، ثم تكتب ملاحظتك. في النهاية تصبح الكراسة تقريرًا كاملًا يقرؤه غيرك ويفهم ماذا فعلت ولماذا.

والدفاتر هي الأداة الأولى لعلماء البيانات حول العالم، وتعمل بها Google Colab وKaggle وVS Code، وRAD IDE أيضًا.

## إنشاء أول دفتر

1. افتح **File > New Notebook** (ملف ← دفتر ملاحظات جديد).
2. اختر **Data Science Starter (pandas + matplotlib)...**، أو **Blank Notebook (.ipynb)...** لدفتر فارغ.
3. اختر مكان الحفظ واسم الملف، مثلًا `Analysis.ipynb`.

يفتح الدفتر في تبويب جديد. في أعلاه **شريط أدوات** فيه: **▶ Run** و**Run All** و**Run Above** و**Run Below** و**■ Interrupt** و**↻ Restart** و**+ Code** و**+ Markdown** و**Clear Outputs** و**Export**، وعلى اليمين **حالة النواة** وقائمة **Kernel**.

وعندما يكون الدفتر هو التبويب الحالي تظهر قائمة **Notebook** (دفتر الملاحظات) في شريط القوائم، وفيها نفس الأوامر وأكثر.

> **قالب Data Science Starter** ينشئ دفترًا جاهزًا فيه أمثلة pandas وmatplotlib، وملف بيانات صغيرًا اسمه `sales.csv` بجانبه. ممتاز لتجربة سريعة.

## تشغيل خلية

اكتب في أول خلية كود:

```python notebook run
# %%
print("مرحبًا من Jupyter!")
2 + 3
```

```text output
مرحبًا من Jupyter!
5
```

ثم اضغط **Shift+Enter** (أو **▶ Run** في الشريط). يحدث الآتي:

1. في أول مرة تبدأ **النواة** (kernel): برنامج Python يعمل في الخلفية وينفذ خلاياك (سنفهمها في الدرس القادم). تظهر حالتها بجوار القائمة: `starting` ثم `idle`.
2. يُطبع النص، ثم تظهر قيمة **آخر سطر في الخلية** (`5`) تلقائيًا دون `print`. هذه ميزة مهمة في الدفاتر.
3. ينتقل التحديد إلى الخلية التالية (أو تُنشأ خلية جديدة).

> **في هذه الدروس:** السطر `# %%` يعني «خلية جديدة»، و`# %% [markdown]` يعني «خلية Markdown». زر «جرّبه» يحوّل المثال إلى دفتر `notebook.ipynb` ويفتحه في الـ IDE ويشغّل كل خلاياه. وهذه هي نفس الصيغة التي يقبلها أمر **File > New Notebook > Import Python Script as Notebook...**.

## عدة خلايا تتشارك المتغيرات

المتغيرات التي تنشئها في خلية تبقى موجودة للخلايا التالية، لأن كل الخلايا تعمل في نفس النواة:

```python notebook run
# %%
prices = [120, 85, 230, 60]

# %%
total = sum(prices)
total

# %%
f"المتوسط: {total / len(prices):.2f}"
```

```text output
495
'المتوسط: 123.75'
```

لاحظ أن النص في آخر خلية ظهر **بين علامتي تنصيص**: هكذا يعرض الدفتر قيمة النص كما هي في Python. إذا أردته بدونها فاطبعه بـ `print(...)`.

## خلايا Markdown

لتحويل خلية إلى Markdown: حددها واضغط **M** (أو **+ Markdown** في الشريط). ولإرجاعها كودًا اضغط **Y**. ثم اكتب نصًا منسقًا:

```text
# تحليل مبيعات الربع الأول
البيانات من **فرع القاهرة**، والهدف:
- معرفة أكثر المنتجات مبيعًا
- مقارنة الأشهر
```

ثم **Shift+Enter** لعرضها منسّقة. انقر عليها مرتين لتعدّلها من جديد.

```python notebook run
# %% [markdown]
# # تجربة سريعة
# هذه خلية **Markdown** تشرح الخلية التالية.

# %%
name = "RAD IDE"
f"أهلًا بك في دفاتر {name}"
```

```text output
'أهلًا بك في دفاتر RAD IDE'
```

## اختصارات لوحة المفاتيح

الدفتر له وضعان: **وضع التحرير** (المؤشر داخل الخلية تكتب فيها) و**وضع الأوامر** (الخلية محددة فقط). اضغط **Esc** للخروج إلى وضع الأوامر، و**Enter** للدخول إلى التحرير.

| الاختصار | الوضع | الأمر |
|---|---|---|
| **Shift+Enter** | الوضعان | شغّل الخلية وانتقل للتالية |
| **Ctrl+Enter** | الوضعان | شغّل الخلية وابقَ فيها |
| **A** / **B** | الأوامر | خلية كود جديدة فوق / تحت |
| **M** / **Y** | الأوامر | حوّل إلى Markdown / إلى كود |
| **D D** | الأوامر | احذف الخلية (اضغط D مرتين بسرعة) |
| **Z** | الأوامر | تراجع عن الحذف |
| **↑** / **↓** | الأوامر | انتقل بين الخلايا |

## حفظ الدفتر

**Ctrl+S** يحفظ الدفتر بصيغة `.ipynb` **مع النتائج**، فإذا أرسلته لزميل يرى الجداول والرسوم دون أن يشغّله. ويحفظه أيضًا **File > Save All**.

## الخلاصة

- الدفتر `.ipynb` خلايا كود وخلايا Markdown، والنتائج تظهر تحت كل خلية.
- **File > New Notebook** لإنشاء دفتر، و**Shift+Enter** للتشغيل، وآخر تعبير يُعرض تلقائيًا.
- المتغيرات مشتركة بين الخلايا لأنها تعمل في نواة واحدة.
- **M** / **Y** / **A** / **B** / **D D** اختصارات وضع الأوامر.

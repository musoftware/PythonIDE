# الدرس 3: نافذة متغيرات الدفتر

مع كثرة الخلايا يصعب أن تتذكر ما في النواة من متغيرات وقيم. **نافذة متغيرات الدفتر** (Notebook Variables) تعرض لك كل ذلك في جدول واحد يتحدث تلقائيًا بعد كل خلية، مثل نافذة **Locals** في المصحح.

## فتح النافذة

أي طريقة من هذه:

- **View > Other Windows > Notebook Variables** (عرض ← ... ← متغيرات الدفتر).
- **Notebook > Variables Window** (والدفتر هو التبويب الحالي).
- في تخطيط VS Code أو Agent: أيقونة **Variables** في اللوحة السفلية.

تظهر النافذة في أسفل الـ IDE، وفيها رسالة «Run a notebook cell to see its variables» حتى تشغّل أول خلية.

## الأعمدة

| العمود | المعنى | مثال |
|---|---|---|
| **Name** | اسم المتغير | `df` |
| **Type** | نوعه | `DataFrame` أو `list` أو `int` |
| **Size** | حجمه: عدد العناصر أو أبعاد الجدول | `6 x 4` لجدول بـ 6 صفوف و4 أعمدة |
| **Value** | لمحة من قيمته | `[120, 85, 230]` |

## جرّب بنفسك

شغّل هذا الدفتر ثم افتح نافذة المتغيرات:

```python notebook run
# %%
import pandas as pd

city = "Cairo"
year = 2026
temps = [18, 21, 25, 30, 34, 36]
info = {"country": "Egypt", "population_m": 22.6}
df = pd.DataFrame({
    "month": ["Jan", "Feb", "Mar", "Apr", "May", "Jun"],
    "temp": temps,
})
print("تم إنشاء", len(df), "صفوف")

# %%
df.shape
```

```text output
تم إنشاء 6 صفوف
(6, 2)
```

ستجد في النافذة شيئًا مثل:

| Name | Type | Size | Value |
|---|---|---|---|
| `city` | `str` | `5` | `'Cairo'` |
| `df` | `DataFrame` | `6 x 2` | `month temp ...` |
| `info` | `dict` | `2` | `{'country': 'Egypt', ...}` |
| `temps` | `list` | `6` | `[18, 21, 25, 30, 34, 36]` |
| `year` | `int` |  | `2026` |

لاحظ أن الوحدات المستوردة (مثل `pd`) والدوال والأصناف والأسماء الداخلية التي تبدأ بشرطة سفلية لا تظهر، لكي تبقى النافذة مركزة على بياناتك.

## النقر المزدوج: عرض المتغير كاملًا

**انقر مرتين** على أي متغير في النافذة، فتضيف الـ IDE خلية جديدة في آخر الدفتر فيها `display(اسم_المتغير)` وتشغّلها. وإذا كان المتغير **DataFrame** فسيظهر **جدولًا منسقًا** بأعمدة وصفوف، وهذه أسرع طريقة لتلقي نظرة على بياناتك.

`display` دالة متاحة في نواة Jupyter، تعرض القيمة بأفضل شكل ممكن (جدول، صورة...) حتى لو لم تكن آخر سطر في الخلية:

```python notebook run
# %%
a = [1, 2, 3]
b = {"x": 10}
print(a)
print(b)
```

```text output
[1, 2, 3]
{'x': 10}
```

> **ملحوظة:** داخل الدفتر في الـ IDE تستطيع كتابة `display(a)` ثم `display(b)` في نفس الخلية فيظهر الاثنان. خارج الدفاتر (في برنامج `.py` عادي) استخدم `print`.

## الترتيب والبحث

- انقر على عنوان أي عمود لترتيب المتغيرات حسبه (مثلًا حسب **Type** لتجمع كل الجداول معًا).
- النافذة تتبع **الدفتر الحالي**: إذا فتحت دفترين وانتقلت بينهما، تتغير القائمة لتعرض متغيرات نواة الدفتر الظاهر.

## متى تفيدك هذه النافذة؟

- **بعد تحميل ملف:** هل عدد الصفوف والأعمدة (Size) كما توقعت؟
- **بعد Restart:** تصبح النافذة فارغة، فتتأكد أن الحالة القديمة مُسحت.
- **عند البحث عن خطأ:** هل `total` فعلًا رقم (`int`) أم نص (`str`) جاء من ملف؟

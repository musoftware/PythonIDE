# الدرس 1: مرحبًا بك في Rust وأول مشروع cargo

أهلًا بك في دورة **Rust**! هذه لغة حديثة ظهرت سنة 2015، وتصوَّت سنوات متتالية كأكثر لغة **يحبها** المبرمجون. سرّها أنها تجمع بين **سرعة C وC++** و**أمان** اللغات الحديثة: لا انهيارات بسبب المؤشرات، ولا تسرب ذاكرة عشوائي.

## لماذا Rust؟

- **أمان الذاكرة دون جامع قمامة:** المترجم نفسه يمنع أخطاء الذاكرة الشهيرة في C (المؤشر المعلق، والتحرير مرتين...) **قبل** أن يعمل البرنامج.
- **سرعة عالية:** مثل C++ تقريبًا.
- **أدوات ممتازة:** `cargo` يدير المشروع والمكتبات والاختبارات، ورسائل المترجم تشرح لك الخطأ وتقترح الحل.
- **مستخدمة في الكبار:** أجزاء من Windows ونواة Linux ومتصفح Firefox وأدوات كثيرة على الإنترنت.

> **تشبيه:** المترجم في Rust مثل **مدرب قيادة صارم** يجلس بجانبك: لن يتركك تتحرك إذا لم تربط الحزام أو إذا نسيت المرآة. في البداية قد يزعجك، لكنك بعدها تقود بأمان تام.

## تثبيت Rust

1. ادخل موقع **rustup.rs** وحمّل `rustup-init.exe` وشغّله (اختر الإعدادات الافتراضية).
2. ثبّت أداة IntelliSense ومصادر المكتبة بالأمر التالي في الطرفية:

```text
rustup component add rust-analyzer rust-src
```

3. أعد تشغيل الـ IDE. تبحث الـ IDE عن `cargo` في `PATH` وفي `%USERPROFILE%\.cargo\bin`.

ويمكنك أيضًا فتح **Tools ← Rust Settings...** لمعرفة حالة rust-analyzer وتثبيته بضغطة زر.

## ما هو cargo؟

`cargo` هو **مدير مشاريع Rust**: ينشئ المشروع، ويترجمه، ويشغله، ويحمّل المكتبات (تسمى **crates**)، ويشغل الاختبارات. أهم أوامره:

| الأمر | وظيفته |
|---|---|
| `cargo new name` | مشروع جديد |
| `cargo run` | ترجم وشغّل |
| `cargo build` | ترجم فقط |
| `cargo check` | افحص الأخطاء بسرعة دون إنتاج ملف تنفيذي |
| `cargo test` | شغّل الاختبارات |
| `cargo add name` | أضف مكتبة من crates.io |

في الـ IDE لن تحتاج كتابة هذه الأوامر غالبًا؛ الأزرار والقوائم تنفذها لك.

## أول مشروع Rust في الـ IDE

1. **File ← New Project...** (ملف ← مشروع جديد).
2. **Native** (أصلي) ← **Rust (Cargo)**.
3. اختر القالب **Console App** (تطبيق طرفية) وسمّ المشروع `hello_rust`.
4. تنشئ الـ IDE مشروع cargo عاديًا فيه:
   - `Cargo.toml`: ملف إعدادات المشروع (الاسم، الإصدار، المكتبات).
   - `src/main.rs`: ملف الكود الرئيسي.
5. افتح `src/main.rs` من **Solution Explorer** (مستكشف الحلول)، وضع فيه:

```rust run
fn main() {
    println!("Hello, Rust!");
    println!("مرحبًا بلغة Rust");
}
```

```text output
Hello, Rust!
مرحبًا بلغة Rust
```

6. اضغط **Ctrl+F5** (Start Without Debugging = بدء بدون تصحيح الأخطاء). تنفذ الـ IDE `cargo run`، ويظهر الناتج في نافذة **Output** (المخرجات).

> **أول ترجمة أبطأ قليلًا** لأن cargo يجهز مجلد `target`؛ بعدها تكون سريعة.

## قوالب Rust الأخرى في New Project

| القالب | ماذا يعطيك |
|---|---|
| **Console App** | برنامج كونسول (`src/main.rs`) |
| **Library** | مكتبة (`src/lib.rs`) مع اختبارات ومثال |
| **GUI App (RAD form)** | نافذة ترسمها في مصمم النماذج ومنطقها بـ Rust (الدرس 15) |
| **egui Desktop App** | تطبيق سطح مكتب بمكتبة egui (الدرس 16) |
| **Workspace** | مساحة عمل فيها مشروعان: تطبيق ومكتبة |

## ملف `Cargo.toml`

```text
[package]
name = "hello_rust"
version = "0.1.0"
edition = "2021"

[dependencies]
```

- `[package]`: معلومات المشروع. `edition` هي «طبعة» لغة Rust المستخدمة.
- `[dependencies]`: المكتبات الخارجية، وسنضيف إليها في الدرس 13.

> **في هذه الدروس:** زر **«▶ جرّبه»** بجانب كل مثال ينشئ مشروع cargo صغيرًا ويشغله. وزر **«تحقق ✓»** في التمارين يترجم كودك ويقارن الناتج بالمطلوب.

## الخلاصة

- Rust آمنة وسريعة، والمترجم يمنع أخطاء الذاكرة.
- `cargo` يدير المشروع، و`Cargo.toml` إعداداته، و`src/main.rs` الكود.
- مشروع جديد: **File ← New Project ← Native ← Rust (Cargo) ← Console App**، و**Ctrl+F5** للتشغيل.

# الدرس 14: أدوات الـ IDE: rust-analyzer وتصحيح الأخطاء

تعلمنا اللغة، والآن نتعلم كيف تجعلك الـ IDE **أسرع وأدق** في كتابة Rust: الإكمال التلقائي الذكي، وقائمة الأخطاء الحية، والتنقل في الكود، ثم **المصحح** (debugger) الذي يوقف البرنامج سطرًا سطرًا لترى ما يحدث بداخله.

> **تشبيه:** rust-analyzer مثل **مساعد يقرأ معك** كل كلمة تكتبها ويهمس: «هذا الحقل اسمه كذا»، «هنا ستحدث مشكلة ملكية». والمصحح مثل **زر الإيقاف المؤقت في فيلم**: توقف المشهد، وتتأمل كل التفاصيل، ثم تكمل لقطة لقطة.

## 1) تجهيز rust-analyzer

rust-analyzer هو **خادم اللغة** الرسمي لـ Rust، والـ IDE تتحدث معه لتعطيك IntelliSense.

1. **Tools > Rust Settings...** (أدوات ← إعدادات Rust...).
2. إن ظهر أنه غير مثبت اضغط **Install** (ينفذ `rustup component add rust-analyzer rust-src`).
3. من نفس النافذة يمكنك اختيار:
   - **Check on save:** الفحص عند الحفظ بـ `cargo check` أو بـ `clippy` (أدق وينصحك بكتابة أفضل).
   - **Inlay hints:** إظهار الأنواع بخط خافت داخل المحرر.
   - **Format on save:** تنسيق الكود تلقائيًا بـ `rustfmt` عند الحفظ.
4. في شريط الحالة أسفل النافذة ترى تقدم rust-analyzer (فهرسة المشروع، cargo check...). أول مرة تأخذ بعض الوقت.

## 2) ما الذي يعطيك إياه rust-analyzer؟

| ما تفعله | النتيجة |
|---|---|
| تكتب `v.` | قائمة بكل توابع المتجه مع شرح كل واحد |
| **Ctrl+Space** | الإكمال التلقائي في أي مكان |
| تمرر الماوس فوق اسم | نوعه وتوثيقه |
| **F12** | **Go to Definition** (الانتقال إلى التعريف) |
| **Shift+F12** | كل الأماكن التي يُستخدم فيها الاسم |
| **F2** | **Rename Symbol...** (إعادة تسمية الرمز) في كل الملفات بأمان |
| **Ctrl+.** | الإصلاحات السريعة: استيراد ناقص، تعبئة حقول، تطبيق سمة... |

جرّب هذا: اكتب في `main.rs` السطر `let m = HashMap::new();` بدون `use`. يظهر خط أحمر تحت `HashMap`. ضع المؤشر عليه واضغط **Ctrl+.** واختر `Import std::collections::HashMap`، فيُضاف سطر الاستيراد في أعلى الملف.

## 3) قائمة الأخطاء (Error List)

افتح **View > Error List** (قائمة الأخطاء). تعرض أخطاء وتحذيرات **كل** ملفات المشروع، حتى المغلقة، مع رمز الخطأ:

```text
error   [rustc E0382]  borrow of moved value: `name`        src/main.rs  12
warning [clippy::needless_return] unneeded `return` statement  src/main.rs  20
```

انقر مرتين على أي سطر فتنتقل إلى مكان الخطأ. وكل رمز مثل `E0382` له شرح مفصل: اكتب في الطرفية `rustc --explain E0382`.

## 4) تصحيح الأخطاء خطوة بخطوة

لنصحح هذا البرنامج الذي يحسب متوسط الدرجات:

```rust run
fn average(marks: &[u32]) -> f64 {
    let mut total = 0;
    for m in marks {
        total += m;                         // ضع نقطة توقف هنا (F9)
    }
    total as f64 / marks.len() as f64
}

fn main() {
    let marks = vec![80, 95, 70, 88];
    let avg = average(&marks);
    println!("المتوسط = {avg}");
    let best = marks.iter().max().unwrap();
    println!("الأعلى = {best}");
}
```

```text output
المتوسط = 83.25
الأعلى = 95
```

الخطوات:

1. ضع المؤشر على سطر `total += m;` واضغط **F9** (**Toggle Breakpoint** - تبديل نقطة التوقف). تظهر دائرة حمراء في الهامش.
2. اضغط **F5** (**Start Debugging** - بدء تصحيح الأخطاء). تبني الـ IDE نسخة تصحيح (للهدف `x86_64-pc-windows-gnu`) وتشغلها تحت المصحح `gdb`.
3. يتوقف البرنامج عند نقطة التوقف، ويظهر سهم أصفر عند السطر.
4. في نافذة **Locals** (المتغيرات المحلية) ترى `total` و`m` و`marks`.
5. اضغط **F10** (**Step Over** - خطوة فوق) لتنفيذ السطر ومشاهدة `total` يتغير.
6. اضغط **F11** (**Step Into** - خطوة إلى الداخل) على سطر فيه استدعاء دالة لتدخل إليها.
7. نافذة **Call Stack** (مكدس الاستدعاءات) تريك أن `average` استُدعيت من `main`.
8. اكتب تعبيرًا مثل `total * 2` في نافذة **Watch** (المراقبة) لتراقبه أثناء التنفيذ.
9. **F5** مرة أخرى للمتابعة حتى نقطة التوقف التالية، و**Shift+F5** لإيقاف التصحيح.

> **ملاحظة:** المصحح يحتاج `gdb` من أدوات MinGW وهدف GNU لـ Rust. إن ظهرت في نافذة **Output** رسالة `the GNU target is missing` فنفّذ مرة واحدة في الطرفية: `rustup target add x86_64-pc-windows-gnu`. وإن لم يتوفر `gdb` يعمل **F5** كتشغيل عادي.

### نقطة توقف شرطية

اضغط بالزر الأيمن على الدائرة الحمراء ← **Breakpoint Condition...** (شرط نقطة التوقف) واكتب `*m == 70`. الآن يتوقف البرنامج فقط عندما تكون الدرجة 70. مفيد جدًا في الحلقات الطويلة.

## 5) التتبع بالطباعة: `dbg!`

أحيانًا أسرع طريقة هي الطباعة. الماكرو `dbg!` يطبع **اسم الملف والسطر والتعبير وقيمته** في مجرى الأخطاء (stderr)، ويرجع القيمة نفسها فيمكنك وضعه في وسط أي تعبير:

```rust
let total = dbg!(a + b) * 2;
// [src/main.rs:3:17] a + b = 7
```

احذف أسطر `dbg!` بعد أن تنتهي من التصحيح.

## 6) شريط أدوات Rust

في شريط الأدوات **Rust** تجد:

- **مربع الهدف:** اختر ما تريد تشغيله: `bin: اسم_المشروع` أو `example: demo` أو `test: all`. **Ctrl+F5** و**F5** يشغلان الهدف المختار.
- **Reload:** بعد تعديل `Cargo.toml` يدويًا.
- **Clippy:** يفحص الكود ويقترح طرقًا أفضل للكتابة.
- **Test:** ينفذ `cargo test`.

ومن قائمة **Native** تجد أوامر cargo الأخرى: `cargo fmt` و`cargo doc --open` و`cargo build --release` وغيرها.

## أخطاء شائعة

- **IntelliSense لا يعمل:** rust-analyzer غير مثبت أو ما زال يفهرس. انظر شريط الحالة و**Tools > Rust Settings...**.
- **نقطة التوقف لا تتوقف:** شغلت بـ **Ctrl+F5** (بلا تصحيح) بدل **F5**، أو `gdb` غير موجود.
- **المتغيرات تظهر `<optimized out>`:** أنت تصحح نسخة `--release`. صحح نسخة debug العادية.

## تمرين

### التمرين 1

البرنامج التالي يجب أن يطبع مجموع الأعداد من 1 إلى 5 (15)، لكنه يطبع 10. استخدم المصحح (أو `dbg!`) لتجد الخطأ وصححه:

```rust exercise
fn main() {
    let mut sum = 0;
    for i in 1..5 {
        sum += i;
    }
    println!("{sum}");
}
```

```rust solution
fn main() {
    let mut sum = 0;
    for i in 1..=5 {
        sum += i;
    }
    println!("{sum}");
}
```

```text output
15
```

`1..5` تتوقف **قبل** 5، و`1..=5` تشمل 5. لو وضعت نقطة توقف داخل الحلقة لرأيت أن `i` لا يصل أبدًا إلى 5.

## الخلاصة

- **Tools > Rust Settings...** لتثبيت rust-analyzer وضبط الفحص والتنسيق.
- **Ctrl+Space** و**F12** و**F2** و**Ctrl+.** تسرّع الكتابة، و**Error List** تجمع كل الأخطاء.
- **F9** ثم **F5** للتصحيح، و**F10**/**F11** للتنقل، و**Locals**/**Watch**/**Call Stack** لمشاهدة الحالة.
- `dbg!` للتتبع السريع.

# الدرس 2: برنامجك الأول و`println!`

## البرنامج كاملًا

```rust run
fn main() {
    println!("Hello, World!");
}
```

```text output
Hello, World!
```

## الشرح

- `fn` تعني **دالة** (function)، و`main` الدالة الرئيسية التي يبدأ منها البرنامج.
- `{ }` جسم الدالة.
- `println!` تطبع سطرًا. لاحظ علامة التعجب `!`: معناها أن `println!` ليست دالة عادية بل **ماكرو** (macro)، أي أداة تكتب كودًا نيابةً عنك وقت الترجمة. لا تقلق من هذا الآن؛ المهم ألا تنسى `!`.
- `;` تنهي التعليمة.

لاحظ أنه لا يوجد `#include` ولا `import`: الأدوات الأساسية مثل `println!` متاحة دائمًا.

## الطباعة المنسقة بالأقواس `{}`

بدل محددات مثل `%d` في C، تستخدم Rust الأقواس `{}`:

```rust run
fn main() {
    let name = "سارة";
    let age = 20;
    println!("الاسم: {}، العمر: {}", name, age);
    println!("الاسم مرة أخرى: {name}");          // اسم المتغير داخل القوسين مباشرة
    println!("{0} و {1} و {0}", "أ", "ب");       // بالترتيب
    println!("السعر: {:.2}", 12.5);               // خانتان عشريتان
    println!("[{:>6}] [{:<6}] [{:^6}]", 42, 42, 42); // محاذاة في عرض 6
    println!("{{ أقواس حقيقية }}");
}
```

```text output
الاسم: سارة، العمر: 20
الاسم مرة أخرى: سارة
أ و ب و أ
السعر: 12.50
[    42] [42    ] [  42  ]
{ أقواس حقيقية }
```

| الكتابة | معناها |
|---|---|
| `{}` | القيمة بشكلها العادي |
| `{name}` | قيمة المتغير `name` |
| `{:.2}` | عدد عشري بخانتين |
| `{:>6}` / `{:<6}` / `{:^6}` | محاذاة يمين / يسار / وسط في عرض 6 |
| `{:?}` | شكل «التصحيح» (Debug) للقيمة |
| `{{` و`}}` | قوس حقيقي |

## الطباعة للتصحيح: `{:?}`

بعض القيم، مثل القوائم، لا تُطبع بـ `{}` بل بـ `{:?}`:

```rust run
fn main() {
    let nums = [1, 2, 3];
    let pair = (10, "عشرة");
    println!("{:?}", nums);
    println!("{:?}", pair);
    println!("{:#?}", pair);   // شكل منسق على عدة أسطر
}
```

```text output
[1, 2, 3]
(10, "عشرة")
(
    10,
    "عشرة",
)
```

## ماكرو مفيدة أخرى

```rust run
fn main() {
    print!("بدون ");
    print!("سطر جديد\n");
    let msg = format!("{} + {} = {}", 2, 3, 2 + 3);   // مثل println لكنها ترجع نصًا
    println!("{msg}");
    eprintln!("هذا يذهب إلى مجرى الأخطاء stderr");
}
```

```text output
بدون سطر جديد
2 + 3 = 5
هذا يذهب إلى مجرى الأخطاء stderr
```

## التعليقات

```rust run
// تعليق من سطر واحد

/* تعليق
   من عدة أسطر */

/// تعليق توثيق: يظهر عند وقوف الماوس على الدالة في المحرر
fn main() {
    println!("التعليقات لا تظهر"); // تعليق في آخر السطر
}
```

```text output
التعليقات لا تظهر
```

التعليق الذي يبدأ بـ `///` تعليق **توثيق**، يقرؤه rust-analyzer ويعرضه لك عندما تقف بالماوس على اسم الدالة.

## رسائل المترجم صديقتك

إذا نسيت علامة التعجب:

<!-- compile-error -->
```rust
fn main() {
    println("Hi");
}
```

```text
error[E0423]: expected function, found macro `println`
help: use `!` to invoke the macro
  |     println!("Hi");
  |            +
```

المترجم لا يقول فقط «خطأ»، بل يشرح ويقترح الحل بالضبط! اعتد على **قراءة الرسالة كاملة**. وفي الـ IDE تظهر هذه الأخطاء أثناء الكتابة بخط أحمر متموج، وفي نافذة **Error List** (قائمة الأخطاء).

## تمارين

### التمرين 1

اطبع بطاقة منتج باستخدام `{}` و`{:.2}`:

```rust exercise
fn main() {
    let product = "قلم";
    let price = 7.5;
    let qty = 4;
    // المنتج: قلم
    // الإجمالي: 30.00
}
```

```rust solution
fn main() {
    let product = "قلم";
    let price = 7.5;
    let qty = 4;
    println!("المنتج: {product}");
    println!("الإجمالي: {:.2}", price * qty as f64);
}
```

```text output
المنتج: قلم
الإجمالي: 30.00
```

(الكتابة `qty as f64` تحول العدد الصحيح إلى عشري؛ سنشرحها في الدرس القادم.)

### التمرين 2

اطبع جدولًا صغيرًا بأعمدة محاذاة: الاسم في عرض 8 لليسار، والدرجة في عرض 4 لليمين:

```rust exercise
fn main() {
    // Ali       90
    // Mona      85
}
```

```rust solution
fn main() {
    println!("{:<8}{:>4}", "Ali", 90);
    println!("{:<8}{:>4}", "Mona", 85);
}
```

```text output
Ali       90
Mona      85
```

## الخلاصة

- `fn main()` بداية البرنامج، و`println!` ماكرو للطباعة.
- `{}` و`{name}` و`{:.2}` و`{:?}` للتنسيق.
- `format!` تبني نصًا، و`eprintln!` تكتب في مجرى الأخطاء.
- اقرأ رسائل المترجم؛ فهي تقترح الحل غالبًا.

# الدرس 2: برنامجك الأول سطرًا سطرًا

في الدرس السابق شغّلنا برنامجًا صغيرًا يطبع رسالة. اليوم سنفهم كل كلمة فيه، ونتعلم كيف نكتب تعليقات، وكيف نطبع العربية بشكل صحيح.

## البرنامج كاملًا

```cpp run
#include <iostream>

int main()
{
    std::cout << "Hello, World!" << std::endl;
    return 0;
}
```

```text output
Hello, World!
```

## الشرح سطرًا سطرًا

### `#include <iostream>`

هذا السطر يقول للمترجم: «أحضر لي مكتبة **iostream**» (اختصار input/output stream، أي تدفق الإدخال والإخراج). هذه المكتبة فيها الأدوات التي نطبع بها على الشاشة ونقرأ بها من لوحة المفاتيح.

> **تشبيه:** المكتبة مثل صندوق عُدّة. لن تستطيع استخدام المفك قبل أن تفتح الصندوق. `#include` هو فتح الصندوق.

### `int main()`

هذه هي **الدالة الرئيسية** (main function). كل برنامج C++ يبدأ التنفيذ من `main`، ولا بد أن تكون موجودة مرة واحدة فقط في البرنامج كله.

- `int` تعني أن الدالة ترجع عددًا صحيحًا عند انتهائها.
- الأقواس `()` تعني أنها دالة. سنفهم الدوال جيدًا في درس لاحق.

### الأقواس المعقوصة `{ }`

كل ما بين `{` و`}` هو **جسم** الدالة، أي التعليمات التي ستُنفذ بالترتيب من أعلى إلى أسفل.

### `std::cout << "Hello, World!" << std::endl;`

- `std::cout` (تُنطق «سي-آوت») هي **الشاشة** أو مخرج الكونسول.
- `<<` عامل الإخراج. تخيّله سهمًا يدفع البيانات نحو الشاشة.
- `"Hello, World!"` نص (string) بين علامتي تنصيص.
- `std::endl` تعني «انزل سطرًا جديدًا» (end line).
- `;` الفاصلة المنقوطة تنهي **التعليمة**، مثل النقطة في آخر الجملة العربية.

و`std::` معناها أن `cout` تنتمي إلى **فضاء الأسماء القياسي** `std` (standard). سنشرح فضاءات الأسماء لاحقًا، والمهم الآن أن كل أدوات المكتبة القياسية تبدأ بـ `std::`.

### `return 0;`

ينهي الدالة `main` ويُرجع القيمة `0` لنظام التشغيل، ومعناها «انتهى البرنامج بنجاح».

## الطباعة على عدة أسطر

يمكنك ربط عدة أجزاء بعامل `<<`، واستخدام `"\n"` للنزول سطرًا بدل `std::endl`:

```cpp run
#include <iostream>

int main()
{
    std::cout << "السطر الأول\n";
    std::cout << "السطر الثاني\n";
    std::cout << "العمر: " << 20 << " سنة" << "\n";
    std::cout << "عمود1\tعمود2\n";
    std::cout << "قال: \"مرحبًا\"\n";
    return 0;
}
```

```text output
السطر الأول
السطر الثاني
العمر: 20 سنة
عمود1	عمود2
قال: "مرحبًا"
```

هذه رموز خاصة تبدأ بالشرطة المائلة العكسية `\` وتسمى **رموز الهروب** (escape sequences):

| الرمز | معناه |
|---|---|
| `\n` | سطر جديد |
| `\t` | مسافة جدولة (Tab) |
| `\"` | علامة تنصيص داخل النص |
| `\\` | شرطة مائلة عكسية واحدة |

> **ما الفرق بين `"\n"` و`std::endl`؟** كلاهما ينزل سطرًا، لكن `std::endl` يُفرّغ أيضًا ذاكرة الإخراج المؤقتة (flush) فورًا، وهذا أبطأ قليلًا. المحترفون يستخدمون `"\n"` غالبًا، وسنستخدم الاثنين في الدورة.

## التعليقات (Comments)

التعليق كلام تكتبه لنفسك أو لزملائك، والمترجم **يتجاهله** تمامًا:

```cpp run
#include <iostream>

// هذا تعليق من سطر واحد

/*
   وهذا تعليق
   من عدة أسطر
*/

int main()
{
    std::cout << "التعليقات لا تظهر في الناتج\n"; // تعليق في آخر السطر
    // std::cout << "هذا السطر معطل ولن يُنفذ\n";
    return 0;
}
```

```text output
التعليقات لا تظهر في الناتج
```

> **نصيحة:** اكتب التعليق ليشرح **لماذا** كتبت الكود بهذه الطريقة، لا **ماذا** يفعل كل سطر بالتفصيل.

## ماذا عن `using namespace std;`؟

ستجد في كثير من الكتب هذا السطر:

```cpp
using namespace std;
```

وهو يسمح لك بكتابة `cout` بدل `std::cout`. هذا مريح في البرامج الصغيرة، لكنه في المشاريع الكبيرة قد يسبب تعارضًا في الأسماء. في هذه الدورة سنكتب `std::` صراحة في الغالب، لأنها عادة جيدة.

## طباعة العربية في الكونسول

داخل الـ IDE (نافذة **Output**) تظهر العربية بشكل صحيح دائمًا، لأن الـ IDE تقرأ ناتج البرنامج بترميز **UTF-8**، وملفات الكود تُحفظ بنفس الترميز.

لكن إذا شغّلت ملف `.exe` بنفسك في نافذة **cmd** القديمة، فقد تظهر الحروف العربية رموزًا غريبة مثل `ظ…ط±ط­ط¨ط§`. السبب أن الكونسول في ويندوز يستخدم ترميزًا قديمًا افتراضيًا. الحل أن نطلب من ويندوز استخدام UTF-8:

```cpp run
#include <iostream>
#ifdef _WIN32
#include <windows.h>
#endif

int main()
{
#ifdef _WIN32
    SetConsoleOutputCP(CP_UTF8); // اجعل الكونسول يعرض UTF-8
#endif
    std::cout << "السلام عليكم، العربية تظهر صحيحة الآن\n";
    return 0;
}
```

```text output
السلام عليكم، العربية تظهر صحيحة الآن
```

- `SetConsoleOutputCP(CP_UTF8)` دالة من ويندوز في الملف `<windows.h>`.
- `#ifdef _WIN32` معناها: «نفّذ هذا الجزء فقط إذا كنا نترجم على ويندوز»، حتى يعمل الكود أيضًا على لينكس وماك.

في بقية الدورة لن نكرر هذه الأسطر لكي تبقى الأمثلة قصيرة، لأن الـ IDE تعرض العربية دون مشكلة. أضفها أنت إذا أردت تشغيل برنامجك خارج الـ IDE.

> **ملحوظة:** اتجاه النص العربي في الكونسول قد يظهر من اليسار لليمين أحيانًا، وهذا يرجع لطريقة عرض الشاشة وليس خطأ في برنامجك.

## أخطاء شائعة

### نسيان `std::`

<!-- compile-error -->
```cpp
#include <iostream>
int main()
{
    cout << "Hello";
    return 0;
}
```

```text
main.cpp:4:5: error: 'cout' was not declared in this scope; did you mean 'std::cout'?
```

**المعنى:** «لم يُعرَّف `cout` في هذا النطاق، هل تقصد `std::cout`؟». المترجم يقترح عليك الحل بنفسه! أضف `std::` قبل `cout`.

### نسيان `#include <iostream>`

<!-- compile-error -->
```cpp
int main()
{
    std::cout << "Hello";
    return 0;
}
```

```text
main.cpp:3:10: error: 'cout' is not a member of 'std'
```

**المعنى:** «`cout` ليست عضوًا في `std`». هي في الحقيقة موجودة، لكنك لم تفتح الصندوق الذي يحتويها. أضف `#include <iostream>` في أول الملف.

### أخطاء أخرى سريعة

- كتابة `Main` أو `MAIN` بدل `main`: لغة C++ **حساسة لحالة الأحرف**، فـ `Main` و`main` اسمان مختلفان.
- نسيان إغلاق علامة التنصيص `"` أو القوس `}`.
- استخدام علامة تنصيص عربية أو ذكية مثل `“` بدل `"` عند النسخ من برنامج Word.

## تمارين

### التمرين 1

اطبع البطاقة التالية تمامًا كما هي، باستخدام `\t` بين الاسم والقيمة:

```cpp exercise
#include <iostream>

int main()
{
    // الناتج المطلوب:
    // الاسم:	سارة
    // المادة:	C++
    // الدرجة:	95
    return 0;
}
```

```cpp solution
#include <iostream>

int main()
{
    std::cout << "الاسم:\tسارة\n";
    std::cout << "المادة:\tC++\n";
    std::cout << "الدرجة:\t" << 95 << "\n";
    return 0;
}
```

```text output
الاسم:	سارة
المادة:	C++
الدرجة:	95
```

## الخلاصة

- `#include` يحضر المكتبات، و`main` نقطة البداية.
- `std::cout <<` للطباعة، و`"\n"` أو `std::endl` لسطر جديد.
- التعليقات `//` و`/* */` يتجاهلها المترجم.
- `SetConsoleOutputCP(CP_UTF8)` لعرض العربية في كونسول ويندوز خارج الـ IDE.

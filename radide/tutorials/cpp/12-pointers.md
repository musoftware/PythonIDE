# الدرس 12: المؤشرات والذاكرة (بهدوء وخطوة بخطوة)

المؤشرات (Pointers) هي الموضوع الذي يخيف كثيرًا من المبتدئين، لكنه في الحقيقة فكرة بسيطة جدًا إذا فهمنا كيف تعمل الذاكرة. خذ نفسًا عميقًا، ولنبدأ بهدوء.

## الذاكرة: شارع طويل من البيوت

> **تشبيه:** تخيّل ذاكرة الكمبيوتر **شارعًا طويلًا جدًا** من البيوت. كل بيت له **عنوان** (رقم)، وفي كل بيت تسكن **قيمة**. عندما تكتب `int age = 20;` فإن البرنامج يحجز بيتًا، ويكتب عليه اسم `age`، ويضع فيه القيمة 20.

- **القيمة**: ما يسكن داخل البيت (20).
- **العنوان**: رقم البيت في الشارع.
- **المؤشر**: ورقة مكتوب عليها **عنوان** بيت. لا تحتوي القيمة نفسها، بل تدلك على مكانها.

## عامل العنوان `&` وعامل المحتوى `*`

```cpp run
#include <iostream>

int main()
{
    int age = 20;
    int* p = &age;   // p مؤشر يحمل عنوان age

    std::cout << "قيمة age: " << age << "\n";
    std::cout << "قيمة age عن طريق المؤشر: " << *p << "\n";

    *p = 35;         // غيّر القيمة الموجودة في العنوان
    std::cout << "age الآن: " << age << "\n";

    std::cout << std::boolalpha;
    std::cout << "p يشير إلى age؟ " << (p == &age) << "\n";
    return 0;
}
```

```text output
قيمة age: 20
قيمة age عن طريق المؤشر: 20
age الآن: 35
p يشير إلى age؟ true
```

لنقرأ الرموز:

| الكود | يُقرأ | المعنى |
|---|---|---|
| `int* p` | p مؤشر إلى int | متغير يحمل عنوان متغير من نوع `int` |
| `&age` | عنوان age | رقم البيت الذي تسكن فيه `age` |
| `*p` | المحتوى عند p | القيمة الموجودة في العنوان الذي يحمله `p` |

> **لاحظ:** الرمز `&` في **التعريف** (`int& r`) يعني مرجعًا كما تعلمنا، وفي **التعبير** (`&age`) يعني «عنوان». والرمز `*` في التعريف (`int* p`) يعني مؤشرًا، وفي التعبير (`*p`) يعني «المحتوى». نفس الرمز، ومعنى مختلف حسب المكان.

لو طبعت العنوان نفسه `std::cout << p;` سترى رقمًا سداسي عشريًا مثل `0x61fe14`، ويختلف في كل تشغيل.

## المؤشر الفارغ `nullptr`

المؤشر الذي لا يشير إلى أي شيء يجب أن يحمل القيمة `nullptr`، وافحصه دائمًا قبل استخدامه:

```cpp run
#include <iostream>

void printValue(const int* p)
{
    if (p == nullptr)
    {
        std::cout << "لا توجد قيمة\n";
        return;
    }
    std::cout << "القيمة: " << *p << "\n";
}

int main()
{
    int x = 7;
    int* empty = nullptr;
    printValue(&x);
    printValue(empty);
    return 0;
}
```

```text output
القيمة: 7
لا توجد قيمة
```

`const int* p` تعني «مؤشر إلى `int` لا يمكن تعديل قيمته من خلاله»، مثل `const&` تمامًا.

## المؤشرات والمصفوفات

اسم المصفوفة التقليدية يتحول تلقائيًا إلى مؤشر لأول عنصر فيها، ويمكن التحرك بالمؤشر عنصرًا عنصرًا:

```cpp run
#include <iostream>

int main()
{
    int nums[4] = {10, 20, 30, 40};
    int* p = nums;               // يشير إلى nums[0]

    std::cout << *p << "\n";       // 10
    std::cout << *(p + 2) << "\n"; // 30 = nums[2]
    p++;                         // انتقل للعنصر التالي
    std::cout << *p << "\n";       // 20

    for (int* q = nums; q != nums + 4; q++)
        std::cout << *q << " ";
    std::cout << "\n";
    return 0;
}
```

```text output
10
30
20
10 20 30 40
```

هذا يسمى **حساب المؤشرات** (pointer arithmetic). من المفيد أن تفهمه، لكن في C++ الحديثة نادرًا ما تحتاجه بفضل `std::vector` والحلقة على المدى.

## الذاكرة الديناميكية: `new` و`delete`

المتغيرات العادية تعيش في منطقة تسمى **المكدّس** (Stack) وتُحذف تلقائيًا عند نهاية النطاق. لكن أحيانًا نحتاج ذاكرة تعيش أطول، أو حجمها غير معروف مسبقًا، فنطلبها من منطقة تسمى **الكومة** (Heap) باستخدام `new`:

> **تشبيه:** المكدّس مثل غرفة في فندق تُخلى تلقائيًا عند انتهاء الإقامة. أما الكومة فمثل **مخزن مستأجر**: يبقى لك حتى **تعيد مفتاحه بنفسك** بـ `delete`. لو نسيت، تبقى تدفع الإيجار للأبد!

```cpp run
#include <iostream>

int main()
{
    int* score = new int(90);    // احجز int في الكومة بقيمة 90
    std::cout << "الدرجة: " << *score << "\n";
    *score += 5;
    std::cout << "بعد الزيادة: " << *score << "\n";
    delete score;                // أعد الذاكرة
    score = nullptr;             // عادة جيدة بعد delete

    int n = 5;
    int* arr = new int[n];       // مصفوفة حجمها معروف وقت التشغيل
    for (int i = 0; i < n; i++)
        arr[i] = i * i;
    for (int i = 0; i < n; i++)
        std::cout << arr[i] << " ";
    std::cout << "\n";
    delete[] arr;                // المصفوفة تُحذف بـ delete[]
    return 0;
}
```

```text output
الدرجة: 90
بعد الزيادة: 95
0 1 4 9 16
```

القواعد الذهبية:

1. كل `new` يقابله `delete` **واحد** فقط.
2. كل `new[]` يقابله `delete[]`.
3. لا تستخدم المؤشر بعد `delete`.

## لماذا يخاف الناس من `new` و`delete`؟

لأن الأخطاء هنا لا يكتشفها المترجم، وتظهر أثناء التشغيل:

| الخطأ | ماذا يحدث |
|---|---|
| **تسرّب الذاكرة** (memory leak): نسيت `delete` | البرنامج يستهلك ذاكرة تزداد باستمرار |
| **المؤشر المعلّق** (dangling pointer): استخدمت المؤشر بعد `delete` | قيم عشوائية أو انهيار |
| **الحذف المزدوج** (double delete) | انهيار البرنامج |
| استخدام `nullptr` بـ `*p` | انهيار فوري (Segmentation fault / Access violation) |

لهذا السبب، في C++ الحديثة **نادرًا** ما نكتب `new` و`delete` بأنفسنا. بدلًا منهما نستخدم:

- `std::vector` و`std::string` للمجموعات والنصوص (تدير ذاكرتها بنفسها).
- **المؤشرات الذكية** (smart pointers)، وهي موضوع الدرس القادم.

لكن من المهم أن تفهم `new` و`delete` لأنك ستراهما في الكود القديم، ولأن المؤشرات الذكية مبنية عليهما.

## المؤشر أم المرجع؟

| | المرجع `int&` | المؤشر `int*` |
|---|---|---|
| يمكن أن يكون فارغًا؟ | لا | نعم (`nullptr`) |
| يمكن تغيير ما يشير إليه؟ | لا، يرتبط مرة واحدة | نعم |
| طريقة الاستخدام | مثل المتغير العادي | يحتاج `*` |

**القاعدة:** استخدم المرجع كلما أمكن، والمؤشر فقط عندما تحتاج «لا شيء» (`nullptr`) أو تغيير الهدف.

## أخطاء شائعة

### نسيان `&` عند أخذ العنوان

<!-- compile-error -->
```cpp
int main()
{
    int x = 5;
    int* p = x;
    return *p;
}
```

```text
main.cpp:4:14: error: invalid conversion from 'int' to 'int*' [-fpermissive]
```

**المعنى:** «تحويل غير صالح من `int` إلى `int*`». المؤشر يحمل **عنوانًا** وليس قيمة. اكتب `int* p = &x;`.

### طباعة المؤشر بدل القيمة

`std::cout << p;` تطبع العنوان (مثل `0x61fe14`)، أما `std::cout << *p;` فتطبع القيمة. إذا رأيت أرقامًا غريبة تبدأ بـ `0x` فغالبًا نسيت `*`.

### إرجاع عنوان متغير محلي

<!-- compile-error -->
```cpp
int* makeNumber()
{
    int n = 42;
    return &n;
}
int main() { return *makeNumber(); }
```

```text
main.cpp:4:12: warning: address of local variable 'n' returned [-Wreturn-local-addr]
```

**المعنى:** «تُرجع عنوان متغير محلي». المتغير `n` يُحذف عند خروج الدالة، فيصبح المؤشر معلّقًا يشير إلى بيت تم هدمه! أرجع القيمة نفسها (`int`) بدلًا من عنوانها.

## تمارين

### التمرين 1

اكتب دالة `void doubleIt(int* p)` تضاعف القيمة التي يشير إليها المؤشر (إذا لم يكن `nullptr`).

```cpp exercise
#include <iostream>

// void doubleIt(int* p)

int main()
{
    int x = 21;
    // doubleIt(&x);
    std::cout << x << "\n";
    return 0;
}
```

```cpp solution
#include <iostream>

void doubleIt(int* p)
{
    if (p != nullptr)
        *p *= 2;
}

int main()
{
    int x = 21;
    doubleIt(&x);
    doubleIt(nullptr);   // آمن: لا يفعل شيئًا
    std::cout << x << "\n";
    return 0;
}
```

```text output
42
```

### التمرين 2

اقرأ عددًا `n`، ثم احجز مصفوفة `double` بحجم `n` باستخدام `new[]`، واقرأ فيها `n` قيمة، واطبع مجموعها، ولا تنسَ `delete[]`.

```cpp exercise
#include <iostream>

int main()
{
    int n = 0;
    std::cin >> n;
    // double* values = new double[n];
    return 0;
}
```

```cpp solution
#include <iostream>

int main()
{
    int n = 0;
    std::cin >> n;
    double* values = new double[n];
    for (int i = 0; i < n; i++)
        std::cin >> values[i];

    double sum = 0;
    for (int i = 0; i < n; i++)
        sum += values[i];
    std::cout << "المجموع: " << sum << "\n";

    delete[] values;
    return 0;
}
```

```text input
3
1.5 2.5 6
```

```text output
المجموع: 10
```

ملحوظة: في برنامج حقيقي استخدم `std::vector<double> values(n);` بدلًا من `new[]`، فهو أسهل وأأمن.

### التمرين 3

بدون تشغيل البرنامج، توقّع ماذا يطبع، ثم تحقق بالتشغيل:

```cpp exercise
#include <iostream>

int main()
{
    int a = 1, b = 2;
    int* p = &a;
    *p = 10;
    p = &b;
    *p += 5;
    std::cout << a << " " << b << "\n";
    return 0;
}
```

```cpp solution
#include <iostream>

int main()
{
    int a = 1, b = 2;
    int* p = &a;   // p يشير إلى a
    *p = 10;       // a = 10
    p = &b;        // الآن p يشير إلى b
    *p += 5;       // b = 7
    std::cout << a << " " << b << "\n";
    return 0;
}
```

```text output
10 7
```

## الخلاصة

- الذاكرة شارع من البيوت، والمؤشر ورقة عليها عنوان بيت.
- `&x` عنوان `x`، و`*p` المحتوى عند `p`، و`nullptr` لمؤشر لا يشير إلى شيء.
- `new`/`delete` و`new[]`/`delete[]` لحجز الذاكرة يدويًا، مع مخاطر التسرب والتعليق.
- في C++ الحديثة: `std::vector` والمؤشرات الذكية بدل الإدارة اليدوية.

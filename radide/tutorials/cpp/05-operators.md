# الدرس 5: العمليات الحسابية والمنطقية (العوامل)

**العامل** (Operator) رمز يقوم بعملية على قيمة أو أكثر، مثل `+` و`*`. في هذا الدرس سنتعرف على العوامل الحسابية، وعوامل المقارنة، والعوامل المنطقية.

## العوامل الحسابية

| العامل | العملية | مثال | الناتج |
|---|---|---|---|
| `+` | جمع | `7 + 2` | `9` |
| `-` | طرح | `7 - 2` | `5` |
| `*` | ضرب | `7 * 2` | `14` |
| `/` | قسمة | `7 / 2` | `3` (!) |
| `%` | باقي القسمة | `7 % 2` | `1` |

### القسمة الصحيحة: أشهر مفاجأة للمبتدئين

عندما تقسم عددًا صحيحًا `int` على عدد صحيح، يكون الناتج **عددًا صحيحًا** ويُحذف الكسر (لا يُقرَّب):

```cpp run
#include <iostream>

int main()
{
    std::cout << "7 / 2   = " << 7 / 2 << "\n";
    std::cout << "7.0 / 2 = " << 7.0 / 2 << "\n";
    std::cout << "7 % 2   = " << 7 % 2 << "\n";

    int total = 17, people = 5;
    std::cout << "نصيب كل شخص: " << total / people << "\n";
    std::cout << "المتبقي: " << total % people << "\n";
    std::cout << "بالكسور: " << static_cast<double>(total) / people << "\n";
    return 0;
}
```

```text output
7 / 2   = 3
7.0 / 2 = 3.5
7 % 2   = 1
نصيب كل شخص: 3
المتبقي: 2
بالكسور: 3.4
```

> **تشبيه:** لديك 17 قطعة حلوى و5 أطفال. كل طفل يأخذ 3 قطع (`17 / 5`) ويتبقى معك قطعتان (`17 % 5`).

- `static_cast<double>(total)` تحوّل القيمة إلى `double` مؤقتًا، فتصبح القسمة عشرية. هذه هي طريقة **التحويل بين الأنواع** (casting) في C++ الحديثة.
- عامل الباقي `%` يعمل مع الأعداد الصحيحة فقط، وهو مفيد جدًا: مثلًا `n % 2 == 0` تعني أن `n` عدد زوجي.

### ترتيب العمليات

مثل الرياضيات تمامًا: الضرب والقسمة والباقي قبل الجمع والطرح، والأقواس أولًا:

```cpp
int a = 2 + 3 * 4;     // 14
int b = (2 + 3) * 4;   // 20
```

> **نصيحة:** إذا شككت في الترتيب، استخدم الأقواس. الوضوح أهم من الاختصار.

## عوامل الإسناد المختصرة والزيادة

| المختصر | يساوي |
|---|---|
| `x += 5` | `x = x + 5` |
| `x -= 5` | `x = x - 5` |
| `x *= 5` | `x = x * 5` |
| `x /= 5` | `x = x / 5` |
| `x++` أو `++x` | `x = x + 1` |
| `x--` أو `--x` | `x = x - 1` |

```cpp run
#include <iostream>

int main()
{
    int balance = 100;
    balance += 50;   // إيداع
    balance -= 30;   // سحب
    balance *= 2;    // مضاعفة
    std::cout << "الرصيد: " << balance << "\n";

    int counter = 0;
    counter++;
    counter++;
    ++counter;
    std::cout << "العداد: " << counter << "\n";
    return 0;
}
```

```text output
الرصيد: 240
العداد: 3
```

الفرق بين `x++` و`++x` يظهر فقط إذا استخدمت الناتج في نفس التعليمة؛ `++x` يزيد ثم يعطي القيمة، و`x++` يعطي القيمة القديمة ثم يزيد. للتبسيط: استخدم الزيادة في تعليمة مستقلة.

## عوامل المقارنة

تقارن بين قيمتين والناتج دائمًا `bool` (أي `true` أو `false`):

| العامل | المعنى |
|---|---|
| `==` | يساوي |
| `!=` | لا يساوي |
| `<` | أصغر من |
| `>` | أكبر من |
| `<=` | أصغر من أو يساوي |
| `>=` | أكبر من أو يساوي |

> **انتبه جدًا:** `==` (علامتان) للمقارنة، و`=` (علامة واحدة) للإسناد. الخلط بينهما من أخطر الأخطاء.

## العوامل المنطقية

تربط بين شروط:

| العامل | الاسم | يكون `true` عندما |
|---|---|---|
| `&&` | و (AND) | الشرطان صحيحان معًا |
| `\|\|` | أو (OR) | أحد الشرطين على الأقل صحيح |
| `!` | ليس (NOT) | الشرط خاطئ |

```cpp run
#include <iostream>

int main()
{
    int age = 20;
    double gpa = 3.4;
    bool hasId = true;

    std::cout << std::boolalpha;
    std::cout << "age >= 18        : " << (age >= 18) << "\n";
    std::cout << "age == 21        : " << (age == 21) << "\n";
    std::cout << "age >= 18 && hasId: " << (age >= 18 && hasId) << "\n";
    std::cout << "gpa > 3.5 || age < 25: " << (gpa > 3.5 || age < 25) << "\n";
    std::cout << "!hasId           : " << (!hasId) << "\n";
    std::cout << "20 is even       : " << (age % 2 == 0) << "\n";
    return 0;
}
```

```text output
age >= 18        : true
age == 21        : false
age >= 18 && hasId: true
gpa > 3.5 || age < 25: true
!hasId           : false
20 is even       : true
```

لاحظ الأقواس حول كل مقارنة داخل `std::cout`؛ بدونها يخلط المترجم بين `<<` و`<`.

> **تشبيه:** `&&` مثل باب بقفلين: يحتاج المفتاحين معًا. `||` مثل بابين: يكفي أن يُفتح أحدهما.

## مكتبة الرياضيات `<cmath>`

```cpp run
#include <cmath>
#include <iostream>

int main()
{
    std::cout << "sqrt(16)   = " << std::sqrt(16.0) << "\n";
    std::cout << "pow(2, 10) = " << std::pow(2.0, 10.0) << "\n";
    std::cout << "abs(-7)    = " << std::abs(-7) << "\n";
    std::cout << "round(2.6) = " << std::round(2.6) << "\n";
    std::cout << "floor(2.6) = " << std::floor(2.6) << "\n";
    std::cout << "ceil(2.1)  = " << std::ceil(2.1) << "\n";
    return 0;
}
```

```text output
sqrt(16)   = 4
pow(2, 10) = 1024
abs(-7)    = 7
round(2.6) = 3
floor(2.6) = 2
ceil(2.1)  = 3
```

## أخطاء شائعة

### القسمة على صفر

القسمة الصحيحة على صفر (`5 / 0` مع `int`) تجعل البرنامج **ينهار** أثناء التشغيل. المترجم قد يحذرك إذا رأى الصفر مكتوبًا صراحة:

<!-- compile-error -->
```cpp
#include <iostream>
int main()
{
    int a = 5;
    std::cout << a / 0;
    return 0;
}
```

```text
main.cpp:5:20: warning: division by zero [-Wdiv-by-zero]
```

**المعنى:** «قسمة على صفر». تأكد دائمًا أن المقسوم عليه ليس صفرًا قبل القسمة.

### نسيان أن `int / int` يحذف الكسر

`double avg = (90 + 85) / 2;` تعطي `87` وليس `87.5`، لأن القسمة تمت بين أعداد صحيحة **قبل** الوضع في `double`. الحل: `/ 2.0`.

### تجاوز حدود النوع (Overflow)

`int` لا يتسع لأكثر من حوالي 2.1 مليار. إذا ضربت `100000 * 100000` بأعداد `int` ستحصل على رقم غريب. استخدم `long long` للأعداد الكبيرة.

### التمرين 3

احسب طول وتر مثلث قائم الزاوية ضلعاه 3 و4 باستخدام `std::sqrt` (فيثاغورس: c = جذر(a² + b²)).

```cpp exercise
#include <cmath>
#include <iostream>

int main()
{
    double a = 3, b = 4;
    // احسب c واطبعه
    return 0;
}
```

```cpp solution
#include <cmath>
#include <iostream>

int main()
{
    double a = 3, b = 4;
    double c = std::sqrt(a * a + b * b);
    std::cout << "الوتر = " << c << "\n";
    return 0;
}
```

```text output
الوتر = 5
```

## الخلاصة

- `+ - * / %`، وانتبه أن `int / int` يحذف الكسر.
- `static_cast<double>(x)` للتحويل بين الأنواع.
- `+=` و`++` اختصارات مفيدة.
- المقارنة `== != < > <= >=` والمنطق `&& || !` تعطي `bool`.
- `<cmath>` فيها `sqrt` و`pow` و`round` وغيرها.

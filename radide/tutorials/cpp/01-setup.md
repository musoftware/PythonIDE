# الدرس 1: مرحبًا بك في C++ وتجهيز بيئة العمل

أهلًا بك في أول درس من دورة **C++** باللغة العربية! في هذه الدورة سنبدأ معًا من الصفر تمامًا، خطوة بخطوة، حتى نصل إلى بناء برنامج حقيقي بواجهة رسومية (نوافذ وأزرار) داخل هذه الـ IDE.

لا تحتاج إلى أي خبرة سابقة في البرمجة. كل ما تحتاجه هو الصبر، والتجربة بيدك.

## ما هي C++؟

**C++** لغة برمجة قوية وسريعة جدًا، ظهرت في الثمانينيات على يد العالم الدنماركي **بيارن ستروستروب** (Bjarne Stroustrup) كتطوير للغة **C**. وما زالت حتى اليوم من أهم لغات العالم، وتُستخدم في:

- الألعاب ومحركات الألعاب.
- أنظمة التشغيل والمتصفحات.
- البرامج التي تحتاج سرعة عالية مثل برامج تحرير الصور والفيديو.
- الأجهزة الصغيرة (السيارات، والأجهزة الطبية، والروبوتات).

في هذه الدورة سنتعلم **C++ الحديثة** (معيار C++17 وC++20)، أي الطريقة التي يكتب بها المحترفون اليوم: نصوص `std::string` بدل المصفوفات القديمة، و`std::vector` بدل إدارة الذاكرة يدويًا، والمؤشرات الذكية بدل `new` و`delete` قدر الإمكان.

## كيف يتحول الكود إلى برنامج؟

الكمبيوتر لا يفهم الكلمات الإنجليزية التي نكتبها، بل يفهم **لغة الآلة** فقط (أصفار وآحاد). لذلك نحتاج إلى **مترجم** (Compiler) يحوّل الكود الذي نكتبه إلى ملف تنفيذي (`.exe`).

> **تشبيه:** تخيّل أنك كتبت وصفة طبخ بالعربية، والطاهي لا يفهم إلا اليابانية. المترجم هو الشخص الذي يترجم الوصفة كاملة إلى اليابانية **مرة واحدة**، ثم يستطيع الطاهي تنفيذها بسرعة كلما أردت.

مراحل العمل دائمًا:

1. **الكتابة:** تكتب الكود في ملف ينتهي بـ `.cpp`.
2. **الترجمة (Compile):** المترجم يقرأ الملف، فإن وجد أخطاء أخبرك بها، وإن لم يجد أنشأ ملفًا تنفيذيًا.
3. **التشغيل (Run):** يعمل البرنامج ويُظهر النتيجة.

المترجم الذي تستخدمه الـ IDE هو **g++** من حزمة **MinGW-w64**، وهو مترجم مجاني ومشهور. تجده الـ IDE تلقائيًا في المجلد:

```text
%LOCALAPPDATA%\RADIDE\toolchains\mingw64\bin
```

إن لم يكن موجودًا، تعرض الـ IDE رسالة تشرح طريقة تثبيته (WinLibs أو MSYS2)، ويمكنها أيضًا استخدام Visual C++ إن كان Visual Studio مثبتًا عندك.

## ثلاث طرق لتجربة الكود في هذه الـ IDE

### 1) زر «جرّبه» في الدروس (الأسهل)

كل مثال في هذه الدروس عليه زر **«جرّبه»**. عند الضغط عليه تنشئ الـ IDE مشروعًا مؤقتًا، وتترجم الكود وتشغّله، وتعرض الناتج في نافذة **Output**. جرّب الآن مع المثال التالي:

```cpp run
#include <iostream>

int main()
{
    std::cout << "Hello, C++!" << std::endl;
    std::cout << "مرحبًا بك في عالم البرمجة" << std::endl;
    return 0;
}
```

الناتج:

```text output
Hello, C++!
مرحبًا بك في عالم البرمجة
```

لا تقلق إن لم تفهم كل سطر الآن، سنشرحه بالتفصيل في الدرس القادم.

### 2) مشروع C++ جديد (برنامج كونسول)

1. من قائمة **File** اختر **New Project**.
2. اختر اللغة **C++ (GUI Bridge, g++ / MSVC)** واكتب اسم المشروع.
3. أضف ملف كود (Module) واكتب فيه الدالة `main` كما في المثال أعلاه.
4. اضغط **F5** للتشغيل. ستبحث الـ IDE عن الملف الذي فيه `main` وتشغّله.

### 3) مشروع بواجهة رسومية (نوافذ وأزرار)

نفس الخطوات، لكنك ترسم النافذة (Form1) بالسحب والإفلات من صندوق الأدوات (Toolbox) كما في Visual Basic تمامًا، ثم تكتب الكود الذي يعمل عند الضغط على الأزرار. هذا ما سنتعلمه بالتفصيل في الدروس الأخيرة من الدورة.

## نافذة Output والأخطاء

عندما تشغّل البرنامج، تظهر أي رسالة من المترجم في نافذة **Output**. هناك نوعان من الرسائل:

| النوع | معناه | هل يعمل البرنامج؟ |
|---|---|---|
| `error` (خطأ) | المترجم لم يفهم الكود | لا |
| `warning` (تحذير) | الكود مفهوم لكنه مشكوك فيه | نعم، لكن انتبه! |

مثال: لو نسيت الفاصلة المنقوطة `;` في آخر السطر:

<!-- compile-error -->
```cpp
#include <iostream>
int main()
{
    std::cout << "Hello"
    return 0;
}
```

سيقول لك المترجم:

```text
main.cpp:4:25: error: expected ';' before 'return'
```

لنقرأ الرسالة معًا:

- `main.cpp` اسم الملف.
- `4:25` السطر 4، العمود 25 (مكان الخطأ تقريبًا).
- `error` نوع الرسالة: خطأ يمنع الترجمة.
- `expected ';' before 'return'` معناها: «كنت أنتظر فاصلة منقوطة قبل كلمة return».

> **نصيحة ذهبية:** اقرأ **أول** رسالة خطأ دائمًا وأصلحها أولًا. أحيانًا خطأ واحد يسبب عشر رسائل بعده، وتختفي كلها عند إصلاح الأول.

> **لو حصلت معاك رسائل كتير:** متخافش! الأخطاء جزء طبيعي من البرمجة، وحتى المحترفين يرونها كل يوم. المهم أن تتعلم قراءتها.

## مثال آخر: البرنامج يحسب

البرنامج لا يطبع النصوص فقط، بل يحسب أيضًا:

```cpp run
#include <iostream>

int main()
{
    std::cout << "2 + 3 = " << 2 + 3 << std::endl;
    std::cout << "عدد الساعات في الأسبوع: " << 7 * 24 << std::endl;
    return 0;
}
```

```text output
2 + 3 = 5
عدد الساعات في الأسبوع: 168
```

لاحظ أن ما بين علامتي التنصيص `"..."` يُطبع كما هو، أما `2 + 3` بدون علامات تنصيص فيُحسب أولًا ثم يُطبع ناتجه.

## تمارين

### التمرين 1

اكتب برنامجًا يطبع اسمك في سطر، ومدينتك في السطر التالي.

```cpp exercise
#include <iostream>

int main()
{
    // اطبع اسمك هنا

    // اطبع مدينتك هنا

    return 0;
}
```

```cpp solution
#include <iostream>

int main()
{
    std::cout << "اسمي: أحمد" << std::endl;
    std::cout << "مدينتي: القاهرة" << std::endl;
    return 0;
}
```

الناتج المتوقع (مع اسمك أنت ومدينتك):

```text output
اسمي: أحمد
مدينتي: القاهرة
```

### التمرين 2

اكتب برنامجًا يطبع عدد الدقائق في يوم كامل (24 ساعة × 60 دقيقة) بحيث يحسبها البرنامج بنفسه.

```cpp exercise
#include <iostream>

int main()
{
    // اطبع: عدد الدقائق في اليوم: ثم الناتج
    return 0;
}
```

```cpp solution
#include <iostream>

int main()
{
    std::cout << "عدد الدقائق في اليوم: " << 24 * 60 << std::endl;
    return 0;
}
```

```text output
عدد الدقائق في اليوم: 1440
```

## الخلاصة

- C++ لغة سريعة وقوية، وسنتعلم أسلوبها الحديث (C++17/20).
- المترجم g++ يحوّل ملف `.cpp` إلى برنامج `.exe`.
- زر **«جرّبه»** يشغّل أي مثال فورًا، وF5 يشغّل مشروعك.
- اقرأ أول رسالة خطأ وأصلحها أولًا.

في الدرس القادم سنفهم برنامجنا الأول سطرًا سطرًا.

# الدرس 13: معالج 8086 في المحاكي التعليمي

**في هذا الدرس ستتعلم:**

- معالج **8086** (1978): جدّ كل معالجات x86، ولماذا ما زالت الجامعات تبدأ به.
- مشروع **8086 Assembly (Emulator)** في RAD IDE ونافذة المحاكي: الشاشة والمسجلات والذاكرة والمكدس.
- مسجلات 16 بت، و**المقاطع** (Segments) والعنوان الفعلي.
- خدمات DOS عبر `int 21h`: طباعة نص وحرف وقراءة مفتاح.
- مكتبة `emu8086.inc`: `PRINT` و`PRINTN` و`PRINT_NUM` و`SCAN_NUM`.

## لماذا 8086؟

كل ما تعلمته عن x86-64 بدأ من 8086: نفس أسماء التعليمات (`mov` و`add` و`cmp` و`jmp` و`loop`...) ونفس فكرة المسجلات والأعلام والمكدس. لكن 8086 أبسط بكثير: **8 مسجلات عامة من 16 بت**، وذاكرة 1 ميغابايت، ولا يوجد نظام تشغيل يحمي الذاكرة. لهذا تحب كتب الجامعات ومقررات «تنظيم الحاسوب» أن تبدأ به.

ولأن ويندوز الحديث لا يشغّل برامج DOS ذات 16 بت، فإن RAD IDE فيها **محاكي 8086** خاص بها: معالج افتراضي كامل مكتوب في الـ IDE، يشغّل برنامجك تعليمة تعليمة ويعرض لك كل ما يحدث داخله.

## مشروع المحاكي

1. **File > New Project...** ثم **Assembly** ثم **8086 Assembly (Emulator)**.
2. سمّه `Hello8086` واضغط **OK**.
3. اضغط `F5`: تظهر نافذة **8086 Emulator** (محاكي 8086) **متوقفة عند أول تعليمة**؛ اضغط `F5` مرة أخرى لتكمل، أو `F11` لتنفذ تعليمة واحدة. أما `Ctrl+F5` فيشغّل البرنامج بأقصى سرعة بلا توقف.

في نافذة المحاكي:

- **الشاشة**: شاشة نصية 80 × 25 مثل شاشة DOS.
- **Registers / Flags** (المسجلات والأعلام): قيمة كل مسجل بالسادس عشر، وتتلون عندما تتغير.
- **Memory** (الذاكرة): البايتات حول أي عنوان تكتبه.
- **Stack** (المكدس) و**Variables** (المتغيرات) و**Listing** (القائمة: كل سطر وعنوانه وبايتاته).
- أزرار: **Run** (تشغيل) و**Pause** (إيقاف مؤقت) و**Step** (خطوة، `F11`) و**Step Over** (خطوة فوق، `F10`) و**Step Back** (خطوة إلى الخلف: ترجع التعليمة الأخيرة!) و**Reload** (إعادة التحميل)، ومنزلق سرعة التنفيذ (من خطوة في الثانية إلى أقصى سرعة).
- نوافذ الـ IDE المعتادة تعمل أيضًا: نقاط التوقف (`F9`) و**Locals** و**Watch** (اكتب `ax` أو `zf` أو `[bx]`).

> **نصيحة:** أفضل طريقة لفهم أي تعليمة: ضع المؤشر عليها، ونفّذها بـ `F11`، وانظر أي مسجل تغيّر لونه. وإذا فاتك شيء فاضغط «خطوة إلى الخلف».

## مسجلات 8086

| النوع | المسجلات |
|---|---|
| عامة (16 بت) | `AX` و`BX` و`CX` و`DX`، ولكل منها نصفان: `AH`/`AL` و`BH`/`BL` و`CH`/`CL` و`DH`/`DL` |
| مؤشرات وفهارس | `SI` و`DI` و`BP` و`SP` |
| مقاطع | `CS` (الكود) و`DS` (البيانات) و`SS` (المكدس) و`ES` (إضافي) |
| خاصة | `IP` (عنوان التعليمة التالية) و`FLAGS` |

لاحظ الشبه: `rax` في x64 ← `eax` ← `ax` ← `ah`/`al`. الـ `ax` هنا هو المسجل الكامل.

## المقاطع والعنوان الفعلي

بمسجل 16 بت تصل إلى 65536 بايتًا فقط، لكن 8086 يملك 1 ميغابايت. الحل: العنوان يتكون من جزأين **مقطع:إزاحة** (`segment:offset`)، والعنوان الفعلي:

```text
العنوان الفعلي = المقطع × 16 + الإزاحة
مثال: 0700h:0100h  ->  7000h + 0100h = 07100h
```

`mov al, [si]` تقرأ من `DS:SI`، و`push`/`pop` تعمل على `SS:SP`، والتعليمات تُجلب من `CS:IP`.

## برنامج COM: الأبسط

برنامج `.COM` كل شيء فيه في مقطع واحد، ويبدأ عند الإزاحة `100h` (أول 256 بايتًا يحجزها DOS لبيانات البرنامج)، لذلك نبدأ بـ `org 100h`. خدمة DOS رقم 9 (`ah = 09h`) تطبع نصًّا ينتهي بعلامة **`$`**، وعنوانه في `DX`:

```asm16 run
org 100h

    mov ah, 09h          ; خدمة DOS: اطبع نصًّا ينتهي بـ $
    lea dx, msg          ; DX = عنوان النص
    int 21h              ; نادِ DOS
    ret                  ; ارجع إلى DOS (نهاية البرنامج)

msg db 'Hello, 8086!$'
```

```text output
Hello, 8086!
```

- `int 21h` **مقاطعة** (Interrupt): تستدعي خدمة من DOS، ورقم الخدمة في `AH`.
- في صياغة هذا المحاكي (مثل MASM وTASM وemu8086) نكتب `lea dx, msg` بلا أقواس، و`msg` اسم المتغير مباشرة.

## خدمات DOS الأساسية

| AH | الخدمة | المدخلات / المخرجات |
|---|---|---|
| `01h` | اقرأ مفتاحًا مع إظهاره | `AL` = الحرف |
| `02h` | اطبع حرفًا | `DL` = الحرف |
| `09h` | اطبع نصًّا ينتهي بـ `$` | `DX` = العنوان |
| `4Ch` | أنهِ البرنامج | `AL` = رمز الخروج |

الحروف من A إلى Z بحلقة `loop` (العدّاد `CX`):

```asm16 run
org 100h

    mov cx, 26           ; 26 حرفًا
    mov dl, 'A'
next:
    mov ah, 02h          ; اطبع الحرف الذي في DL
    int 21h
    inc dl
    loop next            ; CX--، وكرر إذا لم يصبح صفرًا
    ret
```

```text output
ABCDEFGHIJKLMNOPQRSTUVWXYZ
```

## قراءة مفتاح

`ah = 01h` ينتظر مفتاحًا، ويطبعه، ويضعه في `AL`. الأرقام `13, 10` في النص هي CR وLF (سطر جديد):

```asm16 run
org 100h

    mov ah, 09h
    lea dx, ask
    int 21h

    mov ah, 01h          ; AL = المفتاح
    int 21h
    cmp al, 'y'
    je said_yes
    lea dx, no_msg
    jmp show
said_yes:
    lea dx, yes_msg
show:
    mov ah, 09h
    int 21h
    ret

ask     db 'Continue? (y/n) $'
yes_msg db 13, 10, 'You said yes.$'
no_msg  db 13, 10, 'You said no.$'
```

```text input
y
```

```text output
Continue? (y/n) y
You said yes.
```

عند التشغيل في المحاكي اضغط على الشاشة واكتب المفتاح.

## مكتبة `emu8086.inc`: طباعة الأعداد وقراءتها

طباعة عدد في 8086 تحتاج تحويله إلى خانات (قسمة متكررة على 10، كما فعلنا في الدرس 7). مكتبة `emu8086.inc` (يوفرها المحاكي) تفعل ذلك لك:

| الاسم | العمل |
|---|---|
| `PRINT 'نص'` / `PRINTN 'نص'` | اطبع نصًّا (وسطرًا جديدًا مع `PRINTN`) |
| `PUTC 'x'` | اطبع حرفًا |
| `CALL PRINT_NUM` | اطبع `AX` عددًا بإشارة |
| `CALL PRINT_NUM_UNS` | اطبع `AX` عددًا بلا إشارة |
| `CALL SCAN_NUM` | اقرأ عددًا من لوحة المفاتيح إلى `CX` |

الإجراءات تُضاف إلى برنامجك بسطور `DEFINE_...` بعد الكود:

```asm16 run
include 'emu8086.inc'
org 100h

    mov ax, 1234h
    PRINT 'AX = '
    call PRINT_NUM_UNS   ; 1234h = 4660
    PRINTN ''

    mov al, ah           ; AH = 12h
    mov ah, 0
    PRINT 'AH = '
    call PRINT_NUM       ; 12h = 18
    PRINTN ''

    PRINT 'Enter a number: '
    call SCAN_NUM        ; CX = العدد (ضغطة Enter تنزل سطرًا)
    mov ax, cx
    imul cx              ; DX:AX = CX * CX
    PRINT 'Its square is '
    call PRINT_NUM
    ret

DEFINE_PRINT_NUM
DEFINE_PRINT_NUM_UNS
DEFINE_SCAN_NUM
END
```

```text input
12
```

```text output
AX = 4660
AH = 18
Enter a number: 12
Its square is 144
```

## برنامج EXE بالمقاطع

البرامج الأكبر تفصل البيانات والكود والمكدس في مقاطع مختلفة. هذه الصياغة (`.model` و`.data` و`.code`) هي ما ستراه في أغلب الكتب:

```asm16 run
.model small
.stack 100h
.data
    msg  db 'Sum of the array: $'
    nums db 3, 5, 7, 9
.code
main proc
    mov ax, @data        ; DS = مقطع البيانات
    mov ds, ax

    mov ah, 09h
    lea dx, msg
    int 21h

    mov si, offset nums
    mov cx, 4
    xor bx, bx
sum:
    mov al, [si]         ; DS:SI
    cbw                  ; AL -> AX بإشارة
    add bx, ax
    inc si
    loop sum

    mov ax, bx           ; 24: خانتان
    mov dl, 10
    div dl               ; AL = 2، AH = 4
    mov bh, ah
    mov dl, al
    add dl, '0'
    mov ah, 02h
    int 21h
    mov dl, bh
    add dl, '0'
    int 21h

    mov ax, 4C00h        ; أنهِ البرنامج، رمز الخروج 0
    int 21h
main endp
end main
```

```text output
Sum of the array: 24
```

- `mov ax, @data` ثم `mov ds, ax`: لا يمكن وضع رقم في مسجل مقطع مباشرة، فنمرّ عبر `AX`.
- `offset nums` = إزاحة المتغير (مثل `lea`).
- `main proc` ... `main endp` إجراء، و`end main` يحدد نقطة البداية.

## من 8086 إلى x64

| 8086 (DOS) | x64 (ويندوز) |
|---|---|
| `int 21h` بخدمة في `AH` | `call` لدالة من مكتبة C أو Win32 |
| مسجلات 16 بت: `ax` | 64 بت: `rax` (و`eax` و`ax` ما زالت موجودة) |
| مقاطع `DS:SI` | ذاكرة مسطحة: عنوان 64 بت واحد |
| نص ينتهي بـ `$` | نص ينتهي بصفر |
| `ret` / `int 21h` مع `4Ch` | `ret` من `main` |

## الخلاصة

- 8086 أبو x86: مسجلات 16 بت `AX`..`DX` بنصفيها، و`SI`/`DI`/`BP`/`SP`، ومقاطع `CS`/`DS`/`SS`/`ES`.
- العنوان الفعلي = المقطع × 16 + الإزاحة.
- `int 21h`: `AH = 09h` نص بـ `$`، و`02h` حرف، و`01h` مفتاح، و`4Ch` خروج.
- `emu8086.inc`: `PRINT`/`PRINTN`/`PUTC` و`PRINT_NUM`/`SCAN_NUM` مع `DEFINE_...`.
- نافذة المحاكي: المسجلات والذاكرة والمكدس، والتنفيذ خطوة بخطوة وحتى خطوة إلى الخلف.

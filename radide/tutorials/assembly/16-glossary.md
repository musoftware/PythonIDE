# الدرس 16: قاموس المصطلحات (إنجليزي - عربي)

مرجع سريع لكل المصطلحات التي مرت في الدورة، مرتبة حسب الموضوع.

## الأساسيات

| English | العربية | المعنى المختصر |
|---|---|---|
| Machine Code | لغة الآلة | البايتات التي ينفذها المعالج مباشرة |
| Assembly Language | لغة التجميع | أسماء مختصرة لتعليمات المعالج، تعليمة لكل سطر |
| Assembler | المجمّع | يحوّل لغة التجميع إلى لغة آلة (NASM، MASM، FASM، GNU as) |
| Linker | الرابط | يجمع ملفات الكائن والمكتبات في ملف تنفيذي |
| Object File | ملف كائن | ناتج المجمّع (`.obj`) قبل الربط |
| Instruction | تعليمة | أمر واحد للمعالج مثل `mov` أو `add` |
| Mnemonic | الاسم المختصر | اسم التعليمة: `mov` و`jmp` ... |
| Operand | معامل (مُعامَل) | ما تعمل عليه التعليمة: مسجل أو ذاكرة أو ثابت |
| Immediate | قيمة فورية | رقم ثابت مكتوب داخل التعليمة |
| Directive | توجيه | أمر للمجمّع لا للمعالج: `section` و`db` و`equ` و`global` |
| Label | لافتة | اسم لعنوان في البرنامج |
| Local Label | لافتة محلية | تبدأ بنقطة (`.loop`) وتتبع آخر لافتة عادية |
| Comment | تعليق | ما بعد `;` يتجاهله المجمّع |

## الأعداد والبيانات

| English | العربية | المعنى المختصر |
|---|---|---|
| Bit | بت | خانة ثنائية: 0 أو 1 |
| Byte | بايت | 8 بتات |
| Word / Dword / Qword | كلمة / مزدوجة / رباعية | 16 / 32 / 64 بتًا |
| Binary | ثنائي | النظام العددي بالأساس 2 |
| Hexadecimal | سادس عشري | النظام بالأساس 16 (`0x1F`، `1Fh`) |
| Two's Complement | المتمم الثنائي | طريقة تخزين الأعداد السالبة |
| Signed / Unsigned | بإشارة / بلا إشارة | تفسير البتات كعدد قد يكون سالبًا أو موجبًا فقط |
| Sign Extension | توسيع الإشارة | نسخ بت الإشارة عند التكبير (`movsx`، `cdq`) |
| Zero Extension | التوسيع بالأصفار | (`movzx`) |
| Little Endian | الأصغر أولًا | ترتيب البايتات في x86: البايت الأصغر في العنوان الأصغر |
| ASCII | آسكي | جدول أرقام الحروف الإنجليزية |
| UTF-8 | يو تي إف 8 | ترميز يونيكود: الحرف العربي بايتان |
| Null-terminated String | نص منتهٍ بصفر | نص C ينتهي بالبايت 0 |
| Overflow | فيضان | ناتج أكبر من حجم المسجل |

## المعالج والذاكرة

| English | العربية | المعنى المختصر |
|---|---|---|
| CPU | وحدة المعالجة المركزية | المعالج |
| ALU | وحدة الحساب والمنطق | الجزء الذي يجمع ويطرح ويقارن |
| Register | مسجل | مخزن صغير سريع داخل المعالج (`rax` ...) |
| General-Purpose Register | مسجل عام | `rax`..`r15` |
| Instruction Pointer | مؤشر التعليمة | `rip`: عنوان التعليمة التالية |
| Flags Register | مسجل الأعلام | `rflags`: ZF وSF وCF وOF ... |
| Zero / Sign / Carry / Overflow Flag | علم الصفر / الإشارة / الحمل / الفيضان | ملاحظات عن ناتج آخر عملية |
| Fetch-Decode-Execute | الجلب - الفك - التنفيذ | دورة المعالج |
| Memory Address | عنوان الذاكرة | رقم البايت في الذاكرة |
| Addressing Mode | طريقة العنونة | `[أساس + فهرس × مقياس + إزاحة]` |
| RIP-relative | نسبي لمؤشر التعليمة | عنوان محسوب من مكان التعليمة (`default rel`) |
| Section | قسم | `.text` و`.data` و`.bss` و`.rdata` |
| Segment | مقطع | في 8086: `CS` و`DS` و`SS` و`ES` |
| Physical Address | العنوان الفعلي | في 8086: المقطع × 16 + الإزاحة |

## التحكم في التنفيذ

| English | العربية | المعنى المختصر |
|---|---|---|
| Compare | مقارنة | `cmp`: طرح بلا تخزين |
| Unconditional Jump | قفز غير مشروط | `jmp` |
| Conditional Jump | قفز مشروط | `je` و`jg` و`ja` ... |
| Loop | حلقة | قفز إلى الخلف حتى يتحقق شرط |
| Conditional Move | نقل مشروط | `cmovcc` |
| Off-by-one Error | الخطأ بواحد | حلقة تدور مرة زائدة أو ناقصة |

## المكدس والدوال

| English | العربية | المعنى المختصر |
|---|---|---|
| Stack | المكدس | ذاكرة LIFO تنمو للأسفل |
| Stack Pointer | مؤشر المكدس | `rsp` |
| Push / Pop | دفع / سحب | وضع قيمة على المكدس / أخذها |
| Procedure / Function | إجراء / دالة | كود يُستدعى بـ `call` ويرجع بـ `ret` |
| Return Address | عنوان الرجوع | ما تدفعه `call` وتسحبه `ret` |
| Calling Convention | اتفاقية الاستدعاء | قواعد المعاملات والمسجلات بين الدوال |
| Shadow Space | مساحة الظل | 32 بايتًا يحجزها المستدعي في ويندوز x64 |
| Stack Alignment | محاذاة المكدس | `rsp` مضاعف لـ 16 عند `call` |
| Volatile Register | مسجل متطاير | قد تغيّره الدالة المستدعاة (`rax`، `rcx`، `rdx`، `r8`-`r11`) |
| Non-volatile Register | مسجل محفوظ | تعيده الدالة كما كان (`rbx`، `rsi`، `rdi`، `rbp`، `r12`-`r15`) |
| Stack Frame | إطار المكدس | منطقة الدالة على المكدس (`rbp`) |
| Leaf Function | دالة ورقية | لا تستدعي دوال أخرى |
| Recursion | الاستدعاء الذاتي | دالة تستدعي نفسها |
| Callback | دالة رد النداء | دالة تعطي عنوانها لمكتبة لتستدعيها (`qsort`) |

## النظام والأدوات

| English | العربية | المعنى المختصر |
|---|---|---|
| C Runtime (CRT) | مكتبة C | `printf` و`scanf` و`puts` ... |
| Win32 API | واجهة ويندوز البرمجية | دوال `kernel32.dll` و`user32.dll` |
| Handle | مقبض | رقم يمثّل موردًا في ويندوز (ملف، نافذة) |
| Interrupt | مقاطعة | `int 21h`: استدعاء خدمة في DOS / BIOS |
| Buffer | ذاكرة مؤقتة / مخزن | مكان تُجمع فيه البيانات قبل كتابتها |
| Emulator | محاكي | برنامج يقلد معالجًا (محاكي 8086) |
| Debugger | المنقّح | أداة التنفيذ خطوة بخطوة (gdb) |
| Breakpoint | نقطة توقف | مكان يتوقف عنده البرنامج تحت المنقّح |
| Step Into / Over / Out | خطوة إلى الداخل / فوق / إلى الخارج | أوامر التنفيذ خطوة بخطوة |
| Disassembly | التفكيك | عرض لغة الآلة كتعليمات تجميع |
| Access Violation | انتهاك الوصول | قراءة أو كتابة في عنوان غير مسموح (`0xC0000005`) |
| GUI Bridge | جسر الواجهة الرسومية | طريقة RAD IDE لربط نموذج مصمم بكود أي لغة |
| Event Handler | معالج الحدث | `handler btnOK_Click` ... `endhandler` |

# الدرس 1: ما هي لغة التجميع؟ برنامجك الأول

**في هذا الدرس ستتعلم:**

- ما هي **لغة الآلة** و**لغة التجميع** (Assembly)، ولماذا نتعلمها.
- ما دور **المجمّع** (Assembler) و**الرابط** (Linker).
- كيف تنشئ مشروع Assembly في RAD IDE وتشغّله.
- تشريح أول برنامج: `section` و`global` و`extern` و`call` و`ret`.

## من الكود إلى المعالج

المعالج (CPU) لا يفهم Python ولا C ولا حتى الحروف. هو يفهم **أرقامًا** فقط: سلسلة من البايتات، كل مجموعة منها **تعليمة** (instruction) تقول له شيئًا بسيطًا جدًّا مثل «انسخ هذا الرقم» أو «اجمع هذين» أو «اقفز إلى هناك». هذه الأرقام هي **لغة الآلة** (Machine Code).

مثلًا هذه البايتات الثلاث:

```text
48 83 EC 28
```

تعني للمعالج: «اطرح 40 من المسجل rsp». حفظ أرقام كهذه مستحيل عمليًّا، لذلك اخترع المبرمجون **لغة التجميع**: نفس التعليمات لكن بأسماء مختصرة يقرؤها الإنسان:

```asm
sub rsp, 40
```

كل سطر تعليمات في لغة التجميع يقابل **تعليمة واحدة** من لغة الآلة تقريبًا. لذلك تسمّى لغة **منخفضة المستوى**: أنت تكلّم المعالج مباشرة، بلا وسيط.

> **تشبيه:** لغة مثل Python تشبه أن تقول لسائق التاكسي «خذني إلى المطار». لغة التجميع تشبه أن تقود السيارة بنفسك: «اضغط الدواسة، أدر المقود يسارًا 30 درجة، توقف عند الإشارة». أصعب، لكنك تعرف بالضبط ماذا يحدث وتتحكم في كل شيء.

## لماذا نتعلم لغة التجميع؟

- **لتفهم كيف يعمل الحاسوب فعلًا**: المسجلات، والذاكرة، والمكدس، واستدعاء الدوال. بعدها تفهم أي لغة أخرى أعمق.
- **لتصحيح الأخطاء الصعبة**: عندما ينهار برنامج C أو C++ يعرض لك المنقّح نافذة **Disassembly** (التفكيك) بلغة التجميع.
- **للسرعة والتحكم**: أجزاء من أنظمة التشغيل، ومشغّلات الأجهزة (Drivers)، والألعاب، والتشفير تُكتب بها.
- **للأمن والهندسة العكسية**: تحليل البرامج والفيروسات يتم بقراءة لغة التجميع.

## المجمّع والرابط

البرنامج المكتوب بلغة التجميع يمر بمرحلتين قبل أن يصبح ملف `.exe`:

1. **المجمّع** (Assembler) يحوّل ملف `main.asm` إلى لغة آلة في ملف **كائن** (Object File) اسمه `main.obj`. في هذه الدورة نستخدم المجمّع المجاني **NASM**.
2. **الرابط** (Linker) يجمع ملف الكائن مع المكتبات التي نستخدمها (مثل دالة الطباعة `puts` من مكتبة لغة C) وينتج `main.exe`. نستخدم هنا رابط **gcc** من حزمة MinGW-w64.

```text
main.asm  --(nasm -f win64)-->  main.obj  --(gcc)-->  main.exe
```

> **ملاحظة:** هناك مجمّعات كثيرة: NASM وMASM (من مايكروسوفت) وFASM وGNU as. كلها تفهم نفس تعليمات المعالج، لكن **الصياغة** تختلف قليلًا. RAD IDE تفهمها كلها، ونحن نبدأ بـ NASM لأنه واضح ومجاني ويعمل في كل مكان.

## تجهيز بيئة العمل

لا تحتاج إلى تثبيت شيء بنفسك: عند أول بناء لمشروع Assembly تنزّل RAD IDE المجمّع NASM من موقعه الرسمي (nasm.us) إلى المجلد `%LOCALAPPDATA%\RADIDE\tools\nasm` وتتحقق من بصمته، وتستخدم للربط مترجم MinGW-w64 الذي تستخدمه دروس لغة C. ومن **Tools > Assembly Toolchains...** (أدوات > أدوات لغة التجميع) ترى ما هو مثبت.

## إنشاء أول مشروع

1. من القائمة **File > New Project...** (ملف > مشروع جديد) أو `Ctrl+Shift+N`.
2. في شجرة اللغات اختر مجموعة **Assembly** ثم **Assembly (NASM)**، والقالب **Assembly Console (x64 Windows, NASM)** (برنامج كونسول بلغة التجميع).
3. اكتب اسمًا للمشروع مثل `HelloAsm` واضغط **OK** (موافق).

سيفتح الملف `main.asm`. امسح ما فيه واكتب:

```asm run
default rel
global main
extern puts

section .data
    msg db "Hello, World!", 0

section .text
main:
    sub rsp, 40          ; مساحة للدالة التي سنستدعيها
    lea rcx, [msg]       ; المعامل الأول: عنوان النص
    call puts            ; اطبع النص وانزل سطرًا
    xor eax, eax         ; قيمة الرجوع 0 = انتهى بنجاح
    add rsp, 40
    ret                  ; ارجع إلى من استدعى main
```

```text output
Hello, World!
```

اضغط `Ctrl+F5` (**Debug > Start Without Debugging**، أي بدء بدون تصحيح الأخطاء): تجمّع الـ IDE الملف بـ NASM، ثم تربطه بـ gcc، ثم تشغّله، فيظهر الناتج في نافذة **Output** (المخرجات).

> **نصيحة:** في هذه الدروس، كل مثال بجانبه زر «جرّبه». اضغطه وستنشئ لك الـ IDE مشروعًا فيه هذا الكود وتشغّله مباشرة.

## تشريح البرنامج سطرًا سطرًا

- `; ...` كل ما بعد الفاصلة المنقوطة **تعليق** يتجاهله المجمّع.
- `default rel` اطلب من NASM أن يحسب عناوين المتغيرات **نسبةً إلى مكان التعليمة**. هذا ضروري في برامج ويندوز 64 بت (سنرى السبب بعد قليل).
- `global main` اجعل الاسم `main` مرئيًّا للرابط، فهو **نقطة البداية** التي تبدأ منها مكتبة C تشغيل برنامجنا.
- `extern puts` الدالة `puts` ليست في ملفنا، بل في مكتبة C، والرابط سيجدها.
- `section .data` قسم **البيانات**: هنا نضع المتغيرات والنصوص.
- `msg db "Hello, World!", 0` عرّف بايتات (db = define byte) باسم `msg`: حروف النص ثم صفر. الصفر يعلن **نهاية النص** كما تتوقع دوال C.
- `section .text` قسم **الكود**: هنا التعليمات.
- `main:` **لافتة** (Label): اسم لعنوان هذا السطر في الذاكرة.
- `sub rsp, 40` و`add rsp, 40` نحجز مساحة على **المكدس** ثم نعيدها. قواعد ويندوز تطلبها قبل استدعاء أي دالة (الدرس 9 يشرحها بالتفصيل؛ الآن احفظها كقالب).
- `lea rcx, [msg]` ضع **عنوان** النص في المسجل `rcx`. في ويندوز 64 بت المعامل الأول لأي دالة يوضع في `rcx`.
- `call puts` نفّذ الدالة `puts` ثم عُد إلى السطر التالي.
- `xor eax, eax` صفّر `eax`؛ ما في `eax` عند نهاية `main` هو **رمز الخروج** للبرنامج.
- `ret` ارجع.

## طباعة عدة أسطر

كل استدعاء لـ `puts` يطبع نصًّا وينزل سطرًا. يمكنك أيضًا كتابة نص عربي، فالملف محفوظ بترميز UTF-8:

```asm run
default rel
global main
extern puts

section .data
    line1 db "السلام عليكم", 0
    line2 db "أنا أتعلم لغة التجميع", 0

section .text
main:
    sub rsp, 40
    lea rcx, [line1]
    call puts
    lea rcx, [line2]
    call puts
    xor eax, eax
    add rsp, 40
    ret
```

```text output
السلام عليكم
أنا أتعلم لغة التجميع
```

لاحظ أن `rcx` يجب أن يُملأ **قبل كل** `call`، لأن الدالة المستدعاة حرة في تغيير قيمته.

## نظرة على لغة الآلة

بعد التجميع يمكنك رؤية البايتات الحقيقية لكل تعليمة: من القائمة **Debug > Windows > Disassembly** (تصحيح > نوافذ > التفكيك) أثناء التصحيح، أو بأمر `objdump -d -M intel main.exe`. هذه بعض تعليمات برنامجنا ومقابلها:

| التعليمة | البايتات (سادس عشري) |
|---|---|
| `sub rsp, 40` | `48 83 EC 28` |
| `xor eax, eax` | `31 C0` |
| `add rsp, 40` | `48 83 C4 28` |
| `ret` | `C3` |

لاحظ أن `40` بالنظام العشري تساوي `28` بالنظام السادس عشر. هذا موضوع الدرس القادم.

## أخطاء شائعة

**خطأ كتابة في اسم التعليمة:** المجمّع يذكر رقم السطر:

```asm
    mvo rax, 1
```

```text
main.asm:7: error: instruction expected, found `mvo rax'
```

**نسيان `default rel`:** يمر التجميع بتحذير، ثم يفشل الربط لأن العنوان المطلق لا يتسع في 32 بت:

```text
main.asm:8: warning: implicit DEFAULT ABS is deprecated [-w+implicit-abs-deprecated]
main.obj:main.asm:(.text+0x8): relocation truncated to fit: IMAGE_REL_AMD64_ADDR32 against `.data'
collect2.exe: error: ld returned 1 exit status
```

**نسيان الصفر في آخر النص:** تطبع `puts` النص ثم «قمامة» حتى تصادف صفرًا في الذاكرة.

في الـ IDE تظهر أخطاء المجمّع والرابط في **Error List** (قائمة الأخطاء)؛ اضغط على الخطأ مرتين لتقفز إلى السطر.

## تمارين

### التمرين 1

اطبع اسمك في سطر ومدينتك في السطر التالي باستخدام `puts` مرتين.

```asm exercise
default rel
global main
extern puts

section .data
    name db "الاسم: منى", 0
    ; أضف نص المدينة هنا: المدينة: القاهرة

section .text
main:
    sub rsp, 40
    lea rcx, [name]
    call puts
    ; اطبع المدينة هنا
    xor eax, eax
    add rsp, 40
    ret
```

```asm solution
default rel
global main
extern puts

section .data
    name db "الاسم: منى", 0
    city db "المدينة: القاهرة", 0

section .text
main:
    sub rsp, 40
    lea rcx, [name]
    call puts
    lea rcx, [city]
    call puts
    xor eax, eax
    add rsp, 40
    ret
```

```text output
الاسم: منى
المدينة: القاهرة
```

### التمرين 2

اطبع مثلثًا من النجوم بثلاثة أسطر. جرّب أن تكتفي بنص **واحد** فيه الأسطر الثلاثة مفصولة بالرقم `10` (رمز السطر الجديد).

```asm exercise
default rel
global main
extern puts

section .data
    ; *
    ; **
    ; ***
    stars db "*", 0

section .text
main:
    sub rsp, 40
    lea rcx, [stars]
    call puts
    xor eax, eax
    add rsp, 40
    ret
```

```asm solution
default rel
global main
extern puts

section .data
    stars db "*", 10, "**", 10, "***", 0

section .text
main:
    sub rsp, 40
    lea rcx, [stars]
    call puts
    xor eax, eax
    add rsp, 40
    ret
```

```text output
*
**
***
```

## الخلاصة

- لغة الآلة أرقام، ولغة التجميع أسماء مختصرة لنفس التعليمات.
- `nasm -f win64` يجمّع إلى `.obj`، و`gcc` يربط وينتج `.exe`.
- قالب البرنامج: `default rel` و`global main` و`extern` للدوال الخارجية، و`section .data` للبيانات و`section .text` للكود.
- قبل `call` ضع المعامل الأول في `rcx`، واحجز `sub rsp, 40`، وأنهِ `main` بـ `xor eax, eax` و`ret`.

# الدرس 2: الاتصال بالسيارة والسيارة التجريبية

**في هذا الدرس:**

- خطوات الاتصال بسيارة حقيقية بمحوّل ELM327 أو J2534.
- **السيارة التجريبية**: سيارة افتراضية كاملة للتدريب دون أي جهاز.
- **منضدة تشخيص السيارات** وتبويباتها.
- قراءة **رقم الشاسيه** (VIN) و**البحث عن وحدات التحكم** من الكود.

## الاتصال بسيارة حقيقية

1. اركن السيارة في مكان آمن، و**شغّل الإشعال** (المفتاح على ON) أو المحرك حسب ما تريد فحصه.
2. ركّب المحوّل في **مقبس OBD-II** (تحت الطارة غالبًا، وأحيانًا خلف غطاء صغير).
3. في RAD IDE افتح **أدوات > الاتصال بالسيارة > الاتصال بالسيارة...**، واختر نوع المحوّل:
   - **USB أو بلوتوث** (منفذ COM): اضغط بحث المنافذ واختر المنفذ؛ السرعة تُكتشف تلقائيًا.
   - **Wi-Fi**: اتصل بشبكة المحوّل من الويندوز أولًا، والعنوان الافتراضي `192.168.0.10:35000`.
   - **J2534**: يظهر الجهاز المثبّت من تعريفات الويندوز.
4. اترك البروتوكول على **تلقائي** واضغط **اختبار الاتصال** ثم **اتصال**. يظهر الاتصال في شريط الحالة أسفل النافذة.

> **ملاحظة:** بعض محوّلات ELM327 الرخيصة نسخ ضعيفة لا تدعم كل الأوامر. إذا فشل الاتصال جرّب بروتوكولًا محددًا (CAN 11 بت 500 كيلوبود لأغلب السيارات بعد 2008)، وتأكد أن الإشعال يعمل.

## السيارة التجريبية

لا تحتاج سيارة ولا محوّلًا لتتعلم. في RAD IDE **سيارة تجريبية** فيها خمس وحدات تحكم: المحرك، والفرامل ABS / ESP، والوسائد الهوائية، ولوحة العدادات، والتكييف. لها رقم شاسيه، وبيانات حية تتغير مع الوقت (المحرك يسخن، والسرعة تتغير عند القيادة)، وأعطال مخزّنة ومعلّقة ودائمة، ولقطة تجميد، واختبارات جاهزية، ووظائف خدمة حقيقية: دورة تنفيس التبريد، واختبار المروحة، وتصفير الصيانة، وغيرها. وهي **ترفض** بعض الوظائف والمحرك دائر كما تفعل السيارات الحقيقية.

طريقتان لاستعمالها:

- **أدوات > تشخيص السيارات...** ثم من قائمة المحوّل اختر **السيارة التجريبية عبر محاكي ELM327 (مشتركة مع وظائف الصيانة)** واضغط **اتصال**. هذه هي الطريقة الأقرب للحقيقة: المنضدة تكلم محوّل ELM327 محاكى، ووراءه السيارة كلها، فتعمل كل التبويبات ومنها **الخدمة**.
- **أدوات > الاتصال بالسيارة > سيارة تجريبية** تفتح لوحة تتحكم منها في السيارة: الإشعال، تشغيل المحرك، القيادة، سخونة المحرك، وترى اللمبات المنوّرة. هكذا تجرّب مثلًا أن دورة التبريد تُرفض والمحرك دائر.

## منضدة تشخيص السيارات

بعد الاتصال يظهر في الأعلى رأس فيه رقم الشاسيه والبروتوكول وعدد وحدات التحكم وحالة **لمبة المحرك** وعدد الأكواد وجهد البطارية، وتحته التبويبات:

| التبويب | الدرس |
|---|---|
| **الأعطال** | قراءة الأكواد وشرحها، فحص كل الوحدات، مسح الأعطال، حفظ التقرير (الدروس 4 و8 و9) |
| **البيانات الحية** و**لقطة التجميد** | الدرس 5 |
| **الجاهزية** | الدرس 6 |
| **الاختبارات (06)** و**المعلومات (09)** | نتائج اختبارات المراقبة، ورقم الشاسيه وأرقام البرنامج |
| **الدليل** | لمبات التحذير، الأعراض، الشرح بالذكاء الاصطناعي (الدرس 3) |
| **الخدمة** | دورة التبريد، اختبار المشغّلات، مسح عطل معيّن (الدرسان 7 و8) |
| **السجل** | كل رسالة أُرسلت واستُقبلت |

## نفس الشيء بالكود

كل ما تفعله المنضدة موجود في مكتبة بايثون `radide.cardiag` تستطيع استعمالها في سكربتاتك. هذا البرنامج يتصل بالسيارة التجريبية عبر محوّل ELM327 المحاكى، ويقرأ رقم الشاسيه ويبحث عن وحدات التحكم (نفس ما يفعله **أدوات > الاتصال بالسيارة > البحث عن وحدات التحكم**):

```carpy run
from radide.cardiag.sim.car import VirtualCar
from radide.cardiag.link import demo_link, discovery
from radide.cardiag.obd.client import ObdClient
from radide.cardiag.obd.transport import LinkTransport

car = VirtualCar(time_scale=0)                 # time_scale=0: الزمن متوقف فتبقى القيم ثابتة للدرس
link = demo_link(car)                          # اتصال ELM327 بالسيارة التجريبية
print("البروتوكول:", link.protocol.name)

obd = ObdClient(LinkTransport(link))
info = obd.vehicle_info()                      # الوضع 09
print("رقم الشاسيه:", info.vin)
print("رقم المعايرة:", info.calids["7E8"][0])

print("وحدات التحكم:")
for ecu in discovery.discover(link, identify=False):
    kind = "OBD-II" if ecu.obd else "UDS"
    print(f"  {ecu.tx:03X} -> {ecu.rx:03X}  {kind:6}  {ecu.name_ar}")
link.close()
```

```text output
البروتوكول: ISO 15765-4 CAN (11 bit ID, 500 kbaud)
رقم الشاسيه: XRDDEM0CAR0123456
رقم المعايرة: RADSIM-ENG-0142
وحدات التحكم:
  720 -> 728  UDS     لوحة العدادات
  744 -> 74C  UDS     التكييف
  760 -> 768  UDS     الفرامل ABS / ESP
  770 -> 778  UDS     الوسائد الهوائية (SRS)
  7E0 -> 7E8  OBD-II  المحرك (ECM)
```

لاحظ أن **المحرك فقط** أجاب على سؤال OBD-II الموحّد؛ باقي الوحدات وُجدت بسؤال UDS ‏`3E` (TesterPresent) على العناوين الشائعة. أسماء الوحدات هنا **تخمين** من العنوان، لأن العناوين تختلف بين الشركات.

## رقم الشاسيه (VIN)

رقم الشاسيه 17 حرفًا: أول 3 حروف (**WMI**) تدل على الشركة والبلد، والحرف العاشر **سنة الطراز**، والتاسع في السيارات الأمريكية رقم تحقق. تبويب **المعلومات (09)** يشرح ذلك. وأداة التشخيص تحفظ **ملفًا لكل سيارة** باسم رقم شاسيهها، فيه سجل الفحوصات والإصلاحات (تبويب الخدمة > سجل السيارة).

```python run
vin = "XRDDEM0CAR0123456"
print("WMI (الشركة/البلد):", vin[:3])
print("وصف السيارة (VDS):", vin[3:9])
print("حرف سنة الطراز:", vin[9])
print("الرقم التسلسلي:", vin[11:])
print("الطول صحيح؟", len(vin) == 17 and not set("IOQ") & set(vin))
```

```text output
WMI (الشركة/البلد): XRD
وصف السيارة (VDS): DEM0CA
حرف سنة الطراز: R
الرقم التسلسلي: 123456
الطول صحيح؟ True
```

(الحروف I و O و Q لا تُستعمل في رقم الشاسيه حتى لا تختلط بالأرقام 1 و 0.)

# الدرس 1: كيف تعمل كمبيوترات السيارة و OBD-II والمحوّلات

**في هذا الدرس:**

- ما هي **وحدات التحكم** (ECU) في السيارة الحديثة ولماذا يوجد منها عدد كبير.
- ما هو **OBD-II** ومقبسه ذو الـ 16 سنًا، وما الذي يقرؤه منه أي جهاز فحص.
- الفرق بين **OBD-II** (المحرك والانبعاثات) و**UDS** (كل وحدات السيارة).
- **محوّلات** ELM327 و STN و J2534، وكيف يتكلم معها الكمبيوتر.
- **حدود الدورة**: ما الذي ستتعلمه وما الذي لن تجده هنا أبدًا.

## السيارة شبكة كمبيوترات

السيارة الحديثة فيها من 10 إلى أكثر من 70 كمبيوترًا صغيرًا، كل واحد اسمه **وحدة تحكم** (ECU = Electronic Control Unit). أشهرها:

| الوحدة | عملها |
|---|---|
| **المحرك** (ECM / PCM) | الوقود والإشعال والهواء وسرعة الدوران ومراقبة الانبعاثات |
| **ناقل الحركة** (TCM) | تغيير السرعات في الفتيس الأوتوماتيك |
| **الفرامل** (ABS / ESP) | منع انغلاق العجل والثبات |
| **الوسائد الهوائية** (SRS) | الحساسات ونفخ الوسائد عند الحادث |
| **لوحة العدادات** | العدادات واللمبات وموعد الصيانة |
| **التكييف** و**الهيكل** (BCM) | التكييف والأنوار والأبواب والزجاج |

هذه الوحدات تتكلم مع بعضها على **ناقل CAN** (سلكان ملتفّان)، وكل وحدة تراقب حساساتها باستمرار. عندما ترى قيمة غير منطقية (حساس حرارة يقرأ ‎-40 درجة في الصيف مثلًا) تسجّل **كود عطل** (DTC) في ذاكرتها، وقد تنوّر لمبة في التابلوه.

## OBD-II: لغة واحدة لكل السيارات

منذ 1996 في أمريكا (و2001 للبنزين و2004 للديزل في أوروبا) يجب أن يكون في كل سيارة **مقبس OBD-II** تحت الطارة غالبًا، وأن يجيب كمبيوتر المحرك على أسئلة **موحّدة** (المعيار SAE J1979). الأسئلة مقسّمة إلى **أوضاع** (Modes / Services):

| الوضع | ماذا يفعل |
|---|---|
| `01` | البيانات الحية (حرارة المحرك، سرعة الدوران، السرعة...) وحالة لمبة المحرك |
| `02` | لقطة التجميد: القيم لحظة تسجيل العطل |
| `03` / `07` / `0A` | الأعطال المخزّنة / المعلّقة / الدائمة |
| `04` | مسح أعطال المحرك |
| `06` | نتائج اختبارات المراقبة |
| `09` | رقم الشاسيه (VIN) وأرقام برنامج الكمبيوتر |

كل سؤال بايتات قليلة: الوضع ثم رقم القيمة المطلوبة (**PID**). مثلًا `01 0C` تعني «أعطني سرعة دوران المحرك الآن»، فيرد الكمبيوتر بـ `41 0C` (الوضع + 0x40 ثم نفس الـ PID) وبعدها بايتان من البيانات. المعادلة في المعيار: سرعة الدوران = ‎(256 × A + B) ÷ 4.

```python run
reply = "41 0C 1A F8"                     # رد كمبيوتر المحرك على السؤال 01 0C
data = bytes.fromhex(reply)
mode, pid, a, b = data[0], data[1], data[2], data[3]
print("الوضع:", hex(mode), "- يعني رد على الوضع", hex(mode - 0x40))
print("PID:", hex(pid))
print("سرعة الدوران:", (256 * a + b) / 4, "لفة/دقيقة")
```

```text output
الوضع: 0x41 - يعني رد على الوضع 0x1
PID: 0xc
سرعة الدوران: 1726.0 لفة/دقيقة
```

### تمرين

حرارة سائل التبريد هي الـ PID ‏`05`، ومعادلتها: الحرارة = A − 40 (بالدرجة المئوية). اكتب دالة تأخذ الرد النصي وترجع الحرارة، ثم اطبع حرارة الرد `41 05 7B`.

```python exercise
def coolant(reply: str) -> int:
    data = bytes.fromhex(reply)
    # تأكد أن الرد للوضع 01 والـ PID 05 ثم طبّق المعادلة
    return 0


print(coolant("41 05 7B"), "درجة")
```

```python solution
def coolant(reply: str) -> int:
    data = bytes.fromhex(reply)
    assert data[0] == 0x41 and data[1] == 0x05
    return data[2] - 40


print(coolant("41 05 7B"), "درجة")
```

```text output
83 درجة
```

## OBD-II ليس كل شيء: UDS

OBD-II يغطي **المحرك والانبعاثات فقط**. أعطال الفرامل ABS والوسائد الهوائية ولوحة العدادات لا تظهر في الوضع 03. لهذه الوحدات لغة أخرى اسمها **UDS** (المعيار ISO 14229) تستعملها أجهزة الورش:

- `0x19` قراءة الأعطال من أي وحدة، و`0x14` مسحها (كلها أو عطل واحد).
- `0x22` قراءة قيمة (مثل نسبة تشغيل المروحة)، و`0x2F` تشغيل مشغّل (مروحة، طلمبة) للاختبار.
- `0x31` تشغيل **روتين** مثل دورة تنفيس التبريد أو تصفير الصيانة.

كل وحدة لها **عنوان** على ناقل CAN: كمبيوتر المحرك يستقبل غالبًا على `7E0` ويرد على `7E8`، والفرامل في السيارة التجريبية على `760`/`768`. لكن عناوين UDS **تختلف من شركة لأخرى**، ولذلك تحتاج وظائف الخدمة في السيارات الحقيقية إلى **ملف تعريفات** للسيارة (الدرس 7).

## المحوّلات: الجسر بين الكمبيوتر والسيارة

الكمبيوتر لا يتصل بناقل CAN مباشرة؛ بينهما **محوّل** يُركّب في مقبس OBD:

- **ELM327** وأشباهه: الأرخص والأشهر، عن طريق USB أو بلوتوث (منفذ COM) أو Wi-Fi (العنوان `192.168.0.10:35000` غالبًا) أو بلوتوث منخفض الطاقة. يتكلم بأوامر نصية تبدأ بـ `AT`.
- **STN / OBDLink**: متوافقة مع ELM327 وأسرع وأكثر ثباتًا.
- **J2534 PassThru**: أجهزة الورش الاحترافية، يُحمَّل تعريفها (DLL) من الويندوز.

هذا حوار حقيقي مع **محاكي ELM327** المدمج في RAD IDE (المحاكي يتصرف مثل المحوّل الحقيقي تمامًا، ووراءه سيارة افتراضية):

```carpy run
import time
from radide.cardiag.sim.car import VirtualCar
from radide.cardiag.sim.elm import ElmInterpreter

adapter = ElmInterpreter(VirtualCar(time_scale=0))      # محوّل ELM327 وراءه السيارة التجريبية


def send(command: str) -> str:
    adapter.feed((command + "\r").encode())
    out = b""
    while not out.endswith(b">"):                        # المحوّل يكتب ">" عندما يجهز للأمر التالي
        out += adapter.read() or b""
        time.sleep(0.01)
    return " / ".join(x for x in out.decode().replace(">", "").split("\r") if x.strip())


for cmd in ("ATZ", "ATE0", "ATSP0", "0100", "010C", "0105"):
    print(f"{cmd:6} -> {send(cmd)}")
```

```text output
ATZ    -> ATZ / ELM327 v1.5
ATE0   -> ATE0 / OK
ATSP0  -> OK
0100   -> SEARCHING... / 41 00 BE 3F B8 13
010C   -> 41 0C 0C 30
0105   -> 41 05 7A
```

- `ATZ` يعيد تشغيل المحوّل فيرد باسمه، و`ATE0` يوقف ترديد الأوامر، و`ATSP0` يطلب **اكتشاف البروتوكول تلقائيًا**.
- `0100` سؤال «ما الـ PIDs التي تدعمها؟»؛ أول مرة يبحث المحوّل عن البروتوكول (`SEARCHING...`).
- `010C` سرعة الدوران: `0C 30` = 3120 ÷ 4 = **780** لفة (المحرك في الوضع الخامل)، و`0105` الحرارة: `7A` = 122 − 40 = **82** درجة.

في RAD IDE لا تكتب هذه الأوامر بنفسك؛ طبقة الاتصال (`radide/cardiag/link`) تفعل ذلك، وتظهر كل الرسائل في **مراقب الناقل** (أدوات > الاتصال بالسيارة > مراقب الناقل) لمن يحب أن يرى ما يحدث.

## حدود هذه الدورة

أداة التشخيص في RAD IDE مخصصة **لفهم الأعطال وإصلاحها**: قراءة الأكواد وشرحها، والبيانات الحية، ومسح الأعطال بعد الإصلاح، ووظائف الخدمة العادية (تنفيس التبريد، تصفير الصيانة، اختبار المشغّلات، تسجيل البطارية، وضع خدمة الفرامل، معايرة زاوية الدركسيون، الحرق الخدمي لفلتر الجزيئات).

**لا يوجد** فيها ولن تجد في الدورة: وظائف **مانع التشغيل** (الإيموبيلايزر) أو برمجة المفاتيح، أو تغيير **عداد المسافات**، أو كسر خوارزميات **الوصول الأمني**، أو **تعطيل أنظمة الانبعاثات** أو إخفاء أعطالها بشكل دائم أو تزييف الجاهزية. هذه الأشياء تضر بالأمان أو بالمشتري التالي أو بالبيئة، وممنوعة قانونيًا في بلاد كثيرة. حتى ملفات التعريفات التي يستوردها المستخدم تُرفض إن احتوت على شيء منها.

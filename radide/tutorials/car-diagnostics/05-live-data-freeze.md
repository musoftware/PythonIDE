# الدرس 5: البيانات الحية ولقطة التجميد

**في هذا الدرس:**

- أهم **البيانات الحية** وقيمها الطبيعية: حرارة المحرك، سرعة الدوران، تصحيح الوقود، جهد البطارية.
- تبويب **البيانات الحية**: العدّادات والرسم والقيم الدنيا والعليا والتسجيل إلى CSV.
- **لقطة التجميد**: صورة لحالة المحرك لحظة تسجيل العطل، وكيف تساعدك في التشخيص.

## القيم التي تستحق المراقبة

| القيمة (PID) | الطبيعي تقريبًا | ماذا تقول |
|---|---|---|
| حرارة سائل التبريد (`05`) | 85 - 105 °م بعد التسخين | فوق 110 سخونة؛ تبقى تحت 70 بعد 15 دقيقة = ترموستات مفتوح |
| سرعة الدوران (`0C`) | 650 - 900 خامل | تذبذب في الخامل = احتراق ناقص أو تسريب هواء |
| تصحيح الوقود القصير/الطويل (`06`/`07`) | بين ‎-10 و ‎+10 ٪ | موجب كبير = خليط فقير (هواء زائد)، سالب كبير = خليط غني |
| جهد البطارية (`42`) | 13.5 - 14.7 فولت والمحرك دائر | أقل من 13 = الدينامو لا يشحن |
| ضغط المنفولد (`0B`) | 25 - 40 كيلوباسكال خامل | مرتفع في الخامل = تسريب أو مشكلة ميكانيكية |
| حرارة الهواء الداخل (`0F`) | قريبة من حرارة الجو | قيمة ‎-40 = حساس مفصول |

كل قيمة لها **معادلة** في المعيار تحوّل البايتات إلى رقم بوحدة. أمثلة:

```python run
def pct(a):                       # نسبة مئوية: A × 100 ÷ 255
    return round(a * 100 / 255, 1)


def trim(a):                      # تصحيح الوقود: A × 100 ÷ 128 − 100
    return round(a * 100 / 128 - 100, 1)


print("حمل المحرك 04:", pct(0x3D), "%")
print("تصحيح الوقود الطويل 07:", trim(0x92), "%")
print("جهد الكمبيوتر 42:", (0x37 * 256 + 0x14) / 1000, "فولت")
```

```text output
حمل المحرك 04: 23.9 %
تصحيح الوقود الطويل 07: 14.1 %
جهد الكمبيوتر 42: 14.1 فولت
```

تصحيح وقود طويل **+14 ٪** يعني أن الكمبيوتر يضيف 14 ٪ وقودًا زيادة باستمرار ليعوّض هواءً زائدًا - وهذا بالضبط ما يقصده الكود `P0171` (خليط فقير).

### تمرين

ضغط المنفولد (`0B`) معادلته A مباشرة بالكيلوباسكال، وسرعة السيارة (`0D`) A بالكيلومتر/ساعة. اكتب دالة `decode(reply)` تفهم الرد `41 0B 21` والرد `41 0D 3C` وتطبع الاسم والقيمة والوحدة.

```python exercise
def decode(reply: str) -> str:
    d = bytes.fromhex(reply)
    # PID في d[1] والقيمة في d[2]
    return ""


print(decode("41 0B 21"))
print(decode("41 0D 3C"))
```

```python solution
def decode(reply: str) -> str:
    d = bytes.fromhex(reply)
    names = {0x0B: ("ضغط المنفولد", "kPa"), 0x0D: ("سرعة السيارة", "km/h")}
    name, unit = names[d[1]]
    return f"{name}: {d[2]} {unit}"


print(decode("41 0B 21"))
print(decode("41 0D 3C"))
```

```text output
ضغط المنفولد: 33 kPa
سرعة السيارة: 60 km/h
```

## تبويب البيانات الحية

في منضدة التشخيص: تبويب **البيانات الحية** يعرض كل الـ PIDs التي تدعمها السيارة. اختر ما تريد (أو مجموعة جاهزة: «المحرك الأساسي»، «تصحيح الوقود والخليط»، «درجات الحرارة») واضغط **تشغيل**. تظهر العدّادات والقائمة بأقل وأعلى قيمة ورسم بياني، وتستطيع **التسجيل** إلى ملف CSV ثم **إعادة تشغيله** لاحقًا للمقارنة. ومن **دليل الأعطال** زر **راقب في البيانات الحية** يختار لك القيم المهمة لكل كود أو عرَض.

نفس القراءة بالكود:

```carpy run
from radide.cardiag.sim.car import VirtualCar
from radide.cardiag.link import demo_link
from radide.cardiag.obd.client import ObdClient
from radide.cardiag.obd.transport import LinkTransport

NAMES = {0x05: "حرارة سائل التبريد", 0x0C: "سرعة الدوران", 0x0D: "السرعة", 0x07: "تصحيح الوقود الطويل",
         0x42: "جهد البطارية"}
link = demo_link(VirtualCar(time_scale=0))
obd = ObdClient(LinkTransport(link))
for r in obd.read_pids([0x05, 0x0C, 0x0D, 0x07, 0x42]):
    v = r.values[0]
    print(f"{NAMES[r.pid]:20} {round(v.value, 1):>7} {v.unit}")
link.close()
```

```text output
حرارة سائل التبريد        82 °C
سرعة الدوران           780.0 rpm
السرعة                     0 km/h
تصحيح الوقود الطويل     14.1 %
جهد البطارية            14.1 V
```

والقيم **تتغير** مع الزمن: هنا محرك بارد يُشغَّل والزمن في المحاكي أسرع 60 مرة، فترتفع الحرارة خلال ثوانٍ:

```carpy run
import time
from radide.cardiag.sim.car import VirtualCar
from radide.cardiag.link import demo_link
from radide.cardiag.obd.client import ObdClient
from radide.cardiag.obd.transport import LinkTransport

car = VirtualCar(time_scale=60, engine_running=False)     # محرك بارد على حرارة الجو
obd = ObdClient(LinkTransport(demo_link(car)))
cold = obd.read_pids([0x05])[0].value
car.start_engine()
time.sleep(1.5)                                           # حوالي 90 ثانية من زمن السيارة
warm = obd.read_pids([0x05])[0].value
rpm = obd.read_pids([0x0C])[0].value
print("المحرك بارد:", cold, "°C")
print("ارتفعت الحرارة بعد التشغيل؟", warm > cold)
print("المحرك يدور؟", rpm > 500)
```

```text output
المحرك بارد: 27.0 °C
ارتفعت الحرارة بعد التشغيل؟ True
المحرك يدور؟ True
```

## لقطة التجميد (Freeze Frame)

عندما يؤكد كمبيوتر المحرك عطلًا يحفظ معه **لقطة**: قيم الحساسات في تلك اللحظة. هذه اللقطة تجيب عن سؤال مهم: **متى** يحدث العطل؟ والمحرك بارد أم ساخن؟ في الخامل أم على الطريق؟ تحت حمل أم بدون؟

```carpy run
from radide.cardiag.sim.car import VirtualCar
from radide.cardiag.link import demo_link
from radide.cardiag.obd.client import ObdClient
from radide.cardiag.obd.transport import LinkTransport
from radide.cardiag.obd import pids as P

AR = {0x04: "حمل المحرك", 0x05: "حرارة سائل التبريد", 0x06: "تصحيح الوقود القصير", 0x07: "تصحيح الوقود الطويل",
      0x0B: "ضغط المنفولد", 0x0C: "سرعة الدوران", 0x0D: "السرعة", 0x0F: "حرارة الهواء الداخل", 0x11: "فتحة البوابة"}
link = demo_link(VirtualCar(time_scale=0))
obd = ObdClient(LinkTransport(link))
for ecu, ff in obd.freeze_frames().items():              # الوضع 02
    print(f"لقطة {ecu} محفوظة مع الكود {ff.dtc}:")
    for r in ff.readings():
        v = r.values[0]
        print(f"  {r.pid:02X} {AR.get(r.pid, P.get(r.pid).name):22} {round(v.value, 1):>7} {v.unit}")
link.close()
```

```text output
لقطة 7E8 محفوظة مع الكود P0301:
  04 حمل المحرك                23.9 %
  05 حرارة سائل التبريد          88 °C
  06 تصحيح الوقود القصير        2.3 %
  07 تصحيح الوقود الطويل       14.1 %
  0B ضغط المنفولد                33 kPa
  0C سرعة الدوران             812.0 rpm
  0D السرعة                       0 km/h
  0F حرارة الهواء الداخل         36 °C
  11 فتحة البوابة              14.1 %
```

**القراءة:** الاحتراق الناقص `P0301` حدث والسيارة **واقفة** (السرعة 0) على **812** لفة، أي في **الخامل**، والمحرك **ساخن** (88 °م)، وتصحيح الوقود الطويل **+14 ٪**. احتراق ناقص في الخامل مع خليط فقير يجعلنا نشك أولًا في **تسريب هواء** قرب الأسطوانة 1 أو **رشاش** الأسطوانة 1، قبل البوجيه والموبينة (اللتين تظهر مشكلتهما غالبًا تحت الحمل). هكذا تحوّل اللقطة قائمة أسباب طويلة إلى خطة فحص قصيرة.

# الدرس 3: لمبات التحذير في التابلوه: ماذا تعني وماذا تفعل

**في هذا الدرس:**

- **ألوان** اللمبات: الأحمر والأصفر والأخضر والأزرق، ومتى تتوقف فورًا.
- أهم اللمبات: المحرك، الزيت، الحرارة، البطارية، الفرامل، ABS، الوسائد الهوائية.
- **دليل لمبات التحذير** في RAD IDE وزر **اقرأ لمبات العربية**.
- لماذا لا يظهر كود لمبة ABS في جهاز فحص المحرك.

## الألوان أولًا

| اللون | المعنى |
|---|---|
| **أحمر** | خطر: توقف بأمان في أقرب مكان، وافحص قبل أن تكمل (حرارة، ضغط زيت، فرامل، شحن) |
| **أصفر / برتقالي** | عطل يحتاج فحصًا قريبًا؛ السيارة غالبًا تمشي بحذر |
| **أصفر يومض** | عطل خطير يحدث **الآن** (مثل احتراق ناقص شديد يتلف الشكمان): خفّف الحمل والسرعة فورًا |
| **أخضر / أزرق** | معلومة فقط: نظام يعمل (النور العالي، مثبت السرعة) |

عند تشغيل الإشعال تنوّر كل اللمبات ثانيتين **للاختبار** ثم تنطفئ؛ المهم ما يبقى منوّرًا بعد دوران المحرك.

## أهم اللمبات

- **لمبة المحرك (Check Engine / MIL)**: كمبيوتر المحرك سجّل عطلًا يؤثر على الانبعاثات أو الأداء. ثابتة = افحص قريبًا. **تومض** = احتراق ناقص شديد، خفّف فورًا.
- **ضغط الزيت** (إبريق الزيت، أحمر): توقف وأطفئ المحرك **فورًا**. المحرك بدون ضغط زيت يتلف في دقائق.
- **حرارة المحرك** (ترمومتر في سائل، أحمر): توقف وأطفئ المحرك، و**لا تفتح غطاء الردياتير وهو ساخن** - السائل تحت ضغط ويحرق.
- **البطارية / الشحن**: الدينامو لا يشحن. مع لمبة الحرارة معًا غالبًا **سير الدينامو** خرج أو انقطع.
- **الفرامل** (أحمر): فرامل اليد مشدودة، أو زيت الفرامل ناقص. لا تكمل إن كانت الفرامل ضعيفة.
- **ABS**: منع انغلاق العجل معطّل؛ الفرامل العادية تعمل لكن العجل قد يقفل في الفرملة القوية.
- **الوسائد الهوائية (SRS)**: قد لا تنفخ الوسائد عند الحادث. افحصها قريبًا.

## الدليل في RAD IDE

افتح **أدوات > دليل أعطال السيارة...** (أو تبويب **الدليل** داخل منضدة التشخيص) ثم **لمبات التحذير**. اضغط على كل لمبة تراها في التابلوه؛ يظهر لكل واحدة لونها ومعناها **وماذا تفعل الآن**، وتنبيهات **التركيبات** (البطارية + الحرارة = السير)، والأكواد المحتملة وراءها، والبيانات الحية التي تستحق المراقبة.

إذا كنت **متصلًا بالسيارة** اضغط **اقرأ لمبات العربية**: لمبة المحرك تُقرأ من OBD-II في كل السيارات، وفي السيارة التجريبية تُقرأ باقي اللمبات من لوحة العدادات، ولمبتا ABS والوسائد تُستنتجان من أعطال وحداتهما بعد «فحص كل وحدات التحكم». (معرّف اللمبات في لوحة العدادات يختلف من شركة لأخرى، فلا يمكن قراءته بطريقة موحّدة في كل السيارات.)

هذا ما يفعله الدليل للمبتي **البطارية** و**الحرارة** معًا:

```carpy run
from radide.cardiag.kb import lights

result = lights.pick(["battery", "coolant"], lang="ar")
print("توقف فورًا؟", result["stop"])
for text in result["advice"]:
    print("-", text)
print("معًا:", result["combos"][0])
print("أكواد محتملة:", ", ".join(code for code, _score in result["codes"][:4]))
```

```text output
توقف فورًا؟ True
- البطارية / الشحن: أطفئ الأحمال غير الضرورية (التكييف، تدفئة الكراسي، الراديو) واذهب للورشة أو البيت بدون إطفاء المحرك. لو جاءت لمبة البطارية مع سخونية فقد يكون السير مقطوعًا - توقف.
- حرارة المحرك (سائل التبريد): توقف بأمان وأطفئ المحرك. لا تفتح غطاء الردياتير أو قربة المياه وهو ساخن - السائل تحت ضغط وقد يحرقك. اتركه يبرد 30 دقيقة على الأقل ثم افحص المستوى والمروحة والتسريب.
معًا: البطارية والحرارة معًا غالبًا معناهما أن سير الدينامو خرج أو انقطع: يقف الدينامو وفي كثير من المحركات طلمبة المياه أيضًا. أطفئ المحرك وافحص السير.
أكواد محتملة: P0217, P0562, P0118, P0563
```

## اللمبات المنوّرة في السيارة التجريبية

السيارة التجريبية تحسب لمباتها من حالتها: أعطالها، والإشعال، والحرارة، وموعد الصيانة. وتحفظها لوحة العدادات في قيمة UDS (المعرّف `2220`) كل بت فيها لمبة. هكذا يقرؤها زر **اقرأ لمبات العربية**:

```carpy run
from radide.cardiag.sim.car import VirtualCar, LAMPS
from radide.cardiag.link import demo_link
from radide.cardiag.link.uds import UdsClient

car = VirtualCar(time_scale=0)
link = demo_link(car)
cluster = UdsClient(link, 0x720, 0x728)            # لوحة العدادات في السيارة التجريبية
bits = int.from_bytes(cluster.read_did(0x2220)[:2], "big")
print(f"قيمة اللمبات: {bits:010b}")
for bit, key, _en, ar in LAMPS:
    if bits >> bit & 1:
        print(f"  منوّرة: {ar}")

car.set_overheat(True)                             # نجعل المحرك يسخن في لوحة السيارة التجريبية
car.coolant = 121.0
bits = int.from_bytes(cluster.read_did(0x2220)[:2], "big")
print("بعد السخونة، لمبة الحرارة منوّرة؟", bool(bits >> 5 & 1))
link.close()
```

```text output
قيمة اللمبات: 1010000111
  منوّرة: لمبة فحص المحرك (MIL)
  منوّرة: لمبة ABS
  منوّرة: لمبة الوسائد الهوائية (SRS)
  منوّرة: لمبة موعد الصيانة
  منوّرة: لمبة ESP / التحكم في الجر
بعد السخونة، لمبة الحرارة منوّرة؟ True
```

لاحظ **لمبة الصيانة**: موعد الصيانة فات في السيارة التجريبية (‎-350 كم). تصفيرها **بعد** تغيير الزيت وظيفة خدمة عادية (الدرس 7). ولمبة **ESP** منوّرة لأن عطل حساس سرعة العجل في وحدة ABS يعطّل نظام الثبات أيضًا.

### تمرين

```python exercise
COLOURS = {"mil": "amber", "oil": "red", "coolant": "red", "battery": "red", "abs": "amber",
           "airbag": "amber", "brake": "red", "service": "amber"}


def urgent(lamps):
    # أرجع اللمبات الحمراء فقط بنفس الترتيب
    return []


print(urgent(["mil", "oil", "abs", "battery"]))
```

```python solution
COLOURS = {"mil": "amber", "oil": "red", "coolant": "red", "battery": "red", "abs": "amber",
           "airbag": "amber", "brake": "red", "service": "amber"}


def urgent(lamps):
    return [x for x in lamps if COLOURS.get(x) == "red"]


print(urgent(["mil", "oil", "abs", "battery"]))
```

```text output
['oil', 'battery']
```

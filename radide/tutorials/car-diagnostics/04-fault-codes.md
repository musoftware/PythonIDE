# الدرس 4: قراءة أكواد الأعطال وفهمها

**في هذا الدرس:**

- كيف يُقرأ الكود `P0171`: الحرف والأرقام.
- **مخزّن** و**معلّق** و**دائم**: ما الفرق ولماذا يهمك.
- قراءة الأكواد في **تبويب الأعطال** و**فحص كل وحدات التحكم**.
- قاعدة المعارف: الشرح والأسباب وخطوات الفحص و«هل القيادة آمنة؟».
- أكواد UDS ذات **بايت نوع العطل** (`C0035-1F`) والأكواد **الخاصة بالشركة**.

## تشريح الكود

كل كود خمسة رموز:

| الموضع | المعنى |
|---|---|
| الحرف | `P` المحرك وناقل الحركة، `C` الشاسيه (فرامل، توجيه، تعليق)، `B` الهيكل (وسائد، تكييف، أبواب)، `U` الاتصال بين الوحدات |
| الرقم الأول | `0` أو `2` أو `3` (في بعض المجالات): **موحّد** لكل السيارات (SAE J2012)، `1`: **خاص بالشركة** المصنّعة |
| الرقم الثاني (في P0xxx) | المجموعة: `1`/`2` الوقود والهواء، `3` الإشعال والاحتراق الناقص، `4` الانبعاثات المساعدة، `5` السرعة والخامل، `6` الكمبيوتر، `7`/`8`/`9` ناقل الحركة |
| آخر رقمين | العطل المحدد |

مثال: `P0301` = محرك، موحّد، مجموعة الإشعال، **الأسطوانة 1** فيها احتراق ناقص. و`P0302` الأسطوانة 2 وهكذا.

داخل الكمبيوتر الكود **بايتان** فقط: أعلى بتين في البايت الأول للحرف (`00`=P، `01`=C، `10`=B، `11`=U)، ثم البتان التاليان للرقم الأول، والباقي أرقام سادس عشرية:

```python run
def dtc(a: int, b: int) -> str:
    letter = "PCBU"[a >> 6]
    return f"{letter}{(a >> 4) & 0x3}{a & 0x0F:X}{b:02X}"


reply = bytes.fromhex("43 02 03 01 04 20")      # رد الوضع 03: عدد الأكواد ثم كل كود بايتان
count = reply[1]
for i in range(count):
    a, b = reply[2 + 2 * i], reply[3 + 2 * i]
    print(f"{a:02X} {b:02X} -> {dtc(a, b)}")
```

```text output
03 01 -> P0301
04 20 -> P0420
```

## مخزّن ومعلّق ودائم

- **مخزّن (مؤكَّد)** - الوضع 03: العطل تكرر في دورات قيادة كافية فأكّده الكمبيوتر، وغالبًا تنوّر لمبة المحرك.
- **معلّق** - الوضع 07: ظهر مرة واحدة ولم يتأكد بعد. **إنذار مبكر**: لو تكرر يصبح مخزّنًا.
- **دائم** - الوضع 0A: نسخة من عطل انبعاثات مؤكَّد **لا يمسحها أي جهاز فحص**. الكمبيوتر يمسحه بنفسه بعد الإصلاح عندما يعيد اختباره وينجح. مراكز الفحص الفني تنظر إليه.

## في RAD IDE

في منضدة التشخيص، تبويب **الأعطال**: **قراءة الأكواد** تقرأ أكواد المحرك (OBD-II)، و**فحص كل وحدات التحكم** يقرأ أيضًا أعطال الفرامل والوسائد ولوحة العدادات والتكييف (UDS). اضغط على أي كود فيظهر بجانبه: العنوان بالعربية، والنظام، وهل يخص **السلامة** (بالأحمر: فرامل، وسائد، توجيه، سخونة)، والشرح، **والأسباب المحتملة** مرتبة من الأشهر، **وما يجب فحصه** خطوة خطوة، ومعنى حالته. ومن **أدوات > دليل أعطال السيارة...** تبحث في أكثر من 1200 كود بالكود أو بكلمات عربية عامية («مش بتدور»، «بتسخن»).

نفس الخطوات بالكود: قراءة كل الأكواد ثم الشرح من قاعدة المعارف:

```carpy run
from radide.cardiag.sim.car import VirtualCar
from radide.cardiag.link import demo_link
from radide.cardiag.obd.client import ObdClient
from radide.cardiag.obd.transport import LinkTransport
from radide.cardiag import kb

STATUS = {"stored": "مخزّن", "pending": "معلّق", "permanent": "دائم"}
link = demo_link(VirtualCar(time_scale=0))
obd = ObdClient(LinkTransport(link))
for entry in obd.read_all_dtcs():                  # الأوضاع 03 و 07 و 0A معًا
    info = kb.lookup(entry.code)
    kinds = "، ".join(STATUS[k] for k in ("stored", "pending", "permanent") if k in entry.kinds)
    print(f"{entry.code}  [{kinds}]  {info['title_ar']}")

info = kb.lookup("P0171")
print()
print(info["explain_ar"])
print("الأسباب المحتملة:")
for cause in info["causes_ar"][:3]:
    print("  -", cause)
print("الخطورة:", info["severity_text_ar"])
link.close()
```

```text output
P0301  [مخزّن، معلّق، دائم]  احتراق ناقص في الأسطوانة 1
P0420  [مخزّن، دائم]  كفاءة نظام المحوّل الحفزي أقل من الحد (البنك 1)
P0171  [معلّق]  النظام فقير جدًا (خليط فقير) (البنك 1)

يوجد هواء زائد أو وقود ناقص - اضطر الكمبيوتر لإضافة وقود كثير (تصحيح موجب) ووصل إلى حده. أشهر سبب تسريب هواء بعد حساس تدفق الهواء، يليه ضغط وقود منخفض وحساس MAF متسخ.
الأسباب المحتملة:
  - تسريب هواء بعد حساس تدفق الهواء (خرطوم مشروخ، جوان المنفولد، صمام PCV، خرطوم مقوي الفرامل)
  - حساس تدفق الهواء (MAF) متسخ أو تالف
  - ضغط بنزين منخفض (طرمبة ضعيفة، فلتر مسدود، منظم ضغط تالف)
الخطورة: متوسطة - افحصه قريبًا
```

لاحظ: `P0171` **معلّق** فقط، ولذلك لا يظهر في الوضع 03. أجهزة الفحص البسيطة التي تقرأ الوضع 03 وحده تفوّته.

## أعطال باقي الوحدات وبايت نوع العطل

في UDS الكود **ثلاثة بايتات**: البايتان المعروفان + **بايت نوع العطل** (FTB) يقول **ماذا** حدث بالضبط. `C0035-1F` = حساس سرعة العجلة الأمامية اليسرى + `1F` «الدائرة متقطعة» (سلك يفصل ويوصل)، وهذا يختلف تمامًا عن `C0035-11` «قصر للأرضي». ومع كل كود **بايت حالة** بتاته تقول: مؤكَّد، معلّق، العطل موجود الآن، طلب تشغيل لمبة التحذير...

```carpy run
from radide.cardiag.sim.car import VirtualCar
from radide.cardiag.link import demo_link
from radide.cardiag.link.uds import UdsClient
from radide.cardiag import kb

link = demo_link(VirtualCar(time_scale=0))
for name, tx, rx in (("الفرامل ABS", 0x760, 0x768), ("الوسائد الهوائية", 0x770, 0x778), ("التكييف", 0x744, 0x74C)):
    for d in UdsClient(link, tx, rx).read_dtcs(0xFF):      # الخدمة 19 02
        info = kb.lookup(d.text)
        state = "مؤكَّد" if d.confirmed else ("معلّق" if d.pending else "سابق")
        print(f"{name}: {d.text}  [{state}, لمبة={'نعم' if d.mil else 'لا'}]")
        print(f"   {info['title_ar']} - {info['ftb_text'][1]}")
        if info["safety"]:
            print("   يخص السلامة: لا تمسحه قبل الإصلاح والتجربة")
link.close()
```

```text output
الفرامل ABS: C0035-1F  [مؤكَّد, لمبة=نعم]
   حساس سرعة العجلة الأمامية اليسرى - الدائرة - الدائرة متقطعة (تفصل وتوصل)
   يخص السلامة: لا تمسحه قبل الإصلاح والتجربة
الوسائد الهوائية: B0001-1A  [مؤكَّد, لمبة=نعم]
   التحكم في فتح الوسادة الأمامية للسائق - المرحلة 1 - مقاومة الدائرة أقل من الحد
   يخص السلامة: لا تمسحه قبل الإصلاح والتجربة
التكييف: B1424-00  [مؤكَّد, لمبة=لا]
   كود خاص بالشركة المصنّعة - المعنى يختلف - لا توجد معلومات تفصيلية
```

`B1424` كود **خاص بالشركة** (الرقم الأول 1): معناه يختلف من شركة لأخرى، فلا يخمّن RAD IDE معناه. إن كان عندك جدول الشركة استورده (CSV أو JSON) من **دليل أعطال السيارة > أكواد الأعطال > استيراد**، فيظهر وصفه بعد ذلك.

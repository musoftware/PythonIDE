# الدرس 6: اختبارات الجاهزية (Readiness) ودورة القيادة

**في هذا الدرس:**

- ما هي **اختبارات المراقبة** (Monitors) التي يجريها كمبيوتر المحرك بنفسه.
- **مكتمل** و**غير مكتمل**، والاختبارات **المستمرة** وغير المستمرة.
- لماذا **مسح الأكواد** قبل الفحص الفني يجعل السيارة **ترسب** ولا يخفي شيئًا.
- **دورة القيادة** التي تُكمل الاختبارات.

## الكمبيوتر يختبر نفسه

كمبيوتر المحرك لا ينتظر العطل حتى يحدث؛ هو يجري **اختبارات** على أنظمة الانبعاثات أثناء القيادة:

- **مستمرة** (تعمل طول الوقت): الاحتراق الناقص، نظام الوقود، المكوّنات الشاملة (الحساسات والدوائر).
- **غير مستمرة** (تحتاج ظروفًا معينة، مرة كل مشوار): المحوّل الحفزي (الكتلايزر)، نظام تبخر الوقود (EVAP)، حساس الأكسجين وسخّانه، EGR، وفي الديزل فلتر الجزيئات و NOx.

كل اختبار حالته **مكتمل** (جرى ونجح أو فشل وسجّل كوده) أو **غير مكتمل** (لم تتوفر ظروفه بعد). الوضع `01` الـ PID ‏`01` يعطي الحالة **منذ آخر مسح للأكواد**، والـ PID ‏`41` حالة **دورة القيادة الحالية**.

## قراءة الجاهزية

في منضدة التشخيص تبويب **الجاهزية**: جدول بكل اختبار وحالته ونوعه، وبجانبه شرح الاختبار وماذا يحتاج ليكتمل، وسطر ملخص: لمبة المحرك، عدد الأكواد المؤكدة، والاختبارات غير الجاهزة.

```carpy run
from radide.cardiag.sim.car import VirtualCar
from radide.cardiag.link import demo_link
from radide.cardiag.obd.client import ObdClient
from radide.cardiag.obd.transport import LinkTransport
from radide.cardiag.obd import readiness as R

AR = {"misfire": "الاحتراق الناقص", "fuel": "نظام الوقود", "components": "المكوّنات الشاملة",
      "catalyst": "المحوّل الحفزي", "evap": "تبخر الوقود EVAP", "o2_sensor": "حساس الأكسجين",
      "o2_heater": "سخّان حساس الأكسجين"}
link = demo_link(VirtualCar(time_scale=0))
obd = ObdClient(LinkTransport(link))
for ecu, st in obd.readiness().items():
    print(f"لمبة المحرك: {'منوّرة' if st.mil else 'مطفأة'} - أكواد مؤكدة: {st.dtc_count}")
    for m in st.monitors:
        if m.supported:
            kind = "مستمر" if m.continuous else "غير مستمر"
            print(f"  {AR[m.key]:20} {'مكتمل' if m.complete else 'غير مكتمل':10} {kind}")
print()
print(R.explain("evap", arabic=True))
link.close()
```


## المسح يعيد كل شيء إلى «غير مكتمل»

عند مسح الأكواد (الوضع 04، أو مسح أي عطل انبعاثات بـ UDS في أغلب السيارات) **ترجع كل الاختبارات «غير مكتملة»**، وتُمسح لقطة التجميد ونتائج الوضع 06. هذا مقصود في المعيار: الكمبيوتر يجب أن يتأكد من جديد أن كل شيء سليم.

```carpy run
from radide.cardiag.sim.car import VirtualCar
from radide.cardiag.link import demo_link
from radide.cardiag.obd.client import ObdClient
from radide.cardiag.obd.transport import LinkTransport

car = VirtualCar(time_scale=0)
link = demo_link(car)
obd = ObdClient(LinkTransport(link))


def summary():
    st = obd.readiness()["7E8"]
    done = sum(1 for m in st.monitors if m.supported and m.complete)
    total = sum(1 for m in st.monitors if m.supported)
    return f"{done} من {total} مكتملة"


print("قبل المسح:", summary())
print("المسح والمحرك دائر:", obd.clear_dtcs())          # كثير من السيارات ترفض
car.stop_engine()
print("المسح والمحرك مطفأ:", obd.clear_dtcs())
print("بعد المسح:", summary())
print("الأكواد الباقية:", [e.code for e in obd.read_all_dtcs()])
link.close()
```

```text output
قبل المسح: 6 من 7 مكتملة
المسح والمحرك دائر: {'7E8': False}
المسح والمحرك مطفأ: {'7E8': True}
بعد المسح: 0 من 7 مكتملة
الأكواد الباقية: ['P0301', 'P0420']
```

لاحظ ثلاثة أشياء: السيارة **رفضت** المسح والمحرك دائر، وبعد المسح صارت **كل** الاختبارات غير مكتملة (المستمرة تكتمل من جديد بعد دقائق من القيادة، وغير المستمرة تحتاج دورة قيادة)، والكودان **الدائمان** `P0301` و `P0420` **باقيان** - لا يمسحهما جهاز فحص، فقط الكمبيوتر بعد الإصلاح.

## لماذا لا يفيد المسح قبل الفحص الفني

برامج الفحص الفني الحديثة تقرأ الجاهزية والأكواد الدائمة. سيارة مُسحت أكوادها أمس **ترسب** لأن اختباراتها غير مكتملة، والكود الدائم يكشف العطل حتى لو اللمبة مطفأة. لذلك الطريق الوحيد: **أصلح السبب**، ثم امسح، ثم قُد السيارة قيادة عادية حتى تكتمل الاختبارات. RAD IDE **لا يقدم** أي طريقة لتزييف الجاهزية أو إخفاء الأكواد الدائمة.

## دورة القيادة

الاختبارات غير المستمرة تحتاج ظروفًا: محرك بدأ باردًا، سرعة ثابتة، تهدئة بدون فرامل، وقود بين الربع والثلاثة أرباع. هذه دورة عامة تُكمل أغلبها (الدورة الدقيقة في كتيب صيانة السيارة)، وتظهر أيضًا في تبويب الجاهزية:

1. تشغيل على البارد بعد وقوف طوال الليل، ودوران خامل 2-3 دقائق مع الأنوار والتكييف.
2. تسارع هادئ حتى 90 كم/س وثبات 3-5 دقائق.
3. تهدئة حتى 30 كم/س تقريبًا **بدون** فرملة قوية وبدون الدبرياج.
4. تسارع وثبات على 70-90 كم/س لمدة 5 دقائق.
5. توقف ودوران خامل دقيقتين.

ودائمًا **في حدود قواعد المرور** وعلى طريق مناسب. اختيار **دورة القيادة الحالية (01 41)** في تبويب الجاهزية يريك ما اكتمل في هذا المشوار بالذات.

### تمرين

بايتات الـ PID ‏`01`: البايت A فيه لمبة المحرك (البت 7) وعدد الأكواد (البتات 0-6). اكتب دالة تفك `A` وتطبع الحالة لـ `0x82` و `0x00`.

```python exercise
def status_a(a: int) -> str:
    # mil = البت 7، count = البتات 0-6
    return ""


print(status_a(0x82))
print(status_a(0x00))
```

```python solution
def status_a(a: int) -> str:
    mil = bool(a & 0x80)
    count = a & 0x7F
    return f"لمبة المحرك {'منوّرة' if mil else 'مطفأة'}، عدد الأكواد {count}"


print(status_a(0x82))
print(status_a(0x00))
```

```text output
لمبة المحرك منوّرة، عدد الأكواد 2
لمبة المحرك مطفأة، عدد الأكواد 0
```

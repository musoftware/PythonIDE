# الدرس 1: مرحبًا بك في Lua: برنامجك الأول

**Lua** (تُنطق «لوا»، ومعناها «القمر» بالبرتغالية) لغة برمجة صغيرة وسريعة صُنعت في البرازيل سنة 1993. حجم المفسّر كله أقل من ميجابايت واحد، ولذلك تُدمج داخل برامج وألعاب كثيرة لتكون «لغة الإضافات» فيها.

> **تشبيه:** إذا كانت بعض اللغات مثل شاحنة كبيرة فيها كل شيء، فإن Lua مثل **دراجة خفيفة**: قطع قليلة، لكنها تصل بك إلى أي مكان، وتُحمل بسهولة داخل سيارة أخرى.

## أين تُستخدم Lua؟

- **الألعاب:** Roblox (بلغة Luau المشتقة منها)، وإطار LÖVE، وإضافات World of Warcraft.
- **البرامج:** إضافات محرر Neovim، وبرنامج Adobe Lightroom، وخوادم Nginx عبر OpenResty.
- **الأجهزة الصغيرة:** لأنها خفيفة جدًا.

## كيف تعمل الأمثلة؟

اضغط **«▶ جرّبه»** تحت أي مثال: تنشئ الـ IDE مشروع Lua صغيرًا وتشغله، ويظهر الناتج في نافذة **Output** (المخرجات). وتستخدم الـ IDE مفسّر Lua 5.4 المثبت في `%LOCALAPPDATA%\RADIDE\toolchains\lua`.

## برنامجك الأول

```lua run
print("Hello, World!")
print("مرحبًا بك في Lua")
```

```text output
Hello, World!
مرحبًا بك في Lua
```

الدالة `print` تطبع ما بين القوسين ثم تنزل سطرًا جديدًا. والنص يُكتب بين علامتي تنصيص مزدوجتين `"..."` أو مفردتين `'...'`.

## طباعة عدة قيم

```lua run
print("العمر:", 20)
print("أ" .. "ب" .. "ج")
print("النتيجة: " .. 5 * 4)
io.write("بدون ", "سطر جديد")
io.write("\n")
```

```text output
العمر:	20
أبج
النتيجة: 20
بدون سطر جديد
```

- إذا أعطيت `print` عدة قيم مفصولة بفواصل، تطبعها وبينها مسافة جدولة (Tab).
- العامل `..` (نقطتان) **يلصق** النصوص ببعضها، ويحوّل الأرقام إلى نصوص تلقائيًا.
- `io.write` تطبع دون أن تنزل سطرًا، و`"\n"` رمز السطر الجديد.

## Lua آلة حاسبة

```lua run
print(2 + 3)
print(10 - 4)
print(6 * 7)
print(7 / 2)
print(8 / 2)
print(7 // 2)
print(7 % 2)
print(2 ^ 10)
```

```text output
5
6
42
3.5
4.0
3
1
1024.0
```

لاحظ:

- `/` تعطي دائمًا **عددًا عشريًا**: `8 / 2` تساوي `4.0` وليس `4`.
- `//` قسمة صحيحة (تُهمل الكسر)، و`%` باقي القسمة.
- `^` للأس، ونتيجتها عشرية دائمًا.

## التعليقات

```lua run
-- هذا تعليق من سطر واحد
print("سطر يعمل") -- تعليق في آخر السطر
--[[
تعليق
من عدة أسطر
]]
-- print("هذا السطر معطل")
```

```text output
سطر يعمل
```

## مشروعك الخاص في RAD IDE

1. **File > New Project...** (ملف > مشروع جديد...).
2. من مجموعة **Scripting** اختر **Lua (GUI Bridge)** (Lua - جسر الواجهة)، وسمّ المشروع.
3. ينشئ المشروع نافذة `Form1`. لبرنامج نصي بدون نوافذ: **Project > Add Module...** (مشروع > إضافة وحدة برمجية...) باسم `main`، ثم انقر بالزر الأيمن على `Form1` في **Solution Explorer** (مستكشف الحلول) واختر **Remove from Project** (إزالة من المشروع).
4. اكتب الكود في `main.lua` واضغط **Ctrl+F5**: المشروع الذي ليس فيه نوافذ يعمل كبرنامج كونسول، ويظهر ناتجه في **Output**.

## أخطاء شائعة

### استخدام `+` لجمع النصوص

<!-- compile-error -->
```lua
print("أهلًا " + "علي")
```

النتيجة خطأ: `attempt to perform arithmetic on a string value`، أي «محاولة إجراء عملية حسابية على نص». في Lua يُلصق النص بـ `..` وليس بـ `+`.

### نسيان علامة التنصيص

`print("Hello)` تعطي `unfinished string near '"Hello)'`، أي «نص غير مكتمل». أغلق النص.

### كتابة `Print` بحرف كبير

Lua حساسة لحالة الأحرف: `Print` ليست `print`، وستظهر `attempt to call a nil value (global 'Print')`.

## تمارين

### التمرين 1

اطبع بطاقة من ثلاثة أسطر: الاسم، والهواية، واللغة التي تتعلمها (Lua).

```lua exercise
-- الاسم: يوسف
-- الهواية: كرة القدم
-- أتعلم: Lua
```

```lua solution
print("الاسم: يوسف")
print("الهواية: كرة القدم")
print("أتعلم: Lua")
```

```text output
الاسم: يوسف
الهواية: كرة القدم
أتعلم: Lua
```

### التمرين 2

احسب عدد الدقائق في أسبوع، واطبع: `في الأسبوع 10080 دقيقة` باستخدام `..`.

```lua exercise
-- 7 أيام × 24 ساعة × 60 دقيقة
```

```lua solution
print("في الأسبوع " .. 7 * 24 * 60 .. " دقيقة")
```

```text output
في الأسبوع 10080 دقيقة
```

## الخلاصة

- Lua لغة صغيرة وسريعة تُدمج في الألعاب والبرامج.
- `print` للطباعة مع سطر جديد، و`io.write` بدونه، و`..` لإلصاق النصوص.
- `/` قسمة عشرية دائمًا، و`//` قسمة صحيحة، و`%` باقي القسمة، و`^` للأس.
- التعليق يبدأ بـ `--`.

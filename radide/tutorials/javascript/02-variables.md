# الدرس 2: المتغيرات وأنواع البيانات

**في هذا الدرس ستتعلم:**

- ما هو **المتغير**، وكيف تنشئه بـ `let` و`const`.
- أنواع البيانات الأساسية: الأعداد، والنصوص، والقيم المنطقية، و`undefined` و`null`.
- كيف تعرف نوع أي قيمة بـ `typeof`.
- كيف تدمج المتغيرات داخل النص بـ **قوالب النصوص** (template literals).

## ما هو المتغير؟

**المتغير** (variable) صندوق له اسم، نضع فيه قيمة لنستخدمها لاحقًا.

> **تشبيه:** تخيّل علبة مكتوبًا عليها «العمر» وبداخلها ورقة عليها الرقم `20`. كلما احتجت إلى العمر نظرت داخل العلبة، ويمكنك أن تغيّر الورقة متى شئت.

في JavaScript ننشئ المتغير بالكلمة `let`:

```js run
let age = 20;
let name = "سارة";
console.log(name);
console.log(age);

age = 21;            // غيّرنا القيمة
console.log("العمر الجديد:", age);
```

```text output
سارة
20
العمر الجديد: 21
```

- `let age = 20;` تعني: أنشئ صندوقًا اسمه `age` وضع فيه `20`.
- علامة `=` هنا معناها **إسناد** (ضع القيمة في الصندوق)، وليست «يساوي» كما في الرياضيات.
- عند التغيير لا نكتب `let` مرة ثانية: `age = 21;`.

## الثوابت بـ `const`

إذا كانت القيمة لن تتغير أبدًا نستخدم `const` (اختصار constant، أي **ثابت**):

```js run
const PI = 3.14159;
const country = "مصر";
console.log(country, PI);
```

```text output
مصر 3.14159
```

ومحاولة تغيير الثابت خطأ:

```js
const PI = 3.14;
PI = 3;      // TypeError: Assignment to constant variable.
```

> **قاعدة ذهبية:** ابدأ دائمًا بـ `const`، ولا تستخدم `let` إلا إذا احتجت فعلًا إلى تغيير القيمة. هكذا يصبح الكود أوضح وأقل أخطاءً.

ستجد في الكتب القديمة الكلمة `var`. هي الطريقة القديمة لإنشاء المتغيرات ولها سلوك مربك، فلا تستخدمها في الكود الجديد.

## قواعد تسمية المتغيرات

- يبدأ الاسم بحرف أو `_` أو `$`، ولا يبدأ برقم: `total1` صحيح، و`1total` خطأ.
- لا مسافات داخل الاسم. المتعارف عليه في JavaScript طريقة **camelCase**: الكلمة الأولى بحروف صغيرة وكل كلمة بعدها تبدأ بحرف كبير، مثل `firstName` و`totalPrice`.
- الأسماء حساسة لحالة الأحرف: `age` و`Age` متغيران مختلفان.
- لا تستخدم الكلمات المحجوزة مثل `let` و`if` و`function` أسماءً.
- اختر أسماء لها معنى: `price` أفضل بكثير من `p` أو `x`.

## أنواع البيانات

| النوع | مثال | الوصف |
|---|---|---|
| `number` | `42`، `3.5`، `-7` | الأعداد كلها، الصحيحة والعشرية |
| `string` | `"مرحبًا"`، `'Hi'` | النصوص، بين علامتي تنصيص |
| `boolean` | `true`، `false` | قيمة منطقية: صح أو خطأ |
| `undefined` | `undefined` | متغير لم نعطه قيمة بعد |
| `null` | `null` | «لا شيء» نضعه نحن عمدًا |

الأمر `typeof` يخبرك بنوع أي قيمة:

```js run
console.log(typeof 42);
console.log(typeof 3.5);
console.log(typeof "سلام");
console.log(typeof true);
let x;
console.log(x, typeof x);
console.log(typeof null);
```

```text output
number
number
string
boolean
undefined undefined
object
```

> **ملحوظة:** `typeof null` تعطي `"object"`. هذا خطأ تاريخي قديم في اللغة بقي كما هو حتى لا تتعطل المواقع القديمة. احفظه كما هو!

## النصوص (Strings)

يمكن كتابة النص بين `"..."` أو `'...'`، ولا فرق بينهما. ولربط النصوص نستخدم `+`:

```js run
const first = "أحمد";
const last = "علي";
console.log(first + " " + last);
console.log("طول الاسم:", first.length);
```

```text output
أحمد علي
طول الاسم: 4
```

`first.length` تعطي عدد حروف النص.

## قوالب النصوص (Template Literals)

الطريقة الحديثة والأجمل لدمج القيم داخل النص: نكتب النص بين علامتي **backtick** (العلامة `` ` `` الموجودة تحت مفتاح Esc)، ونضع أي قيمة أو عملية داخل `${...}`:

```js run
const product = "قلم";
const price = 5;
const count = 3;
console.log(`اشتريت ${count} ${product} بسعر ${price} جنيهات للواحد`);
console.log(`الإجمالي: ${price * count} جنيهًا`);
```

```text output
اشتريت 3 قلم بسعر 5 جنيهات للواحد
الإجمالي: 15 جنيهًا
```

وقوالب النصوص يمكن أن تمتد على أكثر من سطر:

```js run
const card = `الاسم: منى
المدينة: طنطا`;
console.log(card);
```

```text output
الاسم: منى
المدينة: طنطا
```

## رموز الهروب

داخل النص العادي توجد رموز خاصة تبدأ بالشرطة المائلة العكسية `\`:

| الرمز | معناه |
|---|---|
| `\n` | سطر جديد |
| `\t` | مسافة جدولة (Tab) |
| `\"` | علامة تنصيص داخل النص |
| `\\` | شرطة مائلة عكسية واحدة |

```js run
console.log("السطر الأول\nالسطر الثاني");
console.log("قال: \"مرحبًا\"");
console.log("C:\\Projects\\app.js");
```

```text output
السطر الأول
السطر الثاني
قال: "مرحبًا"
C:\Projects\app.js
```

## التحويل بين الأنواع

كثيرًا ما يأتيك العدد في صورة نص (من خانة نص في نافذة مثلًا)، فتحوّله بـ `Number(...)`، والعكس بـ `String(...)`:

```js run
const text = "25";
const n = Number(text);
console.log(n + 5);
console.log(text + 5);
console.log(Number("abc"));
console.log(String(99) + "!");
```

```text output
30
255
NaN
99!
```

- `"25" + 5` تعطي `"255"`: عندما يكون أحد الطرفين نصًا تتحول `+` إلى **ربط نصوص**.
- `NaN` اختصار Not a Number، أي «ليس رقمًا»، وتظهر عندما يفشل التحويل.

## أخطاء شائعة

- **استخدام متغير قبل إنشائه:** `console.log(total); let total = 5;` يعطي `ReferenceError: Cannot access 'total' before initialization`.
- **إعادة إنشاء المتغير نفسه:** كتابة `let age = 1;` مرتين في المكان نفسه تعطي `SyntaxError: Identifier 'age' has already been declared`. عند التغيير اكتب `age = 2;` فقط.
- **نسيان التحويل:** `"5" + "3"` تعطي `"53"` وليس `8`. حوّل بـ `Number` أولًا.
- **الخلط بين علامات التنصيص:** النص `"مرحبًا'` يبدأ بعلامة وينتهي بأخرى، وهذا خطأ.

## تمارين

### التمرين 1

أنشئ ثابتًا `name` فيه اسمك، ومتغيرًا `year` فيه سنة ميلادك `2005`، ثم اطبع الجملة التالية بقالب نصوص، مع حساب العمر في سنة 2025 داخل `${...}`:

```js exercise
// الناتج المطلوب:
// أنا سارة وعمري 20 سنة
```

```js solution
const name = "سارة";
let year = 2005;
console.log(`أنا ${name} وعمري ${2025 - year} سنة`);
```

```text output
أنا سارة وعمري 20 سنة
```

### التمرين 2

لديك نصّان `"12"` و`"30"`. حوّلهما إلى أعداد واطبع مجموعهما، ثم اطبع نوع الناتج.

```js exercise
const a = "12";
const b = "30";
// اطبع المجموع (42) ثم نوعه (number)
```

```js solution
const a = "12";
const b = "30";
const sum = Number(a) + Number(b);
console.log(sum);
console.log(typeof sum);
```

```text output
42
number
```

### التمرين 3

اطبع البطاقة التالية بأمر `console.log` **واحد**، مستخدمًا `\n` و`\t`:

```js exercise
// الاسم:	علي
// الدرجة:	95
```

```js solution
console.log("الاسم:\tعلي\nالدرجة:\t95");
```

```text output
الاسم:	علي
الدرجة:	95
```

## الخلاصة

- `let` لمتغير يتغير، و`const` لثابت، وابتعد عن `var`.
- الأنواع الأساسية: `number` و`string` و`boolean` و`undefined` و`null`، و`typeof` تكشف النوع.
- قوالب النصوص بين علامتي backtick مع `${...}` أوضح طريقة لدمج القيم.
- `Number(...)` و`String(...)` للتحويل، وانتبه إلى أن `+` مع نص تعني الربط.

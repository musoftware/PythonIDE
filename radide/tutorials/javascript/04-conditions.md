# الدرس 4: الشروط واتخاذ القرار

**في هذا الدرس ستتعلم:**

- الجملة الشرطية `if` و`else` و`else if`.
- الشروط المتداخلة.
- العامل الثلاثي `? :` لاختصار الشرط البسيط.
- جملة `switch` للاختيار بين حالات كثيرة.

## لماذا الشروط؟

حتى الآن كانت برامجنا تنفّذ كل الأسطر بالترتيب. لكن البرامج الحقيقية **تتخذ قرارات**: إن كانت كلمة المرور صحيحة افتح الحساب، وإلا اعرض رسالة خطأ.

> **تشبيه:** الشرط مثل مفترق طرق: إن كانت الإشارة خضراء تعبر، وإن كانت حمراء تقف.

## `if` البسيطة

```js run
const temperature = 35;
if (temperature > 30) {
    console.log("الجو حار، اشرب ماءً كثيرًا");
}
console.log("انتهى البرنامج");
```

```text output
الجو حار، اشرب ماءً كثيرًا
انتهى البرنامج
```

- الشرط يُكتب بين قوسين `( )` بعد `if`.
- التعليمات التي تُنفَّذ عند تحقق الشرط تُكتب بين القوسين المعقوصين `{ }`، ونسمّيها **الكتلة** (block).
- لو كانت الحرارة `25` لما طُبع السطر الأول، لكن «انتهى البرنامج» تُطبع في الحالتين.

## `if ... else`

```js run
const age = 15;
if (age >= 18) {
    console.log("يمكنك استخراج رخصة القيادة");
} else {
    console.log(`انتظر ${18 - age} سنوات أخرى`);
}
```

```text output
انتظر 3 سنوات أخرى
```

## `else if`: أكثر من احتمالين

```js run
const score = 77;
let grade;
if (score >= 90) {
    grade = "ممتاز";
} else if (score >= 80) {
    grade = "جيد جدًا";
} else if (score >= 65) {
    grade = "جيد";
} else if (score >= 50) {
    grade = "مقبول";
} else {
    grade = "راسب";
}
console.log(`الدرجة ${score}: ${grade}`);
```

```text output
الدرجة 77: جيد
```

تُفحص الشروط **من أعلى إلى أسفل**، وأول شرط يتحقق تُنفَّذ كتلته ويُتجاوز الباقي. لذلك رتّبنا الدرجات من الأعلى إلى الأدنى.

## شروط مركّبة ومتداخلة

```js run
const user = "admin";
const password = "1234";

if (user === "admin" && password === "1234") {
    console.log("أهلًا بالمدير");
} else {
    console.log("بيانات الدخول غير صحيحة");
}

const year = 2024;
if (year % 4 === 0) {
    if (year % 100 !== 0 || year % 400 === 0) {
        console.log(`${year} سنة كبيسة`);
    } else {
        console.log(`${year} ليست كبيسة`);
    }
} else {
    console.log(`${year} ليست كبيسة`);
}
```

```text output
أهلًا بالمدير
2024 سنة كبيسة
```

> **نصيحة:** إذا تعمّق التداخل كثيرًا يصعب قراءة الكود. حاول دمج الشروط بـ `&&` و`||` عندما يكون ذلك ممكنًا.

## العامل الثلاثي `? :`

لاختيار قيمة من اثنتين في سطر واحد:

```js run
const n = 7;
const kind = n % 2 === 0 ? "زوجي" : "فردي";
console.log(`${n} عدد ${kind}`);

const items = 1;
console.log(`لديك ${items} ${items === 1 ? "رسالة" : "رسائل"}`);
```

```text output
7 عدد فردي
لديك 1 رسالة
```

الصيغة: `الشرط ? القيمة_إن_تحقق : القيمة_إن_لم_يتحقق`. استخدمه للقيم البسيطة فقط، أما الكتل الطويلة فمكانها `if`.

## `switch`: الاختيار بين حالات

عندما تقارن قيمة واحدة بقيم كثيرة ثابتة، يكون `switch` أوضح من سلسلة `else if`:

```js run
const day = 5;
let name;
switch (day) {
    case 1:
        name = "السبت";
        break;
    case 2:
        name = "الأحد";
        break;
    case 6:
    case 7:
        name = "نهاية الأسبوع";
        break;
    default:
        name = "يوم عمل";
}
console.log(name);
```

```text output
يوم عمل
```

- `switch` تقارن بـ `===`.
- `break` تخرج من `switch`. إن نسيتها يكمل التنفيذ في الحالة التالية!
- يمكن جمع عدة حالات لكتلة واحدة مثل `case 6:` و`case 7:`.
- `default` تُنفَّذ إن لم تطابق أي حالة.

## أخطاء شائعة

### كتابة `=` بدل `===`

```js
let x = 5;
if (x = 10) {          // خطأ منطقي: هذا إسناد وليس مقارنة!
    console.log("x تساوي 10");
}
```

هذا الكود لا يعطي رسالة خطأ، لكنه يضع `10` في `x` ويعتبر الشرط صحيحًا دائمًا. اكتب `if (x === 10)`.

### نسيان `break` في `switch`

```js run
const color = "أحمر";
switch (color) {
    case "أحمر":
        console.log("قف");
    case "أصفر":
        console.log("استعد");
        break;
    default:
        console.log("انطلق");
}
```

```text output
قف
استعد
```

طُبعت «استعد» أيضًا لأننا نسينا `break` بعد الحالة الأولى.

### الفاصلة المنقوطة بعد `if`

`if (age > 18); { ... }` الفاصلة المنقوطة هنا تنهي جملة `if` فورًا، فتُنفَّذ الكتلة دائمًا. لا تضع `;` بعد قوس الشرط.

## تمارين

### التمرين 1

اكتب برنامجًا يطبع حالة الطقس حسب الحرارة `t`: أقل من 10 «بارد»، من 10 إلى أقل من 25 «معتدل»، و25 فأكثر «حار».

```js exercise
const t = 18;
// الناتج المطلوب: معتدل
```

```js solution
const t = 18;
if (t < 10) {
    console.log("بارد");
} else if (t < 25) {
    console.log("معتدل");
} else {
    console.log("حار");
}
```

```text output
معتدل
```

### التمرين 2

آلة حاسبة صغيرة: حسب قيمة `op` (`"+"` أو `"-"` أو `"*"` أو `"/"`) اطبع ناتج العملية على `a` و`b` باستخدام `switch`، وإن كانت العملية غير معروفة اطبع «عملية غير معروفة».

```js exercise
const a = 12, b = 4;
const op = "*";
// الناتج المطلوب: 12 * 4 = 48
```

```js solution
const a = 12, b = 4;
const op = "*";
let result;
switch (op) {
    case "+": result = a + b; break;
    case "-": result = a - b; break;
    case "*": result = a * b; break;
    case "/": result = a / b; break;
    default: result = null;
}
if (result === null) {
    console.log("عملية غير معروفة");
} else {
    console.log(`${a} ${op} ${b} = ${result}`);
}
```

```text output
12 * 4 = 48
```

### التمرين 3

باستخدام العامل الثلاثي، اطبع «ناجح» إن كانت الدرجة `50` فأكثر، وإلا «راسب».

```js exercise
const mark = 42;
// الناتج المطلوب: راسب
```

```js solution
const mark = 42;
console.log(mark >= 50 ? "ناجح" : "راسب");
```

```text output
راسب
```

## الخلاصة

- `if (شرط) { ... } else if (...) { ... } else { ... }` لاتخاذ القرار.
- العامل الثلاثي `شرط ? أ : ب` لاختيار قيمة بسيطة.
- `switch` للمقارنة بقيم ثابتة كثيرة، ولا تنسَ `break`.
- قارن بـ `===`، ولا تضع `;` بعد قوس الشرط.

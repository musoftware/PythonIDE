# الدرس 5: حلقات التكرار

**في هذا الدرس ستتعلم:**

- حلقة التكرار `for` بعدّاد.
- حلقتا `while` و`do ... while`.
- حلقة `for ... of` للمرور على عناصر نص أو مصفوفة.
- التحكم في الحلقة بـ `break` و`continue`.
- الحلقات المتداخلة.

## لماذا حلقات التكرار؟

لو أردت طباعة الأرقام من 1 إلى 100، هل ستكتب `console.log` مئة مرة؟ **حلقة التكرار** (loop) تكرر مجموعة من التعليمات عددًا من المرات، أو ما دام شرط ما متحققًا.

> **تشبيه:** المدرّب يقول للاعب: «اجرِ حول الملعب 5 لفّات». اللاعب لا يحتاج إلى خمسة أوامر منفصلة، بل يعدّ اللفّات حتى يصل إلى 5.

## حلقة `for`

```js run
for (let i = 1; i <= 5; i++) {
    console.log("اللفة رقم", i);
}
```

```text output
اللفة رقم 1
اللفة رقم 2
اللفة رقم 3
اللفة رقم 4
اللفة رقم 5
```

بين القوسين ثلاثة أجزاء تفصلها `;`:

1. **البداية** `let i = 1`: تُنفَّذ مرة واحدة قبل الحلقة.
2. **الشرط** `i <= 5`: يُفحص قبل كل دورة، وإن أصبح خطأً تنتهي الحلقة.
3. **الخطوة** `i++`: تُنفَّذ بعد كل دورة.

يمكن العدّ تنازليًا أو بخطوات أكبر:

```js run
for (let i = 10; i >= 0; i -= 2) {
    console.log(i);
}
```

```text output
10
8
6
4
2
0
```

### مثال: المجموع وجدول الضرب

```js run
let sum = 0;
for (let i = 1; i <= 100; i++) {
    sum += i;
}
console.log("مجموع الأعداد من 1 إلى 100 =", sum);

const n = 7;
for (let i = 1; i <= 5; i++) {
    console.log(`${n} × ${i} = ${n * i}`);
}
```

```text output
مجموع الأعداد من 1 إلى 100 = 5050
7 × 1 = 7
7 × 2 = 14
7 × 3 = 21
7 × 4 = 28
7 × 5 = 35
```

## حلقة `while`

نستخدمها عندما لا نعرف عدد المرات مسبقًا، بل نكرر **ما دام** الشرط صحيحًا:

```js run
let money = 1000;
let years = 0;
while (money < 2000) {
    money *= 1.1;      // زيادة 10% كل سنة
    years++;
}
console.log(`يتضاعف المبلغ بعد ${years} سنوات`);
console.log("المبلغ:", money.toFixed(2));
```

```text output
يتضاعف المبلغ بعد 8 سنوات
المبلغ: 2143.59
```

## حلقة `do ... while`

مثل `while` لكنها تنفّذ الكتلة **مرة واحدة على الأقل** قبل فحص الشرط:

```js run
let k = 10;
do {
    console.log("نُفّذت مرة رغم أن الشرط خطأ، k =", k);
    k++;
} while (k < 5);
```

```text output
نُفّذت مرة رغم أن الشرط خطأ، k = 10
```

## حلقة `for ... of`

أسهل طريقة للمرور على كل عنصر في مصفوفة أو كل حرف في نص:

```js run
const fruits = ["تفاح", "موز", "برتقال"];
for (const fruit of fruits) {
    console.log("أحب", fruit);
}

for (const ch of "JS!") {
    console.log(ch);
}
```

```text output
أحب تفاح
أحب موز
أحب برتقال
J
S
!
```

سنتعمق في المصفوفات في الدرس 7.

## `break` و`continue`

- `break` **تخرج** من الحلقة فورًا.
- `continue` **تتخطى** بقية الدورة الحالية وتنتقل إلى الدورة التالية.

```js run
// أول عدد بين 1 و100 يقبل القسمة على 7 و5 معًا
for (let i = 1; i <= 100; i++) {
    if (i % 7 === 0 && i % 5 === 0) {
        console.log("وجدته:", i);
        break;
    }
}

// الأعداد الفردية فقط من 1 إلى 9
let odds = "";
for (let i = 1; i <= 9; i++) {
    if (i % 2 === 0) continue;
    odds += i + " ";
}
console.log(odds.trim());
```

```text output
وجدته: 35
1 3 5 7 9
```

## الحلقات المتداخلة

حلقة داخل حلقة: الداخلية تكتمل كلها في كل دورة من الخارجية:

```js run
for (let row = 1; row <= 4; row++) {
    let line = "";
    for (let col = 1; col <= row; col++) {
        line += "*";
    }
    console.log(line);
}
```

```text output
*
**
***
****
```

ويمكنك اختصار الحلقة الداخلية هنا بالدالة الجاهزة `"*".repeat(row)`.

## أخطاء شائعة

### الحلقة اللانهائية

```js
let i = 1;
while (i <= 5) {
    console.log(i);
    // نسينا i++ فيبقى الشرط صحيحًا إلى الأبد!
}
```

إن علق برنامجك، أوقفه من **Debug > Stop Debugging** (تصحيح الأخطاء > إيقاف تصحيح الأخطاء) أو `Shift+F5`.

### الخطأ بفارق واحد (off-by-one)

`for (let i = 0; i < 5; i++)` تدور 5 مرات (0 إلى 4)، و`for (let i = 1; i <= 5; i++)` تدور 5 مرات أيضًا (1 إلى 5)، لكن `i <= 5` مع البداية من 0 تدور 6 مرات. انتبه لنقطة البداية وعلامة المقارنة.

## تمارين

### التمرين 1

اطبع مضروب العدد 6 (أي 1 × 2 × 3 × 4 × 5 × 6) بحلقة `for`.

```js exercise
const n = 6;
// الناتج المطلوب: 6! = 720
```

```js solution
const n = 6;
let fact = 1;
for (let i = 2; i <= n; i++) {
    fact *= i;
}
console.log(`${n}! = ${fact}`);
```

```text output
6! = 720
```

### التمرين 2

بحلقة `while`، احسب عدد أرقام العدد `90210` بقسمته على 10 مرة بعد مرة (استخدم `Math.floor`).

```js exercise
let num = 90210;
// الناتج المطلوب: عدد الأرقام: 5
```

```js solution
let num = 90210;
let digits = 0;
while (num > 0) {
    num = Math.floor(num / 10);
    digits++;
}
console.log("عدد الأرقام:", digits);
```

```text output
عدد الأرقام: 5
```

### التمرين 3

اطبع الأعداد من 1 إلى 15، لكن اكتب `Fizz` بدل مضاعفات 3، و`Buzz` بدل مضاعفات 5، و`FizzBuzz` بدل مضاعفات الاثنين معًا، كلها في سطر واحد بينها مسافات.

```js exercise
// الناتج المطلوب:
// 1 2 Fizz 4 Buzz Fizz 7 8 Fizz Buzz 11 Fizz 13 14 FizzBuzz
```

```js solution
let out = [];
for (let i = 1; i <= 15; i++) {
    if (i % 15 === 0) out.push("FizzBuzz");
    else if (i % 3 === 0) out.push("Fizz");
    else if (i % 5 === 0) out.push("Buzz");
    else out.push(i);
}
console.log(out.join(" "));
```

```text output
1 2 Fizz 4 Buzz Fizz 7 8 Fizz Buzz 11 Fizz 13 14 FizzBuzz
```

## الخلاصة

- `for` عندما تعرف عدد المرات، و`while` عندما تكرر ما دام الشرط صحيحًا، و`do ... while` لمرة على الأقل.
- `for ... of` للمرور على عناصر مصفوفة أو حروف نص.
- `break` للخروج، و`continue` للتخطي.
- احذر الحلقة اللانهائية والخطأ بفارق واحد.

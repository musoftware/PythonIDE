# الدرس 1: مرحبًا بك في JavaScript وNode.js

أهلًا بك في دورة **JavaScript** باللغة العربية! سنبدأ معًا من الصفر، خطوة بخطوة، حتى نبني برنامجًا حقيقيًا بنوافذ وأزرار داخل RAD IDE، ثم نتعرف على **TypeScript** وعلى حزم **npm**.

لا تحتاج إلى أي خبرة سابقة. كل ما تحتاجه هو أن تجرّب كل مثال بيدك.

**في هذا الدرس ستتعلم:**

- ما هي JavaScript، وما هو Node.js.
- كيف تجهّز RAD IDE لتشغيل JavaScript.
- كيف تكتب برنامجك الأول وتشغّله.

## ما هي JavaScript؟

**JavaScript** (وتُختصر **JS**) هي لغة الويب: كل موقع تقريبًا تزوره فيه كود JavaScript يعمل داخل المتصفح، يحرّك القوائم ويتحقق من النماذج ويحدّث الصفحة دون إعادة تحميلها.

لكن JavaScript لم تعد حبيسة المتصفح. اليوم تُستخدم في:

- **مواقع الويب** من جهة المتصفح (الواجهة الأمامية Front-end) مثل React وVue وAngular.
- **الخوادم** (الواجهة الخلفية Back-end) مثل Express وNestJS.
- **برامج سطح المكتب** مثل VS Code نفسه، وتطبيقات **الجوال** مثل React Native.
- **الأدوات الصغيرة** وسكربتات الأتمتة.

> **تنبيه:** JavaScript لا علاقة لها بلغة Java رغم تشابه الاسم! التشابه جاء لأسباب تسويقية في التسعينيات فقط.

## ما هو Node.js؟

**Node.js** برنامج يشغّل كود JavaScript **خارج المتصفح**، على جهازك مباشرة. هو الذي يسمح لنا بكتابة برامج سطر أوامر، وخوادم، وقراءة الملفات.

> **تشبيه:** JavaScript هي اللغة، وNode.js هو «المذيع» الذي يقرأ ما تكتبه بصوت عالٍ وينفّذه. المتصفح مذيع آخر يقرأ اللغة نفسها، لكن في مكان مختلف.

ومع Node.js يأتي برنامج **npm** (Node Package Manager)، وهو «متجر» ضخم فيه أكثر من مليوني حزمة جاهزة يمكنك استخدامها في برامجك. سنتعلمه في الدرس 12.

## تجهيز بيئة العمل

1. حمّل **Node.js** الإصدار 22 أو أحدث (النسخة LTS) من الموقع الرسمي `https://nodejs.org` وثبّته بالإعدادات الافتراضية.
2. أعد تشغيل RAD IDE بعد التثبيت.
3. تجد RAD IDE برنامج `node.exe` تلقائيًا. إن كان في مكان غير معتاد، حدّد مساره من **Tools > Options > Languages** (أدوات > خيارات).

للتأكد من التثبيت افتح **View > Terminal** (عرض > الطرفية) أو اضغط ``Ctrl+` `` واكتب:

```text
node --version
npm --version
```

يجب أن ترى رقمي الإصدارين، مثل `v22.22.2` و`10.9.7`.

## ثلاث طرق لتجربة الكود

### 1) زر «جرّبه» في الدروس (الأسهل)

كل مثال في هذه الدروس عليه زر **«جرّبه»**. عند الضغط عليه تنشئ RAD IDE مشروعًا مؤقتًا، وتشغّله، وتعرض الناتج في نافذة **Output** (المخرجات). جرّب الآن:

```js run
console.log("Hello, JavaScript!");
console.log("مرحبًا بك في عالم البرمجة");
```

```text output
Hello, JavaScript!
مرحبًا بك في عالم البرمجة
```

### 2) مشروع سطر أوامر جديد

1. من القائمة **File > New Project** (ملف > مشروع جديد...) أو `Ctrl+Shift+N`.
2. في شجرة اللغات على اليسار اختر المجموعة **Web & Script** (ويب وبرمجة نصية) ثم **JavaScript**.
3. من **Template** اختر **Console Application** (تطبيق سطر أوامر)، واكتب اسم المشروع ثم اضغط **OK**.
4. يفتح الملف `Program.js`. امسح ما فيه واكتب:

```js run
console.log("أول مشروع لي في RAD IDE");
```

```text output
أول مشروع لي في RAD IDE
```

5. اضغط `Ctrl+F5` (**Start Without Debugging**: بدء بدون تصحيح الأخطاء) فيظهر الناتج في نافذة **Output**.

### 3) مشروع بنافذة (Windows Application)

إذا اخترت القالب **Windows Application** (تطبيق Windows) بدل Console Application، يظهر **مصمم النماذج**: تسحب الأزرار وخانات النص من **Toolbox** (صندوق الأدوات) وتكتب كود الأحداث بلغة JavaScript. هذه هي طريقة **GUI Bridge**: الـ IDE ترسم النافذة، وبرنامجك يتحكم فيها. سنصل إلى ذلك في الدرس 14.

## `console.log`: نافذتك على البرنامج

`console.log(...)` تطبع ما بين القوسين في نافذة المخرجات ثم تنزل سطرًا جديدًا. يمكنك أن تعطيها أكثر من قيمة مفصولة بفواصل، فتطبعها بينها مسافة:

```js run
console.log("العمر:", 20);
console.log(10 + 5);
console.log("10 + 5");
console.log("مجموع", 2, "و", 3, "هو", 2 + 3);
```

```text output
العمر: 20
15
10 + 5
مجموع 2 و 3 هو 5
```

لاحظ الفرق بين `10 + 5` (عملية حسابية نتيجتها `15`) و`"10 + 5"` (نص بين علامتي تنصيص يُطبع كما هو).

## التعليقات

التعليق كلام للبشر يتجاهله Node.js تمامًا:

```js run
// هذا تعليق من سطر واحد

/*
   وهذا تعليق
   من عدة أسطر
*/
console.log("التعليقات لا تظهر في الناتج"); // تعليق في آخر السطر
// console.log("هذا السطر معطّل");
```

```text output
التعليقات لا تظهر في الناتج
```

## الفاصلة المنقوطة `;`

نضع `;` في نهاية كل تعليمة، مثل النقطة في آخر الجملة. JavaScript تسامحك أحيانًا إن نسيتها وتضيفها بنفسها، لكن الأفضل أن تكتبها دائمًا لتتجنب مفاجآت غريبة.

## أخطاء شائعة

### كتابة `Console` بحرف كبير

```js
Console.log("Hello");
```

```text
ReferenceError: Console is not defined
```

**المعنى:** «`Console` غير معرَّف». لغة JavaScript **حساسة لحالة الأحرف**: `console` و`Console` اسمان مختلفان تمامًا.

### نسيان علامة التنصيص

```js
console.log("Hello);
```

```text
SyntaxError: Invalid or unexpected token
```

**المعنى:** «رمز غير صالح أو غير متوقع». فتحت النص بـ `"` ولم تغلقه. انتبه أيضًا لعلامات التنصيص «الذكية» مثل `“` عند النسخ من برنامج Word.

## تمارين

### التمرين 1

اطبع اسمك في سطر، ومدينتك في سطر ثانٍ، بأمرين `console.log`.

```js exercise
// اطبع:
// الاسم: سارة
// المدينة: القاهرة
```

```js solution
console.log("الاسم: سارة");
console.log("المدينة: القاهرة");
```

```text output
الاسم: سارة
المدينة: القاهرة
```

### التمرين 2

اطبع ناتج ضرب `7` في `6` بعد النص `"7 × 6 ="` في السطر نفسه، باستخدام `console.log` واحدة وقيمتين مفصولتين بفاصلة.

```js exercise
// الناتج المطلوب: 7 × 6 = 42
```

```js solution
console.log("7 × 6 =", 7 * 6);
```

```text output
7 × 6 = 42
```

## الخلاصة

- JavaScript لغة الويب، وNode.js يشغّلها على جهازك، وnpm متجر الحزم.
- `console.log(...)` تطبع في نافذة **Output**، و`//` و`/* */` للتعليقات.
- مشروع جديد: **File > New Project > Web & Script > JavaScript** ثم **Console Application** أو **Windows Application**.
- JavaScript حساسة لحالة الأحرف.

# قاموس المصطلحات (إنجليزي - عربي)

مرجع سريع لكل المصطلحات التي مرت في الدورة، مرتبة حسب الموضوع. ارجع إليه كلما قابلت كلمة إنجليزية في رسالة خطأ أو في مقال.

## أساسيات اللغة

| English | العربية | شرح مختصر |
|---|---|---|
| variable | متغير | صندوق له اسم يحفظ قيمة: `let x = 5;` |
| constant | ثابت | قيمة لا يُعاد إسنادها: `const PI = 3.14;` |
| value | قيمة | البيانات نفسها: `5` أو `"نص"` |
| data type | نوع البيانات | `number` و`string` و`boolean`... |
| string | نص (سلسلة نصية) | حروف بين علامتي تنصيص |
| number | عدد | صحيح أو عشري |
| boolean | قيمة منطقية | `true` أو `false` |
| template literal | قالب نص | نص بين علامتي backtick فيه `${...}` |
| operator | عامل | رمز عملية مثل `+` و`===` و`&&` |
| expression | تعبير | جزء من الكود ينتج قيمة: `a + b` |
| statement | تعليمة (جملة) | سطر يقوم بعمل وينتهي بـ `;` |
| comment | تعليق | كلام للبشر يتجاهله البرنامج: `//` |
| keyword | كلمة محجوزة | كلمة لها معنى في اللغة مثل `if` و`let` |
| truthy / falsy | قيمة صادقة / كاذبة | ما يُعامل كـ `true` أو `false` في الشروط |

## التحكم في سير البرنامج

| English | العربية | شرح مختصر |
|---|---|---|
| condition | شرط | تعبير نتيجته `true` أو `false` |
| if / else | إذا / وإلا | الجملة الشرطية |
| ternary operator | العامل الثلاثي | `شرط ? أ : ب` |
| switch / case | جملة الاختيار | المقارنة بقيم ثابتة كثيرة |
| loop | حلقة تكرار | تكرار مجموعة تعليمات: `for` و`while` |
| iteration | دورة (تكرار) | مرة واحدة من مرات الحلقة |
| break / continue | خروج / تخطٍّ | إنهاء الحلقة / الانتقال للدورة التالية |
| infinite loop | حلقة لا نهائية | حلقة لا يصبح شرطها خطأً أبدًا |
| block | كتلة | التعليمات بين `{ }` |
| scope | نطاق | المكان الذي يُرى فيه المتغير |

## الدوال

| English | العربية | شرح مختصر |
|---|---|---|
| function | دالة | تعليمات لها اسم تُستدعى عند الحاجة |
| parameter | معامل | متغير الدالة الذي يستقبل القيمة |
| argument | وسيط | القيمة التي نمررها عند الاستدعاء |
| return value | القيمة المرجعة | ما ترجعه الدالة بـ `return` |
| call / invoke | استدعاء | تنفيذ الدالة: `greet()` |
| arrow function | دالة سهمية | `(x) => x * 2` |
| callback | دالة رد النداء | دالة نمررها لدالة أخرى لتستدعيها |
| default parameter | قيمة افتراضية | `function f(x = 10)` |
| recursion | استدعاء ذاتي | دالة تستدعي نفسها |

| JSON | JSON | صيغة نصية لتبادل البيانات |
| regular expression | تعبير نمطي | نمط للبحث في النصوص: `/[0-9]/` |

## البرمجة كائنية التوجه

| English | العربية | شرح مختصر |
|---|---|---|

| inheritance | وراثة | صنف يبني فوق صنف آخر: `extends` |
| override | إعادة تعريف | تابع في الابن بنفس اسم تابع الأب |
| polymorphism | تعدد الأشكال | الاستدعاء نفسه يتصرف حسب نوع الكائن |
| encapsulation | تغليف | إخفاء البيانات الداخلية: الخصائص `#` |
| getter / setter | تابع قراءة / كتابة | `get` و`set` لخاصية محسوبة |
| static | ثابت (تابع الصنف) | يُستدعى باسم الصنف لا الكائن |

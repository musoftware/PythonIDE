# الدرس 3: لغة تجميع AGC - أول برنامج والذاكرة والمسجلات

**في هذا الدرس:**

- شكل السطر في صيغة **yaYUL** (صيغة Virtual AGC لمصدر أبولو).
- الذاكرة **المتغيرة** و**الثابتة** والبنوك.
- المسجلات `A` و`L` و`Q` و`Z`، والتعليمات الأساسية: `CA` و`TS` و`AD` و`INCR` و`TC` و`TCF` و`CCS`.
- التعليمات الموسَّعة بعد `EXTEND`.
- التشغيل خطوة خطوة في نافذة **Apollo AGC**.

## شكل السطر

```agc
LABEL           OPCODE  OPERAND         # تعليق
COUNT           ERASE                   # كلمة في الذاكرة المتغيرة اسمها COUNT
                CA      COUNT           # A = COUNT
                AD      ONE             # A = A + 1
                TS      COUNT           # COUNT = A
ONE             DEC     1               # ثابت في الذاكرة الثابتة
```

- **التسمية** (Label) تبدأ في العمود الأول. إن بدأ السطر بمسافة فلا تسمية فيه.
- `#` يبدأ تعليقًا، و`##` تعليق توضيحي في ملفات أبولو المنقولة.
- **الأرقام ثُمانية** إلا إذا احتوت 8 أو 9 أو انتهت بحرف `D`: `SETLOC 4000` ثماني، و`ERASE +20D` عشري. أما `DEC 100` فعشري دائمًا.
- `$FILE.agc` يضمّ ملفًا آخر في هذا المكان (برنامج أبولو 11 نحو 90 ملفًا اسمها «أقسام السجل» Log Sections).

## الذاكرة

| المدى (ثماني) | النوع | ملاحظات |
|---|---|---|
| 0000 - 0007 | المسجلات | `A`=0 و`L`=1 و`Q`=2 و`EB`=3 و`FB`=4 و`Z`=5 و`BB`=6 و`ZERO`=7 |
| 0010 - 1377 | متغيرة ثابتة الموقع | البنوك E0 و E1 و E2 |
| 1400 - 1777 | متغيرة مُبدَّلة | البنك الذي يختاره `EB` (من E0 إلى E7) |
| 2000 - 3777 | ثابتة مُبدَّلة | البنك الذي يختاره `FB` |
| 4000 - 7777 | ثابتة ثابتة الموقع | البنكان 2 و 3، ومنها يبدأ البرنامج عند 4000 |

- `SETLOC 100` ثم `ERASE`: حجز متغيرات في الذاكرة المتغيرة (ليس لها قيمة ابتدائية؛ صفّرها بنفسك).
- `SETLOC 4000`: الكود والثوابت في الذاكرة الثابتة.
- الكلمة **15 بت** بنظام **المتمم الأحادي** (Ones' Complement): السالب = قلب كل البتات، ولهذا يوجد **+0** و**-0**!
- المركم `A` عرضه **16 بت** ليحتفظ بالفيضان (Overflow).

## أهم التعليمات

| التعليمة | المعنى |
|---|---|
| `CA K` | A = K (ومثلها `CAF` للثوابت و`CAE` للمتغيرة) |
| `CS K` | A = -K |
| `TS K` | K = A (وعند الفيضان تتخطى التعليمة التالية) |
| `AD K` | A = A + K |
| `INCR K` | K = K + 1 |
| `XCH K` | تبديل A مع K |
| `MASK K` | A = A AND K |
| `TC K` | استدعاء إجراء: Q = عنوان الرجوع ثم القفز إلى K؛ الرجوع بـ `RETURN` |
| `TCF K` | قفز إلى K |
| `CCS K` | عدّ ومقارنة وتخطٍّ: A = abs(K) - 1 ثم تفرّع رباعي (موجب، +0، سالب، -0) |
| `INDEX K` | يضيف قيمة K إلى التعليمة التالية (جداول) |
| `EXTEND` | التعليمة التالية **موسَّعة**: `READ` و`WRITE` (القنوات) و`DCA` و`MP` (ضرب) و`DV` (قسمة) و`SU` (طرح) و`BZF` (قفز إذا صفر) و`BZMF` (قفز إذا صفر أو سالب) |

مرّر الفأرة فوق أي تعليمة في المحرر لترى شرحها بالعربية (عندما تكون واجهة الـ IDE بالعربية)، واضغط `F12` على أي اسم لتنتقل إلى تعريفه ولو كان في ملف آخر.

## مثال: إجراء يعدّ

هذا جزء من `MAIN.agc` في مشروع Hello DSKY: إجراء يزيد الثواني ويحمل إلى الدقائق.

```agc
TICK            INCR    SECS            # SECS = SECS + 1
                CA      SECS
                AD      NEG59           # A = SECS - 59
                EXTEND
                BZMF    TICKRET         # إذا كانت SECS <= 59 فانتهينا
                CA      ZERO
                TS      SECS            # SECS = 0
                INCR    MINS            # والدقائق + 1
TICKRET         RETURN
```

لاحظ أن `BZMF` تعليمة موسَّعة، لذلك تسبقها `EXTEND`. ولاحظ أن `59 - 59` في المتمم الأحادي تعطي **-0**، و`BZMF` تعدّه صفرًا.

## شغّل خطوة خطوة

1. في `MAIN.agc` ضع نقطة توقف (`F9`) على سطر `TICK`.
2. اضغط `F5`. بعد ثانية يتوقف البرنامج: نافذة **Locals** فيها `A` و`L` و`Q` و`Z` والمتغيرات `SECS` و`MINS`...
3. اضغط `F10` عدة مرات وراقب `A` في تبويب **Registers** و`SECS` في **Variables**، أو افتح **Erasable Memory** واختر البنك E0.
4. في نافذة **Watch** اكتب `SECS` أو `A` أو عنوانًا ثمانيًا مثل `100`.
5. `Tools > Retro > Apollo AGC > Assembly Listing` يعرض كل سطر وعنوانه (بنك، عنوان) وكلمته الثمانية.

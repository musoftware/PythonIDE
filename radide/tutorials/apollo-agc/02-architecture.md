# الدرس 2: بنية حاسوب AGC والذاكرة والمسجلات

**في هذا الدرس:**

- الكلمة **15 بت** ونظام **المتمم الأحادي** (Ones' Complement): لماذا يوجد +0 و -0.
- الذاكرة **المتغيرة** (Erasable) و**الثابتة** (Fixed) والبنوك.
- المسجلات `A` و`L` و`Q` و`Z` والعناوين الخاصة.
- أول برنامجين يعملان: جمع عددين، ومجموع 1 إلى 10 بالتعليمة العجيبة `CCS`.

## الكلمة: 15 بت ومتمم أحادي

كل كلمة في AGC **15 بت** (ومعها بت تكافؤ لا يراه البرنامج). العدد السالب يُكتب بقلب **كل** البتات:

```text
 +5  = 000 000 000 000 101   (00005 بالثماني)
 -5  = 111 111 111 111 010   (77772 بالثماني)
 +0  = 00000                  -0 = 77777
```

لهذا يوجد صفران! والجمع فيه «حمل دائري» (End-Around Carry). نكتب الأرقام عادة **بالثماني** لأن كل 3 بتات رقم ثماني واحد.

## خريطة الذاكرة

| المدى (ثماني) | النوع | ملاحظات |
|---|---|---|
| 0000 - 0007 | المسجلات | `A`=0 و`L`=1 و`Q`=2 و`EB`=3 و`FB`=4 و`Z`=5 و`BB`=6 و`ZERO`=7 (دائمًا صفر) |
| 0010 - 0060 | مسجلات خاصة | `ARUPT` و`QRUPT` لحفظ المسجلات في المقاطعات، والعدادات `TIME1` ... `TIME6` |
| 0061 - 1377 | متغيرة ثابتة الموقع | البنوك E0 و E1 و E2 |
| 1400 - 1777 | متغيرة مبدَّلة | البنك الذي يختاره `EB` |
| 2000 - 3777 | ثابتة مبدَّلة | البنك الذي يختاره `FB` (36 بنكًا في الحاسوب الحقيقي) |
| 4000 - 7777 | ثابتة ثابتة الموقع | البنكان 2 و 3؛ من **4000** يبدأ التنفيذ |

- **المتغيرة** = ذاكرة مغناطيسية (Core) 2048 كلمة. نحجز فيها بـ `ERASE`.
- **الثابتة** = «ذاكرة الحبال» (Core Rope) 36864 كلمة: البت 1 سلك يمر **داخل** حلقة مغناطيسية، والبت 0 سلك يمر **خارجها**. نسجتها عاملات في مصنع Raytheon يدويًا، لذلك كان تغيير البرنامج يعني نسج حبل جديد!

## المسجلات

| المسجل | العمل |
|---|---|
| `A` | المركم: كل حساب يمر به (16 بت ليحفظ الفيضان) |
| `L` | المسجل الأدنى: النصف الثاني للأعداد المضاعفة |
| `Q` | عنوان الرجوع بعد `TC` (استدعاء إجراء) |
| `Z` | عداد البرنامج: عنوان التعليمة التالية |

## البرنامج الأول: 5 + 10

في هذه الدورة كل برنامج كامل يمكنك لصقه في `MAIN.agc` لمشروع **Apollo AGC Program** فارغ وتشغيله بـ `F5`، ومشاهدة المتغيرات في نافذة **Apollo AGC** (تبويب Variables) وخطوة خطوة بـ `F10`.

> البرامج القصيرة في الدرسين 2 و 3 لا تقرأ `NEWJOB` ولا تستخدم مقاطعة المؤقت، والحاسوب الحقيقي يعيد تشغيل نفسه عندئذ (الدرس 4 يشرح لماذا). أثناء التعلم أضف إلى `project.radproj` السطر `"agc": {"alarms": false}`.

<!-- test: {"show": ["SUM"]} -->
```agc run
# مجموع عددين: SUM = 5 + 10
                SETLOC  100             # الذاكرة المتغيرة
SUM             ERASE                   # كلمة واحدة اسمها SUM

                SETLOC  4000            # الذاكرة الثابتة: من هنا يبدأ التشغيل
                INHINT                  # لا مقاطعات
                TCF     START           # اقفز إلى البرنامج

START           CA      FIVE            # A = 5
                AD      TEN             # A = A + 10
                TS      SUM             # SUM = A
DONE            TCF     DONE            # قف هنا

FIVE            DEC     5               # ثوابت في الذاكرة الثابتة
TEN             DEC     10
```

مدقق الدروس يجمّع البرنامج بمجمِّع RAD IDE ويشغّله في المحاكي جزءًا من الثانية ثم يقرأ `SUM`:

```text output
SUM = 15
```

لاحظ: لا توجد تعليمة «حمّل رقمًا فوريًا» (مثل `lda #5` في 6502). كل رقم يجب أن يكون في كلمة ثابتة (`FIVE DEC 5`) ثم نقرؤه بـ `CA`. كانت الذاكرة الثابتة مليئة بثوابت مثل `ONE` و`TWO` و`NEG59`.

## السالب في المتمم الأحادي

<!-- test: {"show": ["NEG", "BACK"], "octal": ["NEG"]} -->
```agc run
                SETLOC  100
NEG             ERASE
BACK            ERASE

                SETLOC  4000
                INHINT
                TCF     START

START           CS      FIVE            # A = -5 (اقلب كل البتات)
                TS      NEG
                AD      FIVE            # -5 + 5 = -0 في المتمم الأحادي!
                AD      THREE           # -0 + 3 = +3
                TS      BACK
DONE            TCF     DONE

FIVE            DEC     5
THREE           DEC     3
```

```text output
NEG = -5
BACK = 3
NEG = 77772
```

## مجموع 1 إلى 10: التعليمة CCS

`CCS K` (Count, Compare and Skip) تعليمة واحدة تفعل ثلاثة أشياء: تضع في `A` القيمة `|K| - 1`، ثم تقفز **أربعة اتجاهات** حسب K:

| K | التعليمة التي تُنفَّذ بعد CCS |
|---|---|
| موجب | الأولى |
| +0 | الثانية |
| سالب | الثالثة |
| -0 | الرابعة |

فهي مثالية للعدّ التنازلي في الحلقات:

<!-- test: {"show": ["SUM", "COUNT"]} -->
```agc run
ZERO            EQUALS  7               # العنوان 7 قيمته صفر دائمًا

                SETLOC  100
SUM             ERASE
COUNT           ERASE

                SETLOC  4000
                INHINT
                TCF     START

START           CA      ZERO
                TS      SUM             # SUM = 0
                CAF     TEN
                TS      COUNT           # COUNT = 10

LOOP            CA      SUM
                AD      COUNT
                TS      SUM             # SUM = SUM + COUNT
                CCS     COUNT           # A = COUNT - 1 ثم تفرّع
                TCF     NEXT            #   COUNT > 0
                TCF     DONE            #   COUNT = +0
                TCF     DONE            #   COUNT < 0
                TCF     DONE            #   COUNT = -0
NEXT            TS      COUNT           # COUNT = COUNT - 1
                TCF     LOOP

DONE            TCF     DONE

TEN             DEC     10
```

```text output
SUM = 55
COUNT = 0
```

`CAF` مثل `CA` لكنها للذاكرة الثابتة تحديدًا (في الحقيقة هي التعليمة نفسها؛ الاسم يوضح للقارئ).

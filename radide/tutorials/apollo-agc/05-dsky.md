# الدرس 5: لوحة DSKY - الأفعال والأسماء وكلمات المرحِّلات

**في هذا الدرس:**

- تنشئ مشروع **Hello DSKY** وتشغّله بـ `F5`.
- تقرأ شاشة DSKY: PROG و VERB و NOUN والسجلات R1 و R2 و R3 والمصابيح.
- تكتب أوامر حقيقية: `V35E` (اختبار المصابيح) و`V16N36E` (ساعة الحاسوب).
- تكتب برنامجًا يرسم بنفسه على شاشة DSKY بكلمات المرحِّلات في **القناة 10**.

## أنشئ المشروع

1. **File > New Project...** ثم **Space & Science** ثم **Apollo AGC Program (yaYUL)**.
2. اختر القالب **Hello DSKY (clock + keyboard)** وسمّه `HelloDSKY`.
3. اضغط `F5`. يجمّع RAD IDE الملف `MAIN.agc` ويشغّله في المحاكي، وتظهر نافذة **Apollo AGC** وفيها لوحة DSKY.

## اقرأ الشاشة

```text
 COMP ACTY        PROG
                  [  ]
 VERB             NOUN
 [16]             [36]
 ------------------------
 + 0 0 0 0 0        <- R1: الساعات
 + 0 0 0 0 0        <- R2: الدقائق
 + 0 0 3 0 0        <- R3: الثواني × 100 (3.00 ثانية)
```

- **PROG**: رقم البرنامج الرئيسي (Major Mode)، مثل P63 لبداية الهبوط على القمر.
- **VERB / NOUN**: الأمر الحالي. `V16 N36`: «راقب عشريًّا ساعة الحاسوب».
- **R1 و R2 و R3**: ثلاثة سجلات عرض، لكل منها إشارة (+ أو -) وخمسة أرقام.
- على اليسار **المصابيح**: OPR ERR (خطأ المشغّل) و KEY REL و PROG و RESTART و TEMP ...

## اكتب أوامر

انقر على لوحة DSKY (أو استخدم لوحة المفاتيح: `V` = VERB و`N` = NOUN و`Enter` = ENTR و`R` = RSET و`C` = CLR):

| ما تكتبه | النتيجة |
|---|---|
| `V` `3` `5` `Enter` | **اختبار المصابيح**: كل الأرقام 8 وكل المصابيح مضاءة (هذا الفعل حقيقي في أبولو) |
| `V` `1` `6` `N` `3` `6` `Enter` | الرجوع إلى الساعة |
| `V` `2` `1` `Enter` | فعل لا يعرفه برنامجنا: يضيء **OPR ERR** |
| `R` | **RSET** يطفئ مصباح OPR ERR |

> **تجربة سريعة بدون واجهة:** من سطر الأوامر:
> `python -m radide.agc samples/Tests/Retro/AGC/HelloDSKY/MAIN.agc --keys V35E`

## كيف تصل الأرقام إلى الشاشة؟

البرنامج لا يكتب «نصًا». بل يرسل إلى **القناة 10** (Channel 10) كلمات اسمها «كلمات المُرحِّلات» (Relay Words):

```text
 البتات 15-12   رقم الكلمة (1 إلى 12)
 البت 11        إشارة (+ أو -) أو مصباح
 البتات 10-6    رمز الرقم الأيسر (5 بتات)
 البتات 5-1     رمز الرقم الأيمن (5 بتات)
```

مثلًا الكلمة 10 تحمل رقمي VERB، والكلمة 9 رقمي NOUN. ورموز الأرقام ليست 0-9 مباشرة: الصفر رمزه `25` بالثماني، والواحد `3`، والثمانية `35`... (جدول `DIGTAB` في `CONSTANTS.agc`). مرّر الفأرة فوق `WRITE 10` في المحرر لترى الشرح.

### برنامج يكتب على الشاشة بنفسه

جدول الكلمات (من وثائق Virtual AGC):

| الكلمة | البتات 10-6 | البتات 5-1 | البت 11 |
|---|---|---|---|
| 11 | PROG الأيسر | PROG الأيمن | |
| 10 | VERB الأيسر | VERB الأيمن | |
| 9 | NOUN الأيسر | NOUN الأيمن | |
| 8 | | R1 الرقم 1 | |
| 7 | R1 الرقم 2 | R1 الرقم 3 | إشارة + لـ R1 |
| 6 | R1 الرقم 4 | R1 الرقم 5 | إشارة - لـ R1 |

ورموز الأرقام: 0=`25` و1=`3` و2=`31` و3=`33` و4=`17` و5=`36` و6=`34` و7=`23` و8=`35` و9=`37` (ثماني). مثلًا `VERB 06`: رقم الكلمة 10 (=`12` ثماني) في البتات 15-12 = `50000`، والصفر `25` في البتات 10-6 = `1240`، والستة `34` = `34`؛ المجموع `51274`. وهكذا يعرض هذا البرنامج `V06 N65` والسجل R1 = `+00042`:

```agc run

                INHINT

START           CAF     VERBWORD        # VERB 06

                EXTEND
                WRITE   10
                CAF     R1WORD7         # إشارة + والرقمان 0 0
                EXTEND

                EXTEND

VERBWORD        OCT     51274           # 10 << 11 | 0 << 5 | 6
NOUNWORD        OCT     45636           # 9 << 11 | 6 << 5 | 5
R1WORD8         OCT     40025           # 8 << 11 | 0
R1WORD7         OCT     37265           # 7 << 11 | + | 0 << 5 | 0
R1WORD6         OCT     30771           # 6 << 11 | 4 << 5 | 2
```

المدقق يقرأ شاشة DSKY من نموذج المحاكي:

```text output
DSKY: PROG     VERB 06  NOUN 65  R1 +00042  R2         R3
```

في البرنامج الحقيقي لا تُكتب هذه الأرقام يدويًا: الإجراء `PUTNUM` في `DISPLAY.agc` (مشروع Hello DSKY) يحوّل العدد إلى أرقام بجدول `DIGTAB` ويكتب الكلمات في مقاطعة المؤقت.

والمفاتيح تصل بالعكس: كل ضغطة تضع رمز المفتاح في **القناة 15** وتسبب المقاطعة **KEYRUPT1**.

## مرجع الأفعال والأسماء

افتح **Tools > Retro > Apollo AGC > DSKY Verbs, Nouns and Programs**: جداول الأفعال والأسماء والبرامج المعتادة في برنامج مركبة القيادة. وفي المحرر، اكتب في تعليق `V16N36` ومرّر الفأرة فوقه.

# الدرس 6: التعاون المباشر (Live Share)

**في هذا الدرس ستتعلم:**

- الفرق بين **التعاون المباشر** و Git.
- بدء **جلسة تعاون** كمضيف (Host) ومشاركة رابط الدعوة.
- الانضمام كضيف (Guest)، والتحرير معًا، ومؤشرات الزملاء بألوانهم.
- **المتابعة** (Follow)، والدردشة، والطرفية المشتركة، وجعل الضيوف **للقراءة فقط**.

## السبورة المشتركة

Git يشبه تبادل **الرسائل**: كل شخص يكتب في بيته ثم يرسل. أما التعاون المباشر فيشبه **سبورة** يقف أمامها اثنان في الوقت نفسه: ما يكتبه أحدهما يراه الآخر فورًا، ويرى يده (مؤشره) تتحرك.
هذا مفيد جدًا في **البرمجة الثنائية** (Pair programming)، أو عندما يساعدك صديق في خطأ، أو عندما يشرح المعلم للطلاب في المعمل.

| | Git | التعاون المباشر |
|---|---|---|
| التوقيت | كل شخص في وقته | الآن، في اللحظة نفسها |
| الملفات | نسخة عند كل شخص | ملفات المضيف فقط |
| الهدف | تاريخ وفروع ومراجعة | العمل معًا والمساعدة الفورية |

الأفضل استخدامهما معًا: تعملان مباشرة، ثم يودع المضيف النتيجة في Git.

## قائمة Share

| الأمر | الاسم العربي |
|---|---|
| **Share > Start Collaboration Session...** | بدء جلسة تعاون |
| **Share > Join Collaboration Session...** | الانضمام إلى جلسة تعاون |
| **Share > Copy Invite Link** | نسخ رابط الدعوة |
| **Share > Guests Read-only** | الضيوف للقراءة فقط |
| **Share > Follow Participant** | متابعة مشارك |
| **Share > Save Shared File on Host** | حفظ الملف المشترك لدى المضيف |
| **Share > Live Share Window** | نافذة المشاركة المباشرة |
| **Share > End Collaboration Session** | إنهاء جلسة التعاون |

## المضيف: بدء الجلسة

1. افتح مشروعك.
2. **Share > Start Collaboration Session...**. نافذة **Start Collaboration Session**:

| الخانة | المعنى |
|---|---|
| **Shared folder:** | المجلد المشترك؛ مجلد المشروع المفتوح افتراضيًا |
| **Your name:** | اسمك كما يراه الضيوف بجوار مؤشرك |
| **Password:** | كلمة مرور اختيارية؛ لا ينضم إلا من يعرفها |
| **Port:** | منفذ الشبكة (اتركه كما هو غالبًا) |
| **Guests join read-only** | ينضم الضيوف للقراءة فقط: يرون ولا يعدّلون |

3. اضغط **OK**. قد يسألك جدار حماية ويندوز (Windows Firewall) عن السماح بالاتصال؛ اسمح به للشبكات الخاصة.
4. تنشأ **رابط دعوة** يبدأ بـ `radide-collab://` فيه عنوان جهازك والمنفذ ورمز الانضمام. انسخه بـ **Share > Copy Invite Link** أو زر **Copy Link**، وأرسله لزميلك (مع كلمة المرور إن وضعتها).

> 💡 الجلسة تعمل على **الشبكة المحلية** (نفس الواي فاي أو المعمل أو الشبكة الافتراضية للشركة). الضيوف يحتاجون إلى RAD IDE أيضًا.

## الضيف: الانضمام

1. **Share > Join Collaboration Session...**. نافذة **Join Collaboration Session**:
   - **Invite link or code:** الصق الرابط.
   - **Your name:** اسمك.
   - **Password:** إن طلبها المضيف.
2. تظهر **شجرة ملفات المضيف**. انقر ملفًا مرتين فيُفتح في تبويب اسمه ينتهي بـ **[Live]**.
3. اكتب! ما تكتبه يظهر عند المضيف وبقية الضيوف فورًا، ومؤشر كل مشارك وتحديده يظهران **بلونه واسمه**.

حتى لو كتب اثنان في السطر نفسه في اللحظة نفسها، تتوحد النتيجة عند الجميع (البيئة تستخدم تقنية CRDT التي تدمج التعديلات المتزامنة دون تعارض).

## نافذة Live Share

**Share > Live Share Window** تفتح النافذة:

- **قائمة المشاركين**: الأعمدة **Participant** (المشارك) و **Role** (الدور: Host أو Guest) و **File** (الملف الذي يعمل عليه الآن) و **Read-only**.
- **انقر مشاركًا مرتين** لتتابعه (Follow): تنتقل تلقائيًا إلى أي ملف يفتحه وأي مكان يكتب فيه. ممتاز عندما يشرح المعلم.
- تبويب **Chat**: دردشة نصية. اكتب في **Message... (Enter to send)**.
- تبويب **Shared Terminal** (الطرفية المشتركة): ضيوفك يرون طرفية المضيف ونافذة المخرجات (Output) للقراءة فقط؛ فإذا شغّل المضيف البرنامج رأى الجميع النتيجة.
- خانة **Guests read-only** وأزرار **Start Session...** و **Join...** و **Copy Link** و **End Session** (أو **Leave Session** للضيف).

## الأمان والتحكم

- **Guests read-only** (أو **Share > Guests Read-only**): كل الضيوف يرون فقط. ويمكن جعل ضيف واحد للقراءة فقط من قائمة المشاركين. المنع يطبّقه **جهاز المضيف** نفسه، لا مجرد زر في واجهة الضيف.
- **كلمة المرور** تمنع من التقط الرابط بالصدفة.
- الضيوف **لا يصلون** إلا إلى المجلد المشترك.
- **End Session** ينهي الجلسة للجميع فورًا.

## مثال للتجربة مع زميل

ابدأ جلسة على مشروع BASIC فيه هذا البرنامج. اطلب من زميلك أن يضيف سطرًا يطبع اسمه، وأضف أنت سطرًا باسمك في الوقت نفسه، ثم شغّل البرنامج (`F5`) ليرى الجميع النتيجة في **Shared Terminal**:

```vb run
Sub Main()
    Dim team(1 To 2) As String
    Dim i As Integer
    team(1) = "Sara"
    team(2) = "Ali"
    For i = 1 To 2
        Debug.Print "عضو الفريق: " & team(i)
    Next
End Sub
```

```text output
عضو الفريق: Sara
عضو الفريق: Ali
```

## أخطاء شائعة

- **الضيف لا يتصل:** الجهازان على شبكتين مختلفتين، أو جدار الحماية يمنع المنفذ. تأكد من نفس الشبكة واسمح للبيئة في الجدار.
- **الضيف يعدّل في ملف عنده لا في الجلسة:** يجب أن يفتح الملف من شجرة الملفات المشتركة (تبويب **[Live]**).
- **نسيان حفظ التعديلات:** الملفات ملك المضيف؛ احفظها لديه (أو **Share > Save Shared File on Host**) ثم أودعها في Git.
- **ترك الجلسة مفتوحة:** أنهِها بـ **End Session** عند الانتهاء.

## تمرين

### مهمة عملية (مع زميل أو بنافذتين)

يمكنك التجربة وحدك: **File > New Window** (`Ctrl+Alt+N`) يفتح نافذة RAD IDE ثانية تمثّل الضيف.

1. في النافذة الأولى: افتح مشروعًا، ثم **Share > Start Collaboration Session...** باسم `Sara` وكلمة مرور.
2. **Share > Copy Invite Link**.
3. في النافذة الثانية: **Share > Join Collaboration Session...**، والصق الرابط، واكتب `Ali` وكلمة المرور.
4. افتح `Module1.bas` من الشجرة المشتركة واكتب سطرًا؛ راقبه يظهر في النافذة الأولى بلون آخر.
5. في الأولى: فعّل **Guests read-only** وحاول الكتابة من الثانية.
6. جرّب **Chat** و Follow، ثم **End Session**.

## الخلاصة

- **Share > Start Collaboration Session...** يشارك مجلدك على الشبكة المحلية برابط `radide-collab://` وكلمة مرور اختيارية.
- الضيف: **Join Collaboration Session...**، ثم ملفات **[Live]** ومؤشرات ملونة وتحرير متزامن.
- نافذة **Live Share**: المشاركون و Follow و **Chat** و **Shared Terminal** و **Guests read-only** و **End Session**.

# الدرس 3: نافذة محادثة الذكاء الاصطناعي والإشارات @

**في هذا الدرس ستتعلم:**

- فتح نافذة **AI Chat** واختيار المزود والنموذج.
- إضافة **سياق** للسؤال بالإشارات مثل `@current` و`@selection` و`@problems`.
- استخدام أزرار كتل الكود: نسخ، وإدراج عند المؤشر، وتطبيق على ملف، وملف جديد، وتشغيل في الطرفية.
- أين تُحفظ المحادثات، وكيف تبدأ محادثة جديدة.

## فتح النافذة

افتح **View > AI Chat** أو اضغط `Ctrl+Alt+I` (بالعربية: **عرض > محادثة الذكاء الاصطناعي**). تظهر النافذة بجانب **Solution Explorer** (مستكشف الحلول). وفي تخطيط VS Code أو Agent (**View > Layout**) تجدها أيضًا أيقونة في الشريط الجانبي.

في أعلى النافذة قائمة لاختيار **المزود والنموذج**. اختر **Auto** إذا لم تكن متأكدًا.

اكتب سؤالك في المربع السفلي:

- `Enter` يرسل السؤال.
- `Shift+Enter` ينزل سطرًا جديدًا دون إرسال.

> **العربية تعمل بشكل طبيعي:** كل فقرة تأخذ اتجاهها حسب أول حرف فيها، فالأسئلة والإجابات العربية تُقرأ من اليمين إلى اليسار، والكود يبقى من اليسار إلى اليمين.

## السياق: لماذا يحتاج النموذج أن «يرى» الكود؟

إذا سألت «لماذا لا يعمل برنامجي؟» دون أن تُري النموذج البرنامج، فسيخمّن فقط. مثل أن تتصل بميكانيكي وتقول «السيارة لا تعمل» دون أن يراها!

لذلك تتيح لك البيئة إرفاق أجزاء من مشروعك بالسؤال باستخدام **الإشارات** (@-mentions). اكتب `@` في مربع السؤال فتظهر قائمة إكمال:

| الإشارة | ماذا تُرفق |
|---|---|
| `@current` | الملف المفتوح حاليًا |
| `@selection` | الكود المحدد (أو الملف كله إذا لم تحدد شيئًا) |
| `@file:path` | ملف معين، مثل `@file:Form1.py` أو `@file:"my file.py"` |
| `@problems` | الأخطاء في **Error List** (قائمة الأخطاء) |
| `@form` | النموذج الحالي في المصمم (ملف `.form`) |
| `@project` | شجرة ملفات المشروع أو الحل |
| `@git` | التغييرات في Git (`git status` والفروق) |
| `@terminal` | آخر ما ظهر في الطرفية |
| `@output` | آخر ما ظهر في نافذة **Output** (المخرجات) |

أمثلة لأسئلة جيدة:

```text
اشرح لي @current سطرًا سطرًا بالعربية
لماذا يظهر هذا الخطأ؟ @problems @selection
اكتب اختبارات للدالة المحددة @selection
لخّص التغييرات قبل الإيداع @git
```

> **انتبه للحجم:** البيئة تقص السياق إذا كان طويلًا جدًا (تقريبًا 4 حروف لكل «رمز» token). أرفق ما تحتاجه فقط.

## سؤال من المحرر مباشرة

حدد كودًا في المحرر، ثم انقر بالزر الأيمن واختر **Ask AI about This** (اسأل الذكاء الاصطناعي عن هذا). أو من القائمة: **Tools > Ask AI about the Selection** (أدوات > اسأل الذكاء الاصطناعي عن التحديد). يُرفق التحديد تلقائيًا بالسؤال. ويوجد الأمر نفسه في قائمة **Solution Explorer** لملف كامل.

## أزرار كتل الكود

عندما تحتوي الإجابة على كود، تظهر فوقه أزرار:

| الزر | ماذا يفعل |
|---|---|
| Copy | ينسخ الكود |
| Insert at cursor | يدرجه في المحرر مكان المؤشر |
| Apply to file | يطبّقه على ملف، مع **عرض الفروق** أولًا لتقبل أو ترفض |
| New file | ينشئ ملفًا جديدًا بهذا الكود |
| Run in Terminal | يشغّل الأوامر (مثل `pip install ...`) في الطرفية |

**Apply to file** لا يكتب شيئًا مباشرة: يفتح نافذة مقارنة جنبًا إلى جنب، القديم يمينًا والجديد يسارًا (أو العكس حسب اتجاه الواجهة)، وأنت تضغط **Accept** (قبول) أو **Reject** (رفض).

## مثال: كيف تفهم البيئة الإشارات؟

البيئة تبحث في نص سؤالك عن الكلمات التي تبدأ بـ `@` ثم تجمع ما تشير إليه. هذا مثال مبسّط يستخرج الإشارات بالتعبيرات النمطية (regular expressions):

```python run
import re

question = "لماذا يظهر هذا الخطأ؟ @problems @file:Form1.py @selection"

mentions = re.findall(r"@(\w+)(?::(\S+))?", question)
for kind, arg in mentions:
    if arg:
        print("إشارة:", kind, "| الملف:", arg)
    else:
        print("إشارة:", kind)

clean = re.sub(r"\s*@\S+", "", question).strip()
print("السؤال دون الإشارات:", clean)
```

```text output
إشارة: problems
إشارة: file | الملف: Form1.py
إشارة: selection
السؤال دون الإشارات: لماذا يظهر هذا الخطأ؟
```

## حفظ المحادثات

- كل محادثة تُحفظ **مع المشروع** في المجلد `.radide/ai/chats/` داخل مجلد المشروع أو الحل.
- زر **New chat** (محادثة جديدة) يبدأ محادثة فارغة، والمحادثات القديمة تبقى في القائمة.
- **Regenerate** (إعادة الإنشاء) يطلب إجابة جديدة للسؤال الأخير، و**Stop** (إيقاف) يوقف إجابة طويلة.

> **نصيحة:** أضف `.radide/` إلى ملف `.gitignore` إذا كنت لا تريد رفع محادثاتك مع المشروع إلى Git.

## أخطاء شائعة

- **سؤال بلا سياق:** «صلّح الخطأ» وحدها لا تكفي. أضف `@problems` و`@current`.
- **إرفاق المشروع كله دائمًا:** `@project` يرسل شجرة الملفات فقط، وليس كل الكود. أرفق الملفات المهمة بـ `@file:`.
- **لصق الإجابة دون مراجعة:** استخدم **Apply to file** لترى الفروق بدل النسخ واللصق الأعمى.
- **محادثة واحدة طويلة لكل شيء:** النموذج «يتذكر» المحادثة كلها، فإذا تغيّر الموضوع ابدأ **New chat**.

## تمارين

### تمرين 1: عدّ الإشارات

اكتب برنامجًا يعدّ الإشارات في السؤال `"راجع @current وقارنه مع @git ثم انظر @problems"` ويطبع عددها ثم أسماءها مفصولة بفاصلة.

```python exercise
import re

question = "راجع @current وقارنه مع @git ثم انظر @problems"
# استخرج الإشارات واطبع عددها وأسماءها
```

```python solution
import re

question = "راجع @current وقارنه مع @git ثم انظر @problems"
names = re.findall(r"@(\w+)", question)
print("عدد الإشارات:", len(names))
print(", ".join(names))
```

```text output
عدد الإشارات: 3
current, git, problems
```

## الخلاصة

- **AI Chat** (`Ctrl+Alt+I`) للنقاش والأسئلة، بأي مزود تختاره.
- الإشارات `@` تعطي النموذج السياق: الملف الحالي، والتحديد، والأخطاء، وGit، والطرفية.
- أزرار كتل الكود تُدرج الكود أو تطبّقه مع **مراجعة الفروق** دائمًا.

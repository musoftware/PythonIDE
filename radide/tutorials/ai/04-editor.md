# الدرس 4: الذكاء الاصطناعي داخل المحرر: الإكمال المضمّن وCtrl+I

**في هذا الدرس ستتعلم:**

- **الإكمال المضمّن** (ghost text): نص رمادي يقترحه النموذج وأنت تكتب.
- **التعديل بـ `Ctrl+I`**: تحدد كودًا وتكتب بالكلام ما تريد تغييره.
- أوامر القائمة **Edit > AI**: شرح، إصلاح، إعادة هيكلة، تعليقات، توثيق، اختبارات، ترجمة.
- **Fix with AI** من قائمة الأخطاء، ورسالة الإيداع في Git، وتوليد النماذج بالذكاء الاصطناعي.

## الإكمال المضمّن (النص الرمادي)

وأنت تكتب في المحرر، يظهر بعد لحظة نص **رمادي باهت** يكمل سطرك أو دالتك:

- `Tab` يقبل الاقتراح.
- `Esc` يتجاهله.
- `Alt+\` يطلب اقتراحًا فورًا (مفيد مع برامج CLI لأنها لا تُسأل تلقائيًا).

تشغيله وإيقافه:

- زر **AI** في شريط الحالة أسفل النافذة.
- أو **Edit > AI > Inline Completions** (تحرير > الذكاء الاصطناعي > الإكمال المضمّن).

> **تشبيه:** الإكمال المضمّن مثل اقتراح الكلمة التالية في لوحة مفاتيح الهاتف، لكنه يقترح سطرًا أو دالة كاملة. لا تقبله إلا إذا كان هو ما كنت ستكتبه فعلًا.

**أي مزود يُستخدم؟** المزود المختار للغرض **Inline completion** في **Tools > AI Settings...**. النماذج المحلية ومفاتيح API تُسأل تلقائيًا أثناء الكتابة، أما برامج CLI فلا تُسأل إلا بـ `Alt+\`.

## التعديل بـ Ctrl+I

هذه أقوى أداة للتعديل السريع:

**الخطوة 1:** حدد الكود الذي تريد تغييره (أو ضع المؤشر في المكان الذي تريد الإضافة فيه).

**الخطوة 2:** اضغط `Ctrl+I` (أو **Edit > AI > Edit with AI...**، بالعربية: **تحرير > الذكاء الاصطناعي > تعديل بالذكاء الاصطناعي...**).

**الخطوة 3:** يظهر مربع صغير فوق التحديد. اكتب طلبك، مثل: «أضف التحقق من أن الرقم ليس سالبًا».

**الخطوة 4:** يظهر التعديل المقترح **كفرق** داخل المربع. اختر:

| الزر | الاختصار | المعنى |
|---|---|---|
| Accept | `Ctrl+Enter` | قبول التعديل |
| Reject | `Esc` | رفضه وإرجاع الكود كما كان |
| Review Diff... | | فتح مقارنة جنبًا إلى جنب للتغييرات الكبيرة |

## أوامر القائمة الجاهزة

في **Edit > AI** (وفي القائمة التي تظهر بالزر الأيمن داخل المحرر) أوامر جاهزة تعمل على التحديد:

| الأمر | بالعربية | النتيجة |
|---|---|---|
| Explain | شرح | شرح للكود في AI Chat |
| Fix | إصلاح | اقتراح إصلاح للأخطاء |
| Refactor | إعادة الهيكلة | كود أنظف بنفس السلوك |
| Add Comments | إضافة تعليقات | تعليقات توضيحية |
| Generate Docs | إنشاء التوثيق | docstring أو تعليقات توثيق |
| Generate Tests | إنشاء الاختبارات | اختبارات للدالة |
| Translate To | ترجمة إلى | نفس الكود بلغة أخرى من لغات البيئة |

## مثال: من كود فيه خطأ إلى كود صحيح

هذه دالة تحسب متوسط الدرجات، وفيها خطأ: إذا كانت القائمة فارغة يقسم البرنامج على صفر.

```python
def average(grades):
    return sum(grades) / len(grades)

print(average([]))   # ZeroDivisionError!
```

حددنا الدالة وضغطنا `Ctrl+I` وكتبنا: «إذا كانت القائمة فارغة أرجع 0». هذا ما اقترحه النموذج، وراجعناه ثم قبلناه:

```python run
def average(grades):
    if not grades:
        return 0
    return sum(grades) / len(grades)

print(average([80, 90, 100]))
print(average([]))
```

```text output
90.0
0
```

ثم اخترنا **Edit > AI > Generate Tests** على الدالة نفسها. هذه اختبارات بسيطة من النوع الذي يولّده، وشغّلناها للتأكد:

```python run
def average(grades):
    if not grades:
        return 0
    return sum(grades) / len(grades)

def test_average():
    assert average([80, 90, 100]) == 90
    assert average([]) == 0
    assert average([50]) == 50

test_average()
print("كل الاختبارات نجحت")
```

```text output
كل الاختبارات نجحت
```

> **لماذا نشغّل الاختبارات بأنفسنا؟** لأن النموذج قد يكتب اختبارًا خاطئًا أو يتوقع نتيجة غير صحيحة. الاختبار الذي لم يُشغَّل لا قيمة له.

## الذكاء الاصطناعي في أماكن أخرى

- **قائمة الأخطاء (Error List):** انقر بالزر الأيمن على خطأ واختر **Fix with AI** (إصلاح بالذكاء الاصطناعي) أو **Explain with AI** (شرح بالذكاء الاصطناعي).
- **Git Changes** (`Ctrl+Alt+G`): زر **Generate Message with AI** يكتب رسالة إيداع من التغييرات.
- **مصمم النماذج:** **Project > Generate Form with AI...** (مشروع > إنشاء نموذج بالذكاء الاصطناعي...) تصف فيه النافذة بالكلام فيصممها، وبالزر الأيمن على النموذج تجد **AI > Redesign This Form with AI...** و**Generate New Form with AI...**. سنجرب هذا في المشروع العملي (الدرس 8).

## أخطاء شائعة

- **قبول الإكمال بـ Tab دون قراءة:** خصوصًا في الأرقام والشروط، فخطأ صغير مثل `<` بدل `<=` يغيّر النتيجة.
- **تحديد كود كبير جدًا مع `Ctrl+I`:** كلما صغر التحديد كان التعديل أدق. عدّل دالة واحدة في كل مرة.
- **طلب غامض:** «حسّن الكود» قد تعني أي شيء. الأفضل: «اجعل أسماء المتغيرات واضحة ولا تغيّر السلوك».
- **نسيان التشغيل بعد القبول:** شغّل البرنامج (`F5`) أو الاختبارات بعد كل تعديل.

## تمارين

### تمرين 1: أصلح الدالة كما يفعل Ctrl+I

الدالة التالية يجب أن ترجع أكبر رقم في القائمة، وترجع `None` إذا كانت القائمة فارغة، لكنها تتوقف بخطأ مع القائمة الفارغة. أصلحها.

```python exercise
def biggest(numbers):
    best = numbers[0]
    for n in numbers:
        if n > best:
            best = n
    return best

print(biggest([3, 9, 4]))
print(biggest([]))
```

```python solution
def biggest(numbers):
    if not numbers:
        return None
    best = numbers[0]
    for n in numbers:
        if n > best:
            best = n
    return best

print(biggest([3, 9, 4]))
print(biggest([]))
```

```text output
9
None
```

### تمرين 2: اكتب الاختبارات بنفسك

اكتب دالة `test_biggest` فيها ثلاثة اختبارات `assert` للدالة المصححة، ثم اطبع «نجحت الاختبارات».

```python exercise
def biggest(numbers):
    if not numbers:
        return None
    return max(numbers)

def test_biggest():
    pass  # أضف ثلاثة اختبارات

test_biggest()
```

```python solution
def biggest(numbers):
    if not numbers:
        return None
    return max(numbers)

def test_biggest():
    assert biggest([3, 9, 4]) == 9
    assert biggest([-5, -2]) == -2
    assert biggest([]) is None

test_biggest()
print("نجحت الاختبارات")
```

```text output
نجحت الاختبارات
```

## الخلاصة

- الإكمال المضمّن: نص رمادي، `Tab` للقبول، `Esc` للتجاهل، `Alt+\` للطلب الفوري.
- `Ctrl+I`: حدد واطلب بالكلام، ثم **Accept** أو **Reject** بعد رؤية الفرق.
- **Edit > AI** فيها أوامر جاهزة: شرح، إصلاح، إعادة هيكلة، تعليقات، توثيق، اختبارات، ترجمة.
- دائمًا: راجع، ثم شغّل، ثم اختبر.

# الدرس 5: مدير الوكلاء: مهام ينفذها الوكيل وأنت تراجع

**في هذا الدرس ستتعلم:**

- الفرق بين **المحادثة** و**الوكيل** (Agent).
- إنشاء مهمة في **Agent Manager** واختيار المزود و**وضع الأذونات**.
- متابعة الخطوات، والموافقة أو الرفض، ومراجعة **التغييرات** ملفًا ملفًا.
- **نقاط الاستعادة** (checkpoints) وزر **Undo all** (تراجع عن الكل).
- كيف «يستدعي» النموذج الأدوات من الداخل.

## ما الوكيل؟

في المحادثة **أنت** تنفذ: تسأل، تنسخ، تلصق، تشغّل. أما **الوكيل** فينفذ بنفسه عدة خطوات: يقرأ الملفات، ويكتب ويعدّل، ويشغّل الأوامر، ويرى النتيجة، ثم يكمل حتى تنتهي المهمة.

> **تشبيه:** المحادثة مثل أن تسأل خبيرًا على الهاتف. الوكيل مثل **متدرب** تعطيه مهمة مكتوبة: «أنشئ ملف `hello.py` يطبع مرحبًا ثم شغّله». يعمل وحده، لكنه يطرق بابك قبل أي شيء مهم ليأخذ موافقتك.

## فتح مدير الوكلاء

افتح **View > Agent Manager** أو اضغط `Ctrl+Alt+M` (بالعربية: **عرض > مدير الوكلاء**). ولمهمة جديدة مباشرة: **View > New Agent Task...** (مهمة وكيل جديدة...). وفي تخطيط **Agent** (**View > Layout > Agent**) يصبح مدير الوكلاء هو الواجهة الرئيسية.

## إنشاء مهمة

في الجزء الأيسر **منطقة كتابة المهمة**:

| الحقل | معناه |
|---|---|
| نص المهمة | ما تريده بوضوح، مثل: «أضف زر مسح إلى Form1 يمسح خانة الاسم» |
| Agent | المزود والنموذج (Claude Code، Gemini CLI، Ollama ...) |
| وضع الأذونات | متى يطلب الوكيل موافقتك (انظر الجدول التالي) |
| Max steps | أقصى عدد خطوات، حتى لا يدور الوكيل بلا نهاية |
| Folder | المجلد الذي يعمل فيه (مجلد مشروعك عادةً) |

ثم اضغط **Start**. ويمكن تشغيل **عدة مهام في الوقت نفسه**، وكل مهمة تظهر في القائمة بحالتها.

### أوضاع الأذونات

| الوضع | المعنى | متى تستخدمه |
|---|---|---|
| Ask every time | يسألك قبل كل كتابة وكل أمر | **ابدأ به دائمًا**، خصوصًا وأنت تتعلم |
| Auto-approve edits | يعدّل الملفات دون سؤال، لكنه يسأل قبل الأوامر | عندما تثق بالمهمة وتريد السرعة |
| Auto-approve all | لا يسأل أبدًا | لمهام صغيرة في مجلد تجارب فقط |

## متابعة المهمة والموافقة

في الجزء الأيمن ترى **المحادثة**: الخطة، ثم كل خطوة ونتيجتها لحظة بلحظة. عندما يحتاج الوكيل موافقتك يظهر **شريط موافقة**:

- **Approve** (موافقة): نفّذ هذه الخطوة.
- **Always allow**: وافق على هذا النوع من الخطوات حتى نهاية المهمة.
- **Reject** (رفض): لا تنفّذها، وسيحاول الوكيل طريقًا آخر.

وجرس **Inbox** يجمع التنبيهات: «مهمة تحتاج موافقة» و«مهمة انتهت»، حتى لو كنت تعمل في نافذة أخرى.

## مراجعة التغييرات

في تبويب **Changes** (التغييرات) يظهر كل ملف عدّله الوكيل مع الفروق:

- **Accept** / **Reject** لكل ملف على حدة.
- **Accept all** (قبول الكل).
- **Undo all** (تراجع عن الكل): يعيد المجلد كما كان قبل المهمة.

كيف يعمل **Undo all**؟ قبل أن يلمس الوكيل أي ملف، تنسخ البيئة نسخته الأصلية إلى **نقطة استعادة** في المجلد `.radide/ai/checkpoints/<رقم المهمة>/`. لذلك يمكنك دائمًا الرجوع.

وفي تبويب **Artifacts** ملفات يكتبها الوكيل عن عمله: `plan.md` (الخطة) و`walkthrough.md` (شرح ما فعله)، وصور من **Preview** في مشاريع الويب.

## من الداخل: كيف يستدعي النموذج الأدوات؟

مع المزودين العاديين (مثل Ollama) تستخدم البيئة **محركًا داخليًا** للوكيل. يُطلب من النموذج أن يكتب في كل رد **أداة واحدة** على شكل JSON داخل كتلة اسمها `tool`، مثل:

```text
{"tool": "write_file", "path": "hello.py", "content": "print('hello')"}
```

والأدوات المتاحة: `list_files` و`read_file` و`search` و`write_file` و`edit_file` و`run_command` و`finish`. البيئة تقرأ الكتلة، وتنفذ الأداة (بعد موافقتك إن لزم)، وترسل النتيجة للنموذج ليكمل.

هذه محاكاة مبسطة: ردود «نموذج» جاهزة، وأدوات وهمية تعمل في الذاكرة فقط، دون أي ملفات حقيقية:

```python run
import json
import re

FENCE = "`" * 3
replies = [
    "الخطة: 1) أكتب الملف 2) أنهي المهمة\n" + FENCE + "tool\n"
    '{"tool": "write_file", "path": "hello.py", "content": "print(1)"}\n' + FENCE,
    FENCE + "tool\n" + '{"tool": "finish", "summary": "أنشأت hello.py"}\n' + FENCE,
]

files = {}  # "قرص" وهمي في الذاكرة

for reply in replies:
    m = re.search(FENCE + r"tool\n(.*?)" + FENCE, reply, re.S)
    call = json.loads(m.group(1))
    name = call["tool"]
    if name == "write_file":
        print("الوكيل يطلب كتابة", call["path"], "-> موافقة")
        files[call["path"]] = call["content"]
    elif name == "finish":
        print("انتهت المهمة:", call["summary"])
        break

print("الملفات:", files)
```

```text output
الوكيل يطلب كتابة hello.py -> موافقة
انتهت المهمة: أنشأت hello.py
الملفات: {'hello.py': 'print(1)'}
```

أما برامج CLI الرسمية (Claude Code وGemini CLI وCodex ...) فتعمل في **وضع الوكيل الخاص بها** داخل المجلد، والبيئة تحوّل أحداثها إلى خطوات، وتكتشف الملفات المتغيرة بمقارنة المجلد قبل التشغيل وبعده. وفي وضع **Ask every time** يعمل البرنامج أولًا **للقراءة فقط** ليكتب خطة، ثم يعدّل بعد موافقتك على الخطة.

## أخطاء شائعة

- **مهمة غامضة:** «حسّن المشروع» مهمة بلا نهاية. اكتب مهمة محددة يمكن التحقق منها: «أضف زرًا يمسح الخانات، وشغّل البرنامج للتأكد».
- **Auto-approve all في مشروع حقيقي:** قد يحذف الوكيل أو يعيد كتابة ملفات مهمة. ابدأ بـ **Ask every time**.
- **عدم مراجعة Changes:** المهمة «انتهت» لا تعني أنها صحيحة. راجع الفروق وشغّل البرنامج.
- **العمل دون Git:** **Undo all** يحفظ المهمة الحالية فقط. استخدم Git (`Ctrl+Alt+G`) واحفظ إيداعًا قبل المهام الكبيرة.

### تمرين 1: أضف أداة القراءة إلى المحاكاة

أضف إلى المحاكاة ردًا جديدًا (قبل `finish`) يستدعي `read_file` للملف `hello.py`، واجعل البرنامج يطبع «الوكيل قرأ:» ثم محتوى الملف من القاموس `files`.

```python exercise
import json
import re

FENCE = "`" * 3
replies = [
    FENCE + "tool\n" + '{"tool": "write_file", "path": "hello.py", "content": "print(1)"}\n' + FENCE,

files = {}
for reply in replies:
    call = json.loads(re.search(FENCE + r"tool\n(.*?)" + FENCE, reply, re.S).group(1))
    if call["tool"] == "write_file":
        files[call["path"]] = call["content"]
    elif call["tool"] == "finish":
        print("انتهت المهمة:", call["summary"])
```

```python solution
import json
import re

FENCE = "`" * 3
replies = [
    FENCE + "tool\n" + '{"tool": "write_file", "path": "hello.py", "content": "print(1)"}\n' + FENCE,
    FENCE + "tool\n" + '{"tool": "read_file", "path": "hello.py"}\n' + FENCE,
    FENCE + "tool\n" + '{"tool": "finish", "summary": "تم"}\n' + FENCE,
]
files = {}
for reply in replies:
    call = json.loads(re.search(FENCE + r"tool\n(.*?)" + FENCE, reply, re.S).group(1))
    if call["tool"] == "write_file":
        files[call["path"]] = call["content"]
    elif call["tool"] == "read_file":
        print("الوكيل قرأ:", files[call["path"]])
    elif call["tool"] == "finish":
        print("انتهت المهمة:", call["summary"])
```

```text output
الوكيل قرأ: print(1)
انتهت المهمة: تم
```

## الخلاصة

- الوكيل ينفذ مهمة كاملة بعدة خطوات، وأنت توافق وتراجع.
- **Agent Manager** (`Ctrl+Alt+M`): نص المهمة، والمزود، ووضع الأذونات، وأقصى عدد خطوات.
- راجع **Changes** ملفًا ملفًا، و**Undo all** يعيد كل شيء من نقطة الاستعادة.
- ابدأ دائمًا بـ **Ask every time**، واحفظ إيداع Git قبل المهام الكبيرة.

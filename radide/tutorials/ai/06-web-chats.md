# الدرس 6: محادثات الويب داخل البيئة

**في هذا الدرس ستتعلم:**

- فتح مواقع الذكاء الاصطناعي المجانية (ChatGPT وGemini وClaude وDeepSeek ...) داخل البيئة.
- تسجيل الدخول مرة واحدة وبقاء الدخول محفوظًا.
- إرسال **السياق** (التحديد، والأخطاء، والملف) إلى الموقع بضغطة زر.
- **التقاط الكود** من إجابة الموقع وإدراجه أو تطبيقه على ملف.
- إضافة موقع مخصص، وتسجيل الخروج من كل المواقع.

## لماذا محادثات الويب؟

كثير من المواقع تقدم محادثة مجانية بحسابك العادي، دون مفتاح API ودون تثبيت أي برنامج. **AI Web Chats** تفتح هذه المواقع الرسمية نفسها داخل نافذة في البيئة، فلا تحتاج أن تنتقل بين المتصفح والمحرر وتنسخ وتلصق باستمرار.

> **مهم:** البيئة تستخدم **الصفحات الرسمية فقط** كما يستخدمها أي شخص في المتصفح. لا توجد أي طرق غير رسمية أو التفاف على شروط المواقع.

## فتح النافذة

افتح **View > AI Web Chats** أو اضغط `Ctrl+Alt+W` (بالعربية: **عرض > محادثات الذكاء الاصطناعي على الويب**). وفي تخطيط VS Code أو Agent تجدها أيقونة **كرة أرضية** في شريط النشاط.

في أعلى النافذة **قائمة المواقع**: ChatGPT، Gemini، Claude، DeepSeek، Copilot، Perplexity، Grok، Qwen، Le Chat، أو **Custom URL...** لأي عنوان آخر.

## تسجيل الدخول

اختر الموقع وسجّل الدخول **كالمعتاد** داخل الصفحة. البيئة تحفظ الدخول (ملفات تعريف الارتباط وغيرها) في **ملف تعريف واحد دائم** على جهازك في المجلد:

```text
%LOCALAPPDATA%\RADIDE\webchat
```

لذلك لا تحتاج أن تسجل الدخول كل مرة. ولحذف كل ذلك: قائمة **⋯** في النافذة > **Sign out of all sites (delete cookies)...** (تسجيل الخروج من كل المواقع).

## إرسال السياق إلى الموقع

تحت الصفحة شريط فيه:

- **مربع السؤال**: تكتب فيه سؤالك.
- **Context ▾**: تختار ما يُرفق مع السؤال: التحديد أو الملف الحالي، وقائمة الأخطاء، والنموذج، وتغييرات Git، والطرفية، والإشارات `@`.
- **Send context** (إرسال السياق): يكتب السؤال والسياق في مربع الكتابة **داخل الموقع**.
- **Submit**: إذا فعّلته، يضغط زر الإرسال في الموقع تلقائيًا أيضًا.

إذا لم تستطع البيئة الكتابة في مربع الموقع (بعض المواقع تغيّر تصميمها)، تضع النص في **الحافظة** وتعطي الصفحة التركيز، فتلصقه أنت بـ `Ctrl+V`.

ومن المحرر مباشرة: حدد كودًا، ثم بالزر الأيمن **Send Selection to AI Web Chat** (إرسال التحديد إلى محادثة ويب للذكاء الاصطناعي).

## التقاط الكود من الإجابة

بعد أن يجيب الموقع، اضغط **Grab last code block** (التقاط آخر كتلة كود)، أو من قائمة الزر نفسه **All code blocks of the page...** (كل كتل الكود في الصفحة) لتختار كتلة معينة. ثم اختر ماذا تفعل بالكود:

| الإجراء | المعنى |
|---|---|
| Copy | نسخ |
| Insert at cursor | إدراج مكان المؤشر في المحرر |
| Replace selection | استبدال التحديد |
| Apply to file | تطبيق على ملف مع معاينة الفروق ثم قبول أو رفض |
| New file | ملف جديد |

## محادثات الويب كمزودين

كل موقع يظهر أيضًا **مزودًا** في قوائم اختيار المزود (اسمه مثل `web-chatgpt`). عندما تختاره في **AI Chat**، تكتب البيئة سؤالك في صفحة الموقع وتقرأ الإجابة حتى تتوقف عن التغير، كما يقرؤها المستخدم بعينه. هذه الطريقة «أفضل محاولة»، وقد تكون أبطأ وأقل دقة من مزود CLI أو نموذج محلي.

## مثال: لماذا نختصر السياق قبل إرساله؟

مواقع المحادثة لها حد لطول الرسالة، والسياق الطويل جدًا يُبطئ الإجابة ويشتت النموذج. هذا مثال صغير يقص النص الطويل إلى عدد أحرف محدد، ويضيف علامة واضحة أنه مقصوص، بفكرة قريبة مما تفعله البيئة مع السياق:

```python run
def trim(text, limit):
    if len(text) <= limit:
        return text
    return text[:limit] + "\n... (تم قص الباقي)"

code = "\n".join(f"line {i}" for i in range(1, 8))
print(trim(code, 20))
print("---")
print(trim("print('hi')", 20))
```

```text output
line 1
line 2
line 3
... (تم قص الباقي)
---
print('hi')
```

## إضافة موقع مخصص

إذا كانت شركتك تستخدم موقع محادثة داخليًا، أو تريد موقعًا غير موجود في القائمة: قائمة **⋯** > **Add custom site...** (إضافة موقع مخصص...)، واكتب الاسم والعنوان. ولحذفه: **Remove this custom site**.

## الخصوصية

- كل ما ترسله إلى موقع ويب **يذهب إلى خوادم ذلك الموقع**. لا ترسل كلمات مرور أو مفاتيح أو بيانات شخصية لعملائك.
- للكود السري أو بيانات الشركة استخدم نموذجًا محليًا (Ollama) كما في الدرس 2.
- راجع إعدادات الموقع نفسه: بعض المواقع تستخدم المحادثات لتدريب نماذجها إلا إذا أوقفت ذلك.

## أخطاء شائعة

- **السؤال دون تسجيل الدخول:** بعض المواقع لا تقبل الأسئلة قبل الدخول، فيبدو أن **Send context** لا يعمل.
- **إرسال ملف ضخم:** اختر في **Context ▾** ما تحتاجه فقط.
- **لصق الكود الملتقط دون مراجعة:** استخدم **Apply to file** لترى الفروق.
- **توقع أن الموقع يعرف مشروعك:** الموقع لا يرى إلا ما أرسلته في الرسالة.

## تمرين

### تمرين 1: قص بعدد الأسطر

اكتب دالة `trim_lines(text, n)` تُبقي أول `n` أسطر فقط، وتضيف السطر `"... (و X أسطر أخرى)"` إذا حذفت شيئًا، حيث X عدد الأسطر المحذوفة.

```python exercise
def trim_lines(text, n):
    lines = text.split("\n")
    # أكمل

code = "\n".join(f"line {i}" for i in range(1, 6))
print(trim_lines(code, 2))
```

```python solution
def trim_lines(text, n):
    lines = text.split("\n")
    if len(lines) <= n:
        return text
    rest = len(lines) - n
    return "\n".join(lines[:n]) + f"\n... (و {rest} أسطر أخرى)"

code = "\n".join(f"line {i}" for i in range(1, 6))
print(trim_lines(code, 2))
```

```text output
line 1
line 2
... (و 3 أسطر أخرى)
```

### تمرين 2 (عملي في البيئة)

افتح `Ctrl+Alt+W`، واختر موقعًا وسجّل الدخول. حدد دالة في المحرر واستخدم **Send Selection to AI Web Chat**، واطلب «أضف تعليقات عربية». ثم اضغط **Grab last code block** واختر **Apply to file** وراجع الفروق.

## الخلاصة

- **AI Web Chats** (`Ctrl+Alt+W`) تفتح المواقع الرسمية داخل البيئة بحسابك.
- **Send context** يكتب سؤالك وسياقك في الموقع، و**Grab last code block** يعيد الكود إلى المحرر.
- كل موقع يمكن أن يعمل مزودًا، لكن النماذج المحلية وبرامج CLI أدق وأسرع.
- ما ترسله إلى موقع يخرج من جهازك، فاحذر من الأسرار.

# الدرس 7: كتابة طلبات جيدة، والخصوصية، والعمل دون إنترنت

**في هذا الدرس ستتعلم:**

- وصفة بسيطة لكتابة **طلب** (prompt) واضح يعطيك إجابة أفضل.
- كيف تحمي **أسرارك** (كلمات المرور والمفاتيح) قبل إرسال أي كود.
- إعداد بيئة عمل كاملة **دون إنترنت** بنموذج محلي.
- متى لا تستخدم الذكاء الاصطناعي أصلًا.

## وصفة الطلب الجيد: «د.س.ش.ن»

النموذج لا يقرأ أفكارك. كلما كان طلبك أوضح كانت الإجابة أفضل. تذكّر أربعة أشياء:

| الحرف | المعنى | مثال |
|---|---|---|
| **د**ور | من هو النموذج؟ | «أنت مدرس Python للمبتدئين» |
| **س**ياق | ما الذي يجب أن يعرفه؟ | `@current` و`@problems` |
| **ش**رط | ما القيود؟ | «لا تستخدم مكتبات خارجية، واشرح بالعربية» |
| **ن**اتج | ما شكل الإجابة؟ | «أعطني الكود فقط في كتلة واحدة» |

**طلب ضعيف:**

```text
البرنامج فيه مشكلة
```

**طلب جيد:**

```text
أنت مساعد Python للمبتدئين. عند الضغط على زر "احسب" يظهر الخطأ في @problems.
الكود في @current. اشرح سبب الخطأ بالعربية في 3 أسطر، ثم أعطني الدالة المصححة فقط.
```

## مثال: بناء الطلب من أجزائه

هذا برنامج صغير يجمع أجزاء الوصفة في طلب واحد مرتب، ويمكنك استخدام الفكرة نفسها لتحفظ «قوالب طلبات» تكررها:

```python run
def build_prompt(role, context, rules, output):
    parts = [
        "الدور: " + role,
        "السياق: " + context,
        "الشروط: " + "، ".join(rules),
        "الناتج المطلوب: " + output,
    ]
    return "\n".join(parts)

prompt = build_prompt(
    "مدرس Python للمبتدئين",
    "@current @problems",
    ["اشرح بالعربية", "بلا مكتبات خارجية"],
    "الدالة المصححة فقط",
)
print(prompt)
```

```text output
الدور: مدرس Python للمبتدئين
السياق: @current @problems
الشروط: اشرح بالعربية، بلا مكتبات خارجية
الناتج المطلوب: الدالة المصححة فقط
```

## احمِ أسرارك قبل الإرسال

قبل أن ترسل كودًا إلى خدمة سحابية (مزود API أو موقع ويب أو CLI)، تأكد أنه لا يحتوي على:

- كلمات مرور قواعد البيانات.
- مفاتيح API (تبدأ كثيرًا بـ `sk-` أو `AIza` ...).
- بيانات شخصية لعملاء حقيقيين.

**الحل الصحيح:** لا تكتب الأسرار في الكود أصلًا. ضعها في **متغيرات البيئة** أو ملف `.env` مستبعد من Git، واقرأها في البرنامج:

```python run
import os

# المفتاح يأتي من متغير بيئة، وليس مكتوبًا في الكود
api_key = os.environ.get("MY_SERVICE_KEY", "")
if api_key:
    print("تم العثور على المفتاح")
else:
    print("المفتاح غير موجود: عرّف المتغير MY_SERVICE_KEY")
```

```text output
المفتاح غير موجود: عرّف المتغير MY_SERVICE_KEY
```

وهذا مثال لفحص بسيط **يخفي** ما يشبه الأسرار في نص قبل إرساله. هذه فكرة تعليمية فقط، وليست بديلًا عن عدم كتابة الأسرار في الكود:

```python run
import re

code = '''db_password = "Cairo2024!"
api_key = "sk-abc123xyz"
name = "Sara"'''

masked = re.sub(r'((?:password|key|token)\w*\s*=\s*")[^"]*(")', r"\1***\2", code, flags=re.I)
print(masked)
```

```text output
db_password = "***"
api_key = "***"
name = "Sara"
```

## العمل دون إنترنت بالكامل

مع **Ollama** يمكنك أن تعمل في طائرة أو في مكان بلا إنترنت:

**الخطوة 1:** وأنت متصل، ثبّت Ollama ونزّل نموذجين: واحد صغير للإكمال وواحد أكبر للمحادثة:

```text
ollama pull qwen2.5-coder:1.5b
ollama pull qwen2.5-coder:7b
```

**الخطوة 2:** في **Tools > AI Settings...** > **Default provider for each purpose** اجعل كل الأغراض على **Ollama**: الصغير لـ **Inline completion** والأكبر للباقي.

**الخطوة 3:** افصل الإنترنت وجرّب: `Ctrl+Alt+I` للمحادثة، و`Ctrl+I` للتعديل، والنص الرمادي أثناء الكتابة. كل شيء يعمل من جهازك.

> **ملاحظة:** محادثات الويب وبرامج CLI ومفاتيح API تحتاج إنترنت دائمًا.

## متى لا تستخدم الذكاء الاصطناعي؟

- **وأنت تتعلم أساسيات لغة جديدة:** اكتب الحلقات والشروط بنفسك أولًا، ثم اسأل لتفهم. الدورات في **Help > Tutorials** صُممت لهذا.
- **عندما لا تستطيع التحقق من الإجابة:** إذا لم تفهم الكود المقترح، فاطلب شرحه أولًا قبل قبوله.
- **للكود المحمي بحقوق أو المحظور تحليله:** احترم الترخيص وشروط العمل.

## أخطاء شائعة

- **طلب من كلمتين:** أضف الدور والسياق والشروط وشكل الناتج.
- **مفتاح API داخل الكود:** حتى لو حذفته لاحقًا، قد يبقى في سجل Git. ضعه في متغير بيئة.
- **الظن أن النموذج المحلي لا يحتاج مراجعة:** المحلي يحمي الخصوصية، لكنه يخطئ مثل غيره.

def build_prompt(role, context, rules, output):

### تمرين 2: هل في النص سر؟

اكتب دالة `has_secret(text)` ترجع `True` إذا وجدت في النص كلمة `password` أو نصًا يبدأ بـ `sk-`، ثم جرّبها على النصين المعطيين.

```python exercise
def has_secret(text):
    pass  # أكمل

print(has_secret('password = "123"'))
print(has_secret('total = 5'))
```

```python solution
import re

def has_secret(text):
    return bool(re.search(r"password|\bsk-\w+", text, re.I))

print(has_secret('password = "123"'))
print(has_secret('total = 5'))
```

```text output
True
False
```

## الخلاصة

- الطلب الجيد = **دور + سياق + شروط + ناتج**.
- لا تضع الأسرار في الكود، ولا ترسلها إلى أي خدمة سحابية.
- Ollama لكل الأغراض = عمل كامل دون إنترنت.
- الذكاء الاصطناعي يساعدك على التعلم، لكنه لا يتعلم بدلًا منك.

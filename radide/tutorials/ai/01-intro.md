# الدرس 1: ما الذي يقدمه الذكاء الاصطناعي في RAD IDE؟

**في هذا الدرس ستتعرف على:**

- الأدوات الذكية الموجودة في البيئة، وأين تجد كل أداة في القوائم.
- الأنواع الأربعة من **المزودين** (Providers) التي يمكن أن تعمل بها هذه الأدوات.
- القاعدة الذهبية: الذكاء الاصطناعي **يقترح**، وأنت **تقرر**.

## تشبيه بسيط: مساعد في الورشة

تخيّل أنك نجّار في ورشة، ومعك مساعد سريع جدًا: يناولك الأدوات، ويقترح عليك طريقة القص، وأحيانًا يقص بنفسه قطعة صغيرة. لكنه **قد يخطئ**، لذلك لا تركّب أي قطعة قبل أن تنظر إليها بنفسك.

هذا بالضبط دور الذكاء الاصطناعي في RAD IDE: مساعد يكتب ويشرح ويقترح، وأنت صاحب القرار الأخير. ولهذا تعرض البيئة كل تغيير على شكل **فرق** (diff) قبل أن يُكتب في ملفاتك، فتضغط «قبول» أو «رفض».

## خريطة الأدوات الذكية

| الأداة | من أين تفتحها | ماذا تفعل |
|---|---|---|
| محادثة الذكاء الاصطناعي (AI Chat) | **View > AI Chat** (`Ctrl+Alt+I`) | تسأل وتناقش، وتدرج الكود الناتج في ملفاتك |
| التعديل بالذكاء الاصطناعي | `Ctrl+I` داخل المحرر، أو **Edit > AI > Edit with AI...** | تحدد كودًا وتكتب ما تريد تغييره |
| الإكمال المضمّن (Inline Completions) | يعمل وأنت تكتب، أو `Alt+\` | نص رمادي مقترح، يُقبل بـ `Tab` |
| أوامر المحرر الجاهزة | **Edit > AI** | شرح، إصلاح، إعادة هيكلة، تعليقات، توثيق، اختبارات |
| مدير الوكلاء (Agent Manager) | **View > Agent Manager** (`Ctrl+Alt+M`) | مهمة كاملة ينفذها «وكيل» خطوة بخطوة وأنت توافق |
| محادثات الويب (AI Web Chats) | **View > AI Web Chats** (`Ctrl+Alt+W`) | مواقع مثل ChatGPT وGemini وClaude داخل البيئة بحسابك |
| إعدادات الذكاء الاصطناعي | **Tools > AI Settings...** | اختيار المزودين والنماذج واختبارها |
| إنشاء نموذج بالذكاء الاصطناعي | **Project > Generate Form with AI...** | تصف النافذة بالكلام فتُصمَّم لك |

وفي الواجهة العربية للبيئة ستجد الأسماء نفسها مترجمة: **عرض > محادثة الذكاء الاصطناعي**، و**تحرير > الذكاء الاصطناعي > تعديل بالذكاء الاصطناعي...**، و**عرض > مدير الوكلاء**، و**أدوات > إعدادات الذكاء الاصطناعي...**.

> **ملاحظة:** في هذه الدروس نكتب أسماء القوائم بالإنجليزية كما تظهر في البيئة، ثم الاسم العربي حين تكون الواجهة بالعربية (**Tools > Language > العربية**).

## من أين يأتي «الذكاء»؟ أنواع المزودين

**المزود** (Provider) هو البرنامج أو الخدمة التي تجيب فعلًا عن أسئلتك. البيئة نفسها لا تحتوي نموذجًا ذكيًا، بل تتصل بمزود تختاره أنت. هناك أربعة أنواع:

1. **برامج سطر الأوامر الرسمية (CLI) بحسابك أنت:** مثل `claude` (Claude Code) و`gemini` (Gemini CLI، مجاني بحساب Google) و`codex` و`copilot` و`qwen` و`opencode`. تسجّل الدخول مرة واحدة في الطرفية، ولا تحتاج مفتاح API.
2. **نماذج محلية على جهازك:** مثل **Ollama** و**LM Studio** أو أي خادم متوافق مع OpenAI. تعمل **دون إنترنت**، وكودك لا يغادر جهازك.
3. **مفاتيح API (اختيارية):** OpenAI وAnthropic وGemini API وOpenRouter وGroq وDeepSeek وMistral وxAI. تدفع حسب الاستخدام غالبًا.
4. **محادثات الويب:** المواقع المجانية نفسها (ChatGPT وGemini وClaude وDeepSeek ...) تفتحها داخل البيئة وتسجّل الدخول كالمعتاد.

> **تشبيه:** المزود مثل **محطة الكهرباء**، والبيئة مثل **الأجهزة في بيتك**. الأجهزة نفسها تعمل بأي محطة، وأنت تختار المصدر: لوح شمسي على سطحك (نموذج محلي)، أو شركة الكهرباء (خدمة سحابية).

## الخيار «Auto»

في كل مكان تختار فيه مزودًا ستجد الخيار **Auto**: تختار البيئة تلقائيًا **أفضل مزود مجاني متاح** على جهازك. لهذا يمكنك أن تبدأ دون أي إعداد إذا كان عندك مثلًا Ollama أو Gemini CLI مثبتًا.

## مثال: كيف «يرى» البرنامج المحادثة؟

كل المزودين تقريبًا يفهمون المحادثة على أنها **قائمة رسائل**، لكل رسالة **دور** (role) و**محتوى** (content). هذا مثال بلغة Python يبني محادثة صغيرة ويطبعها، دون أي اتصال بالإنترنت:

```python run
messages = [
    {"role": "system", "content": "أنت مساعد برمجة مختصر."},
    {"role": "user", "content": "ما معنى المتغير؟"},
    {"role": "assistant", "content": "صندوق له اسم نضع فيه قيمة."},
]

for m in messages:
    print(m["role"], ":", m["content"])

print("عدد الرسائل:", len(messages))
```

```text output
system : أنت مساعد برمجة مختصر.
user : ما معنى المتغير؟
assistant : صندوق له اسم نضع فيه قيمة.
عدد الرسائل: 3
```

- `system`: تعليمات عامة للنموذج (شخصيته وقواعده).
- `user`: ما تكتبه أنت.
- `assistant`: ردود النموذج السابقة، حتى «يتذكر» سياق المحادثة.

عندما تكتب سؤالًا في **AI Chat** تبني البيئة قائمة مثل هذه وترسلها إلى المزود الذي اخترته.

## القاعدة الذهبية

- **راجع كل كود** يقترحه الذكاء الاصطناعي قبل قبوله، تمامًا كما تراجع كود زميل جديد.
- **شغّل البرنامج وجرّبه** بعد كل تغيير.
- **لا ترسل أسرارًا** (كلمات مرور، مفاتيح، بيانات عملاء) إلى خدمة سحابية. استخدم نموذجًا محليًا للكود الحساس.

## أخطاء شائعة

- **الثقة العمياء:** قبول كل ما يقترحه النموذج دون قراءة. النماذج تخترع أحيانًا دوال غير موجودة.
- **ظن أن البيئة لا تعمل:** إذا لم يكن أي مزود مثبتًا، فلن تجد إجابات. افتح **Tools > AI Settings...** وانظر إلى حالة كل مزود.
- **الخلط بين الأدوات:** المحادثة للنقاش، و`Ctrl+I` لتعديل جزء محدد، والوكيل لمهمة كاملة من عدة خطوات.

## تمرين

### تمرين 1: أكمل المحادثة

أضف إلى القائمة رسالة جديدة من المستخدم نصها `"وما معنى الحلقة؟"` ثم اطبع عدد الرسائل ودور آخر رسالة.

```python exercise
messages = [
    {"role": "system", "content": "أنت مساعد برمجة مختصر."},
    {"role": "user", "content": "ما معنى المتغير؟"},
]
# أضف الرسالة الجديدة هنا

print("عدد الرسائل:", len(messages))
```

```python solution
messages = [
    {"role": "system", "content": "أنت مساعد برمجة مختصر."},
    {"role": "user", "content": "ما معنى المتغير؟"},
]
messages.append({"role": "user", "content": "وما معنى الحلقة؟"})

print("عدد الرسائل:", len(messages))
print("آخر دور:", messages[-1]["role"])
```

```text output
عدد الرسائل: 3
آخر دور: user
```

## الخلاصة

- في البيئة أدوات ذكية كثيرة: محادثة، وتعديل، وإكمال، ووكلاء، ومحادثات ويب.
- كلها تعمل عبر **مزود** تختاره: CLI بحسابك، أو نموذج محلي، أو مفتاح API، أو موقع ويب.
- الذكاء الاصطناعي يقترح، وأنت تراجع وتقرر.

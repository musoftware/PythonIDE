# الدرس 2: المتغيرات والأنواع والإدخال

البرامج تحتاج أن **تتذكر** أشياء: اسم المستخدم، والسعر، وعدد المحاولات. المكان الذي نحفظ فيه قيمة ونعطيه اسمًا هو **المتغير** (variable).

> **تشبيه:** المتغير مثل علبة عليها ملصق. الملصق هو الاسم (`age`)، وما بداخل العلبة هو القيمة (`20`). يمكنك أن تفرغ العلبة وتضع فيها قيمة جديدة في أي وقت.

## إنشاء متغير

في Ruby لا تكتب نوع المتغير؛ يكفي أن تعطيه قيمة بعلامة `=`:

```ruby run
name = "سارة"
age = 20
height = 1.65
student = true

puts name
puts age
puts "#{name} عمرها #{age} سنة وطولها #{height} متر"
age = age + 1
puts "بعد سنة: #{age}"
```

```text output
سارة
20
سارة عمرها 20 سنة وطولها 1.65 متر
بعد سنة: 21
```

علامة `=` هنا ليست «يساوي» كما في الرياضيات، بل معناها **«خزّن»**: `age = age + 1` تعني «احسب `age + 1` ثم خزّن الناتج في `age`».

### قواعد التسمية

- يبدأ الاسم بحرف صغير أو `_`، مثل `total` و`first_name`.
- العُرف في Ruby أن نفصل الكلمات بشرطة سفلية: `first_name` وليس `firstName` (هذا الأسلوب اسمه snake_case).
- الاسم الذي يبدأ بحرف كبير مثل `PI` يكون **ثابتًا** (constant)، ولا يُفترض أن يتغير.

## الأنواع الأساسية

كل قيمة لها **نوع** (صنف)، ويمكنك أن تسألها عنه بالدالة `.class`:

```ruby run
p 42.class
p 3.14.class
p "مرحبا".class
p true.class
p nil.class
p :ok.class
```

```text output
Integer
Float
String
TrueClass
NilClass
Symbol
```

| النوع | معناه | مثال |
|---|---|---|
| `Integer` | عدد صحيح | `42`، `-7`، `1_000_000` |
| `Float` | عدد عشري | `3.14`، `0.5` |
| `String` | نص | `"سلام"`، `'abc'` |
| `true` / `false` | قيمة منطقية (Boolean) | `true` |
| `nil` | «لا شيء»، قيمة فارغة | `nil` |
| `Symbol` | اسم ثابت خفيف | `:red`، `:ok` |

## العمليات الحسابية

```ruby run
puts 7 + 2
puts 7 - 2
puts 7 * 2
puts 7 / 2
puts 7 % 2
puts 7.0 / 2
puts 7.fdiv(2)
puts 2 ** 3
```

```text output
9
5
14
3
1
3.5
3.5
8
```

انتبه للسطر الرابع: **قسمة عدد صحيح على عدد صحيح تعطي عددًا صحيحًا** (`7 / 2` تساوي `3` ويُهمل الكسر). إذا أردت الكسر فاجعل أحد الطرفين عشريًا `7.0 / 2` أو استخدم `fdiv`. والعامل `%` يعطي **باقي القسمة**.

### الاختصارات

`x += 5` تعني `x = x + 5`، ومثلها `-=` و`*=` و`/=`. ولا يوجد في Ruby `x++`.

## التحويل بين الأنواع

```ruby run
puts "5" + "3"
puts "5".to_i + "3".to_i
puts "2.5".to_f * 2
puts 10.to_s + " نقاط"
puts "abc".to_i
puts 3.7.round
puts 3.14159.round(2)
```

```text output
53
8
5.0
10 نقاط
0
4
3.14
```

| الدالة | تحوّل إلى |
|---|---|
| `.to_i` | عدد صحيح (النص غير الرقمي يصبح `0`) |
| `.to_f` | عدد عشري |
| `.to_s` | نص |
| `.round(n)` | تقريب إلى `n` منازل عشرية |

## قراءة الإدخال: `gets`

الدالة `gets` تنتظر المستخدم حتى يكتب سطرًا ويضغط Enter، وتُرجع النص **ومعه رمز السطر الجديد** في آخره. لذلك نضيف `.chomp` لنحذفه:

```ruby run
print "ما اسمك؟ "
name = gets.chomp
print "كم عمرك؟ "
age = gets.to_i
puts
puts "أهلًا يا #{name}!"
puts "بعد عشر سنوات سيكون عمرك #{age + 10}"
```

```text input
عمر
25
```

```text output
ما اسمك؟ كم عمرك؟ 
أهلًا يا عمر!
بعد عشر سنوات سيكون عمرك 35
```

- عند الضغط على «جرّبه» تأخذ الـ IDE المدخلات المكتوبة في الدرس (`عمر` ثم `25`) وترسلها للبرنامج كأن المستخدم كتبها. في مشروعك الخاص ستكتبها أنت.
- `gets.to_i` تكفي للأرقام لأن `to_i` تتجاهل رمز السطر الجديد.
- لاحظ أن ما يكتبه المستخدم لا يظهر في الناتج، لأنه دخل من لوحة المفاتيح وليس من البرنامج؛ لذلك جاءت الأسئلة على سطر واحد.

## الثوابت

```ruby run
PI = 3.14159
radius = 2
area = PI * radius ** 2
puts "مساحة الدائرة = #{area.round(2)}"
```

```text output
مساحة الدائرة = 12.57
```

لاحظ ترتيب العمليات: `**` قبل `*`، كما في الرياضيات. وإذا غيّرت قيمة ثابت لاحقًا فستحذرك Ruby برسالة `already initialized constant`.

## أخطاء شائعة

### جمع نص مع رقم

<!-- compile-error -->
```ruby
age = 20
puts "العمر: " + age
```

النتيجة خطأ: `no implicit conversion of Integer into String` أي «لا يوجد تحويل تلقائي من عدد صحيح إلى نص». الحل: `"العمر: " + age.to_s` أو الأفضل `"العمر: #{age}"`.

### نسيان `chomp`

بدون `chomp` يبقى رمز السطر الجديد داخل الاسم، فإذا كتبت `puts "أهلًا #{name}!"` ستظهر علامة التعجب في سطر جديد.

### نسيان أن `7 / 2` تساوي `3`

إذا حسبت متوسط درجات بـ `(90 + 85) / 2` ستحصل على `87` بدل `87.5`. اكتب `(90 + 85) / 2.0`.

## تمارين

### التمرين 1

اقرأ عددين صحيحين (كل عدد في سطر) واطبع مجموعهما وحاصل ضربهما.

```ruby exercise
a = gets.to_i
b = gets.to_i
# اطبع:
# المجموع = ...
# الضرب = ...
```

```ruby solution
a = gets.to_i
b = gets.to_i
puts "المجموع = #{a + b}"
puts "الضرب = #{a * b}"
```

```text input
6
7
```

```text output
المجموع = 13
الضرب = 42
```

### التمرين 2

اقرأ درجة الحرارة بالمئوية (عدد عشري) وحوّلها إلى فهرنهايت بالقانون `F = C × 9 / 5 + 32`، واطبع الناتج مقربًا لمنزلة واحدة.

```ruby exercise
c = gets.to_f
# f = ...
```

```ruby solution
c = gets.to_f
f = c * 9 / 5 + 32
puts "#{c} مئوية = #{f.round(1)} فهرنهايت"
```

```text input
36.6
```

```text output
36.6 مئوية = 97.9 فهرنهايت
```

### التمرين 3

اقرأ عددًا من الدقائق (مثلًا `135`) واطبعه بالساعات والدقائق: `2 ساعة و 15 دقيقة`. استخدم `/` و`%`.

```ruby exercise
minutes = gets.to_i
```

```ruby solution
minutes = gets.to_i
puts "#{minutes / 60} ساعة و #{minutes % 60} دقيقة"
```

```text input
135
```

```text output
2 ساعة و 15 دقيقة
```

## الخلاصة

- المتغير اسم لقيمة، ويُنشأ بـ `=` دون كتابة النوع.
- الأنواع الأساسية: `Integer` و`Float` و`String` و`true`/`false` و`nil` و`Symbol`.
- `7 / 2` تساوي `3`؛ استخدم `7.0 / 2` أو `fdiv` للكسور، و`%` لباقي القسمة.
- `gets.chomp` لقراءة نص، و`gets.to_i` أو `gets.to_f` لقراءة رقم.

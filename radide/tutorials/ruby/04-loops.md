# الدرس 4: حلقات التكرار

تخيل أنك تريد طباعة الأرقام من 1 إلى 100. هل ستكتب `puts` مئة مرة؟ بالطبع لا. **حلقة التكرار** (loop) تكرر مجموعة من الأوامر عدة مرات.

> **تشبيه:** حلقة التكرار مثل عدّاد اللفات في سباق الجري: «اجرِ لفة، ثم زد العداد، وكرر حتى تصل إلى 10 لفات».

Ruby فيها طرق كثيرة للتكرار، وأجملها تلك التي تُقرأ كالإنجليزية.

## `times`: كرر عددًا محددًا من المرات

```ruby run
3.times do
  puts "مرحبًا"
end

5.times { |i| print i, " " }
puts
```

```text output
مرحبًا
مرحبًا
مرحبًا
0 1 2 3 4 
```

- `3.times do ... end` تنفذ ما بين `do` و`end` ثلاث مرات.
- الجزء `|i|` اسمه **متغير الكتلة**، ويأخذ رقم المرة الحالية بدءًا من **الصفر**.
- `{ ... }` تساوي `do ... end`؛ العُرف: الأقواس المعقوصة للسطر الواحد، و`do ... end` لعدة أسطر.

## `each` مع المدى: من رقم إلى رقم

```ruby run
(1..5).each do |n|
  puts "#{n} × 3 = #{n * 3}"
end

1.step(10, 3) { |n| print n, " " }
puts
10.downto(7) { |n| print n, " " }
puts
```

```text output
1 × 3 = 3
2 × 3 = 6
3 × 3 = 9
4 × 3 = 12
5 × 3 = 15
1 4 7 10 
10 9 8 7 
```

| الطريقة | معناها |
|---|---|
| `(1..5).each { \|n\| }` | من 1 إلى 5 |
| `1.upto(5) { \|n\| }` | من 1 صعودًا إلى 5 |
| `10.downto(1) { \|n\| }` | من 10 نزولًا إلى 1 |
| `1.step(10, 3) { \|n\| }` | من 1 إلى 10 بخطوة 3 |

## `while` و`until`

عندما لا تعرف عدد المرات مقدمًا، بل تعرف **شرط التوقف**:

```ruby run
balance = 1000
years = 0
while balance < 2000
  balance = balance * 1.1
  years += 1
end
puts "يتضاعف المبلغ بعد #{years} سنوات"
puts "الرصيد: #{balance.round(2)}"

count = 3
until count == 0
  puts "العد التنازلي: #{count}"
  count -= 1
end
puts "انطلق!"
```

```text output
يتضاعف المبلغ بعد 8 سنوات
الرصيد: 2143.59
العد التنازلي: 3
العد التنازلي: 2
العد التنازلي: 1
انطلق!
```

- `while` تكرر **ما دام** الشرط صحيحًا.
- `until` تكرر **حتى يصبح** الشرط صحيحًا (عكس `while`).

## `break` و`next`

```ruby run
(1..10).each do |n|
  next if n.even?      # تخطَّ الأرقام الزوجية
  break if n > 7       # توقف تمامًا بعد 7
  print n, " "
end
puts
```

```text output
1 3 5 7 
```

- `next` تتخطى بقية الدورة الحالية وتنتقل للتالية (مثل `continue` في لغات أخرى).
- `break` تخرج من الحلقة كلها.

## حلقة متداخلة: جدول الضرب

```ruby run
(1..4).each do |row|
  line = ""
  (1..4).each do |col|
    line += (row * col).to_s.rjust(4)
  end
  puts line
end
```

```text output
   1   2   3   4
   2   4   6   8
   3   6   9  12
   4   8  12  16
```

الدالة `rjust(4)` تجعل النص بعرض 4 خانات مع محاذاة لليمين، فتصطف الأعمدة.

## حلقة مع إدخال: مجموع حتى الصفر

```ruby run
total = 0
loop do
  n = gets.to_i
  break if n == 0
  total += n
end
puts "المجموع = #{total}"
```

```text input
5
10
20
0
```

```text output
المجموع = 35
```

`loop do ... end` حلقة لا تنتهي بنفسها، ونخرج منها بـ `break` عندما يتحقق شرط.

## أخطاء شائعة

### الحلقة اللانهائية

```ruby
count = 1
while count <= 5
  puts count
  # نسينا: count += 1
end
```

هذا البرنامج لن يتوقف أبدًا لأن `count` لا يتغير! إذا حدث ذلك في الـ IDE فاضغط **Stop** (إيقاف) أو **Shift+F5**.

### نسيان أن `times` تبدأ من الصفر

`5.times { |i| }` تعطي 0 إلى 4. إذا أردت 1 إلى 5 فاستخدم `1.upto(5)` أو `(1..5).each`.

### `do` بعد `while`

`while x < 5 do` صحيحة لكنها غير معتادة. اكتب `while x < 5` في سطرها ثم الجسم ثم `end`.

## تمارين

### التمرين 1

اقرأ عددًا `n` واطبع مجموع الأعداد من 1 إلى `n`.

```ruby exercise
n = gets.to_i
sum = 0
# استخدم (1..n).each
```

```ruby solution
n = gets.to_i
sum = 0
(1..n).each { |i| sum += i }
puts "مجموع 1 إلى #{n} = #{sum}"
```

```text input
100
```

```text output
مجموع 1 إلى 100 = 5050
```

### التمرين 2

اطبع مثلثًا من النجوم بارتفاع يقرؤه البرنامج. تلميح: `"*" * 3` تعطي `***`.

```ruby exercise
h = gets.to_i
```

```ruby solution
h = gets.to_i
1.upto(h) { |i| puts "*" * i }
```

```text input
4
```

```text output
*
**
***
****
```

### التمرين 3

لعبة تخمين: الرقم السري 7. اقرأ تخمينات المستخدم حتى يخمن الرقم، واطبع `أكبر` أو `أصغر` بعد كل تخمين خاطئ، ثم `أحسنت! عدد المحاولات: N`.

```ruby exercise
secret = 7
tries = 0
```

```ruby solution
secret = 7
tries = 0
loop do
  guess = gets.to_i
  tries += 1
  if guess == secret
    puts "أحسنت! عدد المحاولات: #{tries}"
    break
  elsif guess < secret
    puts "أكبر"
  else
    puts "أصغر"
  end
end
```

```text input
3
9
7
```

```text output
أكبر
أصغر
أحسنت! عدد المحاولات: 3
```

## الخلاصة

- `n.times` للتكرار عددًا محددًا، و`(a..b).each` و`upto` و`downto` و`step` للعد.
- `while` ما دام الشرط صحيحًا، و`until` حتى يصبح صحيحًا، و`loop do` مع `break`.
- `next` تتخطى دورة، و`break` تخرج من الحلقة.
- انتبه للحلقة اللانهائية، وأوقفها من الـ IDE بزر Stop.

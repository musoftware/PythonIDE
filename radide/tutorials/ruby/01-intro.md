# الدرس 1: مرحبًا بك في Ruby: برنامجك الأول

**Ruby** (تُنطق «روبي») لغة برمجة صنعها الياباني «يوكيهيرو ماتسوموتو» سنة 1995، وهدفه المعلن أن تكون البرمجة **ممتعة للإنسان** قبل أن تكون مريحة للآلة. لذلك يُقرأ كود Ruby غالبًا كأنه جمل إنجليزية بسيطة.

> **تشبيه:** إذا كانت بعض اللغات مثل استمارة حكومية مليئة بالخانات الإجبارية، فإن Ruby مثل رسالة قصيرة لصديق: تكتب ما تريد مباشرة دون مقدمات طويلة.

## لماذا Ruby؟

- **سهلة القراءة:** لا فواصل منقوطة في آخر كل سطر، ولا أقواس كثيرة.
- **كل شيء كائن:** حتى الرقم `5` له دوال، فتكتب `5.times { ... }` لتكرار شيء خمس مرات.
- **Ruby on Rails:** أشهر إطار لبناء مواقع الويب بسرعة (GitHub وShopify بدأت به)، وسنتعرف عليه في آخر الدورة.

## كيف تعمل الأمثلة في هذه الدروس؟

كل مثال عليه زر **«▶ جرّبه»**: تنشئ الـ IDE مشروع Ruby صغيرًا وتشغله، ويظهر الناتج في نافذة **Output** (المخرجات). وزر **«افتح في المحرر»** يفتح المشروع لتعدّل فيه بنفسك.

الـ IDE تستخدم مفسّر Ruby المثبّت في `%LOCALAPPDATA%\RADIDE\toolchains\ruby` (أو الموجود في `PATH`). لا تحتاج إلى ترجمة (compile) كما في C++، فـ Ruby لغة **مفسَّرة**: المفسّر يقرأ الكود وينفذه سطرًا سطرًا.

## برنامجك الأول

```ruby run
puts "Hello, World!"
puts "مرحبًا بك في Ruby"
```

```text output
Hello, World!
مرحبًا بك في Ruby
```

سطران فقط! الأمر `puts` (اختصار put string، أي «ضع نصًا») يطبع النص ثم ينزل سطرًا جديدًا. والنص يُكتب بين علامتي تنصيص `"..."`.

## `puts` و`print` و`p`

```ruby run
print "بدون "
print "سطر جديد"
puts
puts "مع سطر جديد"
p "p تعرض القيمة كما يراها المبرمج"
p 42
```

```text output
بدون سطر جديد
مع سطر جديد
"p تعرض القيمة كما يراها المبرمج"
42
```

| الأمر | ماذا يفعل |
|---|---|
| `puts x` | يطبع `x` ثم ينزل سطرًا |
| `print x` | يطبع `x` ويبقى على نفس السطر |
| `p x` | يطبع `x` بشكله البرمجي (النص بعلامات التنصيص)، مفيد لتتبع الأخطاء |
| `puts` وحدها | سطر فارغ |

## الحساب مباشرة

Ruby آلة حاسبة جاهزة:

```ruby run
puts 2 + 3
puts 10 - 4
puts 6 * 7
puts 2 ** 10
puts "النتيجة: #{5 * 4}"
```

```text output
5
6
42
1024
النتيجة: 20
```

لاحظ السطر الأخير: داخل النص بعلامتي التنصيص المزدوجتين تكتب `#{...}` فتضع Ruby قيمة ما بين القوسين داخل النص. هذا اسمه **الاستيفاء** (interpolation)، وسنستخدمه كثيرًا.

## التعليقات

التعليق يبدأ بالعلامة `#`، والمفسّر يتجاهله:

```ruby run
# هذا تعليق لا يُنفذ
puts "سطر يعمل" # تعليق في آخر السطر
# puts "هذا السطر معطل"
=begin
تعليق
من عدة أسطر
=end
```

```text output
سطر يعمل
```

## مشروعك الخاص في RAD IDE

الدروس تنشئ المشاريع تلقائيًا، لكن هذه هي الخطوات لتنشئ مشروعًا بنفسك:

1. **File > New Project...** (ملف > مشروع جديد...).
2. من مجموعة **Scripting** اختر **Ruby (GUI Bridge)** (Ruby - جسر الواجهة)، وسمّ المشروع.
3. ينشئ المشروع نافذة `Form1`. لبرنامج نصي (كونسول) بدون نوافذ: **Project > Add Module...** (مشروع > إضافة وحدة برمجية...) وسمّها `main`، ثم في **Solution Explorer** (مستكشف الحلول) انقر بالزر الأيمن على `Form1` واختر **Remove from Project**.
4. اكتب الكود في `main.rb` واضغط **F5** أو **Ctrl+F5**: المشروع الذي ليس فيه نوافذ يعمل كبرنامج كونسول، ويظهر ناتجه في **Output**.

> **ملحوظة:** إذا بقيت `Form1` في المشروع فإن الـ IDE تعرض النافذة وتنتظر الأحداث، وهذا ما سنفعله في درس الواجهات الرسومية.

## أخطاء شائعة

### نسيان علامة التنصيص

<!-- compile-error -->
```ruby
puts "Hello
```

المفسّر سيقول شيئًا مثل `unterminated string meets end of file` أي «نص لم يُغلق حتى نهاية الملف». أغلق النص بعلامة `"`.

### كتابة `Puts` بحرف كبير

Ruby **حساسة لحالة الأحرف**: `Puts` ليست `puts`، وستظهر رسالة `undefined method 'Puts'`، أي «دالة غير معرّفة».

### الاستيفاء مع علامات التنصيص المفردة

`#{}` يعمل فقط داخل `"..."`. أما داخل `'...'` فيُطبع كما هو حرفيًا:

```ruby run
puts "2 + 2 = #{2 + 2}"
puts '2 + 2 = #{2 + 2}'
```

```text output
2 + 2 = 4
2 + 2 = #{2 + 2}
```

## الخلاصة

- Ruby لغة مفسَّرة سهلة القراءة، وكل شيء فيها كائن.
- `puts` للطباعة مع سطر جديد، و`print` بدونه، و`p` لعرض القيمة بشكلها البرمجي.
- `#{...}` داخل `"..."` يضع قيمة تعبير داخل النص.
- المشروع بدون نوافذ يعمل في RAD IDE كبرنامج كونسول، ويظهر ناتجه في نافذة Output.

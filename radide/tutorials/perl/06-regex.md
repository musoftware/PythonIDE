# الدرس 6: التعابير النمطية (Regular Expressions)

**التعبير النمطي** (regular expression، واختصاره regex) طريقة لوصف **شكل** نص: «رقم من أربع خانات»، «كلمة تبدأ بحرف كبير»، «بريد إلكتروني». وPerl هي اللغة التي جعلت التعابير النمطية مشهورة، وهي فيها جزء من اللغة نفسها، لا مكتبة إضافية.

> **تشبيه:** التعبير النمطي مثل **وصف المشتبه به** الذي يعطيه المحقق للشرطة: «رجل طويل، يلبس قبعة حمراء، ويحمل حقيبة». الشرطة لا تعرف الاسم، لكنها تتعرف على كل من يطابق الوصف.

## المطابقة: `=~ m/.../`

```perl run
use strict;
use warnings;

my $text = "طلبت 3 كتب بسعر 250 جنيه";
if ($text =~ /\d+/) {
    print "النص فيه رقم\n";
}
print "لا يوجد بريد\n" if $text !~ /@/;
if ($text =~ /(\d+) كتب/) {
    print "عدد الكتب: $1\n";
}
```

```text output
النص فيه رقم
لا يوجد بريد
عدد الكتب: 3
```

- `$text =~ /نمط/` صحيح إذا وُجد النمط في النص، و`!~` عكسها.
- الأقواس `( )` **تلتقط** الجزء المطابق، ويُحفظ في `$1` (والثاني في `$2`...).

## الرموز الأساسية

| الرمز | يطابق |
|---|---|
| `.` | أي حرف (عدا السطر الجديد) |
| `\d` / `\D` | رقم / ليس رقمًا |
| `\w` / `\W` | حرف كلمة (حرف أو رقم أو `_`) / عكسه |
| `\s` / `\S` | مسافة بيضاء / عكسها |
| `[abc]` / `[^abc]` | أحد هذه الحروف / أي حرف ما عداها |
| `[a-z0-9]` | مدى من الحروف |
| `^` / `$` | بداية النص / نهايته |
| `\b` | حد كلمة |

| المكرِّر | معناه |
|---|---|
| `*` | صفر مرة أو أكثر |
| `+` | مرة أو أكثر |
| `?` | اختياري (صفر أو مرة) |
| `{3}` / `{2,4}` | 3 مرات بالضبط / من 2 إلى 4 |

## أمثلة على الفحص (Validation)

```perl run
use strict;
use warnings;

my @tests = ("2026", "26", "abcd", "12345");
for my $t (@tests) {
    my $ok = $t =~ /^\d{4}$/ ? "سنة صحيحة" : "مرفوض";
    print "$t => $ok\n";
}

for my $email ('ali@mail.com', 'bad@', 'sara.k@site.org') {
    print "$email: ", ($email =~ /^[\w.]+@\w+\.\w{2,}$/ ? "بريد صالح" : "غير صالح"), "\n";
}
```

```text output
2026 => سنة صحيحة
26 => مرفوض
abcd => مرفوض
12345 => مرفوض
ali@mail.com: بريد صالح
bad@: غير صالح
sara.k@site.org: بريد صالح
```

`^` و`$` تجبران النمط على مطابقة **النص كله**، وبدونهما يكفي أن يوجد النمط في أي جزء.

## الالتقاط المتعدد والمطابقة الشاملة

```perl run
use strict;
use warnings;

my $date = "تاريخ الطلب: 2026-11-21";
if (my ($y, $m, $d) = $date =~ /(\d{4})-(\d{2})-(\d{2})/) {
    print "اليوم $d الشهر $m السنة $y\n";
}

my $log = "errors=3 warnings=12 notes=7";
my @numbers = $log =~ /(\d+)/g;
print "@numbers\n";

my %data = $log =~ /(\w+)=(\d+)/g;
print "warnings: $data{warnings}\n";

my $count = () = "banana" =~ /a/g;
print "عدد a في banana: $count\n";
```

```text output
اليوم 21 الشهر 11 السنة 2026
3 12 7
warnings: 12
عدد a في banana: 3
```

- المعدِّل `g` (global) يبحث عن **كل** التطابقات وليس الأول فقط.
- في سياق قائمة يُرجع التعبير كل الأجزاء الملتقطة، فيمكن تخزينها في مصفوفة أو حتى قاموس.

## الاستبدال: `s/.../.../`

```perl run
use strict;
use warnings;

my $s = "أحب القطط. القطط لطيفة.";
(my $t = $s) =~ s/القطط/الكلاب/;
print "$t\n";
(my $u = $s) =~ s/القطط/الكلاب/g;
print "$u\n";

my $phone = "010-1234-5678";
(my $digits = $phone) =~ s/\D//g;
print "$digits\n";

my $spaces = "   نص   بمسافات   كثيرة   ";
$spaces =~ s/^\s+|\s+$//g;
$spaces =~ s/\s+/ /g;
print "[$spaces]\n";

my $name = "ahmed ali";
$name =~ s/\b(\w)/\U$1/g;
print "$name\n";
```

```text output
أحب الكلاب. القطط لطيفة.
أحب الكلاب. الكلاب لطيفة.
01012345678
[نص بمسافات كثيرة]
Ahmed Ali
```

- `s/قديم/جديد/` تستبدل أول تطابق، ومع `g` كل التطابقات.
- `(my $t = $s) =~ s/...//` تنسخ النص ثم تعدّل النسخة، فيبقى الأصل كما هو.
- `\U$1` تحوّل الجزء الملتقط إلى حروف كبيرة.

## المعدِّلات المفيدة

| المعدِّل | معناه |
|---|---|
| `i` | تجاهل حالة الأحرف: `/perl/i` تطابق `PERL` |
| `g` | كل التطابقات |
| `x` | يسمح بمسافات وتعليقات داخل النمط لتوضيحه |
| `r` | `s///r` تُرجع النص الجديد دون تعديل الأصل |

```perl run
use strict;
use warnings;

print "وجدتها\n" if "I love PERL" =~ /perl/i;
my $clean = "a-b-c" =~ s/-/+/gr;
print "$clean\n";
my $re = qr/
    (\d{3})   # رمز المنطقة
    -
    (\d{4})   # الرقم
/x;
print "المنطقة $1 الرقم $2\n" if "اتصل 012-3456" =~ $re;
```

```text output
وجدتها
a+b+c
المنطقة 012 الرقم 3456
```

`qr/.../` تصنع تعبيرًا نمطيًا محفوظًا في متغير لتعيد استخدامه.

## مثال واقعي: تحليل ملف سجل

```perl run
use strict;
use warnings;

my @log = (
    "2026-11-21 10:01:12 ERROR disk full on /dev/sda1",
    "2026-11-21 10:02:00 INFO user ali logged in",
    "2026-11-21 10:05:43 ERROR timeout connecting db",
    "2026-11-21 10:06:10 WARN memory 85%",
);
my %levels;
for my $line (@log) {
    next unless $line =~ /^(\S+) (\S+) (\w+) (.*)$/;
    my ($date, $time, $level, $msg) = ($1, $2, $3, $4);
    $levels{$level}++;
    print "[$time] $msg\n" if $level eq "ERROR";
}
print "$_: $levels{$_}\n" for sort keys %levels;
```

```text output
[10:01:12] disk full on /dev/sda1
[10:05:43] timeout connecting db
ERROR: 2
INFO: 1
WARN: 1
```

## العربية والتعابير النمطية

لكي تعامل Perl الحروف العربية كحروف (وليس بايتات) أضف `use utf8;` واجعل المخرجات UTF-8:

```perl run
use strict;
use warnings;
use utf8;
binmode(STDOUT, ":encoding(UTF-8)");

my $text = "قرأ أحمد ثلاثة كتب";
my @words = $text =~ /(\w+)/g;
print scalar(@words), " كلمات\n";
print "الكلمة الثانية: $words[1]\n";
print "طولها: ", length($words[1]), " حروف\n";
```

```text output
4 كلمات
الكلمة الثانية: أحمد
طولها: 4 حروف
```

## أخطاء شائعة

### نسيان أن `.` تطابق أي حرف

`/1.5/` تطابق `1.5` و`125` و`1x5`. للنقطة الحرفية اكتب `\.`: `/1\.5/`.

### الطمع (Greedy)

`"<b>a</b><b>c</b>" =~ /<b>(.*)<\/b>/` تلتقط `a</b><b>c` كلها، لأن `.*` **طماعة** تأخذ أطول ما يمكن. اكتب `.*?` لتأخذ أقصر ما يمكن.

### استخدام `$1` بعد مطابقة فاشلة

إذا فشلت المطابقة يبقى `$1` بقيمته القديمة! استخدم `$1` فقط داخل `if ($x =~ /.../)`.

## تمارين

### التمرين 1

اقرأ سطرًا يحتوي أسعارًا مثل `قلم 5 دفتر 20 حقيبة 150`، واستخرج كل الأرقام بـ `/g`، واطبع مجموعها وأكبرها.

```perl exercise
use strict;
use warnings;
my $line = <STDIN>;
chomp $line;
```

```perl solution
use strict;
use warnings;
my $line = <STDIN>;
chomp $line;
my @prices = $line =~ /(\d+)/g;
my ($sum, $max) = (0, 0);
for my $p (@prices) {
    $sum += $p;
    $max = $p if $p > $max;
}
print "المجموع: $sum\n";
print "الأغلى: $max\n";
```

```text input
قلم 5 دفتر 20 حقيبة 150
```

```text output
المجموع: 175
الأغلى: 150
```

### التمرين 2

حوّل التواريخ من الصيغة `YYYY-MM-DD` إلى `DD/MM/YYYY` في كل الأسطر المقروءة باستخدام `s///` والالتقاط.

```perl exercise
use strict;
use warnings;
while (my $line = <STDIN>) {
    chomp $line;
    # s/.../.../g;
    print "$line\n";
}
```

```perl solution
use strict;
use warnings;
while (my $line = <STDIN>) {
    chomp $line;
    $line =~ s/(\d{4})-(\d{2})-(\d{2})/$3\/$2\/$1/g;
    print "$line\n";
}
```

```text input
بدأ المشروع 2026-01-15
وانتهى 2026-11-21
```

```text output
بدأ المشروع 15/01/2026
وانتهى 21/11/2026
```

## الخلاصة

- `=~ /نمط/` للمطابقة، والأقواس للالتقاط في `$1` و`$2`.
- `\d` و`\w` و`\s` و`[...]` و`+` و`*` و`?` و`{n}` و`^` و`$`.
- `/g` لكل التطابقات، و`/i` لتجاهل الحالة، و`s/قديم/جديد/g` للاستبدال.
- `use utf8;` مع `binmode` لمعاملة الحروف العربية كحروف.

# الدرس 2: المتغيرات العددية والنصية والإدخال

في Perl يدل **الرمز الذي يسبق اسم المتغير** على نوعه:

| الرمز | النوع | مثال |
|---|---|---|
| `$` | قيمة مفردة (scalar): رقم أو نص | `$age` |
| `@` | مصفوفة (array): قائمة قيم | `@names` |
| `%` | قاموس (hash): مفاتيح وقيم | `%prices` |

> **تشبيه:** الرمز مثل **لون العلبة**: العلبة الزرقاء `$` فيها شيء واحد، والصندوق الأخضر `@` فيه صف من الأشياء، والخزانة الحمراء `%` فيها أدراج عليها أسماء.

في هذا الدرس نركز على `$`، والدرس 4 للمصفوفات والقواميس.

## تعريف متغير بـ `my`

```perl run
use strict;
use warnings;

my $name = "خالد";
my $age = 30;
my $price = 19.99;

print "$name عمره $age سنة\n";
$age = $age + 1;
$age += 1;
$age++;
print "بعد ثلاث سنوات: $age\n";
print "السعر: $price\n";
```

```text output
خالد عمره 30 سنة
بعد ثلاث سنوات: 33
السعر: 19.99
```

- `my` تعرّف متغيرًا جديدًا (ومع `use strict` لا يمكن استخدام متغير قبل تعريفه).
- المتغير `$` يحمل رقمًا أو نصًا، وPerl لا تفرّق كثيرًا بينهما.
- `+=` و`++` اختصارات للزيادة.

## الأرقام والنصوص: سياق العامل

```perl run
use strict;
use warnings;

my $x = "10";
my $y = 5;
print $x + $y, "\n";
print $x . $y, "\n";
print $x x 3, "\n";
print "-" x 20, "\n";
print length("Perl"), "\n";
print uc("perl"), " ", lc("PERL"), " ", ucfirst("perl"), "\n";
```

```text output
15
105
101010
--------------------
4
PERL perl Perl
```

- العامل `x` يكرر النص: `"-" x 20` خط من 20 شرطة.
- `length` طول النص، و`uc` / `lc` / `ucfirst` لتغيير حالة الأحرف الإنجليزية.

## المقارنة: عوامل للأرقام وعوامل للنصوص

نقطة مهمة جدًا في Perl: **مقارنة الأرقام لها عوامل، ومقارنة النصوص لها عوامل أخرى**:

| المعنى | للأرقام | للنصوص |
|---|---|---|
| يساوي | `==` | `eq` |
| لا يساوي | `!=` | `ne` |
| أصغر / أكبر | `<` / `>` | `lt` / `gt` |
| أصغر أو يساوي / أكبر أو يساوي | `<=` / `>=` | `le` / `ge` |

```perl run
use strict;
use warnings;

print 10 == 10.0 ? "متساويان رقميًا\n" : "مختلفان\n";
print "10" eq "10.0" ? "متساويان نصيًا\n" : "مختلفان نصيًا\n";
print "abc" lt "abd" ? "abc قبل abd\n" : "بعد\n";
print 9 < 10 ? "9 أصغر\n" : "9 أكبر\n";
print "9" lt "10" ? "\"9\" قبل \"10\" نصيًا\n" : "\"9\" بعد \"10\" نصيًا\n";
```

```text output
متساويان رقميًا
مختلفان نصيًا
abc قبل abd
9 أصغر
"9" بعد "10" نصيًا
```

`شرط ? قيمة1 : قيمة2` هو **العامل الثلاثي**: إذا كان الشرط صحيحًا فالنتيجة القيمة الأولى، وإلا الثانية. ولاحظ السطر الأخير: نصيًا `"9"` يأتي **بعد** `"10"` لأن المقارنة حرفًا حرفًا (`9` بعد `1`).

## `undef`: القيمة غير المعرّفة

```perl run
use strict;
use warnings;

my $nothing;
print defined($nothing) ? "معرّف\n" : "غير معرّف\n";
$nothing = 0;
print defined($nothing) ? "معرّف الآن\n" : "غير معرّف\n";
my $name;
my $shown = $name // "زائر";
print "$shown\n";
```

```text output
غير معرّف
معرّف الآن
زائر
```

`$x // "قيمة"` تعني: إذا كان `$x` غير معرّف فاستخدم القيمة البديلة.

## الإدخال: `<STDIN>` و`chomp`

```perl run
use strict;
use warnings;

print "ما اسمك؟ ";
my $name = <STDIN>;
chomp $name;
print "كم عمرك؟ ";
my $age = <STDIN>;
chomp $age;
print "\n";
print "أهلًا يا $name!\n";
print "بعد عشر سنوات سيكون عمرك ", $age + 10, "\n";
```

```text input
ريم
18
```

```text output
ما اسمك؟ كم عمرك؟ 
أهلًا يا ريم!
بعد عشر سنوات سيكون عمرك 28
```

- `<STDIN>` تقرأ سطرًا من لوحة المفاتيح **ومعه رمز السطر الجديد**.
- `chomp` تحذف رمز السطر الجديد من آخر النص. نسيانها من أشهر أخطاء المبتدئين.
- عند «جرّبه» ترسل الـ IDE المدخلات المكتوبة في الدرس كأن المستخدم كتبها.

## التنسيق: `printf` و`sprintf`

```perl run
use strict;
use warnings;

my $avg = 87.456;
printf("المتوسط: %.1f\n", $avg);
printf("[%5d] [%-5d] [%05d]\n", 42, 42, 42);
my $text = sprintf("%.2f", 3.14159);
print "π تقريبًا $text\n";
```

```text output
المتوسط: 87.5
[   42] [42   ] [00042]
π تقريبًا 3.14
```

`printf` تطبع بتنسيق، و`sprintf` تُرجع النص المنسق دون طباعته.

## أخطاء شائعة

### نسيان `my`

<!-- compile-error -->
```perl
use strict;
$total = 5;
```

الخطأ: `Global symbol "$total" requires explicit package name`، أي «المتغير يحتاج تعريفًا». اكتب `my $total = 5;`.

### `==` مع النصوص

`if ($name == "علي")` خطأ منطقي: تحوّل Perl النصين إلى أرقام (صفر) فيصبح الشرط صحيحًا دائمًا، مع تحذير `isn't numeric`. استخدم `eq` للنصوص.

اقرأ عددين (كل عدد في سطر) واطبع مجموعهما وحاصل قسمتهما بمنزلتين عشريتين.

```perl exercise
use strict;
use warnings;
```

```text input

4
```

```text output
المجموع = 14
القسمة = 2.50
```

### التمرين 2

اقرأ كلمة إنجليزية واطبعها بحروف كبيرة، وطولها، ومكررة ثلاث مرات بينها شرطة.

```perl exercise
use strict;
use warnings;
my $w = <STDIN>;
chomp $w;
```

```perl solution
use strict;
use warnings;
my $w = <STDIN>;
chomp $w;
print uc($w), "\n";
print "الطول: ", length($w), "\n";
print join("-", ($w) x 3), "\n";
```

```text input
perl
```

```text output
PERL
الطول: 4
perl-perl-perl
```

`($w) x 3` بين قوسين تكرر **قائمة** فتعطي ثلاثة عناصر، و`join("-", ...)` تلصقها بشرطة.

## الخلاصة

- `$` قيمة مفردة، و`@` مصفوفة، و`%` قاموس، وكلها تُعرّف بـ `my`.
- `+` و`==` و`<` للأرقام، و`.` و`eq` و`lt` للنصوص.
- `<STDIN>` ثم `chomp` لقراءة سطر.
- `printf` و`sprintf` للتنسيق، و`//` لقيمة بديلة عند `undef`.

# الدرس 1: مرحبًا بك في Perl: برنامجك الأول

**Perl** (تُنطق «بيرل») لغة برمجة صنعها «لاري وول» سنة 1987، وكان هدفه أن يسهّل **معالجة النصوص والتقارير**: قراءة ملفات السجلات، والبحث فيها، واستخراج الأرقام، وكتابة التقارير. لذلك تُلقب Perl بـ «سكين الجيش السويسري» للنصوص.

> **تشبيه:** إذا كان النص كومة رمل فيها حبات ذهب، فإن Perl **غربال ذكي**: تخبره بشكل الحبة التي تريدها، فيجمعها لك في ثوانٍ.

## أين تُستخدم Perl؟

- **إدارة الأنظمة:** سكربتات لمعالجة ملفات السجلات (logs) والنسخ الاحتياطي.
- **علم الأحياء الحسابي:** تحليل تسلسلات الحمض النووي (DNA) وهي نصوص طويلة.
- **الويب القديم والحديث:** مواقع كثيرة بُنيت بـ Perl، وما زالت أنظمة كبيرة تعمل بها.
- **التعابير النمطية** (Regular Expressions) التي تستخدمها كل اللغات اليوم انتشرت بأسلوب Perl.

## كيف تعمل الأمثلة؟

اضغط **«▶ جرّبه»** تحت أي مثال، فتنشئ الـ IDE مشروع Perl وتشغله، ويظهر الناتج في **Output** (المخرجات). تستخدم الـ IDE مفسّر Perl الموجود في `PATH` أو المثبت في `%LOCALAPPDATA%\RADIDE\toolchains\strawberry`.

## برنامجك الأول

```perl run
use strict;
use warnings;

print "Hello, World!\n";
print "مرحبًا بك في Perl\n";
```

```text output
Hello, World!
مرحبًا بك في Perl
```

- `use strict;` و`use warnings;` سطران **نكتبهما في أول كل برنامج**: الأول يجبرك على تعريف المتغيرات (فيكشف أخطاء الكتابة)، والثاني يحذرك من الأخطاء المحتملة.
- `print` تطبع النص كما هو، **ولا تنزل سطرًا** تلقائيًا؛ لذلك نضيف `\n` (رمز السطر الجديد).
- كل تعليمة تنتهي بفاصلة منقوطة `;`.

## `say`: طباعة مع سطر جديد

```perl run
use strict;
use warnings;
use feature 'say';

say "سطر أول";
say "سطر ثانٍ";
say "النتيجة: ", 6 * 7;
print "بدون ", "سطر جديد", "\n";
```

```text output
سطر أول
سطر ثانٍ
النتيجة: 42
بدون سطر جديد
```

`say` مثل `print` لكنها تضيف `\n` في النهاية، وتحتاج السطر `use feature 'say';`. ويمكن إعطاء `print` و`say` عدة قيم مفصولة بفواصل.

## الحساب

```perl run
use strict;
use warnings;

print 2 + 3, "\n";
print 7 / 2, "\n";
print int(7 / 2), "\n";
print 7 % 2, "\n";
print 2 ** 10, "\n";
print "5" + "3", "\n";
print "5" . "3", "\n";
```

```text output
5
3.5
3
1
1024
8
53
```

- `/` قسمة عادية بكسور، و`int(...)` تحذف الكسر.
- `+` جمع أرقام دائمًا، و`.` (النقطة) **لصق نصوص** دائمًا. Perl تحوّل بين الرقم والنص حسب العامل الذي تستخدمه، وهذا من أهم أفكارها.

## علامتا التنصيص

```perl run
use strict;
use warnings;

my $name = "سارة";
print "مرحبًا $name\n";
print 'مرحبًا $name\n';
print "\n";
```

```text output
مرحبًا سارة
مرحبًا $name\n
```

- داخل `"..."` تُستبدل المتغيرات مثل `$name` بقيمها، وتعمل الرموز مثل `\n`. هذا اسمه **الاستيفاء** (interpolation).
- داخل `'...'` يُطبع كل شيء حرفيًا.

## التعليقات

```perl run
use strict;
use warnings;
# هذا تعليق
print "سطر يعمل\n"; # تعليق في آخر السطر
# print "معطل\n";
```

```text output
سطر يعمل
```

## مشروعك الخاص في RAD IDE

1. **File > New Project...** (ملف > مشروع جديد...).
2. من **Scripting** اختر **Perl (GUI Bridge)** (Perl - جسر الواجهة).
3. لبرنامج كونسول: **Project > Add Module...** (إضافة وحدة برمجية...) باسم `main`، ثم احذف `Form1` من **Solution Explorer** بالنقر بالزر الأيمن ثم **Remove from Project** (إزالة من المشروع).
4. اكتب الكود في `main.pl` واضغط **Ctrl+F5**.

## أخطاء شائعة

### نسيان الفاصلة المنقوطة

<!-- compile-error -->
```perl
print "أ\n"
print "ب\n";
```

الخطأ: `syntax error at main.pl line 2, near "print"`. المفسّر يشير إلى السطر **التالي** للخطأ غالبًا، فانظر إلى نهاية السطر السابق.

### نسيان `\n`

بدون `\n` تلتصق النصوص في سطر واحد: `print "أ"; print "ب";` تطبع `أب`.

### الخلط بين `+` و`.`

`"علي" + "منى"` تعطي `0` مع تحذير `Argument "علي" isn't numeric`. للصق النصوص استخدم النقطة.

## تمارين

### التمرين 1

اطبع ثلاثة أسطر: اسمك، ومدينتك، و`أتعلم Perl`، باستخدام `say`.

```perl exercise
use strict;
use warnings;
use feature 'say';
# الاسم: كريم
# المدينة: المنصورة
# أتعلم Perl
```

```perl solution
use strict;
use warnings;
use feature 'say';
say "الاسم: كريم";
say "المدينة: المنصورة";
say "أتعلم Perl";
```

```text output
الاسم: كريم
المدينة: المنصورة
أتعلم Perl
```

### التمرين 2

احسب عدد الساعات في سنة (365 يومًا) واطبع: `في السنة 8760 ساعة` مستخدمًا `.` للصق.

```perl exercise
use strict;
use warnings;
```

```perl solution
use strict;
use warnings;
print "في السنة " . 365 * 24 . " ساعة\n";
```

```text output
في السنة 8760 ساعة
```

## الخلاصة

- ابدأ كل برنامج بـ `use strict;` و`use warnings;`.
- `print` تطبع دون سطر جديد، و`say` تضيفه.
- `+` للأرقام و`.` للنصوص، وPerl تحوّل بينهما حسب العامل.
- `"..."` تستبدل المتغيرات، و`'...'` حرفية.

# الدرس 4: داخل برنامج التثبيت: Inno Setup

**في هذا الدرس ستتعلم:**

- ما **Inno Setup**، ولماذا تستخدمه البيئة.
- أقسام سكربت التثبيت `.iss` الذي تكتبه البيئة، سطرًا سطرًا.
- التثبيت وإلغاء التثبيت **الصامت** (دون نوافذ) للشركات والاختبارات.
- ماذا يرى المستخدم عند تشغيل برنامج التثبيت.

## ما Inno Setup؟

**Inno Setup** برنامج مجاني معروف منذ سنوات طويلة لصنع برامج التثبيت في ويندوز. تكتب له **سكربتًا** نصيًا (ملف `.iss`) تصف فيه البرنامج والملفات والاختصارات، فيترجمه بالأداة `ISCC.exe` إلى `setup.exe` واحد مضغوط.

البيئة **تكتب السكربت عنك** من إعدادات نافذة النشر في كل مرة تضغط **Publish**، ولذلك أول سطر فيه: «Generated by RAD IDE (Build > Publish). Regenerated on every Publish».

> **تشبيه:** السكربت مثل **ورقة تعليمات** لعامل نقل الأثاث: «ضع هذه الصناديق في الغرفة الفلانية، وعلّق هذه اللوحة على الباب». وInno Setup هو العامل الذي ينفذها عند كل مستخدم.

| القسم / السطر | معناه |
|---|---|
| `[Setup]` | معلومات عامة عن البرنامج وبرنامج التثبيت |
| `AppId` | المعرّف الثابت من `publish.json` (القوس `{` مكرر لأن Inno Setup يستخدمه لرموز خاصة) |
| `DefaultDirName={autopf}\...` | مجلد التثبيت: `{autopf}` يعني `%LOCALAPPDATA%\Programs` للمستخدم الحالي، أو `Program Files` لكل المستخدمين |
| `PrivilegesRequired=lowest` | لا يحتاج صلاحيات المسؤول |
| `PrivilegesRequiredOverridesAllowed=dialog commandline` | يستطيع المستخدم مع ذلك اختيار «كل المستخدمين» |
| `[Languages]` | لغات صفحات التثبيت (English وArabic ...) |
| `[Tasks]` | خيارات يختارها المستخدم، مثل اختصار سطح المكتب |
| `[Files]` | الملفات التي تُنسخ: كل مجلد البرنامج المبني إلى `{app}` |
| `[Icons]` | الاختصارات: في قائمة ابدأ (`{group}`)، وإلغاء التثبيت، وسطح المكتب |
| `[Run]` | ما يعمل بعد التثبيت: «شغّل البرنامج الآن» |

و`{app}` تعني «مجلد التثبيت الذي اختاره المستخدم»، و`{cm:...}` نصوص مترجمة تلقائيًا إلى لغة صفحات التثبيت.

## ماذا يرى المستخدم؟

1. صفحة اختيار: للمستخدم الحالي فقط (دون صلاحيات) أو لكل المستخدمين.
2. صفحة الترخيص (إذا اخترت ملف ترخيص).
3. صفحة الخيارات: «إنشاء اختصار على سطح المكتب».
4. التثبيت، ثم «تشغيل Hello Setup» في الصفحة الأخيرة.

ويظهر البرنامج بعدها في **الإعدادات > التطبيقات المثبتة**، ومنها يُلغى تثبيته.

## التثبيت الصامت

الشركات (وأنظمة الاختبار الآلي) تحتاج تثبيت البرامج **دون أي نافذة**. برامج Inno Setup تدعم ذلك بخيارات قياسية:

```text
HelloSetup-1.0.0-setup.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /CURRENTUSER /DIR="C:\Apps\Hello"
unins000.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART
```

- `/VERYSILENT`: دون أي نافذة.
- `/SUPPRESSMSGBOXES`: دون رسائل.
- `/NORESTART`: لا تعِد تشغيل الجهاز.
- `/CURRENTUSER`: للمستخدم الحالي.
- `/DIR="..."`: مجلد تثبيت محدد.
- `unins000.exe`: برنامج إلغاء التثبيت الذي يضعه Inno Setup في مجلد البرنامج.

هكذا اختُبر مثال `HelloSetup` آليًا: بناء، ثم تثبيت صامت، ثم تشغيل البرنامج المثبت، ثم إلغاء تثبيت صامت، ثم التأكد أن الملفات ومدخل «التطبيقات المثبتة» اختفت.

## مثال: سكربت صغير من الإعدادات

هذا مثال يكتب جزء `[Setup]` من إعدادات بسيطة، بنفس فكرة البيئة (لاحظ مضاعفة القوس `{` في `AppId`):

```python run
def setup_section(cfg):
    lines = ["[Setup]",
             "AppId=" + cfg["app_id"].replace("{", "{{"),
             "AppName=" + cfg["app_name"],
             "AppVersion=" + cfg["version"],
             "DefaultDirName={autopf}\\" + cfg["app_name"]]
    if cfg["per_user"]:
        lines += ["PrivilegesRequired=lowest", "PrivilegesRequiredOverridesAllowed=dialog commandline"]
    else:
        lines.append("PrivilegesRequired=admin")
    return "\n".join(lines)

cfg = {"app_id": "{1234-ABCD}", "app_name": "Temp Converter", "version": "1.0.0", "per_user": True}
print(setup_section(cfg))
```

```text output
[Setup]
AppId={{1234-ABCD}
AppName=Temp Converter
AppVersion=1.0.0
DefaultDirName={autopf}\Temp Converter
PrivilegesRequired=lowest
PrivilegesRequiredOverridesAllowed=dialog commandline
```

## أخطاء شائعة

- **تعديل ملف `.iss` بيدك:** يُكتب من جديد في كل **Publish**. غيّر الإعدادات من نافذة النشر.
- **إلغاء التثبيت يترك بيانات المستخدم:** هذا مقصود. الملفات في `%APPDATA%` تبقى (مثل معظم البرامج)، حتى لا يفقد المستخدم بياناته عند التحديث.
- **التثبيت الصامت دون `/CURRENTUSER`:** قد يحاول طلب صلاحيات المسؤول. أضفه للتثبيت دون صلاحيات.

## الخلاصة

- Inno Setup يحوّل سكربت `.iss` إلى `setup.exe`، والبيئة تكتب السكربت عنك.
- الأقسام: `[Setup]` و`[Languages]` و`[Tasks]` و`[Files]` و`[Icons]` و`[Run]`.
- التثبيت دون صلاحيات: `PrivilegesRequired=lowest`.
- التثبيت الصامت: `/VERYSILENT /SUPPRESSMSGBOXES /NORESTART /CURRENTUSER`.

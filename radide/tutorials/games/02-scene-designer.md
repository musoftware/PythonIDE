# الدرس 2: جولة في مصمم المشاهد

**في هذا الدرس ستتعرف على:**

- أجزاء **مصمم المشاهد**: شريط الأدوات، ولوحة الرسم، وتبويبات Layers و Tiles، ونافذة الخصائص.
- أنواع الكائنات: **كائن رسومي** (sprite) و**نص** (text) و**منطقة** (area).
- الطبقات الثلاث: بلاط، وكائنات، وواجهة.
- خصائص المشهد: المقاس، والسرعة، والجاذبية، والكاميرا.
- قائمة **Game** ونافذة **Game Assets**.

## افتح المشهد

في **Solution Explorer** تحت المشروع ستجد العقدة **Scenes**، وفيها `Level1.scene`. انقر عليها نقرًا مزدوجًا فيُفتح المصمم في تبويب:

```text
[ شريط الأدوات: Play | Select Paint Erase Rect Fill | Add | Sprite Sheet... Tileset... | تراجع إعادة | Front Back | Grid Snap Collision | Fit ]
[ لوحة الرسم (المستوى والشبكة)              | تبويبات: Layers / Tiles     ]
[                                            | Properties (خصائص المحدد)   ]
```

## شريط الأدوات

| الزر | الاسم العربي | الاختصار | ماذا يفعل؟ |
|---|---|---|---|
| **Play** | تشغيل | | يحفظ ويشغّل اللعبة (مثل `Ctrl+F5`) |
| **Select** | | `V` | اختيار الكائنات وتحريكها وتغيير حجمها وتدويرها |
| **Paint** | | `B` | رسم البلاط (الزر الأيمن يلتقط بلاطة من الخريطة) |
| **Erase** | | `E` | مسح البلاط |
| **Rect** | | `R` | ملء مستطيل بالبلاط |
| **Fill** | | `G` | ملء منطقة متصلة (مثل دلو الألوان) |
| **Add** | إضافة | | إضافة كائن: **Sprite from image...** أو **Text** أو **Area (trigger zone)** أو **Particle emitter**، أو طبقة جديدة |
| **Sprite Sheet...** | ورقة كائنات رسومية... | | تقطيع صورة إلى إطارات وصنع حركات (الدرس 4) |
| **Tileset...** | مجموعة بلاطات... | | استيراد صورة البلاط (الدرس 5) |
| **Front** و **Back** | الأمام و رجوع | | ترتيب الكائن فوق غيره أو تحته |
| **Grid** و **Snap** | الشبكة و الالتصاق | | إظهار الشبكة، والتصاق الكائنات بها (اضغط `Alt` للوضع الحر) |
| **Collision** | التصادم | | تلوين طبقات البلاط الصلبة بالأحمر |
| **Fit** | ملاءمة | | تكبير أو تصغير العرض ليظهر المستوى كله |

`Ctrl+Z` و `Ctrl+Y` للتراجع والإعادة، و`Ctrl+C` و `Ctrl+V` و `Delete` تعمل على الكائنات المحددة.

## الطبقات: تبويب Layers

المشهد مكوَّن من **طبقات** فوق بعضها، مثل أوراق شفافة:

| النوع | زر الإضافة | فيها | مثال |
|---|---|---|---|
| **Tiles** | `+Tiles` | خريطة بلاط بشبكة (32x32 عادةً) | الأرض والجدران |
| **Sprites** | `+Sprites` | كائنات حرة تتحرك مع العالم | اللاعب والعملات والأعداء |
| **UI** | `+UI` | كائنات ثابتة على الشاشة لا تتحرك مع الكاميرا | النقاط وعدد الأرواح |

الأزرار `▲` و `▼` تغيّر ترتيب الطبقة (الأعلى يُرسم فوق)، و`✕` تحذفها. والعين والقفل بجانب الطبقة لإخفائها أو قفلها أثناء التصميم.

> **تشبيه:** الطبقات مثل ديكور المسرح: الخلفية المرسومة (Background)، ثم أرضية المسرح (Ground)، ثم الممثلون (Sprites)، ثم لوحة النتائج المعلقة أمام الجمهور (UI).

## أنواع الكائنات

| النوع | ما هو؟ | أحداثه |
|---|---|---|
| **sprite** (كائن رسومي) | صورة أو ورقة حركات | `Collide` و `Click` و `AnimationEnd` و `OutOfWorld` و `Jump` و `Bounce` و `Flap` |
| **text** (نص) | عنوان، ويقبل `{score}` و `{lives}` | `Click` |
| **area** (منطقة) | مستطيل غير مرئي يكشف دخول الكائنات | `Collide` و `Click` |

انقر نقرًا مزدوجًا على كائن في المصمم فيفتح الـ IDE ملف `Level1.py` على **حدثه الافتراضي** (مثلًا `Player_Collide`)، كما في فيجوال بيسك.

## نافذة الخصائص

اختر كائنًا لترى خصائصه: الاسم `name`، والمكان `x` و `y`، والمقاس `w` و `h`، و`scale` و `rotation` و`z` (الترتيب) و`visible`، والصورة أو ورقة الحركات، و**Behaviours** (السلوكيات، الدرس 6)، و**props** (قيم إضافية مثل `group` و `hitbox` و `template`).

وإذا لم تختر شيئًا تظهر **خصائص المشهد**:

| الخاصية | معناها |
|---|---|
| `width` و `height` | مقاس نافذة اللعبة (ما تراه الكاميرا) |
| `background` | لون الخلفية |
| `fps` | الإطارات في الثانية |
| `gravity` | الجاذبية بالبكسل/ثانية² (900 افتراضيًا، و 0 للألعاب من أعلى) |
| `camera.follow` | اسم الكائن الذي تتبعه الكاميرا (مثل `Player`) |

قد يكون المستوى أكبر من النافذة؛ عندها تتحرك الكاميرا مع الكائن المتبوع.

## قائمة Game ونافذة Game Assets

القائمة **Game** (لعبة) تظهر مع مشاريع الألعاب:

| الأمر | الاسم العربي |
|---|---|
| **New Scene...** | مشهد جديد... |
| **Open Scene** | فتح مشهد |
| **Play Scene (Ctrl+F5)** | تشغيل المشهد (Ctrl+F5) |
| **Import Tileset...** | استيراد مجموعة بلاطات... |
| **Sprite Sheet and Animations...** | ورقة الكائنات الرسومية والحركات... |
| **Add Sprite from Image...** | إضافة كائن رسومي من صورة... |
| **Import Sound...** | استيراد صوت... |
| **Game Assets Window** | نافذة موارد اللعبة |
| **Check Scene** | فحص المشهد |
| **Export to Godot...** | تصدير إلى Godot... |

نافذة **Game Assets** (موارد اللعبة) تعرض صور المشهد بصور مصغّرة، وأوراق الحركات، ومجموعات البلاط، والأصوات (مع زر تشغيل). انقر نقرًا مزدوجًا على صورة (أو اسحبها إلى اللوحة) لتضع كائنًا رسوميًا منها.

## جرّب: تعرّف على كائنات المستوى من الكود

هذا كود يُشغَّل على مستوى قالب **Platformer**. يعدّ الكائنات حسب **مجموعاتها** (`group`): الكائنات `Coin1` و `Coin2` ... مجموعتها `Coin` تلقائيًا (الاسم بلا أرقام):

<!-- test: {"template": "platformer", "frames": 1} -->
```game run
def Scene_Load():
    print("المشهد:", game.scene.name, game.scene.view_size)
    print("الطبقات:", [layer.name for layer in game.scene.layers])
    print("العملات:", len(FindGroup("Coin")))
    print("الأعداء:", len(FindGroup("Enemy")))
    print("اللاعب في", Player.x, Player.y, "ومقاسه", Player.width, "x", Player.height)
    print("نص النقاط:", ScoreText.text)
```

```text output
المشهد: Level1 (800, 480)
الطبقات: ['Background', 'Ground', 'Sprites', 'UI']
العملات: 17
الأعداء: 3
اللاعب في 32.0 384.0 ومقاسه 32.0 x 32.0
نص النقاط: Score: {score}
```

- كل كائن في المشهد متغير بنفس اسمه في كودك: `Player` و `ScoreText` ...
- `FindGroup("Coin")` قائمة بكل كائنات المجموعة الحية الآن، و`len` عددها.
- `Find("Goal")` يرجع كائنًا واحدًا بالاسم (أو `None`).

## أخطاء شائعة

- **كائن لا يظهر**: طبقته مخفية، أو `visible` = `False`، أو هو خلف كائن آخر (جرّب **Front**).
- **اللاعب يمر عبر الأرض**: طبقة البلاط ليست صلبة. فعّل خاصية `collision` للطبقة (الدرس 5).
- **غيّرت اسم كائن والكود لا يعمل**: الـ IDE يعيد تسمية الأحداث في الكود تلقائيًا، لكن راجع أي مكان كتبت فيه الاسم القديم كنص مثل `Find("OldName")`.

# الدرس 4: الكائنات الرسومية وأوراقها والحركات

**في هذا الدرس ستتعلم:**

- إضافة كائن رسومي (sprite) من صورة.
- **ورقة الكائنات الرسومية** (sprite sheet): صورة واحدة فيها كل إطارات الشخصية.
- صنع **حركات** (animations) مثل `idle` و `run` و `jump` وتشغيلها من الكود.
- خصائص الكائن المرئية: `scale` و `rotation` و `flip_x` و `visible` و `z`.

## كائن رسومي من صورة

1. **Game > Add Sprite from Image...** (لعبة > إضافة كائن رسومي من صورة...)، أو من زر **Add > Sprite from image...** في شريط المصمم.
2. اختر صورة `PNG` (يفضَّل بخلفية شفافة). ينسخها الـ IDE إلى `assets` ويسجلها في المشهد، ثم يضع الكائن في وسط العرض.
3. غيّر اسمه من نافذة الخصائص إلى اسم واضح مثل `Player` أو `Tree1`.

أو اسحب الصورة من نافذة **Game Assets** إلى لوحة الرسم.

## ورقة الكائنات الرسومية

الشخصية المتحركة تُرسم عادةً في **صورة واحدة** فيها كل الإطارات بجانب بعضها بمقاس ثابت (مثلًا 32x32):

```text
+------+------+------+------+------+------+------+
| idle | idle | run  | run  | run  | run  | jump |
|  0   |  1   |  2   |  3   |  4   |  5   |  6   |
+------+------+------+------+------+------+------+
```

> **تشبيه:** ورقة الكائنات مثل شريط فيلم قديم: كل مربع لقطة، وعرض اللقطات بسرعة يصنع الحركة.

افتح **Game > Sprite Sheet and Animations...** (ورقة الكائنات الرسومية والحركات...) أو زر **Sprite Sheet...**:

1. اختر الصورة، واكتب عرض الإطار وارتفاعه (`frame_w` و `frame_h`)، فيقطعها المحرر إلى إطارات مرقمة من 0.
2. اضغط لإضافة حركة جديدة واكتب اسمها (`run`)، ثم اختر إطاراتها بالترتيب (`2, 3, 4, 5`).
3. اضبط `fps` (سرعة الحركة) و`loop` (تتكرر أم تتوقف عند آخر إطار).
4. المعاينة تعرض الحركة وهي تعمل. اضغط **OK**.

قالب **Platformer** فيه ورقة اسمها `player` بثلاث حركات:

| الحركة | الإطارات | `fps` | `loop` |
|---|---|---|---|
| `idle` | 0, 1 | 2 | نعم |
| `run` | 2, 3, 4, 5 | 10 | نعم |
| `jump` | 6 | 1 | نعم |

## الحركات تعمل وحدها مع السلوكيات

سلوك `platformer` (الدرس 6) يختار الحركة تلقائيًا: `run` عند الجري، و`idle` عند الوقوف، و`jump` في الهواء، ويقلب الصورة أفقيًا (`flip_x`) عند الاتجاه لليسار. بشرط أن تسمّي حركاتك بهذه الأسماء.

في هذا المثال على مستوى القالب، «تحقق» يضغط السهم الأيمن من الإطار 5 إلى 40، ثم الأيسر من 60 إلى 70، و`space` في الإطار 90، ونطبع الحركة كلما تغيّرت:

<!-- test: {"template": "platformer", "frames": 150, "keys": "right:5-40,left:60-70,space:90-92"} -->
```game run
last = ""


def Scene_Update(dt):
    global last
    state = f"{Player.animation} flip={Player.flip_x}"
    if state != last:
        print("الإطار", game.frame, ":", state)
        last = state
```

```text output
الإطار 0 : idle flip=False
الإطار 5 : run flip=False
الإطار 40 : idle flip=False
الإطار 60 : run flip=True
الإطار 70 : idle flip=True
الإطار 90 : jump flip=True
الإطار 128 : idle flip=True
```

- `Player.animation` اسم الحركة الحالية.
- `Player.flip_x` صحيحة عندما تكون الصورة مقلوبة (ينظر لليسار).

## تشغيل حركة من الكود

| الكود | ماذا يفعل؟ |
|---|---|
| `Player.play("run")` | يبدّل إلى حركة `run` (لا شيء إذا لم توجد) |
| `Player.play("attack", restart=True)` | يبدأ الحركة من أولها حتى لو كانت تعمل |
| `Player.has_animation("swim")` | هل توجد حركة بهذا الاسم؟ |
| `Player.set_image("flag")` | يعرض صورة ثابتة بدل ورقة الحركات |
| الحدث `Player_AnimationEnd()` | انتهت حركة **غير متكررة** (`loop` = لا)، مثل حركة الموت أو الهجوم |

وخصائص المظهر:

| الخاصية | معناها |
|---|---|
| `scale` | التكبير: `2` ضعف الحجم |
| `rotation` | الدوران بالدرجات |
| `flip_x` | قلب أفقي |
| `visible` | ظاهر أو مخفي (أو `show()` و `hide()`) |
| `z` | الترتيب داخل الطبقة: الأكبر يُرسم فوق |

<!-- test: {"template": "platformer", "frames": 2, "keys": "d:1-2"} -->
```game run
def Scene_KeyDown(key):
    if key == "d":
        Player.play("run")
        print("الحركة الآن:", Player.animation)
        print("هل توجد حركة swim؟", Player.has_animation("swim"))
        Player.scale = 2
        print("المقاس بعد التكبير:", Player.width, "x", Player.height)
        Goal.hide()
        print("العلم ظاهر؟", Goal.visible)
```

```text output
الحركة الآن: run
هل توجد حركة swim؟ False
المقاس بعد التكبير: 64.0 x 64.0
العلم ظاهر؟ False
```

لاحظ أن `width` و `height` يحسبان `scale`، أما `w` و `h` فهما المقاس الأصلي.

## أخطاء شائعة

- **الحركة لا تتغير مع الجري**: أسماء حركاتك ليست `run` و `idle` و `jump`. سمّها بهذه الأسماء، أو شغّلها بنفسك بـ `play`.
- **الشخصية مقطوعة أو ترتعش**: `frame_w` و `frame_h` لا يطابقان مقاس الإطار الحقيقي في الصورة.
- **`AnimationEnd` لا يحدث**: الحركة `loop` = نعم، فهي لا تنتهي أبدًا.

## الخلاصة

- **Add Sprite from Image...** لصورة ثابتة، و**Sprite Sheet and Animations...** لتقطيع ورقة إلى إطارات وحركات.
- السلوكيات تشغّل `idle` و `run` و `jump` تلقائيًا، و`play()` يشغّل أي حركة من الكود.
- `scale` و `rotation` و `flip_x` و `visible` و `z` تتحكم في مظهر الكائن.

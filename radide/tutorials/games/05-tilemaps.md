# الدرس 5: خرائط البلاط والتصادم والرسم التلقائي

**في هذا الدرس ستتعلم:**

- ما هي **خريطة البلاط** (tilemap) ولماذا تستخدمها الألعاب.
- استيراد **مجموعة بلاطات** (tileset) ورسم المستوى بأدوات Paint و Erase و Rect و Fill.
- جعل طبقة صلبة لا يمر عبرها اللاعب (`collision`).
- **الرسم التلقائي** (auto-tiling): ترسم «عشبًا» فتختار الحواف والزوايا نفسها.
- قراءة البلاط وتغييره من الكود.

## لماذا البلاط؟

بدل رسم المستوى كصورة ضخمة واحدة، نقسمه إلى **شبكة** مربعات صغيرة (32x32 بكسل عادةً)، ونضع في كل مربع **بلاطة** من مجموعة صغيرة: عشب، تراب، طوب، صندوق...

> **تشبيه:** مثل أرضية المطبخ: عدد قليل من أنواع البلاط، لكن ترتيبها يصنع أي شكل. وتعديل مربع واحد لا يحتاج إعادة رسم الأرضية كلها.

المزايا: ملف صغير، وتعديل سهل، والتصادم سريع (اللعبة تعرف فورًا هل المربع صلب).

## الخطوة 1: مجموعة البلاطات

1. اختر طبقة بلاط في تبويب **Layers** (أو أنشئ واحدة بالزر `+Tiles`).
2. **Game > Import Tileset...** (لعبة > استيراد مجموعة بلاطات...) أو الزر **Tileset...**.
3. اختر صورة فيها البلاطات متجاورة، واكتب مقاس البلاطة (`32` x `32`).
4. تظهر البلاطات في تبويب **Tiles**، مرقمة من 0 (من اليسار لليمين ثم من أعلى لأسفل).

## الخطوة 2: ارسم المستوى

| الأداة | الاختصار | الاستخدام |
|---|---|---|
| **Paint** | `B` | اختر بلاطة من تبويب Tiles ثم ارسم بالسحب. الزر الأيمن على الخريطة **يلتقط** البلاطة التي تحته |
| **Erase** | `E` | امسح بالسحب |
| **Rect** | `R` | اسحب مستطيلًا يمتلئ بالبلاطة |
| **Fill** | `G` | يملأ المنطقة المتصلة مثل دلو الألوان |

نصائح: كبّر وصغّر بعجلة الفأرة، والزر **Fit** يعرض المستوى كله، و**Grid** يُظهر الشبكة.

## الخطوة 3: التصادم

اختر الطبقة وفعّل خاصيتها **`collision`** في نافذة الخصائص: كل بلاطة فيها تصبح **صلبة**. اللاعب بسلوك `platformer` يقف عليها، والأعداء بسلوك `enemy_patrol` يرجعون عند حافتها.

زر **Collision** في شريط المصمم يلوّن الطبقات الصلبة بالأحمر لتتأكد. عادةً تكون عندك طبقتان: طبقة **زينة** غير صلبة (عشب طويل، أزهار) وطبقة **أرض** صلبة.

## الرسم التلقائي (Terrains)

رسم حواف العشب وزواياه بلاطة بلاطة متعب. **الأراضي** (terrains) تحل المشكلة:

1. في تبويب **Tiles** اضغط **Terrains...** (الأراضي...).
2. عرّف أرضًا (مثل `grass`) واربطها بمجموعة البلاط، واختر النمط: `16` (يراعي الجيران الأربعة) أو `47` (يراعي الثمانية مع الزوايا). يمكنك أيضًا أن تطلب من المحرر **رسم قالب** بلاطات جاهز بهذا الترتيب لتلوّنه.
3. اختر الأرض في صف **Terrain** بتبويب Tiles، وارسم بـ **Paint**: كل بلاطة تختار شكلها حسب جيرانها، وتتحدث الحواف وأنت ترسم وتمسح.

ومن الكود: `SetTerrain("Ground", col, row, "grass")` يرسم بنفس الطريقة، و`SetTerrain("Ground", col, row, "grass", False)` يمسح.

## البلاط من الكود

| الكود | ماذا يفعل؟ |
|---|---|
| `SetTile("Ground", col, row, 5)` | يضع البلاطة 5 في العمود والصف (`-1` = فارغ) |
| `layer.tile_at(col, row)` | رقم البلاطة في هذا المربع (`-1` = فارغ) |
| `layer.tile_at_point(x, y)` | البلاطة تحت نقطة بالبكسل |
| `layer.cols` و `layer.rows` | عدد الأعمدة والصفوف |
| `game.scene.is_solid_at(x, y)` | هل النقطة داخل شيء صلب؟ |

العمود = `x // 32` والصف = `y // 32` (القسمة الصحيحة `//` تحذف الكسر).

مثال على مستوى قالب Platformer: نطبع مقاس الخريطة، والبلاطة تحت قدمي اللاعب، ثم **نسد حفرة** بالبلاطة نفسها:

<!-- test: {"template": "platformer", "frames": 1} -->
```game run
def layer(name):
    return next(ly for ly in game.scene.layers if ly.name == name)


def Scene_Load():
    ground = layer("Ground")
    print("الخريطة:", ground.cols, "عمود ×", ground.rows, "صف")
    col = int(Player.x // 32)
    row = int(Player.bottom // 32)          # المربع تحت القدمين
    grass = ground.tile_at(col, row)
    print("تحت اللاعب: العمود", col, "الصف", row, "البلاطة", grass)
    print("الحفرة صلبة؟", game.scene.is_solid_at(25 * 32 + 16, 13 * 32 + 16))
    for c in (24, 25, 26):
        SetTile("Ground", c, 13, grass)      # جسر من العشب فوق الحفرة
    print("بعد الجسر صلبة؟", game.scene.is_solid_at(25 * 32 + 16, 13 * 32 + 16))
```

```text output
الخريطة: 60 عمود × 15 صف
تحت اللاعب: العمود 1 الصف 13 البلاطة 0
الحفرة صلبة؟ False
بعد الجسر صلبة؟ True
```

- `next(... for ... if ...)` يرجع أول عنصر يحقق الشرط، وهنا الطبقة التي اسمها `Ground`.
- `Player.bottom` هو `y + height`، أي حافة القدمين.

## أخطاء شائعة

- **البلاطات مزاحة أو مقطوعة**: مقاس البلاطة في **Import Tileset** لا يطابق الصورة.
- **اللاعب يسقط عبر الأرض**: نسيت `collision` للطبقة، أو رسمت على طبقة الزينة.
- **`SetTile` لا يفعل شيئًا**: اسم الطبقة خطأ (الأسماء حساسة لحالة الأحرف).

```game solution
def Scene_Load():
    ground = next(ly for ly in game.scene.layers if ly.name == "Ground")
    empty = 0
    for col in range(ground.cols):
        if ground.tile_at(col, 13) == -1:
            empty += 1
    print("عدد المربعات الفارغة:", empty)
```

## الخلاصة

- مجموعة بلاطات + شبكة = مستوى كامل، ترسمه بـ Paint و Erase و Rect و Fill.
- `collision` يجعل الطبقة صلبة، و**Terrains** يرسم الحواف تلقائيًا.
- `SetTile` و `tile_at` و `is_solid_at` للتعامل مع البلاط من الكود.

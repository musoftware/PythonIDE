# الدرس 1: أنواع مشاريع الألعاب وحلقة اللعبة

**في هذا الدرس ستتعرف على:**

- أنواع مشاريع الألعاب التي تصنعها RAD IDE، ومتى تختار كل نوع.
- إنشاء أول لعبة من قالب جاهز وتشغيلها بـ `F5`.
- **حلقة اللعبة**: الإطارات، والسرعة `fps`، والزمن `dt`.
- أين تكتب كود اللعبة.

## الألعاب في RAD IDE

افتح **File > New Project...** (ملف > مشروع جديد...) واختر المجموعة **Games** (الألعاب). ستجد:

| نوع المشروع | اللغة | يعمل على | ملاحظات |
|---|---|---|---|
| **Python Game (pygame)** | Python | Windows و Linux و macOS | **موضوع هذا الدليل**: مصمم مشاهد كامل، وأسهل بداية |
| **Godot 4 (GDScript)** | GDScript | كل المنصات عبر محرك Godot | نفس المشاهد، تُصدَّر إلى Godot |
| **HTML5 Canvas Game (JavaScript)** | JavaScript | المتصفح | نفس المشاهد، تعمل كموقع |
| **Python Arcade** | Python | Windows و Linux و macOS | كود فقط بمكتبة `arcade`، بلا مصمم |
| **Ring Game (RingRayLib)** | Ring | Windows | ألعاب بلغة Ring |
| **Python 3D (Ursina)** و **Godot 3D** | Python و GDScript | | ألعاب ثلاثية الأبعاد بملفات `.scene3d` |

مشاريع pygame و Godot و HTML5 و Ring تستخدم **نفس ملف المشهد** `.scene` ونفس المصمم ونفس **السلوكيات**، فما تتعلمه هنا ينفعك في كل هذه الأنواع.

كل نوع له ثلاثة قوالب:

| القالب | الاسم في القائمة | ماذا فيه؟ |
|---|---|---|
| منصات | **Platformer** | مستوى يتحرك أفقيًا: أرض من البلاط، ولاعب يجري ويقفز، وعملات، وعدو يتمشّى، وعلم النهاية |
| من أعلى | **Top-down Game** | غرفة تُرى من فوق: بطل يمشي في 4 اتجاهات، وجواهر، وعدو، وجدران |
| فارغ | **Empty Game** | مشهد فارغ 800x600 فيه طبقة كائنات وطبقة واجهة |

## أول لعبة في دقيقة

1. **File > New Project... > Games > Python Game (pygame)**، واختر القالب **Platformer**.
2. اضغط `F5`. تُفتح نافذة اللعبة: الأسهم للحركة، و`Space` للقفز، و`R` لإعادة المستوى، و`Esc` للخروج.

> **ملحوظة:** تحتاج مكتبة **pygame-ce**. إذا لم تكن مثبتة اكتب في نافذة أوامر: `pip install pygame-ce` (أو استخدم مدير الحزم في الـ IDE). المشروع فيه ملف `requirements.txt` يذكرها.

## حلقة اللعبة

البرنامج العادي ينتظر المستخدم. أما اللعبة فتعمل **حلقة تكرار** لا تتوقف، تتكرر عشرات المرات في الثانية:

1. اقرأ لوحة المفاتيح والفأرة.
2. حرّك الكائنات (السلوكيات والفيزياء).
3. افحص التصادمات.
4. نفّذ كودك (`Scene_Update`).
5. ارسم كل شيء على الشاشة.

كل دورة اسمها **إطار** (frame). المشهد يحدد عدد الإطارات في الثانية `fps` (الافتراضي **60**).

> **تشبيه:** اللعبة مثل كتاب رسوم متحركة تقلّب صفحاته بسرعة. كل صفحة إطار، وإذا قلّبت 60 صفحة في الثانية رأيت حركة ناعمة.

الدالة `Scene_Update(dt)` تُستدعى **في كل إطار**، و`dt` هو الزمن بالثواني منذ الإطار السابق (حوالي `0.0167` عند 60 إطارًا في الثانية). لذلك نكتب الحركة هكذا:

```python
Player.x += 120 * dt      # 120 بكسل في الثانية، مهما كانت سرعة الجهاز
```

## جرّب: عدّاد الإطارات

هذا مشهد فارغ (القالب **Empty Game**)، وكوده يطبع رقم الإطار والزمن كل 20 إطارًا. «تحقق» يشغّل اللعبة **60 إطارًا** (ثانية واحدة) بلا نافذة ويقارن ما طُبع:

```game run
def Scene_Load():
    print("بدأ المشهد", game.scene.name)


def Scene_Update(dt):
    if game.frame % 20 == 0:
        print("الإطار", game.frame, "الزمن", round(game.time, 2))
```

```text output
بدأ المشهد Scene1
الإطار 0 الزمن 0.0
الإطار 20 الزمن 0.33
الإطار 40 الزمن 0.67
```

- `game.frame` رقم الإطار الحالي (يبدأ من 0)، و`game.time` الثواني منذ بداية المشهد.
- `%` باقي القسمة: `game.frame % 20 == 0` صحيحة في الإطارات 0 و 20 و 40 ...
- `round(x, 2)` يقرّب الرقم لخانتين عشريتين.

> **ملحوظة:** في الـ IDE يبدأ كل ملف مشهد بسطرين يكتبهما لك: `from radgame import *` و `from Scene1_designer import *`. الأمثلة هنا تحذفهما لتكون أقصر، و«جرّبه» يضيفهما.

## أخطاء شائعة

- **`ModuleNotFoundError: No module named 'pygame'`**: ثبّت `pygame-ce`.
- **الحركة سريعة على جهاز وبطيئة على آخر**: نسيت ضرب السرعة في `dt`.
- **تعديل `radgame.py`**: يُستبدل مع كل تشغيل. اكتب كودك في ملف المشهد.

# الدرس 1: ما هو DOS؟ ومحاكي DOSBox-X

**في هذا الدرس ستتعلم:**

- قصة نظام **DOS** باختصار، ولماذا ما زال ممتعًا أن نبرمج له.
- كيف يعمل برنامج DOS: الوضع الحقيقي، والذاكرة، والمقاطعات.
- ما هو المحاكي **DOSBox-X** وكيف تستخدمه RAD IDE.
- أنواع مشاريع DOS في RAD IDE والمترجمات المجانية التي تبنيها.
- أول ملف دفعي (Batch) يعمل في DOSBox-X.

## قصة قصيرة

في عام 1981 ظهر حاسوب **IBM PC** بمعالج **Intel 8088** بسرعة 4.77 ميجاهرتز، ومعه نظام تشغيل بسيط اسمه **PC DOS**، وباعت مايكروسوفت نسخته لبقية الشركات باسم **MS-DOS**. كلمة DOS اختصار لـ Disk Operating System، أي «نظام تشغيل القرص».

لم يكن في DOS نوافذ ولا فأرة في البداية: شاشة سوداء، وسطر أوامر ينتظر أن تكتب `DIR` أو اسم برنامج. ومع ذلك كُتبت له آلاف البرامج والألعاب الشهيرة طوال الثمانينيات والتسعينيات، بلغات مثل **QBasic** و**Turbo Pascal** و**Turbo C** ولغة التجميع.

اليوم لا يعمل DOS مباشرة على ويندوز الحديث، لكن:

- يوجد نظام **FreeDOS** الحر المتوافق مع MS-DOS.
- وتوجد محاكيات مثل **DOSBox-X** تشغّل برامج DOS داخل نافذة على ويندوز.
- وتوجد مترجمات مجانية حديثة تُنتج برامج DOS حقيقية: **FreeBASIC** و**Free Pascal** و**Open Watcom** و**JWasm**.

> **لماذا نتعلم برمجة DOS اليوم؟** لأنها أقرب طريقة لترى الحاسوب «عاريًا»: تكتب في ذاكرة الشاشة بنفسك، وتقرأ لوحة المفاتيح من البيوس، وتستدعي النظام برقم مقاطعة. وهي أيضًا باب لصيانة البرامج القديمة وتشغيل الألعاب الكلاسيكية التي تملكها.

## كيف يعمل برنامج DOS؟

| الفكرة | المعنى |
|---|---|
| **الوضع الحقيقي** (Real Mode) | المعالج يعمل كأنه 8086: عناوين 16 بت، وذاكرة قدرها 1 ميجابايت فقط |
| **المقطع والإزاحة** (Segment:Offset) | كل عنوان رقمان: `B800:0000` يعني العنوان الحقيقي `B800h × 16 + 0000h` |
| **الذاكرة التقليدية** | أول 640 كيلوبايت للبرامج، والباقي للشاشة والبيوس |
| **المقاطعات** (Interrupts) | خدمات جاهزة برقم: `INT 21h` لخدمات DOS، و`INT 10h` للشاشة، و`INT 16h` للوحة المفاتيح، و`INT 33h` للفأرة |
| **ذاكرة الشاشة** | في وضع النص تبدأ عند `B800:0000`، وفي وضع الرسوم 13h عند `A000:0000` |

ملفات البرامج نوعان:

- **`.COM`**: أبسط شكل: صورة من الذاكرة لا يزيد حجمها عن 64 كيلوبايت تقريبًا، تبدأ عند الإزاحة `100h`.
- **`.EXE`** بصيغة **MZ**: برنامج أكبر بعدة مقاطع، وفي أوله الحرفان `MZ`.

## المحاكي DOSBox-X

**DOSBox-X** برنامج مفتوح المصدر يحاكي حاسوبًا كاملًا من عصر DOS: المعالج وبطاقة الشاشة وكرت الصوت والفأرة، وفيه سطر أوامر يشبه DOS. لا تحتاج إلى تثبيته بنفسك: عند أول تشغيل تنزّل RAD IDE النسخة المحمولة الرسمية إلى `%LOCALAPPDATA%\RADIDE\tools\dosbox-x`.

عندما تضغط `Ctrl+F5` في مشروع DOS:

1. تبني RAD IDE البرنامج إن تغيّر مصدره.
2. تكتب ملف إعداد لـ DOSBox-X يجعل مجلد مشروعك هو القرص **C:**.
3. تضبط سرعة المعالج المحاكى (XT أو 286 أو 386 أو 486 أو Pentium أو أقصى سرعة) ونوع البطاقة والذاكرة من **Project > DOS Project Settings...** (المشروع > إعدادات مشروع DOS).
4. تشغّل برنامجك في نافذة DOSBox-X. والزر **Stop** (إيقاف) في الـ IDE يغلق المحاكي أيضًا.

> **نصيحة:** الألعاب القديمة سريعة جدًّا على أقصى سرعة، لأنها كانت تنتظر بعدّ الحلقات. اختر عندها سرعة **286** أو **386** من الإعدادات.

## مشاريع DOS في RAD IDE

من **File > New Project...** (ملف > مشروع جديد) افتح مجموعة **DOS**:

| النوع | الملف الرئيسي | المترجم المجاني (يُنزَّل عند أول بناء) |
|---|---|---|
| QBasic / QuickBASIC | `MAIN.BAS` | FreeBASIC لنظام DOS بالخيار `-lang qb` |
| Turbo Pascal-style | `MAIN.PAS` | Free Pascal للمعالج 8086 (نظام msdos) بأسلوب Turbo Pascal |
| Turbo C-style | `MAIN.C` | Open Watcom C (برامج DOS بـ 16 بت) |
| DOS Assembly (16-bit MASM) | `MAIN.ASM` | JWasm بصيغة MASM |
| DOS Batch (.BAT) | `MAIN.BAT` | لا يحتاج مترجمًا |
| DOS Text-Mode Forms App | `Main.tform` | مصمم الشاشات (الدرس 6) |

كل المترجمات تُنزَّل من مواقعها الرسمية إلى `%LOCALAPPDATA%\RADIDE\tools` دون صلاحيات المسؤول، مع التحقق من بصمة SHA-256. ترى حالتها من **Tools > Retro > DOS Programming > DOS Toolchains...** (أدوات > ريترو > برمجة DOS > أدوات DOS).

أما QBasic و QuickBASIC و Turbo Pascal و Turbo C الأصلية فبرامج تجارية لا تنزّلها RAD IDE أبدًا. إن كانت عندك نسخة منها تملكها فاكتب مسارها في نفس النافذة، وستعمل معها (الدرس 10).

## أول ملف دفعي

الملف الدفعي (Batch) قائمة أوامر DOS تُنفَّذ بالترتيب. أنشئ مشروعًا من نوع **DOS Batch (.BAT)** واكتب في `MAIN.BAT`:

```dos-batch run
@ECHO OFF
ECHO Hello from DOS!
SET NAME=RAD IDE
ECHO Made with %NAME%
FOR %%I IN (1 2 3) DO ECHO Step %%I
```

```text output
Hello from DOS!
Made with RAD IDE
Step 1
Step 2
Step 3
```

اضغط `Ctrl+F5`: تفتح نافذة DOSBox-X وتظهر الأسطر. وإن أردت أن ترى الناتج في نافذة **Output** (المخرجات) بلا نافذة محاكي، فاختر **Tools > Retro > DOS Programming > Run with Captured Output...** (تشغيل مع التقاط المخرجات).

- `@ECHO OFF` يمنع DOS من طباعة كل أمر قبل تنفيذه (و`@` تخفي هذا السطر نفسه).
- `SET NAME=...` ينشئ متغير بيئة، و`%NAME%` يقرأ قيمته.
- `FOR %%I IN (...) DO ...` يكرر أمرًا لكل قيمة. داخل الملف الدفعي نكتب `%%I` بعلامتين.

## أوامر DOS تحتاجها

| الأمر | العمل |
|---|---|
| `DIR` | عرض الملفات |
| `CD NAME` | الدخول إلى مجلد، و`CD ..` للرجوع |
| `C:` أو `D:` | الانتقال إلى قرص آخر |
| `TYPE FILE.TXT` | عرض محتوى ملف نصي |
| `COPY A B` و `DEL FILE` و `REN A B` | نسخ وحذف وإعادة تسمية |
| `MD NAME` | إنشاء مجلد |
| `CLS` | مسح الشاشة |
| `EXIT` | إغلاق المحاكي (في DOSBox-X) |

أسماء ملفات DOS قصيرة: ثمانية حروف ثم نقطة ثم ثلاثة حروف (8.3)، مثل `GAME.EXE` و`README.TXT`. لذلك تسمّي RAD IDE البرنامج الناتج باسم مشروعك مقصوصًا إلى ثمانية حروف.

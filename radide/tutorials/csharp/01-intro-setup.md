# الدرس 1: مرحبًا بك في C# و.NET

أهلًا بك في دورة **C#** (تُنطق «سي شارب»). في هذه الدورة سنبدأ من الصفر تمامًا: لا نفترض أنك كتبت سطر كود من قبل. وفي النهاية ستبني برنامجًا حقيقيًا بنافذة وأزرار وقوائم، بنفس الطريقة التي اشتهر بها Visual Basic: ترسم النافذة بالفأرة، ثم تكتب الكود الذي يعمل عند الضغط على الأزرار.

## ما هي C#؟ وما هي .NET؟

**C#** لغة برمجة حديثة صممتها شركة Microsoft سنة 2000، وهي اليوم من أكثر اللغات استخدامًا في العالم: برامج سطح المكتب، ومواقع الويب (ASP.NET)، والألعاب (محرك Unity)، وتطبيقات الهاتف.

أما **.NET** (تُنطق «دوت نت») فهي **المنصة** التي تعمل عليها برامج C#. تخيّلها هكذا:

> **تشبيه:** C# هي **اللغة** التي تكتب بها الوصفة، و.NET هي **المطبخ** المجهز بالأدوات والأفران. الوصفة وحدها لا تطبخ شيئًا، والمطبخ وحده لا يعرف ماذا يطبخ. معًا يصنعان الطعام!

في .NET ستجد:

- **المترجم** (compiler): يحوّل كود C# الذي تكتبه إلى صيغة يفهمها الحاسوب.
- **المكتبة القياسية**: آلاف الأدوات الجاهزة للنصوص والملفات والتواريخ والشبكات...
- **أداة سطر الأوامر `dotnet`**: تبني البرنامج وتشغّله وتضيف إليه المكتبات.

## تجهيز بيئة العمل

تحتاج إلى شيء واحد فقط بجانب RAD IDE: **.NET SDK** (حزمة التطوير).

1. نزّلها من الموقع الرسمي `https://dotnet.microsoft.com/download`، أو اكتب في نافذة الأوامر:

```text
winget install Microsoft.DotNet.SDK.9
```

2. أغلق RAD IDE وافتحها من جديد بعد التثبيت.
3. للتأكد، افتح نافذة الأوامر واكتب `dotnet --version`، فيظهر رقم الإصدار مثل `9.0.300`.

> **ملحوظة:** الـ IDE تبحث عن `dotnet` تلقائيًا في `PATH` وفي `C:\Program Files\dotnet`. إذا لم تجده فستكتب لك في نافذة **Output** (المخرجات) رسالة توضح ما يجب تثبيته.

## برنامجك الأول

هذا أصغر برنامج C# يمكن كتابته. اضغط زر **▶ جرّبه** فوقه:

```csharp run
Console.WriteLine("Hello, World!");
```

```text output
Hello, World!
```

ماذا حدث عندما ضغطت «جرّبه»؟

1. أنشأت الـ IDE **مشروع Visual Studio حقيقيًا** في مجلد الدروس: ملف المشروع `Lesson.csproj` وملف الكود `Program.cs`.
2. فتحت المشروع **في مكانه** (in place)، فظهر في **Solution Explorer** (مستكشف الحلول) تمامًا كما يظهر في Visual Studio.
3. بنته بالأمر `dotnet build` ثم شغّلته، وظهر الناتج في نافذة **Output** (المخرجات).

أي أن ما تتعلمه هنا يعمل كما هو في Visual Studio وفي أي مكان فيه .NET.

> **ملحوظة:** ستجد في المشروع ملفًا صغيرًا اسمه `RadUtf8.cs`. وظيفته أن تظهر الحروف العربية صحيحة في نافذة Output. سنشرحه في الدرس القادم، ولا تحتاج إلى تعديله.

## العربية في الناتج

```csharp run
Console.WriteLine("السلام عليكم");
Console.WriteLine("أنا أتعلم C# اليوم");
```

```text output
السلام عليكم
أنا أتعلم C# اليوم
```

كل `Console.WriteLine` تطبع سطرًا واحدًا ثم تنزل إلى سطر جديد. والنص الذي نطبعه يوضع بين علامتي تنصيص `"..."`.

## كيف تُكتب برامج C#؟ من النص إلى البرنامج

```text
Program.cs  --(المترجم csc)-->  Lesson.dll  --(dotnet)-->  البرنامج يعمل
```

- أنت تكتب **الكود المصدري** (source code) في ملفات تنتهي بـ `.cs`.
- المترجم يحوله إلى ملف `.dll` فيه لغة وسيطة اسمها **IL**.
- عند التشغيل تحوّل .NET هذه اللغة الوسيطة إلى أوامر المعالج مباشرة.

> **تشبيه:** المترجم مثل **مترجم الكتب**: يأخذ كتابك المكتوب بلغة يفهمها البشر ويحوله إلى لغة يفهمها القارئ الآخر (الحاسوب). وإذا وجد جملة غير مفهومة توقف وأخبرك برقم السطر.

## جولة سريعة في الـ IDE

| النافذة | الاسم العربي في الـ IDE | وظيفتها |
|---|---|---|
| **Solution Explorer** | مستكشف الحلول | ملفات المشروع |
| **Output** | المخرجات | ناتج البرنامج ورسائل البناء والأخطاء |
| **Toolbox** | صندوق الأدوات | الأزرار ومربعات النص (للبرامج الرسومية) |
| **Properties** | الخصائص | خصائص الأداة المختارة في المصمم |

وأهم الاختصارات:

| الاختصار | الأمر |
|---|---|
| `F5` | تشغيل مع التصحيح: **Debug > Start Debugging / Continue** (تصحيح الأخطاء > بدء تصحيح الأخطاء / متابعة) |
| `Ctrl+F5` | تشغيل دون تصحيح |
| `Shift+F5` | إيقاف البرنامج |
| `Ctrl+S` | حفظ الكل |
| `Ctrl+Shift+F1` | فتح الدروس |

## أخطاء شائعة

- **نسيان الفاصلة المنقوطة `;`** في آخر السطر: كل تعليمة في C# تنتهي بـ `;`.
- **كتابة `console` بحرف صغير:** C# **حساسة لحالة الأحرف**، فـ `Console` و`console` اسمان مختلفان.
- **استخدام علامات تنصيص ذكية** مثل `“` بدل `"` عند النسخ من Word.

## الخلاصة

- C# هي اللغة، و.NET هي المنصة التي تبني البرنامج وتشغله.
- تحتاج إلى **.NET SDK** فقط بجانب الـ IDE.
- `Console.WriteLine("...")` تطبع سطرًا في نافذة Output.
- أمثلة الدروس تُفتح كمشاريع Visual Studio حقيقية (`.csproj`).

# الدرس 4: تجربة الواجهات بـ REST Client وملفات .http

**في هذا الدرس ستتعلم:**

- فتح **REST Client** (عميل REST) وإرسال طلبات `GET` و`POST` و`PUT` و`DELETE`.
- قراءة الرد: رقم الحالة والزمن والحجم وJSON المنسّق والترويسات.
- حفظ الطلبات في ملفات `.http` وتشغيلها من المحرر بزر **Send Request**.
- المتغيرات والبيئات (environments)، واستخدام نتيجة طلب في طلب آخر.

## لماذا نحتاج REST Client؟

المتصفح يرسل طلبات `GET` فقط عندما تكتب عنوانًا. أما لتجربة إضافة ملاحظة (`POST`) أو حذفها (`DELETE`) فتحتاج أداة ترسل أي طلب بأي بيانات. RAD IDE فيها أداة مدمجة تشبه **Postman**، وتفهم ملفات `.http` بالصيغة نفسها التي تستخدمها إضافة **REST Client** المشهورة في VS Code.

> **تشبيه:** المتصفح مثل زبون لا يعرف إلا أن يقول «أرني». أما REST Client فزبون محترف يستطيع أن يقول «أضف هذا»، و«عدّل ذاك»، و«احذف هذا»، ويقرأ الفاتورة بالتفصيل.

## الخطوة 1: أول طلب

1. شغّل مشروع الملاحظات من الدرس السابق بـ `Ctrl+F5`، وانسخ عنوانه من شريط عنوان **Preview** (مثل `http://127.0.0.1:52341`).
2. افتح **Tools > REST Client** (أدوات > عميل REST) أو اضغط `Ctrl+Alt+K`. يفتح تبويب جديد.
3. في الأعلى: اختر الطريقة `GET`، واكتب العنوان مع `/api/notes`، واضغط **Send** (أو `Ctrl+Enter`).

في نصف الرد ترى:

- **رقم الحالة** (مثل `200 OK`) والزمن بالملي ثانية وحجم الرد.
- تبويب **Body**: الرد منسقًا (JSON ملون ومرتب)، و**Headers**: ترويسات الرد، و**Raw**: الرد كما وصل حرفيًا.

## الخطوة 2: إرسال بيانات بـ POST

1. غيّر الطريقة إلى `POST`، والعنوان `/api/notes`.
2. افتح تبويب **Body** في نصف الطلب واختر **JSON**، واكتب:

```json
{ "text": "مراجعة الدرس الرابع" }
```

3. اضغط **Send**. يجب أن يصل الرد `201 Created` ومعه الملاحظة الجديدة ورقمها.
4. جرّب إرسال `{}` فقط: يجب أن يصل `400` ومعه `{"error":"النص مطلوب"}`. هكذا تتأكد أن التحقق في الخادم يعمل.

تبويبات الطلب الأخرى:

| التبويب | وظيفته |
|---|---|
| **Params** | معاملات العنوان (ما بعد `?`) في جدول |
| **Headers** | ترويسات الطلب، مثل `Accept` أو مفتاح API |
| **Body** | جسم الطلب: لا شيء، أو JSON، أو نموذج (form)، أو نص خام. الزر **Beautify** ينسّق JSON |
| **Auth** | المصادقة: رمز **Bearer** أو اسم مستخدم وكلمة مرور (**Basic**) |

وفي اليسار تبويب **History** (السجل) فيه كل طلب أرسلته، وتبويب **Collections** فيه الطلبات المحفوظة في ملفات المشروع.

## الخطوة 3: ملفات `.http`

بدل إعادة كتابة الطلبات كل مرة، احفظها في ملف. أضف إلى المشروع ملفًا جديدًا اسمه `notes.http` (أو اضغط **Save** في REST Client فيُضاف الطلب الحالي إلى ملف `.http`):

```http
@host = http://127.0.0.1:52341

### كل الملاحظات
GET {{host}}/api/notes
Accept: application/json

### إضافة ملاحظة
# @name created
POST {{host}}/api/notes
Content-Type: application/json

{ "text": "ملاحظة من ملف .http" }

### تعليم الملاحظة التي أضفناها كمنجزة
PUT {{host}}/api/notes/{{created.response.body.$.id}}
Content-Type: application/json

{ "done": true }

### حذفها
DELETE {{host}}/api/notes/{{created.response.body.$.id}}
```

قواعد الملف:

- `###` تفصل بين الطلبات، وما بعدها في السطر نفسه عنوان للطلب.
- `@host = ...` **متغير** على مستوى الملف، ونستخدمه بـ `{{host}}`. عندما يتغير المنفذ تعدّله في مكان واحد.
- سطر الطلب: الطريقة ثم العنوان. بعده الترويسات، ثم **سطر فارغ**، ثم الجسم.
- `# @name created` تعطي الطلب اسمًا، فتستخدم نتيجته في طلب لاحق: `{{created.response.body.$.id}}` هي قيمة `id` في رد ذلك الطلب.

عندما تفتح الملف في المحرر يظهر فوق كل طلب الزر **▶ Send Request**. اضغطه فيُرسَل الطلب ويظهر الرد في تبويب REST Client. ويمكنك أيضًا وضع المؤشر داخل الطلب والضغط على `Ctrl+Alt+K`، أو اختيار **Send Request** من قائمة الزر الأيمن في المحرر.

## متغيرات النظام والبيئات

متغيرات جاهزة تُحسب لحظة الإرسال:

| المتغير | القيمة |
|---|---|
| `{{$guid}}` | معرّف فريد عشوائي |
| `{{$timestamp}}` | الوقت الحالي بالثواني |
| `{{$randomInt 1 100}}` | عدد عشوائي من 1 إلى أقل من 100 |
| `{{$datetime iso8601}}` | التاريخ والوقت الحاليان |
| `{{$processEnv NAME}}` | متغير بيئة من نظام التشغيل |
| `{{$dotenv NAME}}` | قيمة من ملف `.env` في المشروع |

و**البيئات** (environments) تسمح بقيم مختلفة للتطوير والإنتاج. اختر البيئة من القائمة **Env:** في أعلى REST Client، وعدّلها بالزر `...` بجانبها. تُحفظ في `.vscode/settings.json` تحت `rest-client.environmentVariables`، وهو المكان نفسه الذي تستخدمه VS Code، فيعمل الملف في البرنامجين:

```json
{
  "rest-client.environmentVariables": {
    "$shared": { "token": "dev-token-123" },
    "local": { "host": "http://127.0.0.1:3000" },
    "production": { "host": "https://api.example.com" }
  }
}
```

> **أمان:** لا تضع كلمات المرور ومفاتيح API الحقيقية في ملفات يرفعها المشروع إلى Git. استخدم `{{$dotenv API_KEY}}` وضع القيمة في ملف `.env` مضاف إلى `.gitignore`.

## النسخ والتبادل

من الزر **More** في REST Client:

- **Copy as cURL**: ينسخ الطلب أمرًا لبرنامج `curl` لترسله لزميل أو تضعه في التوثيق.
- **Copy as .http**: ينسخه بصيغة ملفات `.http`.
- **Paste .http / cURL request**: يلصق طلبًا منسوخًا من مكان آخر.
- **Follow redirects** و**Verify TLS certificates**: خياران للتحويلات وشهادات HTTPS.

وفي نافذة **Requests** (الطلبات) يمكنك أيضًا النقر بالزر الأيمن على أي طلب وصل إلى موقعك واختيار **Copy as curl**.

## أخطاء شائعة

- **نسيان السطر الفارغ قبل الجسم:** بدونه يُعتبر الجسم ترويسات.
- **نسيان `Content-Type: application/json`:** لا يقرأ Express الجسم فتصل `req.body` فارغة.
- **المنفذ تغيّر:** RAD IDE قد تختار منفذًا مختلفًا في كل تشغيل. ثبّته من **Site > Site Settings... > Port:**، أو حدّث المتغير `@host`.
- **`ECONNREFUSED`:** الخادم لا يعمل. شغّله أولًا بـ `Ctrl+F5`.

## تمارين

### التمرين 1

اكتب ملف `.http` فيه طلبان: الأول يضيف ملاحظة نصها «تمرين» ويسمّى `n`، والثاني يجلب الملاحظة نفسها برقمها.

```http
@host = http://127.0.0.1:3000

### أضف
# اكتب الطلب هنا

### اجلب
# اكتب الطلب هنا
```

**الحل:**

```http
@host = http://127.0.0.1:3000

### أضف
# @name n
POST {{host}}/api/notes
Content-Type: application/json

{ "text": "تمرين" }

### اجلب
GET {{host}}/api/notes/{{n.response.body.$.id}}
```

### التمرين 2 (في RAD IDE)

أرسل من REST Client طلب `DELETE` إلى `/api/notes/999` (رقم غير موجود). ما رقم الحالة الذي يرجعه الخادم؟ وما الذي يظهر في نافذة **Requests** لهذا الطلب؟ (الجواب: `404`، ويظهر في Requests بلون الخطأ.)

## الخلاصة

- **Tools > REST Client** (`Ctrl+Alt+K`): الطريقة والعنوان و**Send**، والتبويبات Params وHeaders وBody وAuth.
- ملفات `.http`: `###` بين الطلبات، و`@متغير = قيمة`، و`# @name` لاستخدام نتيجة طلب في غيره، وزر **▶ Send Request** فوق كل طلب.
- متغيرات النظام مثل `{{$guid}}`، والبيئات في `.vscode/settings.json`.
- **Copy as cURL** لمشاركة الطلبات.

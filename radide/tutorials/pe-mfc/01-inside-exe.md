# الدرس 1: ماذا يوجد داخل ملف EXE؟ الرأس والأقسام والموارد

**في هذا الدرس ستتعرف على:**

- صيغة **PE** (Portable Executable) التي تُبنى بها برامج ويندوز `.exe` و`.dll`.
- **الأقسام** (Sections): الكود والبيانات والموارد.
- **الموارد** (Resources): النوافذ الحوارية والقوائم والنصوص والأيقونات ومعلومات الإصدار.
- كيف تفتح برنامجًا في **منضدة موارد PE / MFC** في RAD IDE، وما حدودها.

## برنامج ويندوز = رأس + أقسام

عندما يترجم Visual C++ برنامجك المكتوب بلغة C أو C++ (مع MFC أو بدونها) يكتب ملفًا بصيغة PE. يبدأ الملف دائمًا بالحرفين `MZ` (من أيام DOS)، وفي الموضع `0x3C` رقم يشير إلى توقيع `PE\0\0`، وبعده رأس يقول نوع المعالج وعدد الأقسام:

```python run
import struct

# رأس DOS صغير ثم توقيع PE ثم رأس COFF (بيانات تجريبية مكتوبة هنا)
dos = bytearray(64)
dos[0:2] = b"MZ"
struct.pack_into("<I", dos, 0x3C, 64)          # e_lfanew: مكان توقيع PE
coff = struct.pack("<HHIIIHH", 0x8664, 6, 0, 0, 0, 240, 0x22)
data = bytes(dos) + b"PE\0\0" + coff

pe_off = struct.unpack_from("<I", data, 0x3C)[0]
machine, nsections = struct.unpack_from("<HH", data, pe_off + 4)
print("MZ:", data[:2] == b"MZ")
print("PE at offset", pe_off, data[pe_off:pe_off + 4] == b"PE\0\0")
print("machine:", {0x14C: "x86 (32-bit)", 0x8664: "x64 (64-bit)"}[machine])
print("sections:", nsections)
```

```text output
MZ: True
PE at offset 64 True
machine: x64 (64-bit)
sections: 6
```

أشهر الأقسام في برامج Visual C++:

| القسم | ماذا فيه |
|---|---|
| `.text` | **الكود**: تعليمات المعالج x86 أو x64 الناتجة من دوالك |
| `.rdata` | بيانات للقراءة فقط: النصوص الثابتة، جداول الاستيراد، **جداول رسائل MFC**، معلومات RTTI |
| `.data` | المتغيرات العامة |
| `.rsrc` | **الموارد**: النوافذ والقوائم والأيقونات... |
| `.reloc` | جدول **الإزاحات** (Relocations): الأماكن التي يصححها ويندوز إذا حمّل البرنامج في عنوان آخر |

## الموارد: الواجهة محفوظة كبيانات

في مشروع Visual C++ تصمم النوافذ في ملف `.rc`، والمترجم `rc.exe` يحولها إلى بيانات ثنائية داخل قسم `.rsrc`. لذلك يمكن تعديل الواجهة **دون الكود المصدري**: تغيير عنوان نافذة، أو نص زر، أو ترجمة القوائم إلى العربية.

الموارد مرتبة كشجرة من ثلاثة مستويات: **النوع** (Dialog، Menu، String Table...) ثم **الاسم أو الرقم** (مثل 101) ثم **اللغة** (مثل 1033 للإنجليزية و1025 للعربية). ويمكن أن يحتوي البرنامج النافذة نفسها بأكثر من لغة.

## افتح برنامجًا في RAD IDE

1. **Tools > PE / MFC Resource Workbench...** واختر ملف `.exe` أو `.dll` (أو افتح الملف مباشرة من File > Open أو من Solution Explorer).
2. تفتح المنضدة في تبويب له خمسة أقسام: **Resources** و**Code** و**MFC Events** و**Patches** و**Info**.
3. في **Info** ترى نوع المعالج والأقسام وقائمة الدوال المستوردة من مكتبات ويندوز.

للتجربة استخدم برنامج **MiniMfc** المرفق مع RAD IDE في المجلد `samples/Tests/PE/MfcResources` (نسختا 32 و64 بت في `prebuilt`، انسخ إحداهما وغيّر امتدادها إلى `.exe`).

> **الحدود**: المنضدة لبرامجك أنت أو برامج مسموح لك بتعديلها وللتعلم. هي تعدّل الموارد وتجري تعديلات صغيرة في المكان نفسه، ولا تضيف كودًا جديدًا إلى البرنامج أبدًا، وليس فيها أي شيء لتجاوز التراخيص أو الحمايات. وكل حفظ يكتب **ملفًا جديدًا**، والأصل لا يتغير.

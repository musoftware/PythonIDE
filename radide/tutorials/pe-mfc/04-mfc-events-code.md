# الدرس 4: أحداث MFC والكود المفكك والحفظ الآمن

**في هذا الدرس ستتعرف على:**

- **جداول الرسائل** (Message Maps) في MFC: كيف يربط البرنامج الزر بدالته.
- قراءة **الكود المفكك** (Disassembly) لمعالج حدث.
- **إعادة توجيه** معالج إلى دالة أخرى موجودة، وحذف مدخل.
- **تعديل تعليمة** في مكانها، والحفظ في ملف جديد.

## جدول الرسائل

في كود MFC تكتب:

```text
BEGIN_MESSAGE_MAP(CMainDlg, CDialog)
    ON_BN_CLICKED(IDC_BUTTON1, OnButton1)
    ON_COMMAND(ID_FILE_HELLO, OnFileHello)
END_MESSAGE_MAP()
```

هذه الماكروهات تصبح **جدولًا من البيانات** داخل البرنامج. كل مدخل فيه: رقم الرسالة، ورمز الإشعار، ومعرّف العنصر (من..إلى)، ونوع الدالة، وعنوان الدالة:

```python run
import struct

# مدخل واحد من جدول رسائل MFC في برنامج 32 بت: ستة أرقام كل منها 4 بايت = 24 بايت
WM_COMMAND, BN_CLICKED = 0x111, 0
entry = struct.pack("<IIIIII", WM_COMMAND, BN_CLICKED, 1001, 1001, 0x13, 0x401210)
print("entry size:", len(entry))

msg, code, cid, last, sig, pfn = struct.unpack("<IIIIII", entry)
print(f"message 0x{msg:X}, code {code}, control {cid}..{last}, handler 0x{pfn:X}")

# إعادة التوجيه = تغيير آخر حقل فقط (عنوان دالة موجودة أخرى)
retargeted = entry[:20] + struct.pack("<I", 0x401290)
print(f"new handler 0x{struct.unpack_from('<I', retargeted, 20)[0]:X}")
print("64-bit entry size:", struct.calcsize("<IIIIQQ"))
```

```text output
entry size: 24
message 0x111, code 0, control 1001..1001, handler 0x401210
new handler 0x401290
64-bit entry size: 32
```

المنضدة تبحث عن هذه الجداول، وتعرف اسم الصنف (مثل `CMainDlg`) من معلومات **RTTI** التي يضعها المترجم، وتتبع الصنف الأب (`CDialog` ثم `CWnd`).

## تبويب MFC Events

- كل صنف ومداخله بصيغة الماكرو: `ON_COMMAND / ON_BN_CLICKED(1001, OnButton1)`، `ON_EN_CHANGE`، `ON_CONTROL_RANGE`، `ON_MESSAGE`...
- **Show Handler Code**: يفتح كود الدالة في تبويب Code.
- **Retarget Handler...**: يجعل المدخل يشير إلى **دالة موجودة** أخرى. اختر معالجًا من النوع نفسه (مثلًا معالج زر آخر)، لأن الدالة الجديدة تستقبل المعاملات نفسها.
- **Remove Entry**: يحذف المدخل فلا يعالج الصنف هذا الحدث. والمكان الذي فرغ يمكن أن تضيف فيه مدخلًا جديدًا بـ **Add Entry...** (الجدول لا يُنقل ولا يُكبَّر).

ومن المصمم: انقر نقرًا مزدوجًا على زر فتظهر دالته مباشرة.

**جرّب على MiniMfc:** وجّه مدخل `IDC_BUTTON1` إلى معالج `IDC_BUTTON2`، واحفظ، وشغّل البرنامج المحفوظ: الزر الأول يعرض الآن رسالة الزر الثاني. ثم **Undo** يعيد كل شيء.

## تبويب Code

قائمة الدوال (معالجات MFC أولًا باللون الأخضر)، والكود المفكك مع تعليقات بأسماء الدوال المستوردة مثل `USER32!SetDlgItemTextW` والنصوص، و**Called From** لمن يستدعي الدالة. وزر **Decompile (Ghidra)** يعرض كود C تقريبيًا إن كان Ghidra مثبتًا.

**Edit Instruction...** يكتب تعليمة جديدة بلغة التجميع في المكان نفسه، بشرط أن تكون **بنفس الحجم أو أصغر** (والباقي يُملأ بتعليمات NOP). التعديل الأكبر يُرفض برسالة واضحة، لأن المنضدة لا تضيف كودًا إلى البرنامج.

## الحفظ

**Save As...** يكتب `اسم_البرنامج_edited.exe`، ويحفظ نسخة `.bak` من أي ملف يُكتب فوقه، ويعيد حساب **المجموع الاختباري** للملف، ويزيل **التوقيع الرقمي** إن وُجد (لأنه لا يعود صالحًا بعد أي تعديل) ويخبرك بذلك. وتبويب **Patches** يعرض كل تعديلات الكود والجداول مع زر **Revert Patch**.

# الدرس 3: القوائم وجداول النصوص والإصدار وملف .rc

**في هذا الدرس ستتعرف على:**

- تعديل **القوائم** (MENU / MENUEX) ومعرّفات أوامرها.
- **جداول النصوص** وكيف تُخزن في كتل من 16 نصًا.
- **مفاتيح الاختصار** و**معلومات الإصدار** و**الأيقونات والصور**.
- **التصدير إلى ملف .rc** والاستيراد منه.

## القوائم

كل عنصر في القائمة له نص ومعرّف أمر (مثل `40001` لأمر File > Hello). في تبويب Resources افتح **Menu**: الشجرة تعرض النص والمعرّف والأعلام، وعمود **MFC handler** يعرض الدالة التي تنفذ الأمر. عدّل النص أو المعرّف مباشرة في الشجرة، وأضف عناصر بـ **Add Item** و**Add Submenu** و**Add Separator**، ثم **Apply**.

## جداول النصوص

البرامج تحفظ رسائلها في جدول نصوص حتى تسهل ترجمتها. الجدول مقسم إلى **كتل** في كل منها 16 نصًا متتاليًا:

```python run
import struct

# جدول النصوص: كل كتلة فيها 16 نصًا، ورقم الكتلة = رقم النص // 16 + 1
def block_of(string_id):
    return string_id // 16 + 1, string_id % 16

for sid in (2001, 2002, 2003):
    print(sid, "-> block", *block_of(sid))

# كل نص في الكتلة: طوله (WORD) ثم حروفه بترميز UTF-16 بلا صفر في النهاية
texts = {1: "Hello", 2: "مرحبا"}
blob = b"".join(struct.pack("<H", len(texts.get(i, ""))) + texts.get(i, "").encode("utf-16-le")
                for i in range(16))
print("block size:", len(blob), "bytes")
```

```text output
2001 -> block 126 1
2002 -> block 126 2
2003 -> block 126 3
block size: 52 bytes
```

في المنضدة لا تحتاج التفكير في الكتل: محرر **String Table** يعرض كل نصوص اللغة في جدول (ID ونص)، وعند **Apply** يعيد بناء الكتل.

## مفاتيح الاختصار والإصدار والصور

- **Accelerators**: اكتب المفتاح مثل `Ctrl+H` أو `Shift+Delete` أو `F1` ومعرّف الأمر.
- **Version**: إصدار الملف والمنتج (مثل `2.0.0.7`) وقيم مثل CompanyName وFileDescription التي تظهر في خصائص الملف في مستكشف ويندوز.
- **Icon Group / Bitmap**: معاينة، و**Replace from File...** لاستبدال الأيقونة بملف `.ico` أو الصورة بملف `.bmp`، و**Export...** للحفظ.
- **Toolbar (MFC)** و**Dialog Init (MFC)**: موارد خاصة بمكتبة MFC لترتيب أزرار شريط الأدوات ولنصوص القوائم المنسدلة.

## ملف .rc

**Export .rc...** يكتب كل الموارد في ملف نصي `.rc` (بنفس صيغة Visual Studio) ومجلد `res` للأيقونات والصور. يمكنك تعديله بأي محرر ثم **Import .rc...** لإعادته. المنضدة تقرأ ملف .rc بنفسها، فلا تحتاج `rc.exe`.

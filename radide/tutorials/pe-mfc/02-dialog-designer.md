# الدرس 2: تعديل النوافذ الحوارية بالمصمم المرئي

**في هذا الدرس ستتعرف على:**

- قالب النافذة الحوارية **DIALOG / DIALOGEX** وعناصره.
- **وحدات النافذة** (Dialog Units) ولماذا لا تُقاس بالبكسل.
- تحريك العناصر وتغيير حجمها، وتعديل العنوان والمعرّف والنمط، وإضافة عنصر أو حذفه.

## القالب: نافذة + عناصر

كل نافذة حوارية في الموارد قالب فيه: عنوان النافذة، ونمطها (Style)، وخطها، وحجمها، ثم قائمة **عناصر التحكم**. لكل عنصر:

| الحقل | المعنى |
|---|---|
| Class | الصنف: `Button` أو `Edit` أو `Static` أو `ComboBox` أو `ListBox` أو صنف مخصص |
| Caption | النص الظاهر (الحرف بعد `&` يصبح اختصارًا بـ Alt) |
| ID | **المعرّف**: رقم يستخدمه الكود ليعرف أي زر ضُغط (مثل 1001) |
| X, Y, Width, Height | المكان والحجم **بوحدات النافذة** |
| Style | أعلام مثل `WS_VISIBLE` و`WS_TABSTOP` ونوع الزر |

## وحدات النافذة (DLU)

حتى تبقى النافذة مناسبة مع أي خط، تُقاس الأبعاد بأرباع متوسط عرض الحرف أفقيًا وبأثمان ارتفاعه رأسيًا. المصمم في RAD IDE يحوّلها إلى بكسلات بنفس الطريقة:

```python run
# وحدات النافذة الحوارية (DLU): العرض بأرباع متوسط عرض الحرف، والارتفاع بأثمان ارتفاعه
base_x, base_y = 6, 13            # خط MS Shell Dlg بحجم 8 على شاشة 96 DPI تقريبًا
def to_pixels(x, y, cx, cy):
    return (round(x * base_x / 4), round(y * base_y / 8),
            round(cx * base_x / 4), round(cy * base_y / 8))

print("dialog 260 x 170 DLU ->", to_pixels(0, 0, 260, 170)[2:], "pixels")
print("button at (175, 9) size 75 x 16 ->", to_pixels(175, 9, 75, 16))
```

```text output
dialog 260 x 170 DLU -> (390, 276) pixels
button at (175, 9) size 75 x 16 -> (262, 15, 112, 26)
```

## العمل في المصمم

1. في تبويب **Resources** افتح **Dialog** واختر النافذة (مثل 101).
2. **اسحب** عنصرًا لتحريكه، و**اسحب الركن الأزرق** لتغيير حجمه. المواضع تُقرَّب إلى وحدات النافذة.
3. في لوحة الخصائص غيّر **Caption** و**ID** و**Style**، أو علّم **Visible** / **Disabled** / **Tab stop**، ثم Enter أو **Apply Properties**.
4. بدون اختيار أي عنصر تعدّل خصائص النافذة نفسها: العنوان والحجم والخط.
5. من **Toolbox** أضف زرًا أو مربع نص أو قائمة، و**Delete Control** يحذف العنصر المختار.
6. **Preview (Windows)** يعرض القالب بواسطة ويندوز نفسه لترى الشكل الحقيقي.

كل تعديل يمكن التراجع عنه بـ **Undo** (أو Ctrl+Z). والنقطة الخضراء على عنصر تعني أن له **معالج حدث MFC** (الدرس 4). وانقر نقرًا مزدوجًا على أي عنصر لترى كود معالجه، كما في نافذة الكود في Visual Basic.

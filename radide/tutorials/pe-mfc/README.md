# PE / MFC course (Arabic)

`course.json` + 4 lessons (`NN-slug.md`) about the PE / MFC Resource Workbench (docs/PE_MFC.md): what is inside
a Windows `.exe` / `.dll`, editing dialogs in the visual designer, menus / string tables / version info / icons
and `.rc` export, then the disassembly, MFC message maps (button and menu handlers), retargeting a handler and
saving safely to a new file.

Scope: your own programs and learning. The workbench (and the course) never adds code to a program and has
nothing for licence checks, DRM or other protections. Examples use the MiniMfc test program built from source
in `samples/Tests/PE/MfcResources/` and small byte strings written in the lessons.

Runnable blocks are standard-library `python run` blocks with their `text output`.

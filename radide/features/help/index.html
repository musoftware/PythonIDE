RAD IDE Help

RAD IDE is a Visual Basic style environment: draw a window with the mouse, double-click a control and write its event handler. The same designer works for several programming languages; a project can even mix them.

Getting started

  1. File > New Project (Ctrl+Shift+N) or the Start Page. Pick a language and a template:
    • Windows Application - an empty form.
    • Dialog Application - a fixed-size form with a message, OK and Cancel buttons.
    • Data Entry Form - labels, text boxes, a list and Save / New / Delete buttons; records are stored in a JSON file next to the program (code provided for Python, VB6 and Ring).
    • Console Application - no form: a code module with a main entry point; output goes to the Output window.
  2. Drag controls from the Toolbox onto the form, set their properties in the Properties window.
  3. Double-click a control to create and open its default event handler (for example btnOK_Click).
  4. Press F5 to run with the debugger or Ctrl+F5 to run without it.

Files of a project: project.radproj (the project), Form1.form (the form layout, JSON), Form1.<ext> (your code) and Form1_designer.<ext> (generated from the form every time you save - do not edit it).

Designer

  • Toolbox: click a tool then click/drag on the form, or drag the tool onto the form. Containers (Panel, GroupBox, TabControl) hold other controls.
  • Selection: click, Ctrl+click or drag a rubber band; arrow keys move, Shift+arrows resize.
  • Grid and snap: Tools > Options > Windows Forms Designer sets the grid size and turns snapping on/off.
  • Format menu: align, make same size, center in form, bring to front / send to back.
  • Non-visual components (Timer, dialogs, MenuStrip, ToolStrip) appear in the tray under the form; the Menu Editor edits menus.
  • Properties window: categorized or alphabetical; the Events tab lists events, those with a handler are bold. Anchor and Dock make controls follow the window when it is resized.
  • Undo/redo, cut/copy/paste of controls, right-click menus everywhere.

Code editor

  • Syntax highlighting for every language, Arabic / right-to-left text, auto-indent, brace matching.
  • IntelliSense while typing and with Ctrl+Space; parameter info with Ctrl+Shift+Space.
  • Find / Replace (Ctrl+F / Ctrl+H), Find in Files (Ctrl+Shift+F), Go to Line (Ctrl+G), Go to Definition (F12), toggle comment (Ctrl+/).
  • Error List: the project is checked every time you save (and with Ctrl+Shift+B); TODO / FIXME comments appear as tasks.
  • Auto-save writes unsaved changes to .radide_backup (interval in Tools > Options); after a crash the IDE offers to restore them.

Run & debug

  • F5 start / continue, Shift+F5 stop, F9 toggle breakpoint (or click the margin), F10 step over, F11 step into, Shift+F11 step out.
  • While paused: Locals, Call Stack, the Immediate window (type an expression and press Enter) and the value of a variable when the mouse rests on it.
  • Program output (print / Debug.Print / see) goes to the Output window.

GUI Bridge: languages without a GUI toolkit still get forms. The IDE draws the window and the program talks to it over standard input/output (EVENT, SET, GET, CALL, MSGBOX, DONE).

Multi-language projects

  • A form can be written in a different language than the project (its language is stored in project.radproj under form_languages); modules get their language from the file extension (.py, .ring, .bas, ...).
  • Call a function written in another language with radcall("Module.function", args...). Values travel as JSON (numbers, strings, booleans, null, lists, objects).
  • When the program runs, the IDE starts RAD Hub, which starts one worker per module language and routes the calls.
# Python form calling a Ring module (Helpers.ring defines func add a, b)
total = radcall("Helpers.add", 2, 3)      # -> 5

Packages (Project > Manage Packages...)

A NuGet-style window for the language's package manager (pip for Python, RingPM for Ring, and NuGet, npm, cargo, composer, gem, ... for the other language plugins that define one).

  • Browse: search for a package (for pip, enter the exact name to see its versions), pick a version (empty = latest) and click Install. Open Website searches the package site in your browser.
  • Installed: the packages the tool reports; Uninstall or Update... the selected one.
  • Commands run in the project folder and their output is shown at the bottom. If the manifest (requirements.txt, package.json, .csproj, ...) is missing it is created first. For Python, requirements.txt is kept up to date (name==version).
  • pip installs into the interpreter set for the language - use a virtual environment's python.exe in Tools > Options to keep projects separate.
  • The VB6 language has no package manager: add shared code with Project > Add Existing Item.

Terminal (View > Terminal, Ctrl+`)

  • Command Prompt, PowerShell or Git Bash running in the project folder (choose in the Shell box).
  • Type a command and press Enter. Up / Down browse the history, Ctrl+C stops the running command (the shell keeps running), Ctrl+L or cls clears the screen. Restart starts a new shell.

Git (View > Git Changes, Ctrl+Alt+G)

  • Init Repository creates a repository in the project folder with a suitable .gitignore.
  • The list shows Staged Changes and Changes with their state (Modified, Added, Deleted, Renamed, Untracked, Conflict). Select files and click Stage / Unstage, or Stage All.
  • Selecting a file shows its diff; the History tab lists commits (double-click to see one).
  • Write a message and click Commit (Ctrl+Enter). With nothing staged, the IDE offers to stage everything.
  • Pull and Push appear only when the repository has a remote, and run only when you click them (push asks for confirmation).
  • The current branch is shown in the status bar; changed files are coloured in the Solution Explorer (blue = modified, green = new, red = deleted).

Options & themes (Tools > Options)

  • Environment: color theme - System (follows Windows light/dark, live), Light (Visual Studio 2005), Blue (Visual Studio 2010), Dark, High Contrast - and the auto-save interval.
  • Text Editor: font, size, tab / indent width.
  • Windows Forms Designer: grid size and snap to grid.
  • Languages: interpreter / compiler path for each language.

Changes apply immediately to open editors and designers. In the dark theme the form being designed keeps the light look of the real program.

F1 help

Press F1 on a word in the code editor, or with a control selected in the designer:

  • VB6: the bundled VB6 language reference (keywords, statements, functions, control members).
  • Python: docs.python.org (built-in functions, keywords, standard modules), Tkinter, and the Qt for Python class pages for Q... classes.
  • Ring: the Ring documentation (local copy when installed, otherwise ring-lang.github.io); RingQt classes open the Qt 5 class reference.

Where no topic is under the cursor, F1 opens this page.

Import & build

  • File > Import > Python GUI Program: reads the windows of a Tkinter or Qt program and turns them into forms with their handlers.
  • File > Import > Visual Basic 6 Project (.vbp / .frm): forms, controls, menus and code; runs as-is with the VB6 language.
  • Project > Build EXE: PyInstaller for Python, ring2exe for Ring.

تعليمات RAD IDE

RAD IDE بيئة تطوير على طريقة Visual Basic: ارسم النافذة بالماوس، وانقر مرتين على أي عنصر تحكم واكتب معالج الحدث الخاص به. نفس المصمم يعمل مع لغات برمجة كثيرة، بل يمكن أن يجمع المشروع الواحد أكثر من لغة.

لتغيير لغة واجهة بيئة التطوير: أدوات > خيارات > البيئة > اللغة (أو أدوات > اللغة) واختر English أو العربية. التبديل فوري، وكودك ونماذجك لا تتغير، ومحررات الكود تبقى من اليسار لليمين.

البداية المصمم محرر الكود التشغيل وتصحيح الأخطاء اللغات مشروعات متعددة اللغات الحلول والمراجع الحزم الطرفية Git مواقع الويب الذكاء الاصطناعي الخيارات والسمات تعليمات F1 الاستيراد والبناء اختصارات لوحة المفاتيح

البداية

  1. ملف > مشروع جديد (Ctrl+Shift+N) أو من صفحة البدء. اختر لغة ثم قالبًا:
    • تطبيق Windows - نموذج فارغ.
    • تطبيق حوار - نموذج بحجم ثابت فيه رسالة وزرّا موافق وإلغاء.
    • نموذج إدخال بيانات - عناوين ومربعات نص وقائمة وأزرار حفظ / جديد / حذف؛ والسجلات تُحفظ في ملف JSON بجوار البرنامج.
    • تطبيق سطر أوامر - بدون نموذج: وحدة كود فيها نقطة دخول main، والمخرجات تظهر في نافذة المخرجات.
    • مكتبة أصناف - دوال عامة تستخدمها مشروعات أخرى في نفس الحل.
  2. اسحب عناصر التحكم من صندوق الأدوات إلى النموذج، واضبط خصائصها في نافذة الخصائص.
  3. انقر مرتين على عنصر تحكم لإنشاء معالج حدثه الافتراضي وفتحه (مثلًا btnOK_Click).
  4. اضغط F5 للتشغيل مع المصحح أو Ctrl+F5 للتشغيل بدونه.

ملفات المشروع: project.radproj (المشروع)، وForm1.form (تخطيط النموذج بصيغة JSON)، وForm1.<ext> (كودك)، وForm1_designer.<ext> (يتم توليده من النموذج عند كل حفظ - لا تعدّله يدويًا).

المصمم

  • صندوق الأدوات: اضغط على أداة ثم اضغط/اسحب على النموذج، أو اسحب الأداة إلى النموذج. الحاويات (Panel و GroupBox و TabControl) تحتوي عناصر تحكم أخرى.
  • التحديد: نقرة، أو Ctrl+نقرة، أو اسحب مستطيل تحديد؛ الأسهم تحرّك، وShift+الأسهم تغيّر الحجم.
  • الشبكة والالتصاق: أدوات > خيارات > مصمم نماذج Windows يضبط حجم الشبكة ويشغّل/يوقف الالتصاق.
  • قائمة تنسيق: محاذاة، توحيد الحجم، توسيط في النموذج، إحضار إلى الأمام / إرسال إلى الخلف.
  • المكونات غير المرئية (Timer والحوارات و MenuStrip و ToolStrip) تظهر في الشريط أسفل النموذج؛ ومحرر القوائم يحرّر القوائم.
  • نافذة الخصائص: مصنّفة أو أبجدية؛ وتبويب الأحداث يعرض الأحداث، والتي لها معالج تظهر بخط عريض. Anchor و Dock يجعلان العناصر تتبع النافذة عند تغيير حجمها.
  • أسماء الخصائص وعناصر التحكم تبقى بالإنجليزية (مثل Text و BackColor و Button) لأنها جزء من الكود، كما في Visual Basic.
  • تراجع/إعادة، وقص/نسخ/لصق لعناصر التحكم، وقوائم الزر الأيمن في كل مكان.

محرر الكود

  • تلوين الصيغة لكل لغة، ونصوص عربية / من اليمين لليسار داخل النصوص والتعليقات، ومسافة بادئة تلقائية، ومطابقة الأقواس.
  • IntelliSense أثناء الكتابة ومع Ctrl+Space؛ ومعلومات المعاملات مع Ctrl+Shift+Space.
  • بحث / استبدال (Ctrl+F / Ctrl+H)، والبحث في الملفات (Ctrl+Shift+F)، والانتقال إلى سطر (Ctrl+G)، والانتقال إلى التعريف (F12)، وتبديل التعليق (Ctrl+/).
  • قائمة الأخطاء: يتم فحص المشروع عند كل حفظ (ومع Ctrl+Shift+B)؛ وتعليقات TODO / FIXME تظهر كمهام.
  • الحفظ التلقائي يكتب التغييرات غير المحفوظة في .radide_backup (الفاصل الزمني في أدوات > خيارات)؛ وبعد أي عطل تعرض بيئة التطوير استعادتها.

التشغيل وتصحيح الأخطاء

  • F5 بدء / متابعة، وShift+F5 إيقاف، وF9 نقطة توقف (أو اضغط على الهامش)، وF10 خطوة فوق، وF11 خطوة إلى الداخل، وShift+F11 خطوة إلى الخارج.
  • أثناء الإيقاف المؤقت: المتغيرات المحلية ومكدس الاستدعاءات والمراقبة ونافذة الأوامر الفورية (اكتب تعبيرًا واضغط Enter)، وقيمة المتغير عند وضع الماوس عليه.
  • مخرجات البرنامج (print / Debug.Print / see) تظهر في نافذة المخرجات.

اللغات

ملف > مشروع جديد يعرض كل اللغات ويوضح المثبّت منها. أهمها:

Python (Tkinter)TkinterPython (أو مفسّر بيئة التطوير)pip و requirements.txt
Python (PySide6 / Qt)عناصر QtPython مع PySide6pip و requirements.txt

المفسّر أو المترجم المستخدم لكل لغة يُضبط في أدوات > خيارات > اللغات (فارغ = يُكتشف تلقائيًا).

جسر الواجهة (GUI Bridge): اللغات التي ليس لها مكتبة واجهات تحصل على نماذج أيضًا. بيئة التطوير ترسم النافذة والبرنامج يتحدث معها عبر الإدخال/الإخراج القياسي (EVENT وSET وGET وCALL وMSGBOX وDONE).

مشروعات متعددة اللغات

  • يمكن كتابة نموذج بلغة غير لغة المشروع؛ والوحدات تأخذ لغتها من امتداد الملف (.py و.ring و.bas ...).
  • استدعِ دالة مكتوبة بلغة أخرى بـ radcall("Module.function", args...). القيم تنتقل بصيغة JSON.
# Python form calling a Ring module (Helpers.ring defines func add a, b)
total = radcall("Helpers.add", 2, 3)      # -> 5

الحلول والمراجع (مثل Visual Studio)

  • الحل (.radsln) يضم عدة مشروعات، لكل مشروع لغة واحدة: تطبيق Windows أو مكتبة أصناف.
  • إضافة مرجع (انقر بالزر الأيمن على المراجع في مستكشف الحلول): تبويبات المشروعات / الحزم / استعراض. بيئة التطوير تولّد غلافًا بلغة المشروع المستهلك، فتستدعي المكتبة ككود عادي، مثلًا MathLib.Add(2, 3).
  • تعيين كمشروع بدء التشغيل يحدد ما يشغّله F5، وبناء الحل يحدّث الأغلفة.

الحزم (مشروع > إدارة الحزم...)

  • استعراض: ابحث عن حزمة، واختر إصدارًا (فارغ = الأحدث) واضغط تثبيت.
  • المثبّت: الحزم الموجودة؛ إلغاء التثبيت أو تحديث... للحزمة المحددة.
  • لمشروعات Python تُثبَّت الحزم في .venv خاص بالمشروع، وملف requirements.txt يبقى محدثًا.
  • لغة VB6 ليس لها مدير حزم: أضف الكود المشترك بـ مشروع > إضافة عنصر موجود.

الطرفية (عرض > الطرفية، Ctrl+`)

  • موجّه الأوامر أو PowerShell أو Git Bash في مجلد المشروع (اختر من مربع الصدفة).
  • اكتب أمرًا واضغط Enter. أعلى / أسفل لتصفح السجل، وCtrl+C يوقف الأمر الجاري، وCtrl+L يمسح الشاشة.

Git (عرض > تغييرات Git، Ctrl+Alt+G)

  • تهيئة مستودع تنشئ مستودعًا في مجلد المشروع مع ملف .gitignore مناسب.
  • القائمة تعرض التغييرات المُجهّزة والتغييرات مع حالتها. حدد ملفات واضغط تجهيز / إلغاء التجهيز.
  • اكتب رسالة واضغط إيداع (Ctrl+Enter). والفروع والسحب والدفع والمزامنة والدمج وحل التعارضات موجودة في نفس النافذة وفي قائمة Git.
  • الفرع الحالي يظهر في شريط الحالة؛ والملفات المتغيرة ملوّنة في مستكشف الحلول.

مواقع الويب

  • مشروع جديد > ويب: موقع PHP، أو موقع HTML/CSS/JS، أو Node.js (Express)، ومعرض التطبيقات فيه قوالب جاهزة.
  • F5 يشغّل خادم التطوير مع إعادة تحميل مباشرة؛ ونافذة المعاينة (أجهزة، تدوير، فتح في المتصفح) ونافذة الطلبات.
  • عرض التصميم / المقسوم / الكود، وقواعد البيانات (SQLite و MySQL و PostgreSQL)، والنشر (FTP / SFTP / مجلد)، والتقارير (SEO)، وSuperPreview.

الذكاء الاصطناعي

  • أدوات > خيارات > الذكاء الاصطناعي: نماذج محلية مجانية (Ollama و LM Studio)، أو وكلاء سطر أوامر بحسابك (Claude Code و Gemini CLI و Codex ...)، أو محادثات الويب؛ ومفاتيح API اختيارية.
  • محادثة الذكاء الاصطناعي (Ctrl+Alt+I): اسأل بالعربي أو الإنجليزي، وطبّق الكود كفروق قابلة للمراجعة.
  • الإكمال المضمّن (نص شبحي)، وCtrl+I للتعديل بالذكاء الاصطناعي، وإنشاء نموذج بالذكاء الاصطناعي، ومدير الوكلاء لمهام كاملة مع الموافقة والتراجع.

الخيارات والسمات (أدوات > خيارات)

  • البيئة: سمة الألوان (نظام / فاتح / أزرق / داكن / تباين عالٍ)، وتخطيط منطقة العمل (Visual Studio أو VS Code أو الوكيل)، وحجم الخط، واللغة (English / العربية)، والحفظ التلقائي.
  • محرر النصوص: الخط والحجم وعرض المسافة البادئة.
  • مصمم نماذج Windows: حجم الشبكة والالتصاق بها.
  • اللغات: مسار المفسّر / المترجم لكل لغة.

التغييرات تُطبَّق فورًا على المحررات والمصممات المفتوحة.

تعليمات F1

اضغط F1 على كلمة في محرر الكود، أو مع عنصر تحكم محدد في المصمم: مرجع VB6 المدمج، أو توثيق Python و Tkinter و Qt، أو توثيق Ring. وإذا لم يكن تحت المؤشر موضوع، يفتح F1 هذه الصفحة.

الاستيراد والبناء

  • ملف > استيراد > برنامج واجهة Python: يقرأ نوافذ برنامج Tkinter أو Qt ويحوّلها إلى نماذج مع معالجاتها.
  • ملف > استيراد > مشروع Visual Basic 6 (.vbp / .frm): النماذج والعناصر والقوائم والكود.
  • ملف > استيراد > برنامج (.exe / .dll): يحوّل برنامجًا مترجَمًا (مسموح لك بتحليله) إلى مشروع.
  • مشروع > بناء EXE: PyInstaller لـ Python، و ring2exe لـ Ring.

# FolderBrowserDialog

Lets the user pick a folder: ShowDialog() returns "OK" or "Cancel".

**Kind:** component (shown in the component tray below the form, not on it). **Toolbox:** Dialogs. **New name:** FolderBrowserDialog1, FolderBrowserDialog2 ...

## Properties

Besides Name:

| Property | Type | Default | Description |
|---|---|---|---|
| SelectedPath | str | "" | The chosen folder (after ShowDialog). |

## VB6

Written to a VB6 .frm as `MSComDlg.CommonDialog`.

See docs/COMPONENTS.md for how component packages work.

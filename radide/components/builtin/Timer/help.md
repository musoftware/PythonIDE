# Timer

Raises Tick at a regular interval.

**Kind:** component (shown in the component tray below the form, not on it). **Toolbox:** Components. **New name:** Timer1, Timer2 ...

## Properties

Besides Name:

| Property | Type | Default | Description |
|---|---|---|---|
| Interval | int | 100 | Milliseconds between Tick events. |
| Enabled | bool | false | Start the timer when the form loads. |

## Events

Double-clicking the control in the designer writes the handler of **Tick**.

- **Tick** - The timer interval has elapsed.

## VB6

Written to a VB6 .frm as `VB.Timer`.
Imported from: `VB.Timer`.

# StatusBar

A status line, docked at the bottom of the form.

**Kind:** visual control. **Toolbox:** Menus & Toolbars. **New name:** StatusBar1, StatusBar2 ...

**Default size:** 200 x 22 pixels.

## Events

Double-clicking the control in the designer writes the handler of **Click**.

- **Click** - Occurs when the control is clicked.
- the common mouse, keyboard and focus events (Click, MouseDown, KeyDown, GotFocus ...).

## VB6

Written to a VB6 .frm as `MSComctlLib.StatusBar`.

See docs/COMPONENTS.md for how component packages work.

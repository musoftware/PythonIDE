# FontDialog

Lets the user pick a font: ShowDialog() returns "OK" or "Cancel".

**Kind:** component (shown in the component tray below the form, not on it). **Toolbox:** Dialogs. **New name:** FontDialog1, FontDialog2 ...

## Properties

Besides Name:

| Property | Type | Default | Description |
|---|---|---|---|
| FontName | font | Segoe UI | The chosen font family. |
| FontSize | int | 9 | The chosen size in points. |

## VB6

Written to a VB6 .frm as `MSComDlg.CommonDialog`.

See docs/COMPONENTS.md for how component packages work.

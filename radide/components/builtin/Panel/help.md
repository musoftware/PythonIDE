# Panel

Groups other controls.

**Kind:** container (hosts other controls). **Toolbox:** Containers. **New name:** Panel1, Panel2 ...

**Default size:** 200 x 100 pixels.

## Events

Double-clicking the control in the designer writes the handler of **Click**.

- **Click** - Occurs when the control is clicked.
- the common mouse, keyboard and focus events (Click, MouseDown, KeyDown, GotFocus ...).

## VB6

Written to a VB6 .frm as `VB.PictureBox`.
Imported from: `comctllib.toolbar`, `mscomctllib.toolbar`, `vb.line`, `vb.ole`, `VB.PictureBox`, `vb.shape` (`comctllib.toolbar`, `mscomctllib.toolbar`, `vb.line`, `vb.ole`, `vb.shape` approximated).

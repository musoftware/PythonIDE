# ColorDialog

Lets the user pick a colour: ShowDialog() returns "OK" or "Cancel".

**Kind:** component (shown in the component tray below the form, not on it). **Toolbox:** Dialogs. **New name:** ColorDialog1, ColorDialog2 ...

## Properties

Besides Name:

| Property | Type | Default | Description |
|---|---|---|---|
| Color | color | #000000 | The chosen colour (after ShowDialog). |

## VB6

Written to a VB6 .frm as `MSComDlg.CommonDialog`.

See docs/COMPONENTS.md for how component packages work.

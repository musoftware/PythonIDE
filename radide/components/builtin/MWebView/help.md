# MWebView

Shows a web page inside the app.

**Kind:** visual control. **Toolbox:** Mobile. **New name:** WebView1, WebView2 ...

**Default size:** 360 x 300 dp.

## Properties

Besides the common properties (Name, Left, Top, Width, Height, colours, font, Enabled, Visible, Anchor, Dock ...):

| Property | Type | Default | Description |
|---|---|---|---|
| Url | str | https://flutter.dev | Page shown in the view. |

## Events

Double-clicking the control in the designer writes the handler of **Load**.

- **Load** - Occurs before the form is displayed for the first time.

See docs/COMPONENTS.md for how component packages work.

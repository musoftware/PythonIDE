# GroupBox

A frame with a caption around other controls.

**Kind:** container (hosts other controls). **Toolbox:** Containers. **New name:** GroupBox1, GroupBox2 ...

**Default size:** 200 x 100 pixels.

## Events

Double-clicking the control in the designer writes the handler of **Click**.

- the common mouse, keyboard and focus events (Click, MouseDown, KeyDown, GotFocus ...).

## VB6

Written to a VB6 .frm as `VB.Frame`.
Imported from: `VB.Frame`.

See docs/COMPONENTS.md for how component packages work.

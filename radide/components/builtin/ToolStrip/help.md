# ToolStrip

A tool bar under the menu; each button raises <ItemName>_Click.

**Kind:** component (shown in the component tray below the form, not on it). **Toolbox:** Menus & Toolbars. **New name:** ToolStrip1, ToolStrip2 ...

## Properties

Besides Name:

| Property | Type | Default | Description |
|---|---|---|---|
| Items | menu | [] | Tool bar buttons (Text "-" = separator) - double-click to edit. |

See docs/COMPONENTS.md for how component packages work.

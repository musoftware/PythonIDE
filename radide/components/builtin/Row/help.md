# Row

Lays out its children left to right (drag a child to reorder).

**Kind:** container (hosts other controls). **Toolbox:** Mobile. **New name:** Row1, Row2 ...

**Default size:** 320 x 64 dp.

## Properties

Besides the common properties (Name, Left, Top, Width, Height, colours, font, Enabled, Visible, Anchor, Dock ...):

| Property | Type | Default | Description |
|---|---|---|---|
| Spacing | int | 8 | Gap between the children in dp. |
| Align | enum | Start | Start / Center / End / Stretch: where the children sit across the container (Stretch = full width in a Column, full height in a Row). SpaceBetween / SpaceAround: spread the children along the container. Values: Start, Center, End, Stretch, SpaceBetween, SpaceAround. |
| Padding | int | 8 | Space inside the edges in dp. |

See docs/COMPONENTS.md for how component packages work.

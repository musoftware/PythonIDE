# Word Scramble (Dart game)

Word game in Dart: Timer control, ProgressBar countdown, words.txt, hints, score.

## What it shows

- Timer control ticking every second (Timer1_Tick) and a ProgressBar countdown
- Reading `words.txt` with dart:io, `Random`, list shuffling
- Game state kept in Dart between events; Enter key in the TextBox (KeyPress)
- Enabling / disabling a button, MsgBox at the end of the game

**Language / project type:** `dart-bridge`

## Run

F5. Type the word and press Enter or Check; Hint shows the first letters.

## Publish

Build > Publish: bridge program; `words.txt` is copied with the app.

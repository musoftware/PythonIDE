# Tip Calculator (Dart)

Dart GUI Bridge form: TrackBar, NumericUpDown, ComboBox, CheckBox, history list, About form.

## What it shows

- GUI Bridge: the IDE draws the form, `Rad.get / Rad.set / Rad.call` talk to the controls
- TrackBar / NumericUpDown / CheckBox / ComboBox ValueChanged events update the result live
- Input validation with `Rad.msgbox`, number formatting, a currency map
- MenuStrip and a second form opened with `Rad.show('Form2')`, closed with `Rad.hide`

**Language / project type:** `dart-bridge`

## Run

F5 (the Dart SDK is found from Flutter: `C:\flutter\bin\cache\dart-sdk`).

## Publish

Build > Publish: bridge program (`dart` run by the bundled bridge host) - see the results table.

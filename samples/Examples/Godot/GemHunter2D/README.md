# GemHunter2D - Gem Hunter 2D (Godot 4)

**Language / project type:** `godot` (created with File > New Project, then customised)

Top-down Godot game from a RAD IDE scene: walls, gems, patrolling guards, countdown, lives, best score.

## What it shows
- Room1.scene designed in RAD IDE, exported to Room1.tscn for Godot 4
- GDScript rules in Room1.gd: add_timer + RoundTimer_Tick, Hero_Collide, find_group
- save_data / load_data (best score), restart_scene, show_message
- Art generated by the IDE's template (assets/)

## Run
Needs Godot 4 (the IDE finds it in PATH / WinGet). Open the folder, F5. Arrows move; collect all gems in 60 s.

## Publish
Export with Godot's own export templates (Godot: Project > Export).

## Test
`.venv\Scripts\python samples\Tests\Examples\test_examples_scripting.py Godot/GemHunter2D` (group `pyweb`, see
`samples/Tests/Examples/ex_pyweb.py`).

About this site

This is a static web site made in RAD IDE: plain HTML, CSS and JavaScript, served by the IDE's built-in web server with live reload. Nothing to install.

What it shows

  • Several pages with a shared stylesheet and navigation
  • A list built from JavaScript data, with filtering
  • Favourites and form drafts saved in localStorage
  • A contact form validated in JavaScript
  • An Arabic page laid out right-to-left (dir="rtl")

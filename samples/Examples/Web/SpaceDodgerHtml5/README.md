# SpaceDodgerHtml5 - Space Dodger (HTML5 canvas game)

**Language / project type:** `html5-game` (created with File > New Project, then customised)

Canvas shooter from the scene designer: cloned bullets/meteors, spawn timer, lives, best score.

## What it shows
- Space.scene (scene designer) + Space.js handlers on radgame.js
- Clone() of hidden template objects, AddTimer + SpawnTimer_Tick
- overlaps(), destroy(), {score}/{lives}/{best} text, localStorage best score
- Runs in any browser - also straight from the disk

## Run
Open the folder, F5 (built-in web server). Left/Right move, Space fires, P pauses.

## Publish
Site > Publish: "Local folder" profile - upload the folder to any static host.

## Test
`.venv\Scripts\python samples\Tests\Examples\test_examples_scripting.py Web/SpaceDodgerHtml5` (group `pyweb`, see
`samples/Tests/Examples/ex_pyweb.py`).

# Sales Analysis notebook (Jupyter .ipynb)

A Jupyter notebook that reads `sales.csv` and answers questions with the Python standard library only:
revenue per region and product, the best month, month-over-month change, a text bar chart.

**What it shows**
- The IDE's notebook editor (radide/notebook): markdown + code cells, Run Cell (Shift+Enter) / Run All,
  outputs and the value of the last expression, the kernel picker (any Python with `ipykernel`).
- File > Export as Python (.py) / HTML.
- A notebook next to its data file (relative path `sales.csv`).

**Run**: File > Open File... > `SalesAnalysis.ipynb` (or Open Folder on this folder), choose a Python kernel,
**Run All**.  If the chosen Python has no ipykernel, the editor offers to install it.

# دفتر تحليل المبيعات (Jupyter .ipynb)

دفتر Jupyter يقرأ ملف `sales.csv` ويحسب الإيرادات حسب المنطقة والمنتج وأفضل شهر والتغير الشهري ورسماً بيانياً نصياً،
باستخدام مكتبة بايثون القياسية فقط.

**ماذا يوضح**: محرر الدفاتر في البيئة (خلايا نصية وخلايا كود، تشغيل خلية أو تشغيل الكل، النتائج، اختيار النواة)،
والتصدير إلى ملف بايثون أو HTML.

**التشغيل**: ملف > فتح ملف ثم اختر `SalesAnalysis.ipynb`، واختر نواة بايثون، ثم **Run All**.

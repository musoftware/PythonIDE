# Ring Data Tool (console)

Console statistics tool: CSV reading, classes, sorting, ASCII chart, matrix, report file.

## What it shows

- A `Stats` class (mean, median, standard deviation, min, max)
- Reading `data/sales.csv`, `try / catch`, command-line argument (`sysargv`)
- Lists of lists, selection sort, 2x2 matrix product
- Formatted console output and an ASCII bar chart; `report.txt` written with `write()`

**Language / project type:** `ring-app`

## Run

F5 - the output appears in the Output window (F5 with breakpoints debugs it).

## Publish

Build > Publish (ring2exe) makes `RingDataTool.exe`; copy `data/` next to it.

# Frontend_Vue_Vite

**node-web + Vite (Vue 3)** - made with *Site > New Front-end App > Vue (Vite)* (`npm create vite@latest`,
template `vue`).

**Try it:** open, F5 (the first run does `npm install`). F9 on the `count++` line of
`src/components/HelloWorld.vue`, click the button in the Preview - the debugger stops in the .vue file
(source maps). *Site > Build Production* writes `dist/`. `.vue` files open with HTML highlighting / IntelliSense.

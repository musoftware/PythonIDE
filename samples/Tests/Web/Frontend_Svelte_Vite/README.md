# Frontend_Svelte_Vite

**node-web + Vite (Svelte 5)** - made with *Site > New Front-end App > Svelte (Vite)* (`npm create vite@latest`,
template `svelte`).

**Try it:** open, F5 (the first run does `npm install`). F9 on line 5 of `src/lib/Counter.svelte`
(`onclick={() => count++}`), click the button in the Preview - the debugger stops in the .svelte file.
*Site > Build Production* writes `dist/`.

# Frontend_Angular

**node-web + Angular CLI 20** - made with *Site > New Front-end App > Angular* (`ng new --defaults
--ssr=false`). The latest Angular CLI needs Node.js 22.22.3+; on older Node.js the IDE uses `@angular/cli@20`
automatically (this sample was made that way on Node 22.22.2).

**Try it:** open, F5 (`npm install` first, then `ng serve` in the Preview - the first compile takes ~20 s).
Edit `src/app/app.html` - Angular reloads the Preview. *Site > Build Production* runs `ng build` into
`dist/my-angular/browser`.

# User controls tests

* `UC_PythonTk_AddressBox` - Tkinter: a user control reused twice + nested in another user control.
* `UC_PythonQt_AddressBox` - the same in Qt (PySide6).

Project > **Add User Control...** creates one; its properties / events are declared with
Project > **User Control Properties and Events...**; it appears in the Toolbox under the project name.

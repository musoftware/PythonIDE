# Tutorials test projects

Projects generated by the "جرّبه" (Try it) button of the Tutorials view
(`radide/features/tutorials.py`, `radide/tutorials.make_project`). The IDE writes them under
`%LOCALAPPDATA%\RADIDE\tutorial-runs\<course>\<lesson>-<n>`; these copies were used to test it.

| Folder | Source block | What it checks |
|---|---|---|
| `BASIC_Console` | vb-basic lesson 03, block 3 (`vb run`) | BASIC console program run with `radide.runtimes.vbrun` |
| `BASIC_Form` | vb-basic lesson 13, block 0 (`vb form run`) | VB6 `.frm` text converted with `radide/importers/vb6_import.py` into `Form1.form` + `Form1.bas` |
| `CPP_ConsoleInput` | cpp lesson 04, block 6 (`cpp run` + `text input`) | C++17 console program built with MinGW g++ and fed `input.txt` on stdin |

Expected output of `CPP_ConsoleInput` with `input.txt`:

```
اكتب اسمك الكامل: الكلمة الأولى: محمد
الباقي: علي حسن
```

Open any folder with File > Open Project and press F5.

# VB_Form

**vb-basic (VB6 dialect)** - Two VB forms (.frm + .bas) with a menu, `MsgBox`, `.AddItem`, `Unload Me`, `Dim` declarations - VB code produced by the exe importer.

**Try it:** Press F5, type a name and press Greet.

*Origin:* agents5 exe-core: Greeter.exe imported as vb-basic (copied from the IDE's test runs, build output removed).

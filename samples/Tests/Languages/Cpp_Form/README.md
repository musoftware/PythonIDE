# Cpp_Form

**cpp-bridge (GUI Bridge)** - Form with two TextBoxes, Add/second Button, result Label and ListBox; `cmdAdd_Click` reads the numbers with `rad::get_num` and writes the sum with `rad::set` - also the C++ debugger (gdb) test project.

**Try it:** F5 (g++ / MinGW). Debug: breakpoint on line 13 of Form1.cpp (`int total = ...`), F5, type 2 and 3, press Add: it stops, Watch `a`, `b`.

*Origin:* agents7 bridge debuggers (copied from the IDE's test runs, build output removed).

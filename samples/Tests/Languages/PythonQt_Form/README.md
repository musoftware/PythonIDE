# PythonQt_Form

**python-qt (PySide6)** - Two forms with a menu (File: Clear, Exit; Help: About), ListBox, TextBox, Labels, Close button; handlers recovered from a native exe by the importer.

**Try it:** Press F5, type a name, press Greet: the label shows `Hello, <name>!` and the name is added to the list. Help > About shows a MessageBox.

*Origin:* agents5 exe-core: Greeter.exe imported as python-qt (copied from the IDE's test runs, build output removed).

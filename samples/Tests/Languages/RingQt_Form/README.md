# RingQt_Form

**ring-qt** - Same event-argument test as PythonTk_Form, written in Ring (`func Button1_MouseMove e` ... `e.getx()`), plus a Helpers.ring module.

**Try it:** Press F5 (needs Ring in PATH or the IDE's Ring setup), move the mouse over the button / type - Output shows `move`, `key`, `num`.

*Origin:* fix_shell regression run of `reg_ev_test.py` (ring-qt) (copied from the IDE's test runs, build output removed).

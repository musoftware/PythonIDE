# PythonTk_Form

**python-tk** - Event handlers with event arguments: Button MouseMove(e.X, e.Y), TextBox KeyPress(e.KeyChar), FormClosing(e.Cancel), NumericUpDown/TrackBar ValueChanged; Multiline TextBox, ProgressBar, PictureBox, bold centred Label.

**Try it:** Open the folder, press F5, move the mouse over the button / type in the text box / change the number - the Output window prints `move`, `key`, `num`.

*Origin:* fix_shell regression run of `reg_ev_test.py` (python-tk) (copied from the IDE's test runs, build output removed).

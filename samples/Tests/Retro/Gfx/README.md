# Retro graphics and game-text tools (slice "gfx")

Tile / sprite editor on ROM bytes, Atari 2600 playfield and player tools, tile maps, text tables (.tbl) and
script dump / insert (with Arabic shaping) - see `docs/RETRO.md`, section "Graphics and game text".

## Licence of the sample files

Every file in `Sample/` is **original and generated by `make_sample.py`** in this folder (the tiles, the castle
playfield, the sprite, the strings and the map were drawn / written for this test). No commercial ROM, game
graphics or game text is used. The sample files are dedicated to the public domain (CC0 1.0).

| File | What it is | Try it |
|---|---|---|
| `Sample/homebrew.chr` | 8 KB NES CHR: digits, letters, smiley, brick, heart, ship | File > Open File: the Tile Editor opens (NES 2bpp). Draw with Pencil / Fill / Line, Ctrl+S writes the bytes back. |
| `Sample/castle.bin` | Atari 2600 data block: castle playfield tables at 0x20 (PF0[16], PF1[16], PF2[16]) and an 8-line player sprite at 0x80 | Tools > Retro > Graphics & Text > Tile Editor, open castle.bin, format "Atari 2600 player graphics", offset 0x80: try NUSIZ and Reflect. |
| `Sample/castle.rtpf` | Playfield Editor document of the castle (reflected) | Open it, draw, "Write to ROM..." writes into castle.bin at 0x20. Export DASM / ca65 / ACME / C. |
| `Sample/level.rtmap` | 32x30 NES nametable using homebrew.chr | Open it; paint tiles, make metatiles, export ca65 / RGBDS / C (with the attribute table). |
| `Sample/demo.rom` | synthetic 1 KB "ROM": pointer table at 0x40 (5 pointers, base $8000, add $10) -> English strings at 0x100 | Tools > Retro > Graphics & Text > Script Dump / Insert. |
| `Sample/demo.tbl` | ASCII + one code per Arabic letter form from 0x80 | Opens in the Text Table Editor. |
| `Sample/demo_ar.csv` | the script sheet with Arabic translations | In Script Dump / Insert: Dump, Load Sheet, tick Shape Arabic + Right-to-left, mode "Repack", region 100-180, Insert -> `demo_translated.rom`. |

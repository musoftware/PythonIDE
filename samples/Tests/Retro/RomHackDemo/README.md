# RomHackDemo - a ROM Hacking Project sample

Made with **New Project > Retro > ROM Hacking Project (Demo ROM)**.

| File | What |
|------|------|
| `rom/demo.nes` | The "clean ROM": a 24 KB iNES image (NROM, 16 KB PRG + 8 KB CHR) generated by `radide/retro/rom/synth.py` - an endless 6502 loop, the text `HELLO FROM RAD IDE` and some simple tiles. **Original homebrew written for RAD IDE, no game data. Licence: CC0 (public domain dedication).** |
| `patches/001_message.ips` | An IPS patch that changes the text to `PATCHED BY RAD IDE` (CC0). |
| `tables/ascii.tbl` | A character table (hex=text) for the hex editor's text column. |
| `notes.md` | Notes page. |
| `rom.json` | The project: source ROM + CRC32, patch order, output, tables. |

Try it:

1. File > Open Project, pick this folder.
2. Project > ROM Hacking > Patch Manager - the patch list, Build, Build & Run.
3. Build writes `build/RomHackDemo_patched.nes`; `rom/demo.nes` is never written (it opens read-only).
4. Edit Working Copy, change some bytes in the hex editor, save, Capture Edits as Patch -> `patches/002_*.ips`.
5. F5 / Ctrl+F5 builds and starts the NES emulator (Tools > Retro > Emulators downloads Mesen / FCEUX).

Use the same project type with **your own** ROM files (Set Source ROM...).

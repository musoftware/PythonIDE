# DosHelloCom - a DOS .COM program in assembly (retro-dos)

`HELLO.ASM` is an original sample, released as CC0. It prints a line, draws eight blocks with BIOS teletype and waits for a key.

* Open the folder with File > Open Project. Press **F5**: NASM assembles `HELLO.COM` on Windows, then DOSBox-X runs it.
  NASM is downloaded automatically, the same way as for the Assembly projects. DOSBox-X is downloaded only from
  Tools > Retro > Emulators... (official portable build). F5 tells you when it is missing.
* Project > DOS Settings... changes the CPU cycles, the memory, the machine (VGA / EGA / CGA ...) and the sound card.

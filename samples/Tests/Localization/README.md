# Localization tests

* `Loc_PythonTk_ArabicMirrored` - Tkinter: Arabic (mirrored, right-to-left) + French resources, user control reused twice.
* `Loc_PythonQt_ArabicMirrored` - the same in Qt (PySide6).

Form property **Localizable = True**, then pick a **Language** to translate; Format > **Localization Strings...**
edits every language in one table.

# Ring editor tests

* RingIntelDemo  - IntelliSense test project: completions (see/give/len/substr, RingQt QPushButton members,
  RingLibCurl functions, members of a user class after `new Point`), signature help, hover, F12 into
  `shapes.ring` and into the Ring library (`guilib/classes/ring_qt.ring`), Find All References, the
  Document Outline, F1 (local Ring manual) and the Error List (`ring file -norun`).
* RingWebDemo    - New Project > Ring (Console / Web / Library) > Web Application (RingHTTPLib), port 8080.
* RingLibDemo    - Ring Library template (library + test.ring startup).
* RingWebLibDemo - WebLib page generator template.

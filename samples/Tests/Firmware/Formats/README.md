# Firmware formats and analysis - tests

Slice "formats" of the firmware tools (docs/FIRMWARE.md "Formats and analysis").

| Script | What | Needs |
|---|---|---|
| `test_formats_core.py` | Intel HEX / S-record (S19 / S28 / S37) / ELF32-64 LE-BE / raw round trips with gaps, start address and symbols; checksum errors; even / odd and 16-bit interleave, 4-way, byte / word swap, cut, merge with gaps; entropy regions, fill areas, strings + identification tags; CPU + base detection for 10 CPU families (default, without vector table, other base); Capstone listings and every calibration-table reference found; the CLI; the Firmware Analysis project (read-only original, SHA-256, tamper check). | nothing (synthetic images) |
| `test_rusefi.py` | Real open-source ECU firmware: rusEFI for STM32F407 (ARM Cortex-M4). Detects Thumb + base 0x08000000, the S-record application at 0x08008000 matches the .bin, round trips, reset handler listing, 200k-instruction reference index, strings used by code. | internet once (GitHub releases), cached in `%TEMP%\radide-fw-data\rusefi` |
| `test_ghidra.py` | Analyze in Ghidra (headless) on synthetic Thumb / PowerPC / TriCore images at their bases, and an ELF; `--rusefi` also runs rusEFI. | Ghidra + JDK (skipped otherwise) |
| `test_formats_ide.py` | The IDE (qh.py harness): New Project > Firmware > Firmware / ECU Analysis, Solution Explorer node, menus, the analysis view (all tabs, references, Show in hex, notice bar), S-record / ELF in the view, Firmware Converter, Build report, Ghidra tab, Arabic. Screenshots via `widget.grab()` in `%TEMP%\radide-qa\shots\fwfmt_*.png`. | Ghidra optional (`RADIDE_TEST_SKIP_GHIDRA=1` skips it) |
| `download_rusefi.py` | Downloads the rusEFI bundle from <https://github.com/rusefi/rusefi/releases> (SHA-256 checked against GitHub's digest) and keeps `rusefi.bin`, `rusefi_update.srec`, `rusefi.ini` and `SOURCE.json`. | internet |

## Test data and licences

* All images in the core / IDE tests are generated by `radide/firmware/analysis/synth.py` (original bytes, no
  manufacturer software, no vehicle data).
* rusEFI: GPL-3.0 with rusEFI's additional terms (`license.txt` in the rusEFI repository: intended for off-road
  use, not compliant with automotive environmental regulations). Downloaded only from the official GitHub
  releases, never committed.
* No proprietary ECU dumps (Mercedes, Bosch, Continental ...) are downloaded or used.

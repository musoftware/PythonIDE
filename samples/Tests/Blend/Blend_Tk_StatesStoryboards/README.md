# Blend_Tk_StatesStoryboards

**python-tk: Blend** - Visual States (MouseOver/Pressed/Focused/Disabled + custom form state `Big`), two Storyboards (Storyboard1 on click, `Intro` autostart) and data binding (people.json -> ListBox/Label/NumericUpDown, cities.csv -> ComboBox).

**Try it:** Open Form1: View > States / Objects and Timeline / Data panels. F5: hover Button1 (red), press it (storyboard moves it), Button2 toggles the `Big` state.

*Origin:* agents3 blend `make_form.py` (handlers + project.radproj added) (copied from the IDE's test runs, build output removed).

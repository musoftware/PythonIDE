# Godot_Platformer

**godot** - Native Godot platformer template (GDScript).

**Try it:** F5 (Godot 4 in PATH). Headless check: `godot --headless --editor --path . --quit` once (imports assets), then `godot --headless --path . --quit-after 120`.

*Origin:* agents5 game-runtime (copied from the IDE's test runs, build output removed).

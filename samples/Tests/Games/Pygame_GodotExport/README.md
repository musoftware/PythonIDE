# Pygame_GodotExport

**pygame + Godot export** - A pygame game plus its Godot export (project.godot, Level1.tscn, Level1.gd, radgame_scene.gd).

**Try it:** F5 runs the pygame version; open the folder in Godot 4 to run the exported version.

*Origin:* agents5 game-runtime Godot export test (copied from the IDE's test runs, build output removed).

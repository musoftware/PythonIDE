# Pygame_Platformer

**pygame** - Two-level platformer made in the scene designer (Level1/Level2 .scene + handlers), radgame runtime.

**Try it:** Open Level1.scene in the scene designer, press Play/F5. Headless: `set SDL_VIDEODRIVER=dummy & set RADGAME_FRAMES=120 & python main.py`.

*Origin:* agents5 game-designer IDE test (copied from the IDE's test runs, build output removed).

# Native_C_Cpp

**Solution: C, C++, Python** - Native libraries (MathC in C, TextCpp in C++) called from Python, and native apps (CApp, CppApp) calling a Python library.

**Try it:** Open `NativeC.radsln` (startup PyApp), F5: prints ADD/GREET/TWICE/EVEN/SUM3/JOIN/SQ lines and a readable error for a bad call. Needs gcc/g++ (MinGW).

*Origin:* agents2 refs-native (the .radsln was added for this sample) (copied from the IDE's test runs, build output removed).

# JS_Jest

Tests the Test Explorer with **Jest** (`describe`/`test`, durations, failure messages) and Jest
**coverage** (lcov) shown in the editor gutter: `max()` in `sum.js` is never tested.

**Try it:** run `npm install` once in the Terminal (creates node_modules - not kept in the sample), open
the folder, Test > Run All Tests -> 1 passed, 1 failed; Test > Run All Tests with Coverage, open `sum.js`.

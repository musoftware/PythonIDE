# Node_NodeTest

Tests the Test Explorer with Node's built-in runner (`node --test`, no packages needed): `describe`/`it`
groups and a top-level `test`. One test (`fails on purpose`) fails.

**Try it:** open the folder, Test > Test Explorer, Run All -> 2 passed, 1 failed (the assertion diff is
in Test Detail). Needs Node.js 20 or newer.

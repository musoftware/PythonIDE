# DelphiConsole - Delphi console program (test fixture)

`Hello.dpr` + `MathUtils.pas`: a VCL-free console program. Without Delphi, RAD IDE builds it with
Free Pascal in Delphi mode (`fpc -Mdelphi -NSSystem ...`), from the Lazarus toolchain that
RAD IDE downloads into `%LOCALAPPDATA%\RADIDE\toolchains\lazarus`.

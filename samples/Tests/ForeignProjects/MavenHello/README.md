# MavenHello - foreign project test (Maven)

A Maven quickstart-style project (`pom.xml`, `src/main/java`). Open `pom.xml`: RAD IDE builds with
`mvnw`/`mvn` (`mvn compile dependency:build-classpath`) and runs `com.example.hello.App` (`exec.mainClass`);
Debug uses JDWP. Without Maven it compiles with javac into the IDE state folder.

# CoreNasmWinApi

**asm-nasm, x64** - Template *Win32 API (x64, NASM)*: MessageBoxA (Yes / No), MessageBeep, a second MessageBoxA chosen with CMOVE.

**Try it:** Ctrl+F5: answer the question; the Output window shows the value MessageBoxA returned (6 = Yes, 7 = No).

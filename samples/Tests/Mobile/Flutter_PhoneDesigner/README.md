# Flutter_PhoneDesigner

**flutter (designer)** - All 16 mobile control types on one phone form: AppBar, BottomNav, Card, ListView, Switch, Slider, TextField, Image, Icon, Drawer, TabBar, WebView, Column/Row/Stack, FAB.

**Try it:** Open the form: phone frame, device presets, Portrait/Landscape. (Only the .form - the IDE generates the Dart code when you run it.)

*Origin:* agents5 mobile-designer test (53/53) (copied from the IDE's test runs, build output removed).

# Flutter_Screens

**flutter** - Three screens (Main, Details, About) with routes, AppBar, Drawer, BottomNav, ListView, TextField, Switch, Slider, FAB, and a Helpers.dart module.

**Try it:** Open, pick a device (Windows / Chrome / emulator) in the Device selector, F5 (`flutter run`). Save a change: hot reload.

*Origin:* agents5 mobile-lang IDE test (copied from the IDE's test runs, build output removed).
